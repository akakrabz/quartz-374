## Note errors reported by the writer — verdicts

Note 3:
- p. 5, "H_k − 1 + H_{n−k+1} − 1 < ln k + ln(n−k+1) − 2 < 2 ln n − 2": **confirmed** (first step reversed for all n, k
  since H_m > ln(m+1); final bound false exactly for n ≤ 16). Correct: ≤ ln k + ln(n−k+1) ≤ 2 ln((n+1)/2) < 2 ln n.
- p. 7, "1 + Σ_{k≥0} 2^{−k} = 2": **confirmed** (left side 3).
- p. 9, "E[L(x)] = Σ Pr[L ≥ ℓ]" → E[L], and "lg n + Σ_{i≥1} 2^{−i} = lg n + 2": **confirmed** (sum is 1; lg n + 2 still
  true as ⌈lg n⌉ + 1).
- pp. 9–10, search time: **confirmed** that it is a sketch (equal expected heads and tails plus "jumps are O(log n) whp"
  does not give a whp bound on the walk length); the page's Chernoff completion is correct (t = 4ℓ, e^{−t/16}).

Note 4:

  (E[XY] = E[X]E[Y] can hold for dependent X, Y); the second ("f(X), f(Y) independent for every f") indeed fails for
  dependent X, Y (f = id). Page wording narrowed to "too strong for the first".

## New note errors found

- Note 4, p. 7: with the note's labels (coin flip already at i = depth(k)), "each level i ≥ 1 is good with probability
  at least 1/2" is false: n = 5, k = 2, level 1 is good with probability 7/15 (also 29/60 for k = 3; conditional values
  down to 11/24). Splitting also at i = depth(k) (coin only for i > depth(k)) makes every conditional probability ≥ 1/2
  (exact, n ≤ 7, i ≤ 3; and the existing m ≤ 400 check, which already used this labeling). The page now uses that labeling
  and says so.
- Note 4, p. 6: the general Chebyshev line Pr[X ≥ αN] ≤ 1/((2α−1)N) is false, not just underived: α = 0.55, N = 100
  gives 0.1 < Pr[X ≥ 55] = 0.1841.
- Note 4, p. 6: traditional Chernoff forms "for any positive reals ∆ and δ": the lower-tail forms need ∆ < µ, δ < 1.
- Minor typos not listed on the pages: note 4 p. 2 "X and Y are and only if"; p. 6 "chosen vary carefully".
