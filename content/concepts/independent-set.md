> [!definition] Definitions (§12.7, §12.9)
> In an undirected graph $G = (V, E)$ with $n$ vertices, a set $S\subseteq V$ is
> - an **independent set** if no edge joins two vertices of $S$;
> - a **clique** if every two vertices of $S$ are joined by an edge;
> - a **vertex cover** if every edge has at least one endpoint in $S$.
>
> The optimization problems $\textsf{MaxIndSet}$ and $\textsf{MaxClique}$ ask for the largest size, $\textsf{MinVertexCover}$ for the smallest. The decision versions take $(G, k)$: is there an independent set, or a clique, of size **at least** $k$; a vertex cover of size **at most** $k$? ("Exactly $k$" is the same question: subsets of independent sets and cliques, and supersets of vertex covers, keep the property.) All are NP-hard; the decision versions are NP-complete, the set itself being a certificate checkable in $O(n^2)$ time. With $\overline{G}$ the **edge-complement** of $G$ (same vertices, exactly the pairs that are *not* edges of $G$):
> $$
> S \text{ independent in } G \iff S \text{ a clique in } \overline{G} \iff V\setminus S \text{ a vertex cover of } G,
> $$
> so $\textsf{MaxIndSet}(G) = \textsf{MaxClique}(\overline{G}) = n - \textsf{MinVertexCover}(G)$.

**Why it works.** The first equivalence is the definition of $\overline G$. For the second, an edge $uv$ misses $V\setminus S$ exactly when both $u$ and $v$ lie in $S$, so $V\setminus S$ touches every edge iff no edge lies inside $S$. Hence $(G, k)\mapsto(\overline{G}, k)$ reduces IndependentSet to Clique in $O(V^2)$ time, and $(G, k)\mapsto(G, n-k)$ reduces it to VertexCover; both maps also run backwards, so the three problems are equally hard. IndependentSet itself is hard by the reduction from 3SAT below: a triangle per clause allows at most one chosen literal per clause, and an edge between contradictory literals keeps the choices consistent.

> [!template] Template — IndependentSet is NP-hard (rubric form)
> **Reduce from 3SAT.** Given an arbitrary 3CNF formula $\Phi$ with $k$ clauses, build the graph $G$: one vertex for each of the $3k$ literal occurrences; an edge between every two vertices of the same clause (a **triangle**); an edge between every occurrence of $x$ and every occurrence of $\bar x$, for every variable $x$ (**conflict edges**). Output $(G, k)$. $G$ has $3k$ vertices and $O(k^2)$ edges, so the reduction runs in polynomial time.
>
> **⇒** Suppose $\Phi$ is satisfiable. Fix a satisfying assignment and choose one true literal in each clause. The $k$ chosen vertices lie in different triangles, and no two of them are $x$ and $\bar x$, which cannot both be true; so they form an independent set of size $k$.
>
> **⇐** Suppose $G$ has an independent set $S$ of size $k$. A triangle holds at most one vertex of $S$, so $S$ has exactly one vertex in each clause. Make every literal of $S$ true — consistent, because $S$ contains no conflict edge — and give the other variables any values. Every clause contains a true literal, so $\Phi$ is satisfiable.
>
> So $\Phi$ is satisfiable if and only if $G$ has an independent set of size $k$, and IndependentSet is NP-hard. **Clique and VertexCover:** the maps $(G, k)\mapsto(\overline G, k)$ and $(G, k)\mapsto (G, n - k)$, polynomial time.

> [!trap]
> - **Direction.** To prove a new problem hard, reduce IndependentSet (or Clique, VertexCover, 3SAT) **to** it. Building an independent-set algorithm out of nothing but the new problem's black box is the right direction; the reverse proves nothing.
> - **One vertex per occurrence**, not per variable: a literal in three clauses gets three vertices. The target is $k$ = the number of **clauses**, not of variables.
> - **Two different complements.** Clique uses the *edge*-complement $\overline G$ and the same $k$; vertex cover uses the *vertex*-complement $V\setminus S$ in the same graph, and $n - k$.
> - **Easy special cases.** On a tree, MaxIndSet takes $O(n)$ time by the two-state dynamic program of [[concepts/dynamic-programming-on-trees|dynamic programming on trees]]; for a fixed constant $k$, trying all $\binom{n}{k}$ sets is polynomial. NP-hardness is about general graphs with $k$ part of the input.

**Example.** $\Phi = (a\lor b\lor c)\land(\bar a\lor\bar b\lor c)\land(a\lor\bar b\lor\bar c)$, with $k = 3$ clauses. Writing the clause as a subscript, $G$ has 9 vertices, 9 triangle edges and 6 conflict edges — $a_1\bar a_2$, $b_1\bar b_2$, $b_1\bar b_3$, $c_1\bar c_3$, $\bar a_2a_3$, $c_2\bar c_3$ — 15 edges in all. The set $\{a_1, c_2, \bar b_3\}$ is independent, and it gives $a = c = \textsf{True}$, $b = \textsf{False}$, which satisfies $\Phi$ (as do 4 other assignments; only $a, b, c$ = FFF, TTF, FTT fail). Since a triangle holds at most one chosen vertex, $\textsf{MaxIndSet}(G) = 3$; so $\textsf{MinVertexCover}(G) = 9 - 3 = 6$ (the six other vertices) and the largest clique of $\overline{G}$, which has $36 - 15 = 21$ edges, has 3 vertices.
