> [!definition] Definition (§12.10)
> A **proper $k$-coloring** of an undirected graph $G = (V, E)$ is a function $c\colon V\to\{1, 2, \dots, k\}$ with $c(u)\ne c(v)$ for every edge $uv$. $\textsf{kColor}$: given $G$, does it have a proper $k$-coloring? The **graph coloring** problem asks for the smallest such $k$ (the chromatic number).
> - **2Color is easy:** give each start vertex color 1 and alternate colors along a whatever-first search; $G$ is 2-colorable iff no edge then has equal colors at its ends, iff $G$ has no odd cycle (it is bipartite). $O(V + E)$ time.
> - **3Color is NP-hard**, and NP-complete (the coloring is a certificate). So are $\textsf{kColor}$ for every fixed $k\ge 3$ — add $k - 3$ new vertices adjacent to each other and to every old vertex — and the minimum number of colors, since that answers 3Color.

**Why it works — 3SAT → 3Color.** Given an arbitrary 3CNF formula $\Phi$ with variables $x_1, \dots, x_n$ and $k$ clauses, build $G$ from three kinds of gadgets:
1. **Truth gadget:** a triangle $T, F, X$. A 3-coloring gives it three different colors; *name* them True, False and Other after these vertices.
2. **Variable gadget** for each $x_i$: a triangle $x_i, \bar x_i, X$. Neither literal vertex can be Other, so one is True and the other False — an assignment.
3. **Clause gadget** for each clause $(\ell_1\lor\ell_2\lor\ell_3)$: five new vertices $u, v, w, y, z$ and ten edges, $\ell_1u$, $\ell_2v$ and the triangle $uvw$, then $wy$, $\ell_3z$ and the triangle $yzT$.

$G$ has $3 + 2n + 5k$ vertices and $3 + 3n + 10k$ edges, built in $O(n + k)$ time. Each half of the clause gadget is a "majority gate": two inputs hang on two corners of a triangle whose third corner is the output. Equal inputs force the two corners to the other two colors, and then the output to the inputs' color; different inputs leave all three colors possible for the output. So $\ell_1 = \ell_2 = $ False forces $w$ = False, and if $\ell_3$ is False as well, the second half would force $T$ to be False — impossible.

> [!template] Template — 3Color is NP-hard (rubric form)
> **Reduce from 3SAT.** Given an arbitrary 3CNF formula $\Phi$, build $G$ as above, in polynomial time.
>
> **⇒** Given a satisfying assignment, color $T, F, X$ True, False, Other and every literal vertex by its value. Each clause has a true literal, so its gadget can be colored: if $\ell_1$ or $\ell_2$ is True, give $w$ True, $u$ and $v$ the colors False and Other (each avoiding its literal's color), and $y$, $z$ False and Other with $z$ Other when $\ell_3$ is False; otherwise $\ell_3$ is True, and $u, v, w, y, z$ get True, Other, False, Other, False.
>
> **⇐** Given a proper 3-coloring, name its colors after the vertices $T, F, X$. Each $x_i$ and $\bar x_i$ touch $X$ and each other, so one is True and one is False; set $x_i$ = True iff $x_i$ has the color of $T$. A clause with three False literals would force $w$ False and then $y$ and $z$ both Other (each touches $T$ and a False vertex) — but $yz$ is an edge. So every clause has a true literal.
>
> So $\Phi$ is satisfiable if and only if $G$ is 3-colorable, and 3Color is NP-hard.

> [!trap]
> - **Two colors are easy, three are hard.** A "proof" that 2Color is NP-hard is wrong somewhere (compare 2SAT, also polynomial).
> - **Colors are only labels.** A coloring may use any three colors; the proof *names* them after the vertices $T, F, X$. Without the truth triangle there is nothing to say which color means True.
> - **Wire the clause gadget exactly:** two literals into the first triangle, its output $w$ and the third literal into the second, whose third corner is $T$ (not $F$, not $X$).
> - **Direction.** For a problem that labels objects from a small fixed set, reduce 3Color (or kColor) **to** it.

**Example.** The clause gadget for $(a\lor b\lor\bar c)$ with $a = b = c = $ False, so $a$ and $b$ are False and $\bar c$ is True. Then $u$ and $v$ avoid False and each other, so they are True and Other in some order; $w$ must be False; $y$ (next to $w$ and $T$) is Other; $z$ (next to $\bar c$, $T$ and $y$) is False — exactly 2 completions. If $\bar c$ were False too, $y$ and $z$ would both be forced to Other. For the book's 4-variable, 4-clause formula, $G$ has $3 + 8 + 20 = 31$ vertices and $3 + 12 + 40 = 55$ edges.
