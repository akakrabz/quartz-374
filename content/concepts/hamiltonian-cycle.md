> [!definition] Definition (§12.11)
> A **Hamiltonian cycle** in a graph (directed or undirected) is a cycle that visits every vertex exactly once; a **Hamiltonian path** is a simple path that visits every vertex exactly once. $\textsf{HamCycle}$ and $\textsf{HamPath}$ ask whether one exists. All four versions — directed or undirected, cycle or path — are NP-hard, and NP-complete (the order of the vertices is a certificate). Do not confuse them with an **Euler tour**, a closed walk through every *edge* once, which takes linear time. **TravelingSalesman** — the cheapest Hamiltonian cycle (or path) in a graph with weighted edges — is NP-hard too: with every weight 1, a tour of cost $V$ exists iff the graph is Hamiltonian.

**Why it works — 3SAT → DirectedHamCycle.** Each variable gets a row of vertices that a Hamiltonian cycle must cross completely, left to right (True) or right to left (False). Each clause gets one extra vertex, reachable only by a short detour out of a row and back, and the detour's edges point the way that makes the clause's literal true. So the cycle can collect every clause vertex exactly when its row directions satisfy every clause. **Spacer** vertices between the clauses' positions and **hubs** between the rows stop the cycle from using a clause vertex to jump between rows (see the first trap).

> [!recipe] Recipe — the reduction, for $n$ variables and $k$ clauses
> **Graph $H$** (directed), from an arbitrary 3CNF formula $\Phi$ with variables $x_1, \dots, x_n$ and clauses $c_1, \dots, c_k$:
> - **Row** for each $x_i$: vertices $(i, 0), (i, 1), \dots, (i, 3k)$, with edges both ways between neighbors. Positions $3j-2$ and $3j-1$ belong to clause $c_j$; positions $0, 3, \dots, 3k$ are spacers.
> - **Hubs** $h_1, \dots, h_n$: edges $h_i\to(i, 0)$, $h_i\to(i, 3k)$, $(i, 0)\to h_{i+1}$, $(i, 3k)\to h_{i+1}$, where $h_{n+1}$ means $h_1$.
> - **Clause vertex** $[j]$ for each $c_j$: if $x_i$ is in $c_j$, edges $(i, 3j-2)\to[j]\to(i, 3j-1)$, a detour for left-to-right travel; if $\bar x_i$ is in $c_j$, edges $(i, 3j-1)\to[j]\to(i, 3j-2)$, a detour for right-to-left travel.
>
> $H$ has $n(3k+2) + k$ vertices and $6kn + 4n + 6k$ edges (when each clause has three different literals), built in $O(nk)$ time.
>
> **⇒** Given a satisfying assignment, go $h_1\to\text{row } 1\to h_2\to\text{row } 2\to\cdots\to\text{row } n\to h_1$, crossing row $i$ left to right if $x_i$ = True and right to left if $x_i$ = False. For each clause $c_j$ choose one true literal, $x_i$ or $\bar x_i$, and replace the step between positions $3j-2$ and $3j-1$ of row $i$ by the detour through $[j]$; its direction matches the crossing.
>
> **⇐** A case analysis (this is what the spacers and hubs are for) shows that a Hamiltonian cycle returns from every clause vertex to the row it came from, and so crosses each row completely between two consecutive hubs. Set $x_i$ = True iff row $i$ is crossed left to right. Each $[j]$ lies on a detour in some row $i$, and that detour exists in the direction of the crossing only if the corresponding literal of $c_j$ is true. So every clause is satisfied.

**The book's other proof — from VertexCover.** Given $G$ and $k$, build a directed $H$ with an **edge gadget** for each edge $uv$ — four vertices $(u, v, \text{in}), (u, v, \text{out}), (v, u, \text{in}), (v, u, \text{out})$ and six edges ($\text{in}\to\text{out}$ on both sides, and both directions between the two "in" and between the two "out" vertices) — a **vertex chain** for each vertex $u$ through the gadgets of its edges, and $k$ **cover vertices**, each with an edge to the start and from the end of every chain. A Hamiltonian cycle passes a gadget straight through on both sides (both endpoints in the cover) or by a detour through the other side (only one), and it traverses exactly $k$ chains; so $H$, with $4E + k$ vertices, is Hamiltonian iff $G$ has a vertex cover of size $k$. This assumes $G$ has no isolated vertices and $k\le V$: an isolated vertex has no chain, so one edge plus an isolated vertex with $k = 3$ has a cover of size 3 but a non-Hamiltonian $H$. So delete isolated vertices first, and answer YES at once if $k$ is at least the number of vertices left.

**Variants** (left as exercises in the book). HamCycle and HamPath reduce to each other, and a directed graph becomes an undirected one by splitting each vertex $v$ into a path $v_{\text{in}}\,v_{\text{mid}}\,v_{\text{out}}$ and turning each edge $u\to v$ into $u_{\text{out}}v_{\text{in}}$; so all four versions are NP-hard. LongestPath, which generalizes HamPath, is NP-hard as well.

> [!trap]
> - **The book's 3SAT construction needs the repair.** In the book, each row has $2k$ vertices (the text's indices $(i, 0), \dots, (i, 2k)$ give $2k+1$; either way fails), the clauses' positions are adjacent with no spacers, and the ends of consecutive rows are joined directly. That version is not correct: for the unsatisfiable formula made of all eight clauses on $a, b, c$, with $(\bar a\lor b\lor c)$ last, a cycle can cross row $a$ left to right, go from the last vertex of row $a$ through $[8]$ to the last vertex of row $b$ instead of along the connecting edge, cross rows $b$ and $c$ right to left, and collect the other seven clause vertices by ordinary detours — a Hamiltonian cycle, although $\Phi$ has no satisfying assignment.
> - **Direction.** When a problem asks for an *order* of objects, reduce HamCycle, HamPath or TravelingSalesman **to** it ([[2-algorithms/12-np-hardness#1214-choosing-the-right-problem|§12.14]]), never the other way.
> - **Hamilton is not Euler**, and the longest simple path is not a shortest path with negated weights: shortest-path algorithms need the absence of negative cycles.
> - **Undirected graphs.** The detours work because edges have directions. For undirected HamCycle, reduce 3SAT to the directed version first, then split the vertices as above.

**Example.** $\Phi = (a\lor\bar b\lor c)\land(\bar a\lor b\lor\bar c)$, so $n = 3$ and $k = 2$: each row has 7 vertices, and $H$ has $3\cdot 8 + 2 = 26$ vertices and $6\cdot 2\cdot 3 + 4\cdot 3 + 6\cdot 2 = 60$ edges. $\Phi$ has 6 satisfying assignments and $H$ exactly 12 Hamiltonian cycles: one for each satisfying assignment and each choice of a true literal per clause. For $a$ = True, $b = c = $ False, clause 1 has two true literals, $a$ and $\bar b$, and clause 2 has one, $\bar c$, giving 2 of the 12; the figure shows the one that collects $[1]$ from row $a$.
