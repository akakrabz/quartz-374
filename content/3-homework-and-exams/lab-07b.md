> [!abstract] In one breath
> Each Lab 7a recursion takes exponential time because it solves the same subproblems again and again — but every subproblem is named by one or two indices, so there are only $O(n^2)$ different ones. Store each value in an array the first time it is computed, and fill the array in an order where every entry comes after the entries it reads: column by column from the right for the scans of Problems 1 and 2, row by row from the bottom for the convex recurrence and for the two palindrome recurrences. That gives $O(n^2)$ time for decreasing and alternating subsequences, $O(n^3)$ for convex ones ($O(n^2)$ pairs, $O(n)$ candidates for the next element each) and $O(n^2)$ for both palindrome problems. Alternating subsequences even have an $O(n)$ greedy algorithm — count the peaks and valleys of the array — but, like every greedy algorithm, it needs a proof. Two official answers need small fixes: the alternating answer formula also counts sequences that start upward, and the convex recurrence is one too small.

## From backtracking to dynamic programming

The handout's steps for developing a dynamic program, in short:

1. **Formulate the problem recursively** — the hard part, done in [[3-homework-and-exams/lab-07a|Lab 7a]]. (a) **Specification:** a precise English description of *what* the function returns, not how it is computed; leaving it out can cost all the points. (b) **Solution:** a recurrence for the whole problem in terms of smaller instances of *exactly the same* problem; if you need a different problem, go back to (a). (c) **Don't optimize prematurely:** many "obvious" shortcuts are wrong, and many right ones don't change the final running time.
2. **Build the solutions bottom up.** (a) Identify all the subproblems the recursion can reach. (b) Analyze the running time: the work per subproblem, ignoring recursive calls, summed over all subproblems. (c) Choose a memoization structure — usually an array indexed by the parameters. (d) Identify the dependencies: draw the array, pick a generic entry, and draw arrows from the entries it reads. (e) Find an evaluation order in which every entry comes after the entries it reads — base cases first. (f) Write the algorithm: usually nested loops around the recurrence.
3. **Try to improve.** Find the bottleneck; *now* is the time for shortcuts and greedy choices — each with a proof.

## Problem 1 — Longest decreasing subsequence

> [!question] Problem 1
> Describe and analyze a dynamic programming algorithm, based on your Lab 7a recurrence, that computes the length of a longest **decreasing** subsequence of an integer array $A[1\,..\,n]$ ($B[i] < B[i-1]$ for every $i \ge 2$). (Lab 7a's example: 5 for the array above.)

> [!hint]- Hint
> In the recurrence for $\textsf{LDSsmaller}(i, j)$, every entry reads only entries of column $j + 1$.

> [!solution]- Solution
> **The idea.** The recursion $\textsf{LDSsmaller}(i, j)$ of [[3-homework-and-exams/lab-07a#problem-1--longest-decreasing-subsequence|Lab 7a, Problem 1]] can make $2^{n+1} - 1$ calls, but there are only $O(n^2)$ different ones — one per pair $i < j$. Store each value once. The only real question is the order: entry $(i, j)$ reads $(i, j+1)$ and $(j, j+1)$, both in **column $j+1$**, so fill the columns from right to left (left panel of the figure above). This is exactly [[2-algorithms/03-dynamic-programming#36-longest-increasing-subsequence|§3.6]]'s $\textsf{FastLIS}$ with the comparison flipped.
>
> **Function.** For $0 \le i < j \le n+1$, $\textsf{LDSsmaller}(i, j)$ is the length of a longest decreasing subsequence of $A[j\,..\,n]$ in which every element is smaller than $A[i]$. With the sentinel $A[0] = +\infty$ we need $\textsf{LDSsmaller}(0, 1)$.
>
> **Recurrence** (Lab 7a):
> $$
> \textsf{LDSsmaller}(i, j) = \begin{cases}
> 0 & \text{if } j > n\\
> \mathit{skip} & \text{if } A[j] \ge A[i]\\
> \max\{\mathit{skip},\ 1 + \mathit{take}\} & \text{otherwise}
> \end{cases}
> $$
> where $\mathit{skip} = \textsf{LDSsmaller}(i, j+1)$ and $\mathit{take} = \textsf{LDSsmaller}(j, j+1)$.
>
> - **Memoization:** an array $\mathit{LDSsmaller}[0\,..\,n,\ 1\,..\,n+1]$; only the entries with $i < j$ are used.
> - **Evaluation order:** outer loop over the columns $j$ from $n+1$ (the base cases) down to 1; inner loop over $i$ from 0 to $j - 1$, in any order.
> - **Time:** $O(n^2)$ entries, $O(1)$ time each: $O(n^2)$. (Keeping only two columns brings the space down to $O(n)$.)
>
> ```text
> FastLDS(A[1 .. n]):
>   A[0] ← ∞                                  ⟨⟨Add a sentinel⟩⟩
>   for i ← 0 to n                             ⟨⟨Base cases⟩⟩
>     LDSsmaller[i, n + 1] ← 0
>   for j ← n down to 1
>     for i ← 0 to j − 1
>       if A[j] ≥ A[i]
>         LDSsmaller[i, j] ← LDSsmaller[i, j + 1]
>       else
>         LDSsmaller[i, j] ← max{LDSsmaller[i, j + 1], 1 + LDSsmaller[j, j + 1]}
>   return LDSsmaller[0, 1]
> ```
>
> **Other ways.** Lab 7a's one-parameter recurrence $\textsf{LDSfirst}(i) = 1 + \max\{\textsf{LDSfirst}(j) \mid j > i,\ A[j] < A[i]\}$ fits in an array $\mathit{LDSfirst}[0\,..\,n]$ filled for $i$ from $n$ down to 0; each entry scans all $j > i$, so it also takes $O(n^2)$ time, but only $O(n)$ space. Or negate (or reverse) the array and call $\textsf{FastLIS}$. (A slip in the official solution: its first description says "every element is *larger* than $A[i]$"; it must be "smaller", as its pseudocode comment says.)
>
> **Answer.** $\textsf{FastLDS}$ computes $\textsf{LDSsmaller}(0, 1)$ in $O(n^2)$ time; 5 on the example.

## Problem 2 — Longest alternating subsequence

> [!question] Problem 2
> The same for a longest **alternating** subsequence: $B[i] < B[i-1]$ for every even $i \ge 2$ and $B[i] > B[i-1]$ for every odd $i \ge 3$ — the steps go down, up, down, …, starting with a step down. (Lab 7a's example: 17.)

> [!hint]- Hint
> Two tables, filled together: an entry of either table reads column $j + 1$ of the same table and of the other one.

> [!solution]- Solution (dynamic programming)
> **The idea.** The two functions of [[3-homework-and-exams/lab-07a#problem-2--longest-alternating-subsequence|Lab 7a, Problem 2]] call each other, but every call still goes from column $j$ to column $j+1$. So use two tables of the same shape as in Problem 1 and fill them **together**, column by column from the right.
>
> **Functions.** For $0 \le i < j \le n+1$: $\textsf{LASabove}(i, j)$ is the length of a longest subsequence of $A[j\,..\,n]$ whose first element (if any) is larger than $A[i]$ and whose steps go down, up, down, …; $\textsf{LASbelow}(i, j)$ is the length of a longest subsequence of $A[j\,..\,n]$ whose first element (if any) is smaller than $A[i]$ and whose steps go up, down, up, …. With the sentinel $A[0] = -\infty$ we need $\textsf{LASabove}(0, 1)$.
>
> **Recurrences** (Lab 7a): both are 0 if $j > n$; otherwise
> $$
> \begin{aligned}
> \textsf{LASabove}(i, j) &= \begin{cases} \textsf{LASabove}(i, j+1) & \text{if } A[j] \le A[i]\\ \max\big\{\textsf{LASabove}(i, j+1),\ 1 + \textsf{LASbelow}(j, j+1)\big\} & \text{if } A[j] > A[i]\end{cases}\\[4pt]
> \textsf{LASbelow}(i, j) &= \begin{cases} \textsf{LASbelow}(i, j+1) & \text{if } A[j] \ge A[i]\\ \max\big\{\textsf{LASbelow}(i, j+1),\ 1 + \textsf{LASabove}(j, j+1)\big\} & \text{if } A[j] < A[i]\end{cases}
> \end{aligned}
> $$
>
> - **Memoization:** two arrays $\mathit{LASabove}[0\,..\,n,\ 1\,..\,n+1]$ and $\mathit{LASbelow}[0\,..\,n,\ 1\,..\,n+1]$.
> - **Evaluation order:** outer loop $j$ from $n+1$ down to 1, inner loop $i$ from 0 to $j-1$, computing **both** $(i, j)$ entries at each step: they read only column $j+1$ of the two arrays.
> - **Time:** $O(n^2)$ pairs of entries, $O(1)$ each: $O(n^2)$.
>
> ```text
> FastLAS(A[1 .. n]):
>   A[0] ← −∞                                 ⟨⟨Add a sentinel⟩⟩
>   for i ← 0 to n                             ⟨⟨Base cases⟩⟩
>     LASabove[i, n + 1] ← 0;  LASbelow[i, n + 1] ← 0
>   for j ← n down to 1
>     for i ← 0 to j − 1
>       LASabove[i, j] ← LASabove[i, j + 1]
>       if A[j] > A[i]
>         LASabove[i, j] ← max{LASabove[i, j], 1 + LASbelow[j, j + 1]}
>       LASbelow[i, j] ← LASbelow[i, j + 1]
>       if A[j] < A[i]
>         LASbelow[i, j] ← max{LASbelow[i, j], 1 + LASabove[j, j + 1]}
>   return LASabove[0, 1]
> ```
>
> **A fix to the official answer.** The official solution returns, in this page's names, $\max_j \max\{1 + \textsf{LASabove}(j, j+1),\ 1 + \textsf{LASbelow}(j, j+1)\}$. The first term counts subsequences that start at $A[j]$ and go **up** first, which are not alternating in the problem's sense: on $A = [1, 2]$ it returns 2, but $1, 2$ is not alternating and the answer is 1. In general the formula computes the longest zigzag in either direction, which can be one too long. Return $\textsf{LASabove}(0, 1)$ as above — or $\max_j\{1 + \textsf{LASbelow}(j, j+1)\}$, and 0 if $n = 0$.
>
> **Answer.** $\textsf{FastLAS}$ runs in $O(n^2)$ time; 17 on the example.

> [!solution]- Faster: a linear-time greedy algorithm, with its proof
> **The idea.** Draw the array as a mountain profile (figure below). An alternating subsequence jumps down, up, down, …, and the best places to jump between are the profile's **turning points**: its peaks and valleys. The claim is that the turning points themselves form a longest alternating subsequence, so it is enough to count them. Two details: equal neighbors ($A[i] = A[i+1]$) are merged into one element, since an alternating subsequence can use at most one of them; and since the first step must go *down*, a sentinel $-\infty$ goes in front — it makes $A[1]$ a peak when the array starts downward, and when the array starts upward $A[1]$ is not a turning point and is not needed.
>
> ```text
> GreedyLAS(A[1 .. n]):
>   if n = 0
>     return 0
>   B[0] ← −∞;  B[1] ← A[1];  m ← 1        ⟨⟨Sentinel, then A without repeats⟩⟩
>   for i ← 2 to n
>     if A[i] ≠ B[m]
>       m ← m + 1;  B[m] ← A[i]
>   ℓ ← 1                                    ⟨⟨B[m] always counts⟩⟩
>   for i ← 1 to m − 1                       ⟨⟨Count peaks and valleys⟩⟩
>     if B[i] > max{B[i − 1], B[i + 1]} or B[i] < min{B[i − 1], B[i + 1]}
>       ℓ ← ℓ + 1
>   return ℓ
> ```
>
> Two passes over the array: $O(n)$ time.
>
> **Proof.** Call a sequence a **zigzag** if its steps strictly alternate between up and down, starting either way. In $B[0\,..\,m]$, call $B[0]$, $B[m]$ and every interior **peak** (larger than both neighbors) or **valley** (smaller than both) a **turning point**; the algorithm returns the number $t$ of turning points minus one (it does not count $B[0]$).
>
> 1. *Merging equal neighbors changes nothing.* Two elements of one run of equal neighbors would be adjacent in an alternating subsequence, with equal values — not allowed. So every alternating subsequence of $A$ uses at most one element per run, and corresponds to an alternating subsequence of $B[1\,..\,m]$ of the same length; conversely $B[1\,..\,m]$ is itself a subsequence of $A$.
> 2. *The sentinel costs exactly one.* If $S$ is an alternating subsequence of $B[1\,..\,m]$, then $-\infty, S$ is a zigzag of $B[0\,..\,m]$, one longer. Conversely, from a zigzag $Z$ of $B[0\,..\,m]$ drop its first element if $Z$ starts at $B[0]$ or with an up-step: what is left is alternating and at most one shorter. So the answer is the length of a longest zigzag of $B[0\,..\,m]$, minus one.
> 3. *A longest zigzag of $B[0\,..\,m]$ has exactly $t$ elements* (here $m \ge 1$ and neighbors in $B$ differ).
>     - At least $t$: between two consecutive turning points $B$ is strictly monotone, and the direction changes at every interior turning point; so the turning points, in order, form a zigzag.
>     - At most $t$: let $Z = B[s_1], \ldots, B[s_L]$ be a zigzag with $L \ge 3$. Each interior element $B[s_r]$ ($1 < r < L$) is larger than both its neighbors in $Z$ (a peak of $Z$) or smaller than both (a valley). For a peak, let $p_r$ be a position of the maximum of $B$ over $s_{r-1} \le p \le s_{r+1}$. Because $B[s_r]$ beats both ends, $s_{r-1} < p_r < s_{r+1}$; both neighbors of $p_r$ lie in the window, so they are not larger, and since neighbors differ, $B[p_r]$ is an interior peak of $B$. Valleys of $Z$ give interior valleys of $B$ the same way. Two peaks of $Z$ are at least two places apart, so their open windows $(s_{r-1}, s_{r+1})$ are disjoint and their images differ; the same holds for valleys; and no position is both a peak and a valley. So the $L - 2$ interior elements of $Z$ map to distinct interior turning points: $L - 2 \le t - 2$. (For $L \le 2$ there is nothing to prove, since $t \ge 2$.)
>
> Together: the answer is $t - 1$, which is what $\textsf{GreedyLAS}$ returns. This is a counting argument rather than the usual exchange argument ([[0-toolkit/02-proof-templates#21-proving-a-greedy-algorithm-correct|template §21]]); either way, a greedy algorithm without a proof earns nothing.
>
> **About the official version.** The official $\textsf{GreedyLAS}$ has no sentinel and starts its count at 2. It therefore counts zigzags that start upward too (it returns 2 on $[1, 2]$, where the answer is 1), and it returns 2 on a one-element or constant array. The sentinel fixes both.
>
> **Answer.** $\textsf{GreedyLAS}$ returns the length of a longest alternating subsequence in $O(n)$ time; on the example it counts 17 turning points after the sentinel.

## Problem 3 — Longest convex subsequence

> [!question] Problem 3
> The same for a longest **convex** subsequence: $B[i] - B[i-1] > B[i-1] - B[i-2]$ for every $i \ge 3$. (Lab 7a's example: 6.)

> [!hint]- Hint
> Entry $(i, j)$ reads the entries $(j, k)$ with $k > j$ — part of a lower row.

> [!solution]- Solution
> **The idea.** The recursion $\textsf{LXS}(i, j)$ of [[3-homework-and-exams/lab-07a#problem-3--longest-convex-subsequence|Lab 7a, Problem 3]] has one subproblem per pair $i < j$, and each tries up to $n$ third elements: $O(n^2)$ entries with $O(n)$ work each. Entry $(i, j)$ reads $(j, k)$ for $k > j$, which is in row $j > i$, so fill the rows from the bottom up (middle panel of the figure).
>
> **Function.** For $1 \le i < j \le n$, $\textsf{LXS}(i, j)$ is the length of a longest convex subsequence of $A[i\,..\,n]$ whose first two elements are $A[i]$ and $A[j]$. We need $\max_{i < j}\textsf{LXS}(i, j)$, or $n$ if $n \le 1$.
>
> **Recurrence** (Lab 7a):
> $$
> \textsf{LXS}(i, j) = \max\Big(\{2\} \cup \big\{1 + \textsf{LXS}(j, k) \bigm| j < k \le n,\ A[i] + A[k] > 2A[j]\big\}\Big)
> $$
>
> - **Memoization:** an array $\mathit{LXS}[1\,..\,n,\ 1\,..\,n]$; only the entries with $i < j$ are used.
> - **Evaluation order:** outer loop $i$ from $n - 1$ down to 1; inner loop $j$ from $i + 1$ to $n$ in any order (the loop over $k$ inside it computes one entry).
> - **Time:** $O(n^2)$ entries, $O(n)$ each: $O(n^3)$. (The $k$-loop runs $\binom{n}{3}$ times in all.)
>
> ```text
> FastLXS(A[1 .. n]):
>   best ← min{n, 2}
>   for i ← n − 1 down to 1
>     for j ← i + 1 to n
>       LXS[i, j] ← 2                         ⟨⟨Just A[i], A[j]⟩⟩
>       for k ← j + 1 to n
>         if A[i] + A[k] > 2 · A[j]
>           LXS[i, j] ← max{LXS[i, j], 1 + LXS[j, k]}
>       best ← max{best, LXS[i, j]}
>   return best
> ```
>
> **A correction.** The official pseudocode starts each entry at $\mathit{LCS}[i, j] \gets 1$ (its recurrence uses $\max\varnothing = 0$), so every entry is one too small and it returns 5 on the example. A pair $A[i], A[j]$ alone already has length 2.
>
> **Answer.** $\textsf{FastLXS}$ runs in $O(n^3)$ time; 6 on the example.

## Problem 4 — Longest palindrome subsequence

> [!question] Problem 4
> The same for a longest **palindrome** subsequence ($B[i] = B[\ell - i + 1]$ for every $i$). (Lab 7a's example array has answer **9**, not the handout's 7: see [[3-homework-and-exams/lab-07a#problem-4--longest-palindrome-subsequence-harder|Lab 7a, Problem 4]].)

> [!hint]- Hint
> An entry reads three neighbors: below, left, and diagonally below-left. Which loop order has them all ready?

> [!solution]- Solution
> **The idea.** The interval recursion of [[3-homework-and-exams/lab-07a#problem-4--longest-palindrome-subsequence-harder|Lab 7a, Problem 4]] has one subproblem per interval $A[i\,..\,j]$ — $O(n^2)$ of them — and each looks at most three shorter intervals. In the table, $(i, j)$ reads $(i+1, j)$ (the row below), $(i, j-1)$ (to the left) and $(i+1, j-1)$ (diagonally between them), so fill the rows from the bottom up and each row from left to right (right panel of the figure). Going by increasing interval length also works.
>
> **Function.** For $1 \le i \le n+1$ and $i - 1 \le j \le n$, $\textsf{LPS}(i, j)$ is the length of a longest palindrome subsequence of $A[i\,..\,j]$. We need $\textsf{LPS}(1, n)$.
>
> **Recurrence** (Lab 7a): $\textsf{LPS}(i, i-1) = 0$, $\textsf{LPS}(i, i) = 1$, and for $i < j$
> $$
> \textsf{LPS}(i, j) = \max\begin{cases}
> \textsf{LPS}(i+1, j)\\
> \textsf{LPS}(i, j-1)\\
> 2 + \textsf{LPS}(i+1, j-1) & \text{only if } A[i] = A[j]
> \end{cases}
> $$
>
> - **Memoization:** an array $\mathit{LPS}[1\,..\,n+1,\ 0\,..\,n]$; only the entries with $j \ge i - 1$ are used.
> - **Evaluation order:** outer loop $i$ from $n + 1$ down to 1; inner loop $j$ from $i - 1$ (the empty interval) up to $n$.
> - **Time:** $O(n^2)$ entries, $O(1)$ each: $O(n^2)$.
>
> ```text
> FastLPS(A[1 .. n]):
>   for i ← n + 1 down to 1
>     LPS[i, i − 1] ← 0
>     for j ← i to n
>       if j = i
>         LPS[i, j] ← 1
>       else
>         LPS[i, j] ← max{LPS[i + 1, j], LPS[i, j − 1]}
>         if A[i] = A[j]
>           LPS[i, j] ← max{LPS[i, j], 2 + LPS[i + 1, j − 1]}
>   return LPS[1, n]
> ```
>
> **Improving?** Lab 7a's proved shortcut (when $A[i] = A[j]$, take $2 + \textsf{LPS}(i+1, j-1)$ and nothing else) saves a comparison per entry but not the $O(n^2)$ bound — as the official solutions put it, the optimization did not speed anything up, so it was not worth the proof.
>
> **Answer.** $\textsf{FastLPS}$ runs in $O(n^2)$ time; 9 on the example.

## Problem 5 — Shortest palindrome supersequence

> [!question] Problem 5
> The same for a shortest **palindrome supersequence** of $A$: a palindrome that contains $A$ as a subsequence. (Lab 7a's example: 15 for $3, 1, 4, 1, 5, 9, 2, 6, 5, 3$.)

> [!hint]- Hint
> Same table and same order as Problem 4.

> [!solution]- Solution
> **The idea.** [[3-homework-and-exams/lab-07a#problem-5--shortest-palindrome-supersequence-harder|Lab 7a, Problem 5]]'s recurrence has exactly the shape of $\textsf{LPS}$ — the same three neighbors — with $2 + \min$ in place of $\max$. So the table, the order and the time are those of Problem 4.
>
> **Function.** For $1 \le i \le n+1$ and $i - 1 \le j \le n$, $\textsf{SPS}(i, j)$ is the length of a shortest palindrome supersequence of $A[i\,..\,j]$. We need $\textsf{SPS}(1, n)$.
>
> **Recurrence** (Lab 7a): $\textsf{SPS}(i, i-1) = 0$, $\textsf{SPS}(i, i) = 1$, and for $i < j$
> $$
> \textsf{SPS}(i, j) = 2 + \min\begin{cases}
> \textsf{SPS}(i+1, j)\\
> \textsf{SPS}(i, j-1)\\
> \textsf{SPS}(i+1, j-1) & \text{only if } A[i] = A[j]
> \end{cases}
> $$
>
> - **Memoization:** an array $\mathit{SPS}[1\,..\,n+1,\ 0\,..\,n]$.
> - **Evaluation order:** outer loop $i$ from $n + 1$ down to 1; inner loop $j$ from $i - 1$ up to $n$.
> - **Time:** $O(n^2)$ entries, $O(1)$ each: $O(n^2)$.
>
> $\textsf{FastSPS}$ is $\textsf{FastLPS}$ with the two assignments in the `else` branch replaced by $\mathit{SPS}[i, j] \gets 2 + \min\{\mathit{SPS}[i+1, j], \mathit{SPS}[i, j-1]\}$ and, if $A[i] = A[j]$, $\mathit{SPS}[i, j] \gets \min\{\mathit{SPS}[i, j],\ 2 + \mathit{SPS}[i+1, j-1]\}$.
>
> **Or reuse Problem 4.** Lab 7a shows $\textsf{SPS}(i, j) = 2(j - i + 1) - \textsf{LPS}(i, j)$, so $2n - \textsf{FastLPS}(A)$ gives the same answer with no second table.
>
> **Example.** For $A = 3, 1, 4, 1, 5$, each cell shows $\textsf{LPS}(i, j)$ / $\textsf{SPS}(i, j)$; in every cell the two add up to twice the length of the interval.
>
> | $i \backslash j$ | 1 (3) | 2 (1) | 3 (4) | 4 (1) | 5 (5) |
> |---|---|---|---|---|---|
> | **1** (3) | 1 / 1 | 1 / 3 | 1 / 5 | 3 / 5 | 3 / 7 |
> | **2** (1) | | 1 / 1 | 1 / 3 | 3 / 3 | 3 / 5 |
> | **3** (4) | | | 1 / 1 | 1 / 3 | 1 / 5 |
> | **4** (1) | | | | 1 / 1 | 1 / 3 |
> | **5** (5) | | | | | 1 / 1 |
>
> The top-right cell: a longest palindrome subsequence is $1, 4, 1$, and a shortest palindrome supersequence is $3, 5, 1, 4, 1, 5, 3$, of length $10 - 3 = 7$.
>
> **Answer.** $\textsf{FastSPS}$ (or $2n - \textsf{FastLPS}$) runs in $O(n^2)$ time; 15 on the example.
