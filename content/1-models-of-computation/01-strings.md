> [!abstract] In one breath
> A string is either empty or a symbol followed by a string. Because that definition is recursive, every function on strings — length, concatenation, reversal, counting — is defined by the same two cases, and every proof about strings is an **induction whose cases mirror the definition**: $w = \varepsilon$ or $w = ax$, with a hypothesis that covers every shorter string. Lemmas 1.1–1.3 ($w\bullet\varepsilon = w$, lengths add, concatenation is associative) state facts you already believe; their proofs are practice for a pattern that returns in every later chapter, for automata, regular expressions, grammars and Turing machines. Midterm-1-style exams devote a whole problem to exactly this kind of proof about a newly defined string function.

## 1.1 Strings

An **alphabet** $\Sigma$ is a finite set; its elements are called **symbols** — bits, letters, ASCII characters, anything. A string over $\Sigma$ is then defined the way a linked list is defined in a program:

> [!definition] Definition — string, $\Sigma^*$
> A **string** over $\Sigma$ is either
> - the **empty string**, written $\varepsilon$, or
> - an ordered pair $(a, x)$, written $a\cdot x$ or just $ax$, where $a\in\Sigma$ is a symbol and $x$ is a string over $\Sigma$.
>
> $\Sigma^*$ is the set of all strings over $\Sigma$. For a non-empty alphabet it is an infinite set, but every string in it is **finite**: it is built by finitely many applications of the second rule.

So `STRING` is shorthand for $(\mathtt{S},(\mathtt{T},(\mathtt{R},(\mathtt{I},(\mathtt{N},(\mathtt{G},\varepsilon))))))$ — six pairs, with the empty string at the end:

**Conventions** (the book's, used on every page of this site): $a, b, c$ are symbols; $w, x, y, z$ are strings; explicit symbols and strings are set in monospace, like $\mathtt{0}$, $\mathtt{1}$, `0110`, `STRING`. Formally the symbol $a$ and the one-symbol string $a\cdot\varepsilon$ are different objects, but everyone writes both as $a$. The difference matters only inside proofs, where $a\bullet z = a\cdot(\varepsilon\bullet z) = a\cdot z$ uses both cases of the definition of concatenation below.

## 1.2 Two recursive functions

Because strings are defined recursively, functions on strings are defined recursively too: one case for $\varepsilon$, and one case for $ax$ that calls the function on the shorter string $x$.

> [!definition] Definition — length and concatenation
> $$
> \lvert w\rvert := \begin{cases} 0 & \text{if } w = \varepsilon\\ 1 + \lvert x\rvert & \text{if } w = ax\end{cases}
> \qquad\qquad
> w\bullet z := \begin{cases} z & \text{if } w = \varepsilon\\ a\cdot(x\bullet z) & \text{if } w = ax\end{cases}
> $$
> The **small dot** in $a\cdot x$ puts one *symbol* in front of a string: it builds a pair. The **big dot** in $w\bullet z$ glues two *strings* together. Both dots are usually left out.

Unfolding the definition on an example:
$$
\mathtt{NOW}\bullet\mathtt{HERE}
= \mathtt{N}\cdot(\mathtt{OW}\bullet\mathtt{HERE})
= \mathtt{N}\cdot\big(\mathtt{O}\cdot(\mathtt{W}\bullet\mathtt{HERE})\big)
= \mathtt{N}\cdot\Big(\mathtt{O}\cdot\big(\mathtt{W}\cdot(\varepsilon\bullet\mathtt{HERE})\big)\Big)
= \mathtt{NOWHERE}.
$$

Three consequences to keep in mind:

- **Concatenation recurses on its left argument.** The right argument rides along unchanged until the base case returns it. So a proof about $w\bullet z$ inducts on $w$ and keeps $z$ fixed (Lemma 1.2 below).
- **$\varepsilon$ is a left identity by definition** ($\varepsilon\bullet z = z$ is the first case) but **a right identity only by proof** ($w\bullet\varepsilon = w$ is Lemma 1.1).
- **Concatenation is not commutative** — $\mathtt{NOW}\bullet\mathtt{HERE} = \mathtt{NOWHERE}$ but $\mathtt{HERE}\bullet\mathtt{NOW} = \mathtt{HERENOW}$ — **but it is associative** (Lemma 1.3), which is what licenses writing $wxyz$ with no dots and no parentheses.

Chapter 3 defines a [[concepts/dfa|DFA]]'s extended transition function $\delta^*$ by exactly this recursion on the input string ([[1-models-of-computation/03-finite-state-machines#32-formal-definitions|§3.2]]).

## 1.3 Induction on strings

Every proof about strings in this course follows two design rules.

1. **The cases mirror the recursive definition.** A string is either $\varepsilon$ or $ax$, so the proof has a case $w = \varepsilon$ and a case $w = ax$. (If the function in the claim is defined by other cases, mirror *its* cases — see $\textsf{swap}$ at the end of this page.)
2. **The induction hypothesis is as strong as possible:** assume the claim for *every* string shorter than $w$ — "there is no counterexample shorter than $w$". In the case $w = ax$ we have $\lvert x\rvert = \lvert w\rvert - 1 < \lvert w\rvert$, so the hypothesis applies to $x$, and to any other shorter string the argument needs.

This strong hypothesis costs nothing compared with the weak one ("assume the claim for $x$, prove it for $ax$"), the graders prefer it, and it still works when a proof needs a string two symbols shorter, or half as long.

> [!template] Template — induction on strings
> Let $w$ be an arbitrary string. \
> Assume, for every string $x$ with $\lvert x\rvert < \lvert w\rvert$, that *[the claim holds for $x$]*. \
> There are two cases to consider. \
> **Case $w = \varepsilon$.** … Therefore *[the claim holds for $w$]*. \
> **Case $w = ax$** for some symbol $a$ and string $x$. The induction hypothesis implies that *[the claim holds for $x$]*. … Therefore *[the claim holds for $w$]*. \
> In both cases, *[the claim holds for $w$]*. $\blacksquare$

Write this boilerplate *first*, with room in each case; then write out the claim and the hypothesis in full, with variable names that do not clash; only then start on the algebra.

> [!key] Lemma 1.1
> $w\bullet\varepsilon = w$ for every string $w$.

> [!key] Lemma 1.2
> $\lvert w\bullet x\rvert = \lvert w\rvert + \lvert x\rvert$ for all strings $w$ and $x$.

> [!key] Lemma 1.3
> $(w\bullet x)\bullet y = w\bullet(x\bullet y)$ for all strings $w$, $x$ and $y$.

> [!example] Proof of Lemma 1.2 — the model to copy
> Let $w$ and $x$ be arbitrary strings. Assume that $\lvert y\bullet x\rvert = \lvert y\rvert + \lvert x\rvert$ for every string $y$ with $\lvert y\rvert < \lvert w\rvert$. (We induct on $w$, the argument that ${\bullet}$ recurses on, and keep $x$ fixed; the shorter string is called $y$ because $x$ is taken.) There are two cases.
>
> **Case $w = \varepsilon$.** By the definitions of ${\bullet}$ and $\lvert\cdot\rvert$,
> $$
> \lvert w\bullet x\rvert = \lvert\varepsilon\bullet x\rvert = \lvert x\rvert = 0 + \lvert x\rvert = \lvert\varepsilon\rvert + \lvert x\rvert = \lvert w\rvert + \lvert x\rvert.
> $$
> **Case $w = ay$** for some symbol $a$ and string $y$. Then $\lvert y\rvert < \lvert w\rvert$, so the induction hypothesis applies to $y$, and
> $$
> \begin{aligned}
> \lvert w\bullet x\rvert &= \lvert a\cdot(y\bullet x)\rvert && \text{by definition of } {\bullet}\\
> &= 1 + \lvert y\bullet x\rvert && \text{by definition of } \lvert\cdot\rvert\\
> &= 1 + \lvert y\rvert + \lvert x\rvert && \text{by the induction hypothesis}\\
> &= \lvert w\rvert + \lvert x\rvert && \text{by definition of } \lvert\cdot\rvert.
> \end{aligned}
> $$
> In both cases, $\lvert w\bullet x\rvert = \lvert w\rvert + \lvert x\rvert$. $\blacksquare$

What to copy: an arbitrary $w$ (and $x$); a hypothesis written out in full, for *all* shorter strings; cases that cover every string; one justification per equation; and an explicit reason why the hypothesis applies ($\lvert y\rvert < \lvert w\rvert$). No step says "clearly".

> [!proof]- Proof of Lemma 1.1 (click to expand)
> Let $w$ be an arbitrary string, and assume that $x\bullet\varepsilon = x$ for every string $x$ with $\lvert x\rvert < \lvert w\rvert$.
> - **$w = \varepsilon$:** $w\bullet\varepsilon = \varepsilon\bullet\varepsilon = \varepsilon = w$, by the first case of the definition of ${\bullet}$.
> - **$w = ax$:** $w\bullet\varepsilon = a\cdot(x\bullet\varepsilon)$ by the definition of ${\bullet}$, and $x\bullet\varepsilon = x$ by the induction hypothesis because $\lvert x\rvert < \lvert w\rvert$; so $w\bullet\varepsilon = a\cdot x = w$.
>
> In both cases $w\bullet\varepsilon = w$. $\blacksquare$

> [!proof]- Proof of Lemma 1.3 (click to expand)
> Induct on $w$: both sides then unfold by the definition of ${\bullet}$. (Inducting on $y$ gets stuck — nothing in the definition takes a *right* argument apart.) Let $w$, $x$, $y$ be arbitrary strings, and assume $(z\bullet x)\bullet y = z\bullet(x\bullet y)$ for every string $z$ with $\lvert z\rvert < \lvert w\rvert$.
>
> **Case $w = \varepsilon$.** $(\varepsilon\bullet x)\bullet y = x\bullet y = \varepsilon\bullet(x\bullet y)$, using the definition of ${\bullet}$ twice.
>
> **Case $w = az$.** Then $\lvert z\rvert < \lvert w\rvert$, and
> $$
> \begin{aligned}
> (az\bullet x)\bullet y &= \big(a\cdot(z\bullet x)\big)\bullet y && \text{by definition of } {\bullet}\\
> &= a\cdot\big((z\bullet x)\bullet y\big) && \text{by definition of } {\bullet}\\
> &= a\cdot\big(z\bullet(x\bullet y)\big) && \text{by the induction hypothesis}\\
> &= az\bullet(x\bullet y) && \text{by definition of } {\bullet}.
> \end{aligned}
> $$
> In both cases $(w\bullet x)\bullet y = w\bullet(x\bullet y)$. $\blacksquare$

Concept page: [[concepts/induction-on-strings]].

## 1.4 More than one path up the mountain

The two-case boilerplate is the default, not the law. Any induction works as long as **its cases cover every string** and **every string the hypothesis is applied to is shorter than $w$**. A useful alternative: a string $w$ is non-empty if and only if either

- $w = a$ for a single symbol $a$, or
- $w = u\bullet v$ for two **non-empty** strings $u$ and $v$ — and then $\lvert u\rvert, \lvert v\rvert < \lvert w\rvert$ by Lemma 1.2, so the hypothesis applies to *both* pieces.

> [!trap] Quantify the hypothesis over the other arguments
> In the proof of Lemma 1.2 the second argument $x$ never changed, so the hypothesis could keep it fixed. Proving associativity with $w = u\bullet v$ is different: each step below applies the claim $(z\bullet x')\bullet y' = z\bullet(x'\bullet y')$ to a shorter $z$, and three of the four steps use *other* second and third arguments.
> $$
> \begin{aligned}
> \big((u\bullet v)\bullet x\big)\bullet y &= \big(u\bullet(v\bullet x)\big)\bullet y && (z, x', y') = (u,\ v,\ x)\\
> &= u\bullet\big((v\bullet x)\bullet y\big) && (z, x', y') = (u,\ v\bullet x,\ y)\\
> &= u\bullet\big(v\bullet(x\bullet y)\big) && (z, x', y') = (v,\ x,\ y)\\
> &= (u\bullet v)\bullet(x\bullet y) && (z, x', y') = (u,\ v,\ x\bullet y)
> \end{aligned}
> $$
> So the hypothesis must read: "$(z\bullet x')\bullet y' = z\bullet(x'\bullet y')$ **for all strings $x'$ and $y'$** and every string $z$ with $\lvert z\rvert < \lvert w\rvert$." A hypothesis about the fixed $x$ and $y$ alone justifies only the third step.

> [!proof]- Lemma 1.3 again, by the three-case split (click to expand)
> Let $w$ be an arbitrary string. Assume that $(z\bullet x')\bullet y' = z\bullet(x'\bullet y')$ for all strings $x'$, $y'$ and every string $z$ with $\lvert z\rvert < \lvert w\rvert$. Let $x$ and $y$ be arbitrary strings.
> - **$w = \varepsilon$:** $(\varepsilon\bullet x)\bullet y = x\bullet y = \varepsilon\bullet(x\bullet y)$ by the definition of ${\bullet}$.
> - **$w = a$:** $(a\bullet x)\bullet y = (a\cdot x)\bullet y = a\cdot(x\bullet y) = a\bullet(x\bullet y)$, using $a\bullet z = a\cdot z$ (§1.1) and the definition of ${\bullet}$.
> - **$w = u\bullet v$ with $u$, $v$ non-empty:** $\lvert u\rvert, \lvert v\rvert < \lvert w\rvert$ by Lemma 1.2, so each of the four steps in the trap above is a legal use of the hypothesis, and they show $(w\bullet x)\bullet y = w\bullet(x\bullet y)$.
>
> In all three cases $(w\bullet x)\bullet y = w\bullet(x\bullet y)$. $\blacksquare$

## 1.5 Indices, substrings, and subsequences

> [!definition] Definition — pieces of a string
> Let $w$ be a string of length $n$.
> - **Index:** $w_i$ is the $i$th symbol of $w$. Recursively, if $w = ax$, then $w_1 := a$ and $w_i := x_{i-1}$ for $i > 1$; $w_i$ is undefined if $i < 1$ or $i > n$. We often write $w = w_1w_2\cdots w_n$ or $w[1..n]$ — but $n$ may be $1$, or even $0$.
> - **Substring:** $y$ is a substring of $w$ if $w = xyz$ for some strings $x$ and $z$. The substring from position $i$ to position $j$ is $w[i..j] := \varepsilon$ if $j < i$, and $w[i..j] := w_i\cdot w[i+1..j]$ otherwise.
> - **Prefix, suffix:** $p$ is a **prefix** of $w$ if $w = px$ for some string $x$ (equivalently, $p = w[1..j]$ for some $0\le j\le n$); $s$ is a **suffix** of $w$ if $w = xs$ for some string $x$ (equivalently, $s = w[i..n]$ for some $1\le i\le n+1$).
> - **Subsequence:** a string obtained from $w$ by deleting zero or more symbols, anywhere. Recursively, $z$ is a subsequence of $w$ if and only if $z = \varepsilon$; or $w = ax$ and $z$ is a subsequence of $x$; or $w = ax$, $z = ay$, and $y$ is a subsequence of $x$.
> - **Proper:** a proper substring, prefix, suffix or subsequence of $w$ is one that is not $w$ itself.

The recursive definition of subsequence is "delete" spelled out symbol by symbol: the first symbol of $w$ is either deleted (second case) or kept as the first symbol of $z$ (third case).

Every substring is a subsequence, but not conversely: `METAL` is a subsequence of `MEATBALL` but not a substring of it, and `00` is a subsequence of `0110` but not a substring. ("Contiguous substring" says the same thing twice: substrings are always contiguous.)

**How many?** A string of length $n$ has exactly $n+1$ prefixes and $n+1$ suffixes (counting $\varepsilon$ and $w$ itself), at most $n(n+1)/2$ distinct non-empty substrings, and at most $2^n$ distinct subsequences (counting $\varepsilon$ and $w$). The bounds are reached when all $n$ symbols are different. At the other extreme, `0000` has just five distinct substrings — $\varepsilon$, `0`, `00`, `000`, `0000` — and these are also its only subsequences.

> [!trap] Substring or subsequence?
> "Contains `00`" means as a *substring* unless the problem says *subsequence*, and the two languages are different: `0110` contains `00` as a subsequence but not as a substring. Read the problem statement twice — a correct answer to the wrong question is a wrong answer.

## More recursive functions

The chapter's exercises define many more functions by the same recursion and ask for proofs of their properties. The standard ones:

| function | base case | recursive case |
|---|---|---|
| $\#(a, w)$, the number of $a$'s in $w$ | $\#(a,\varepsilon) := 0$ | $\#(a, bx) := [a = b] + \#(a, x)$ |
| reversal $w^R$ | $\varepsilon^R := \varepsilon$ | $(ax)^R := x^R\bullet a$ |
| powers $w^n$ (recursion on $n$) | $w^0 := \varepsilon$ | $w^n := w\bullet w^{n-1}$ for $n\ge1$ |
| binary complement $w^c$ | $\varepsilon^c := \varepsilon$ | $(\mathtt{0}x)^c := \mathtt{1}\cdot x^c$ and $(\mathtt{1}x)^c := \mathtt{0}\cdot x^c$ |

Here $[a = b]$ is $1$ if $a = b$ and $0$ otherwise. For example, $\#(\mathtt{0},\mathtt{0110}) = 2$, $(\mathtt{001})^R = \mathtt{100}$, $(\mathtt{001})^c = \mathtt{110}$, and $(\mathtt{01})^3 = \mathtt{010101}$. Each of the following facts is a short induction on the argument that the definitions recurse on:

- $\#(a, x\bullet y) = \#(a, x) + \#(a, y)$, and $\lvert w\rvert = \sum_{a\in\Sigma}\#(a,w)$;
- $\lvert w^R\rvert = \lvert w\rvert$, $\#(a, w^R) = \#(a, w)$, $(w\bullet x)^R = x^R\bullet w^R$, and $(w^R)^R = w$;
- $w^m\bullet w^n = w^{m+n}$, $\lvert w^n\rvert = n\lvert w\rvert$, $\#(a, w^n) = n\cdot\#(a,w)$, and $(w^R)^n = (w^n)^R$;
- $(x\bullet y)^c = x^c\bullet y^c$, $(w^c)^c = w$, $\#(\mathtt{1}, w) = \#(\mathtt{0}, w^c)$, and $(w^R)^c = (w^c)^R$;
- cancellation: $x\bullet z = y\bullet z$ implies $x = y$, and $x\bullet y = x\bullet z$ implies $y = z$.

> [!example] Model exam answer — $(w\bullet x)^R = x^R\bullet w^R$ for all strings $w$ and $x$
> *Which variable?* Both ${\bullet}$ and ${}^R$ take strings apart from the front, and the front of $w\bullet x$ is the front of $w$: induct on $w$ and keep $x$ fixed. *What gets cited?* The definitions of ${\bullet}$ and ${}^R$, Lemma 1.1 and Lemma 1.3.
>
> Let $w$ and $x$ be arbitrary strings. Assume that $(y\bullet x)^R = x^R\bullet y^R$ for every string $y$ with $\lvert y\rvert < \lvert w\rvert$. There are two cases.
>
> **Case $w = \varepsilon$.** By the definition of ${\bullet}$, Lemma 1.1, and the definition of ${}^R$,
> $$
> (\varepsilon\bullet x)^R = x^R = x^R\bullet\varepsilon = x^R\bullet\varepsilon^R.
> $$
> **Case $w = ay$** for some symbol $a$ and string $y$. Then $\lvert y\rvert < \lvert w\rvert$, so the induction hypothesis applies to $y$, and
> $$
> \begin{aligned}
> (ay\bullet x)^R &= \big(a\cdot(y\bullet x)\big)^R && \text{by definition of } {\bullet}\\
> &= (y\bullet x)^R\bullet a && \text{by definition of } {}^R\\
> &= (x^R\bullet y^R)\bullet a && \text{by the induction hypothesis}\\
> &= x^R\bullet(y^R\bullet a) && \text{by Lemma 1.3}\\
> &= x^R\bullet(ay)^R && \text{by definition of } {}^R.
> \end{aligned}
> $$
> In both cases, $(w\bullet x)^R = x^R\bullet w^R$. $\blacksquare$

Once proved, a fact like this can be cited. The inductive case of $(w^R)^R = w$, for instance, becomes one line: $\big((ax)^R\big)^R = (x^R\bullet a)^R = a^R\bullet(x^R)^R = a\bullet x = ax$, by the definition of ${}^R$, the fact above, then $a^R = a$ together with the induction hypothesis for $x$, and finally $a\bullet x = a\cdot x$ (§1.1).

> [!trap] Test the identity before you prove it
> The order flips: $(w\bullet x)^R = x^R\bullet w^R$, not $w^R\bullet x^R$ — with $w = \mathtt{0}$ and $x = \mathtt{1}$, $(w\bullet x)^R$ is `10` while $w^R\bullet x^R$ is `01`. Trying a two- or three-symbol example takes ten seconds and exposes most false "facts", on true/false questions too.

**When the definition has more cases, so does the proof.** The exercise function
$$
\textsf{swap}(w) := \begin{cases} w & \text{if } \lvert w\rvert\le1\\ b\cdot a\cdot\textsf{swap}(x) & \text{if } w = abx\end{cases}
$$
exchanges adjacent pairs of symbols: $\textsf{swap}(\mathtt{0110}) = \mathtt{1001}$ and $\textsf{swap}(\mathtt{011}) = \mathtt{101}$. A proof that $\lvert\textsf{swap}(w)\rvert = \lvert w\rvert$, or that $\textsf{swap}(\textsf{swap}(w)) = w$, has three cases — $w = \varepsilon$, $w = a$, $w = abx$ — and applies the hypothesis to $x$, which is two symbols shorter than $w$. The "every shorter string" hypothesis covers that for free.

> [!exam] How the induction problem is graded
> Midterm-1-style exams devote a whole problem to proving properties of a **newly defined recursive string function**, like the ones in the table above. It is graded out of 10: **1** for starting from an arbitrary string; **2** for an explicitly stated, strong induction hypothesis (weak induction is discouraged); **2** for cases that cover every string; **1** for the base case(s); **2** for applying the hypothesis correctly — only to shorter strings, with the right values of the other arguments; **2** for the remaining details. Lemmas 1.1–1.3, and any result from lecture, the lecture notes, labs or homework solutions, may be cited without proof.

## Summary

- A string is $\varepsilon$ or a pair $a\cdot x$; $\Sigma^*$ is infinite, but every string in it is finite.
- Functions on strings are defined by the cases $\varepsilon$ and $ax$. Concatenation recurses on its **left** argument; it is associative but not commutative.
- String induction: an arbitrary $w$, a hypothesis for **every shorter string**, cases that mirror the definition, and a justification on every line.
- Lemmas 1.1–1.3: $w\bullet\varepsilon = w$, $\lvert w\bullet x\rvert = \lvert w\rvert + \lvert x\rvert$, and associativity. Induct on the argument the definitions recurse on.
- Other splits ($w = a$ or $w = u\bullet v$; or $w = xa$) are fine. If the hypothesis is applied with different values of the other arguments, it must say "for all" of them.
- Substrings are contiguous, subsequences need not be; prefixes and suffixes are special substrings; "proper" excludes $w$ itself.
- Reversal turns concatenation around: $(w\bullet x)^R = x^R\bullet w^R$. Test any identity on a tiny example before proving it.
