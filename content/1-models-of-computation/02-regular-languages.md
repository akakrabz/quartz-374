> [!abstract] In one breath
> A **language** is any set of strings. The **regular** languages are the ones built from the empty language and single strings by finitely many unions, concatenations and Kleene stars, and **regular expressions** are the notation for them: $\mathtt{0}+\mathtt{1}(\mathtt{0}+\mathtt{1})^*\mathtt{00}$ describes the binary numerals (without leading 0s) of the multiples of 4. Because the definition is recursive, a proof about regular expressions is an induction with five cases — $\varnothing$, a string, $S+T$, $ST$, $S^*$ — and a proof about regular languages picks an expression and inducts on it. A handful of identities, including Arden's rule for equations $L = AL\cup B$, let you calculate with languages without any induction. And a counting argument shows that almost all languages are *not* regular.

## 2.1 Languages

> [!definition] Definition — language
> A (formal) **language** over an alphabet $\Sigma$ is any set of strings over $\Sigma$: any subset $L\subseteq\Sigma^*$. It may be finite or infinite.

Examples over $\{\mathtt{0},\mathtt{1}\}$: the empty language $\varnothing$; $\{\varepsilon\}$; $\{\mathtt{0},\mathtt{1},\mathtt{10}\}$; all of $\Sigma^*$; the palindromes; the binary numerals of prime numbers. A language is the same thing as a yes/no problem — given a string $w$, decide whether $w\in L$ — and the rest of the course asks which machines can solve such problems.

> [!trap] Three different "empty" things
> - $\varnothing$ is the **empty language**: it contains no strings at all.
> - $\{\varepsilon\}$ is a language with **exactly one string**, the empty string. It is not empty.
> - $\varepsilon$ is a **string** of length 0, not a language.
>
> They behave differently: $\varnothing\bullet L = \varnothing$ but $\{\varepsilon\}\bullet L = L$ (§2.2), and $\varnothing^* = \{\varepsilon\}$. In a regular expression, $\varnothing$ denotes $\varnothing$ and $\varepsilon$ denotes $\{\varepsilon\}$; a missing or extra $\varepsilon$ is the typical "one mistake" deduction on a graded regular expression.

## 2.2 Building languages

Languages are sets, so $A\cup B$, $A\cap B$, $A\setminus B$ and $A\oplus B$ are languages, and so is the **complement** $\overline{A} := \Sigma^*\setminus A$. Two more operations use the fact that the elements are strings.

> [!definition] Definition — concatenation, Kleene star, Kleene plus
> - **Concatenation:** $A\bullet B := \{xy \mid x\in A \text{ and } y\in B\}$, usually written $AB$.
> - **Kleene star:** $L^*$ is the set of strings $w$ such that either $w = \varepsilon$, or $w = xy$ for some $x\in L$ and $y\in L^*$. Equivalently, $L^*$ is the smallest superset of $L$ that contains $\varepsilon$ and is closed under concatenation: all concatenations of zero or more strings from $L$.
> - **Kleene plus:** $L^+ := L\bullet L^*$, all concatenations of *one* or more strings from $L$.

For example, $\{\mathtt{HOCUS},\mathtt{ABRACA}\}\bullet\{\mathtt{POCUS},\mathtt{DABRA}\}$ contains four strings: `HOCUSPOCUS`, `ABRACAPOCUS`, `HOCUSDABRA` and `ABRACADABRA`. A concatenation can have fewer than $\lvert A\rvert\cdot\lvert B\rvert$ strings, because different pairs can glue to the same string: $\{\mathtt{0},\mathtt{00}\}\bullet\{\mathtt{0},\mathtt{00}\} = \{\mathtt{00},\mathtt{000},\mathtt{0000}\}$. The star $\{\mathtt{0},\mathtt{11}\}^*$ begins $\varepsilon, \mathtt{0}, \mathtt{00}, \mathtt{11}, \mathtt{000}, \mathtt{011}, \mathtt{110},\dots$ The two exceptions are $\varnothing^* = \{\varepsilon\}^* = \{\varepsilon\}$; for every other language, $L^*$ is infinite. And $\Sigma^*$ really is the star of the language $\Sigma$ of one-symbol strings, so the notation of Chapter 1 is consistent.

> [!key] Lemma 2.1
> For all languages $A$, $B$ and $C$:
> - (a) $A\cup B = B\cup A$;
> - (b) $(A\cup B)\cup C = A\cup(B\cup C)$;
> - (c) $\varnothing\bullet A = A\bullet\varnothing = \varnothing$;
> - (d) $\{\varepsilon\}\bullet A = A\bullet\{\varepsilon\} = A$;
> - (e) $(A\bullet B)\bullet C = A\bullet(B\bullet C)$;
> - (f) $A\bullet(B\cup C) = (A\bullet B)\cup(A\bullet C)$;
> - (g) $(A\cup B)\bullet C = (A\bullet C)\cup(B\bullet C)$.

> [!key] Lemma 2.2
> For every language $L$:
> - (a) $L^* = \{\varepsilon\}\cup L^+ = L^*\bullet L^* = (L\cup\{\varepsilon\})^* = (L\setminus\{\varepsilon\})^* = \{\varepsilon\}\cup L\cup(L^+\bullet L^+)$;
> - (b) $L^+ = L\bullet L^* = L^*\bullet L = L^+\bullet L^* = L^*\bullet L^+ = L\cup(L^+\bullet L^+)$;
> - (c) $L^+ = L^*$ if and only if $\varepsilon\in L$.

These identities are the algebra of regular expressions: for instance, $(\mathtt{0}+\mathtt{1})^*(\mathtt{0}+\mathtt{1})^*$ simplifies to $(\mathtt{0}+\mathtt{1})^*$ by Lemma 2.2(a).

> [!trap] Identities that look true but are not
> - Concatenation is **not commutative**: $\{\mathtt{0}\}\bullet\{\mathtt{1}\} = \{\mathtt{01}\}\ne\{\mathtt{10}\} = \{\mathtt{1}\}\bullet\{\mathtt{0}\}$.
> - Concatenation does **not distribute over $\cap$**. With $A = \{\varepsilon,\mathtt{0}\}$, $B = \{\mathtt{0}\}$, $C = \{\mathtt{00}\}$: $A(B\cap C) = A\bullet\varnothing = \varnothing$, but $AB\cap AC = \{\mathtt{0},\mathtt{00}\}\cap\{\mathtt{00},\mathtt{000}\} = \{\mathtt{00}\}$. Only $A(B\cap C)\subseteq AB\cap AC$ holds.
> - $L^+ = L^*$ only when $\varepsilon\in L$: for $L = \{\mathtt{0}\}$, $L^+$ is $\mathtt{0}\mathtt{0}^*$ and $L^*$ is $\mathtt{0}^*$.

> [!key] Lemma 2.3 (Arden's rule)
> Let $A$, $B$ and $L$ be languages with $L = A\bullet L\cup B$. Then $A^*\bullet B\subseteq L$. Moreover, if $\varepsilon\notin A$, then $L = A\bullet L\cup B$ holds **if and only if** $L = A^*\bullet B$.

> [!proof]- Proof (click to expand)
> *$A^*B\subseteq L$.* Write $A^0 := \{\varepsilon\}$ and $A^n := A\bullet A^{n-1}$, so that $A^* = \bigcup_{n\ge0}A^n$ and therefore $A^*B = \bigcup_{n\ge0}A^nB$. So it suffices to show $A^nB\subseteq L$ for every $n\ge0$, by induction on $n$. For $n = 0$: $B\subseteq AL\cup B = L$. For $n\ge1$, assuming $A^{n-1}B\subseteq L$, we get $A^nB = A(A^{n-1}B)\subseteq AL\subseteq L$, because $L = AL\cup B$.
>
> *$A^*B$ is a solution* (for every $A$): $A(A^*B)\cup B = (A^+\cup\{\varepsilon\})B = A^*B$ by Lemma 2.1(a, d, e, g) and Lemma 2.2(a, b).
>
> *If $\varepsilon\notin A$, there is no other solution.* Suppose $L = AL\cup B$ but $L\not\subseteq A^*B$, and let $w$ be a **shortest** string in $L\setminus A^*B$. Since $B\subseteq A^*B$, $w\notin B$, so $w\in AL$: $w = xy$ with $x\in A$ and $y\in L$. Because $\varepsilon\notin A$, the string $x$ is non-empty, so $\lvert y\rvert < \lvert w\rvert$, and $y\in A^*B$ by the choice of $w$. Then $w = xy\in A(A^*B)\subseteq A^*B$, a contradiction. So $L\subseteq A^*B$, and with the first part, $L = A^*B$. $\blacksquare$

> [!example] Arden's rule on a single equation
> As in regular expressions, a string here stands for the language that contains just that string. If $L = \mathtt{0}L\cup\mathtt{1}$, then $A = \{\mathtt{0}\}$ does not contain $\varepsilon$, so the **only** solution is $L = \mathtt{0}^*\mathtt{1}$. Check: $\mathtt{0}\mathtt{0}^*\mathtt{1}\cup\mathtt{1} = \mathtt{0}^+\mathtt{1}\cup\mathtt{1} = \mathtt{0}^*\mathtt{1}$.
>
> The condition $\varepsilon\notin A$ matters. The equation $L = \{\varepsilon,\mathtt{0}\}\bullet L\cup\mathtt{1}$ is solved by $\mathtt{0}^*\mathtt{1}$ but also by $\Sigma^*$; Arden's rule only says that $\{\varepsilon,\mathtt{0}\}^*\mathtt{1} = \mathtt{0}^*\mathtt{1}$ is the *smallest* solution.

## 2.3 Regular languages and regular expressions

> [!definition] Definition — regular language
> A language $L$ is **regular** if and only if it satisfies one of these conditions:
> - $L$ is empty;
> - $L$ contains exactly one string (which may be $\varepsilon$);
> - $L$ is the union of two regular languages;
> - $L$ is the concatenation of two regular languages; or
> - $L$ is the Kleene star of a regular language.

So every finite language is regular (it is empty, or a union of finitely many one-string languages), and so is $\Sigma^*$. Regular expressions are the compact notation for this definition: omit the braces around one-string sets, write $+$ for union, and write concatenation by juxtaposition.

> [!definition] Definition — regular expression, $L(R)$, matching, equivalence
> A **regular expression** is $\varnothing$, a string $w$ (possibly $\varepsilon$), or $S+T$, $ST$ or $S^*$ for regular expressions $S$ and $T$, with parentheses for grouping. Its **language** $L(R)$ is defined by
> - $L(\varnothing) := \varnothing$ and $L(w) := \{w\}$;
> - $L(S+T) := L(S)\cup L(T)$, $L(ST) := L(S)\bullet L(T)$ and $L(S^*) := L(S)^*$.
>
> A string $w$ **matches** $R$ if $w\in L(R)$. Two regular expressions are **equivalent** if they have the same language. **Precedence:** $^*$ binds tightest, then concatenation, then $+$.

> [!trap] Precedence
> - $\mathtt{1}\mathtt{0}^*$ means $\mathtt{1}(\mathtt{0}^*)$, the language $\{\mathtt{1},\mathtt{10},\mathtt{100},\dots\}$ — not $(\mathtt{10})^* = \{\varepsilon,\mathtt{10},\mathtt{1010},\dots\}$.
> - $\mathtt{0}+\mathtt{1}^*$ means $\mathtt{0}+(\mathtt{1}^*)$, not $(\mathtt{0}+\mathtt{1})^*$.
> - $\mathtt{0}+\mathtt{1}(\mathtt{0}+\mathtt{1})^*\mathtt{00}$ means $\mathtt{0}+\big(\mathtt{1}(\mathtt{0}+\mathtt{1})^*\mathtt{00}\big)$: the union is applied last.
>
> When in doubt, add parentheses; redundant ones are never wrong.

The book's examples, all over $\{\mathtt{0},\mathtt{1}\}$:

| regular expression | its language: the binary strings … |
|---|---|
| $\mathtt{0}^*$ | made of 0s only (including $\varepsilon$) |
| $\mathtt{0000}\mathtt{0}^*$ | made of at least four 0s |
| $(\mathtt{00000})^*$ | made of 0s, a multiple of 5 of them |
| $(\mathtt{0}+\mathtt{1})^*$ | — all of them |
| $(\varepsilon+\mathtt{1})(\mathtt{01})^*(\varepsilon+\mathtt{0})$ | that alternate: no `00` and no `11` |
| $(\mathtt{0}+\mathtt{1})^*\mathtt{0000}(\mathtt{0}+\mathtt{1})^*$ | that contain the substring `0000` |
| $((\varepsilon+\mathtt{0}+\mathtt{00}+\mathtt{000})\mathtt{1})^*(\varepsilon+\mathtt{0}+\mathtt{00}+\mathtt{000})$ | without `0000`: at most three 0s before each `1` and at the end |
| $((\mathtt{0}+\mathtt{1})(\mathtt{0}+\mathtt{1}))^*$ | of even length |
| $\mathtt{1}^*(\mathtt{0}\mathtt{1}^*\mathtt{0}\mathtt{1}^*)^*$ | with an even number of 0s: after the leading 1s, the 0s come in pairs |
| $\mathtt{0}+\mathtt{1}(\mathtt{0}+\mathtt{1})^*\mathtt{00}$ | that are binary numerals of multiples of 4, without leading 0s |
| $\mathtt{0}^*\mathtt{0}+\mathtt{0}^*\mathtt{1}(\mathtt{1}\mathtt{0}^*\mathtt{1}+\mathtt{0}\mathtt{1}^*\mathtt{0})^*\mathtt{1}\mathtt{0}^*$ | that are non-empty binary numerals of multiples of 3 (leading 0s allowed) |

The last expression is hard to invent directly; Chapter 4 derives it by state elimination from a DFA that tracks the remainder mod 3, with a separate non-accepting start state (the three remainder states alone would also accept $\varepsilon$, which the expression does not match). Different expressions can describe the same language: $(\mathtt{0}+\mathtt{1})^*$, $(\mathtt{1}+\mathtt{0})^*$, $(\mathtt{0}^*\mathtt{1}^*)^*$ and $(\mathtt{00}+\mathtt{01}+\mathtt{10}+\mathtt{11})^*(\mathtt{0}+\mathtt{1}+\varepsilon)$ are all equivalent — union is commutative; every single symbol is in $\mathtt{0}^*\mathtt{1}^*$; and every string splits into pairs of symbols plus at most one leftover symbol. Without the last factor, $(\mathtt{00}+\mathtt{01}+\mathtt{10}+\mathtt{11})^*$ describes only the even-length strings.

By [[concepts/kleenes-theorem|Kleene's theorem]] ([[1-models-of-computation/03-finite-state-machines#37-closure-properties|§3.7]]), the regular languages are exactly the languages that DFAs accept. Regular expressions have no symbol for $\cap$ or complement, but regular languages are closed under both anyway — the DFA view proves it (Corollary 3.4).

### Designing a regular expression

> [!recipe] Recipe — from a description to a regular expression
> 1. **List short examples**, in and out of the language, including $\varepsilon$ and every string of length 1 and 2.
> 2. **Find blocks.** Cut a typical string into pieces that a star can repeat — runs, or chunks that end at each `1` — and handle the beginning and the end separately.
> 3. **Write the expression piece by piece, and explain each piece in English.** Homework requires the explanation, and it is how you catch your own mistakes.
> 4. **Test both directions:** every string the expression generates is in the language (nothing extra), and every string in the language is generated (nothing missing). Check $\varepsilon$ explicitly.
> 5. **"And" is hard.** Expressions have no $\cap$. Refine the blocks until both conditions can be read off them (Example 2), or build a [[concepts/product-construction|product DFA]] and convert it (Chapter 4).

> [!example] Example 1 — every `1` is immediately followed by `00`
> **Idea.** Each `1` must be followed by `00`, so each `1` starts a block `100`; these blocks cannot overlap, because a block's second and third symbols are 0s. Every other symbol is a `0` standing alone.
>
> **Answer:** $(\mathtt{0}+\mathtt{100})^*$.
>
> **In English:** $\mathtt{100}$ is a `1` together with the two 0s it requires; $\mathtt{0}$ is a 0 that belongs to no `1`; the star allows any sequence of these blocks, in any order. The empty sequence gives $\varepsilon$, which is in the language because it has no `1` that could violate the condition.
>
> **Test:** $\varepsilon$, `0`, `100`, `1000` and `0100100` match; `1`, `10`, `11` and `1001` do not, and none of them is in the language.
>
> **A wrong answer:** $(\mathtt{0}^*\mathtt{100})^*$ forces every non-empty string to end with the block `100`, so it misses `0`, `00`, `1000` and infinitely many other strings of the language.

> [!example] Example 2 — an even number of 0s and no substring `11`
> **Idea.** In a string without `11`, every `1` except possibly the last symbol is immediately followed by a `0`. So the string splits into blocks `0` and `10`, possibly followed by one final `1`: the strings without `11` are exactly $(\mathtt{0}+\mathtt{10})^*(\varepsilon+\mathtt{1})$. Each block contains **exactly one** 0 and the final `1` contains none, so the number of 0s equals the number of blocks — and it is even exactly when the blocks come in pairs.
>
> **Answer:** $\big((\mathtt{0}+\mathtt{10})(\mathtt{0}+\mathtt{10})\big)^*(\varepsilon+\mathtt{1})$.
>
> **In English:** $(\mathtt{0}+\mathtt{10})(\mathtt{0}+\mathtt{10})$ is two consecutive blocks, each a single 0 possibly preceded by one 1, and so contains two 0s and no `11`; the star repeats such pairs; $(\varepsilon+\mathtt{1})$ allows one final 1, which cannot create `11` because every block ends with 0.
>
> **Test:** $\varepsilon$, `1`, `00`, `010` and `1001` match; `0`, `11`, `101` and `0110` do not, and none of them is in the language.
>
> **Two wrong answers:** dropping $(\varepsilon+\mathtt{1})$ misses `1`, `001`, `00001`, …; and $(\mathtt{0}+\mathtt{10})^*(\varepsilon+\mathtt{1})$ ignores the parity, so it also matches `0`, `000`, `00000`, …. Both are wrong on infinitely many strings.

> [!exam] How a regular expression is graded
> Midterm-1-style exams ask for a regular expression (together with a DFA, [[1-models-of-computation/03-finite-state-machines|Chapter 3]]) for a described language, with no proof required. The standard rubric, out of 10 points: **2** for syntax and **8** for correctness, with exam deductions twice the homework ones — **2** for one mistake (typically a missing or extra $\varepsilon$), **4** for a few wrong strings, and **all 8** if infinitely many strings are wrong, as in each of the wrong answers above. An answer of $\varnothing$ or $\Sigma^*$ earns no credit. Homework answers must also explain each piece in English, as the examples do.

## 2.4 Things that aren't regular expressions

Programming languages and editors provide **regexen**: patterns with many conveniences. In most of them `+` means "one or more", union is written `|`, `?` means "optional", `{2,3}` means "two or three times", `[01]` is a character class, and `\1` refers back to an earlier group. Most of these are abbreviations — `0+` is $\mathtt{0}\mathtt{0}^*$, `0?` is $\varepsilon+\mathtt{0}$, `0{2,3}` is $\mathtt{00}(\mathtt{0}+\varepsilon)$ — but **back-references are not**. The regex `(.*)\1` matches exactly the strings of the form $ww$, and $\{ww \mid w\in\Sigma^*\}$ is not regular: $\mathtt{0}^*\mathtt{1}$ is an infinite [[concepts/fooling-sets|fooling set]] for it, because the suffix $\mathtt{0}^i\mathtt{1}$ completes $\mathtt{0}^i\mathtt{1}$ to a square but not $\mathtt{0}^j\mathtt{1}$ for $j\ne i$ ([[1-models-of-computation/03-finite-state-machines#38-proving-a-language-is-not-regular|§3.8]]). So a regex is not necessarily a regular expression. Shell globs (`*.md`, `file?.txt`) go the other way: they are much weaker than regular expressions.

> [!trap] Use only the real syntax
> A regular expression in this course is built from $\varnothing$, strings (including $\varepsilon$), $+$ for **union**, concatenation, $^*$ and parentheses — nothing else. Write $RR^*$ for "one or more copies of $R$" (the regex `0+1` means $\mathtt{0}\mathtt{0}^*\mathtt{1}$, but the regular expression $\mathtt{0}+\mathtt{1}$ means "`0` or `1`"). There is no $\cap$, no complement, and no counter: $\mathtt{0}^n\mathtt{1}^n$ is not a regular expression, and $\{\mathtt{0}^n\mathtt{1}^n \mid n\ge0\}$ is not even regular (Lemma 3.6).

## 2.5 Regular expression trees

> [!definition] Definition — expression tree, size, subexpression
> A **regular expression tree** is a leaf labeled $\varnothing$; a leaf labeled with a string; a node labeled ${+}$ or ${\bullet}$ with two subtrees; or a node labeled $^*$ with one subtree. (The cases mirror the definition of regular languages exactly.) The **size** of an expression is the number of nodes in its tree. A **subexpression** of $R$ is an expression whose tree is a subtree of some tree for $R$; a **proper** subexpression is any subexpression other than $R$ itself.

"Some tree" because concatenation and union are associative: $\mathtt{1}(\mathtt{0}+\mathtt{1})^*\mathtt{00}$ can be grouped as $\mathtt{1}\bullet\big((\mathtt{0}+\mathtt{1})^*\mathtt{00}\big)$ or as $\big(\mathtt{1}(\mathtt{0}+\mathtt{1})^*\big)\bullet\mathtt{00}$, and both trees are fine.

The size counts operators, including the invisible concatenations, but not parentheses: $\mathtt{0}+\mathtt{1}(\mathtt{0}+\mathtt{1})^*\mathtt{00}$ has 11 characters but size 10, and the book's tree for the multiples-of-3 expression $\mathtt{0}^*\mathtt{0}+\mathtt{0}^*\mathtt{1}(\mathtt{1}\mathtt{0}^*\mathtt{1}+\mathtt{0}\mathtt{1}^*\mathtt{0})^*\mathtt{1}\mathtt{0}^*$ has 29 nodes for 22 characters.

**Subexpression vs. substring.** Every subexpression is a substring of $R$, but a substring that happens to be a well-formed expression need not be a subexpression. In the book's example, $\mathtt{1}\mathtt{0}^*\mathtt{1}$ is a subexpression, but $\mathtt{0}^*\mathtt{0}+\mathtt{0}^*\mathtt{1}$ and $\mathtt{0}^*\mathtt{1}+\mathtt{0}\mathtt{1}^*\mathtt{0}$ are not. Any expression can be parsed into its tree in linear time, so algorithms (and proofs) may assume they are handed the tree.

> [!template] Template — induction on regular expressions
> Let $R$ be an arbitrary regular expression. \
> Assume that every proper subexpression of $R$ *[has the property]*. \
> There are five cases to consider. \
> **Case $R = \varnothing$.** … Therefore $R$ *[has the property]*. \
> **Case $R$ is a single string** $w$ (possibly $\varepsilon$). … Therefore $R$ *[has the property]*. \
> **Case $R = S+T$** for some regular expressions $S$ and $T$. The induction hypothesis implies that $S$ and $T$ *[have the property]*. … \
> **Case $R = ST$** for some regular expressions $S$ and $T$. The induction hypothesis implies that $S$ and $T$ *[have the property]*. … \
> **Case $R = S^*$** for some regular expression $S$. The induction hypothesis implies that $S$ *[has the property]*. … \
> In all five cases, $R$ *[has the property]*. $\blacksquare$

If structural induction feels unfamiliar, induct on the **size** instead: "assume every regular expression smaller than $R$ has the property". The cases are identical, because $S$ and $T$ are smaller than $S+T$, $ST$ and $S^*$.

> [!key] Lemma 2.4
> If a regular expression does not use the symbol $\varnothing$, then its language is not empty.

> [!example] Proof of Lemma 2.4 — the model to copy
> Let $R$ be an arbitrary regular expression that does not use $\varnothing$. Assume that every proper subexpression of $R$ that does not use $\varnothing$ represents a non-empty language. There are five cases.
> - **$R = \varnothing$.** This case is impossible, because $R$ does not use $\varnothing$.
> - **$R$ is a single string $w$.** Then $w\in L(R) = \{w\}$, so $L(R)$ is non-empty.
> - **$R = S+T$.** $S$ is a proper subexpression of $R$, and it does not use $\varnothing$ because $R$ does not. So the induction hypothesis gives a string $x\in L(S)$, and $x\in L(S)\cup L(T) = L(R)$.
> - **$R = ST$.** Neither $S$ nor $T$ uses $\varnothing$, so the induction hypothesis gives strings $x\in L(S)$ and $y\in L(T)$. Then $xy\in L(S)\bullet L(T) = L(R)$.
> - **$R = S^*$.** $\varepsilon\in L(S)^* = L(R)$ by the definition of Kleene star. (The induction hypothesis is not needed.)
>
> In all five cases, $L(R)$ is non-empty. $\blacksquare$

The converse is false: $\varnothing^*$ and $\mathtt{0}+\varnothing$ use $\varnothing$, yet $L(\varnothing^*) = \{\varepsilon\}$ and $L(\mathtt{0}+\varnothing) = \{\mathtt{0}\}$.

> [!trap] The star case: the hypothesis covers $S$, not $S^*$
> In the case $R = S^*$, the expression $S^*$ *is* $R$, so the hypothesis says nothing about it. Unrolling $L(S^*) = \{\varepsilon\}\cup L(S)\bullet L(S^*)$ and then "applying the hypothesis to $S^*$" is circular. When the star case needs real work, use what the hypothesis gives about $S$, plus a second induction on the number of pieces: every string in $L(S)^*$ is $x_1x_2\cdots x_k$ with each $x_i\in L(S)$.

## 2.7 Proofs about regular languages

A language is just a set: it has no recursive structure to induct on, and "smaller" means nothing useful — a subset of a regular language need not even be regular ($\{\mathtt{0}^n\mathtt{1}^n\mid n\ge0\}\subseteq(\mathtt{0}+\mathtt{1})^*$). So to prove that **every regular language** has a property, let $L$ be regular, choose a regular expression $R$ with $L(R) = L$ (one exists by definition), and prove the property by induction on $R$.

> [!key] Lemma 2.5
> Every regular language other than $\varnothing$ is the language of some regular expression that does not use the symbol $\varnothing$.

> [!proof]- Proof (click to expand)
> A structural induction proves a claim about *every* regular expression, and the subexpressions of an expression with a non-empty language can have empty languages (the $\varnothing$ in $\mathtt{0}+\varnothing$). So state the claim in a form that holds for all of them: for every regular expression $R$, *either $L(R) = \varnothing$, or $L(R) = L(R')$ for some regular expression $R'$ that does not use $\varnothing$.* Assume the claim for every proper subexpression of $R$.
> - **$R = \varnothing$:** $L(R) = \varnothing$.
> - **$R$ is a string:** $R' = R$ itself.
> - **$R = S+T$:** if $L(S)$ and $L(T)$ are both empty, so is $L(R)$. If only $L(T)$ is empty, then $L(R) = L(S) = L(S')$ for the $\varnothing$-free $S'$ given by the hypothesis; symmetrically if only $L(S)$ is empty. If neither is empty, $R' = S'+T'$.
> - **$R = ST$:** if $L(S)$ or $L(T)$ is empty, then $L(R) = \varnothing$ by Lemma 2.1(c). Otherwise $R' = S'T'$.
> - **$R = S^*$:** if $L(S) = \varnothing$, then $L(R) = \varnothing^* = \{\varepsilon\}$, so $R' = \varepsilon$. Otherwise $R' = (S')^*$.
>
> For a non-empty regular language $L = L(R)$, the first alternative is impossible, so $R'$ is the expression the lemma asks for. For example, $\varnothing^*$ becomes $\varepsilon$, $(\mathtt{0}+\varnothing)\mathtt{1}$ becomes $\mathtt{01}$, and $\mathtt{0}\varnothing+\mathtt{1}^*$ becomes $\mathtt{1}^*$. $\blacksquare$

Stating the claim so that it covers every object the hypothesis will be applied to — here every subexpression, even one with an empty language — is the same move as quantifying over all arguments in [[1-models-of-computation/01-strings#14-more-than-one-path-up-the-mountain|§1.4]], or proving a claim for every state of a DFA in [[1-models-of-computation/03-finite-state-machines#33-proving-a-dfa-correct|§3.3]].

> [!example] Structural recursion builds new expressions — reversal
> Define $\textsf{rev}(R)$ by recursion on $R$: $\textsf{rev}(\varnothing) := \varnothing$, $\textsf{rev}(w) := w^R$, $\textsf{rev}(S+T) := \textsf{rev}(S)+\textsf{rev}(T)$, $\textsf{rev}(ST) := \textsf{rev}(T)\,\textsf{rev}(S)$ (order swapped), and $\textsf{rev}(S^*) := \textsf{rev}(S)^*$. A structural induction, using $(xy)^R = y^Rx^R$ from [[1-models-of-computation/01-strings#more-recursive-functions|Chapter 1]], proves $L(\textsf{rev}(R)) = \{w^R \mid w\in L(R)\}$. So the reversal of every regular language is regular. For example, $\textsf{rev}\big(\mathtt{0}+\mathtt{1}(\mathtt{0}+\mathtt{1})^*\mathtt{00}\big) = \mathtt{0}+\mathtt{00}(\mathtt{0}+\mathtt{1})^*\mathtt{1}$.

This is one of two standard ways to prove that a transformed language is regular; the other modifies a DFA ([[1-models-of-computation/04-nondeterministic-automata#49-regular-language-transformations|§4.9]], [[concepts/language-transformations]]).

## 2.8 Not every language is regular

A counting argument shows that regular languages are rare, without exhibiting a single non-regular one. Work over the one-symbol alphabet $\{\mathtt{1}\}$.

- **Countably many regular languages.** A regular expression over $\{\mathtt{1}\}$ is a string over the seven symbols $\mathtt{1}$, $+$, $($, $)$, $^*$, $\varepsilon$, $\varnothing$. Read these symbols as the digits 1 to 7 and the expression as a base-8 numeral: different expressions get different positive integers. So the regular expressions, and therefore the regular languages, can be listed in a sequence.
- **Uncountably many languages.** Write each real number $0\le\alpha<1$ in binary as $\alpha = 0.b_1b_2b_3\ldots$ (never ending in infinitely many 1s), and let $L_\alpha := \{\mathtt{1}^n \mid b_{n+1} = 1\}$. Different reals have different expansions, so different $\alpha$ give different languages — and there are uncountably many reals in $[0,1)$.

So all but countably many languages over $\{\mathtt{1}\}$ are not regular. The same argument works for context-free grammars ([[1-models-of-computation/05-context-free-languages#56-not-every-language-is-context-free|§5.6]]) and for Turing machines (Chapter 7). A specific non-regular language needs a specific proof: the fooling sets of [[1-models-of-computation/03-finite-state-machines#38-proving-a-language-is-not-regular|§3.8]]. One curious example: the set of all regular expressions over $\{\mathtt{0},\mathtt{1}\}$ is itself a non-regular language, because its parentheses must balance — the prefixes $(^i$ and $(^j$ are distinguished by the suffix $\mathtt{0})^i$.

## Summary

- A language is any set of strings; $\varnothing$ (no strings), $\{\varepsilon\}$ (one string) and $\varepsilon$ (a string) are three different things.
- $AB$, $L^*$ and $L^+$ build new languages. Lemmas 2.1–2.2 are their algebra; concatenation is not commutative and does not distribute over $\cap$.
- Arden's rule: if $\varepsilon\notin A$, then $L = AL\cup B$ if and only if $L = A^*B$ — enough to turn a small DFA into an expression.
- Regular languages are built from $\varnothing$ and single strings by ${\cup}$, ${\bullet}$ and ${}^*$; regular expressions write them down, with precedence $^*$, then concatenation, then $+$.
- Design expressions by cutting strings into blocks; explain every piece in English; test $\varepsilon$ and short strings in both directions.
- An expression is really a tree; subexpressions are subtrees, not arbitrary well-formed substrings.
- Structural induction has five cases ($\varnothing$, string, $S+T$, $ST$, $S^*$); the claim must hold for every subexpression, even one with an empty language (Lemma 2.5). Prove facts about regular languages through an expression that represents them.
- There are countably many regular languages but uncountably many languages.
