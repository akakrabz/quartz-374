> [!abstract] In one breath
> An NFA may have several transitions — or none — for the same state and symbol, and may move without reading anything ($\varepsilon$-transitions); it accepts a string if **some** sequence of choices ends in an accepting state. NFAs are no more powerful than DFAs: a DFA can track the *set* of states the NFA might be in (the **subset construction**), at a cost of up to $2^n$ states that is sometimes unavoidable. NFAs make **Kleene's theorem** easy to prove: Thompson's algorithm turns a regular expression into an NFA by gluing small gadgets with $\varepsilon$-transitions, and state elimination turns any NFA back into an expression. Above all, NFAs are the tool for proving that **transformed languages** are regular: start from a DFA for $L$ and let an NFA guess whatever it cannot know. Reversal (Lemma 4.4) and $\textsf{half}(L)$ (Lemma 4.5) are the models, and Midterm-1-style exams devote a whole problem to such constructions.

## 4.1 Nondeterministic state machines

A DFA has exactly one transition for each state and symbol. An **NFA** drops that rule: a state may have several transitions on the same symbol, or none at all. The book's first example accepts the strings that contain `00` or `11`:

On input `0110` the walk $s\xrightarrow{\mathtt{0}}s\xrightarrow{\mathtt{1}}b\xrightarrow{\mathtt{1}}c\xrightarrow{\mathtt{0}}c$ ends in the accepting state $c$, so `0110` is accepted. It does not matter that other walks end elsewhere or get stuck — $s\xrightarrow{\mathtt{0}}a$ is stuck at once, because $a$ has no transition on `1`. In general, if the input contains `00`, some walk waits in $s$ until the first `0` of the pair and then moves to $a$ and $c$; if it contains neither `00` nor `11`, a walk that moves to $a$ or $b$ gets stuck on the next symbol (if there is one), and no walk reaches $c$.

> [!definition] Definition — NFA
> A **nondeterministic finite-state automaton** is a tuple $M = (\Sigma, Q, s, A, \delta)$ exactly like a DFA, except that the transition function returns a **set** of states, possibly empty: $\delta\colon Q\times\Sigma\to 2^Q$, where $2^Q$ is the set of all subsets of $Q$. The extended transition function $\delta^*\colon Q\times\Sigma^*\to 2^Q$ collects the ends of all walks labeled $w$:
> $$
> \delta^*(q, w) := \begin{cases} \{q\} & \text{if } w = \varepsilon\\ \displaystyle\bigcup_{r\in\delta(q,a)}\delta^*(r, x) & \text{if } w = ax.\end{cases}
> $$
> $M$ **accepts** $w$ iff $\delta^*(s,w)\cap A\ne\varnothing$ — iff **some** walk from $s$ labeled $w$ ends in an accepting state. Its language $L(M)$ is the set of strings it accepts.

Every DFA is an NFA: replace $\delta(q,a)$ by the one-element set $\{\delta(q,a)\}$. So NFAs accept every regular language; §4.5 shows that they accept nothing else.

**Running an NFA by hand.** Keep the set $C$ of states the machine could be in. Start with $C = \{s\}$; reading $a$ replaces $C$ by $\delta(C,a) := \bigcup_{q\in C}\delta(q,a)$; accept iff the final set contains an accepting state. After reading $w$, $C$ is exactly $\delta^*(s,w)$.

| $i$ | prefix of `10010` | $C$ | prefix of `0101` | $C$ |
|---|---|---|---|---|
| 0 | $\varepsilon$ | $\{s\}$ | $\varepsilon$ | $\{s\}$ |
| 1 | `1` | $\{s,b\}$ | `0` | $\{s,a\}$ |
| 2 | `10` | $\{s,a\}$ | `01` | $\{s,b\}$ |
| 3 | `100` | $\{s,a,c\}$ | `010` | $\{s,a\}$ |
| 4 | `1001` | $\{s,b,c\}$ | `0101` | $\{s,b\}$ |
| 5 | `10010` | $\{s,a,c\}$ | | |

On the second symbol of `10010` the walk in $b$ dies, because $\delta(b,\mathtt{0}) = \varnothing$, while $s$ starts a new one in $a$; the third symbol takes that walk to $c$, where it stays. So `10010` is accepted. On `0101` no walk ever reaches $c$, because a walk that moves to $a$ or $b$ dies on the next symbol; the final set $\{s,b\}$ contains no accepting state, so `0101` is rejected.

> [!trap] "Some walk", not "every walk" — and swapping does not complement
> - An NFA accepts $w$ if **at least one** walk labeled $w$ ends in $A$. It rejects $w$ only if **every** walk fails, by ending outside $A$ or by getting stuck; a string with no complete walk at all is rejected.
> - Exchanging the accepting and non-accepting states does **not** complement an NFA. With $A = \{s,a,b\}$ the machine above accepts *every* string, because the walk that never leaves $s$ always exists. To complement an NFA, convert it to a DFA first (§4.5), then swap.

## 4.2 Intuition

Nobody builds a nondeterministic machine; nondeterminism is a compact way to describe a search. Three equivalent pictures help:

> [!intuition] Three ways to think about nondeterminism
> - **Clairvoyance.** At every choice the machine magically picks a transition that leads to acceptance, if there is one. It still cannot accept a string that has no accepting walk.
> - **Parallel threads.** Every choice spawns a new thread; a thread with no transition dies; the machine accepts if some thread is in an accepting state when the input ends. The set $C$ of §4.1 is the set of states of the living threads.
> - **Proofs.** A prover who knows the input supplies the choices, and the machine only *verifies* them: every step must be a legal transition, and the last state must be accepting. $w\in L(M)$ iff a valid proof for $w$ exists.

The third picture can be made formal. A proof for $w = a_1a_2\cdots a_n$ is the sequence of states $\omega = r_1r_2\cdots r_n$ that an accepting walk visits after $s$, and checking it is a job for a DFA over the alphabet $\Sigma\times Q$ of pairs. This DFA starts in $s$, accepts in $A$, and from state $q$ the pair $(a,r)$ leads to $r$ if $r\in\delta(q,a)$ and to a dump state otherwise. Then $M$ accepts $w$ iff some $\omega\in Q^{\lvert w\rvert}$ makes this DFA accept $(a_1,r_1)(a_2,r_2)\cdots(a_n,r_n)$. For the machine of §4.1, the proof for `0110` is $\omega = s\,b\,c\,c$.

Guessing is the design tool of this chapter. The NFA of §4.1 guesses where the pair begins; the machines of §4.9 guess a state of another machine, or the symbols of a string they never see. Wrong guesses cost nothing, because only one thread has to succeed. The same three pictures return for Turing machines in [[1-models-of-computation/09-nondeterministic-turing-machines#95-nondeterminism-as-advice|§9.5]].

## 4.3 Epsilon-transitions

An **$\varepsilon$-transition** $p\xrightarrow{\varepsilon}q$ lets the machine move from $p$ to $q$ without reading anything. Now $\delta\colon Q\times(\Sigma\cup\{\varepsilon\})\to 2^Q$, and $M$ accepts $w$ iff there is a walk $s = q_0\xrightarrow{a_1}q_1\xrightarrow{a_2}\cdots\xrightarrow{a_\ell}q_\ell$ with $q_\ell\in A$, every $a_i\in\Sigma\cup\{\varepsilon\}$, and $a_1a_2\cdots a_\ell = w$: the $\varepsilon$'s vanish from the label.

> [!definition] Definition — $\varepsilon$-reach, and $\delta^*$ with $\varepsilon$-transitions
> The **$\varepsilon$-reach** of a state $q$ is the set of states reachable from $q$ by zero or more $\varepsilon$-transitions: it contains $q$, and with every state $r$ it contains every state of $\delta(r,\varepsilon)$. For a set $S$ of states, $\varepsilon\text{-reach}(S) := \bigcup_{q\in S}\varepsilon\text{-reach}(q)$. The extended transition function takes the $\varepsilon$-reach before every symbol and at the end:
> $$
> \delta^*(p, w) := \begin{cases} \varepsilon\text{-reach}(p) & \text{if } w = \varepsilon\\ \displaystyle\bigcup_{r\in\varepsilon\text{-reach}(p)}\ \bigcup_{q\in\delta(r,a)}\delta^*(q, x) & \text{if } w = ax,\end{cases}
> $$
> and $M$ accepts $w$ iff $\delta^*(s,w)\cap A\ne\varnothing$.

By hand: start with $C = \varepsilon\text{-reach}(\{s\})$ instead of $\{s\}$, and after each symbol $a$ replace $C$ by $\varepsilon\text{-reach}\big(\delta(C,a)\big)$.

**Example.** The NFA $E$ has states $p$ (start), $q$ and $r$ (accepting); it loops on `0` at $p$, on `1` at $q$ and on `0` at $r$, and has the $\varepsilon$-transitions $p\xrightarrow{\varepsilon}q\xrightarrow{\varepsilon}r$. It reads some 0s, then some 1s, then some 0s: $L(E) = \mathtt{0}^*\mathtt{1}^*\mathtt{0}^*$, the strings whose 1s form a single block. Here $\varepsilon\text{-reach}(p) = \{p,q,r\}$ needs two steps. On `0010` the sets are $\{p,q,r\}$, $\{p,q,r\}$, $\{p,q,r\}$, $\{q,r\}$, $\{r\}$ — accepted; on `01010` the set becomes $\varnothing$ at the second `1`.

**Removing $\varepsilon$-transitions.** An $\varepsilon$-move can always be merged into the symbol transition that follows it, or into the acceptance test if no symbol follows — without new states.

> [!definition] Definition — $\varepsilon$-removal
> Given an NFA $M = (\Sigma, Q, s, A, \delta)$ with $\varepsilon$-transitions, let $M' = (\Sigma, Q, s, A', \delta')$, with the same states and start state and
> $$
> A' := \{q\in Q \mid \varepsilon\text{-reach}(q)\cap A\ne\varnothing\},\qquad \delta'(q,a) := \bigcup_{r\in\varepsilon\text{-reach}(q)}\delta(r,a).
> $$
> Then $M'$ has no $\varepsilon$-transitions, and $L(M') = L(M)$.

For $E$, before and after:

| state | $\delta(\cdot,\mathtt{0})$ | $\delta(\cdot,\mathtt{1})$ | $\delta(\cdot,\varepsilon)$ | $\varepsilon$-reach | $\delta'(\cdot,\mathtt{0})$ | $\delta'(\cdot,\mathtt{1})$ | in $A'$? |
|---|---|---|---|---|---|---|---|
| → $p$ | $\{p\}$ | $\varnothing$ | $\{q\}$ | $\{p,q,r\}$ | $\{p,r\}$ | $\{q\}$ | yes |
| $q$ | $\varnothing$ | $\{q\}$ | $\{r\}$ | $\{q,r\}$ | $\{r\}$ | $\{q\}$ | yes |
| $r$ \* | $\{r\}$ | $\varnothing$ | $\varnothing$ | $\{r\}$ | $\{r\}$ | $\varnothing$ | yes |

The new edges $p\xrightarrow{\mathtt{1}}q$, $p\xrightarrow{\mathtt{0}}r$ and $q\xrightarrow{\mathtt{0}}r$ absorb $\varepsilon$-moves, and $p$ and $q$ become accepting because they reach $r$ by $\varepsilon$-moves alone. So $\varepsilon$-transitions are a pure convenience: allow or forbid them, whichever makes a construction easier.

> [!proof]- Why $\varepsilon$-removal is correct (click to expand)
> Write $(\delta')^*$ for the extended transition function of $M'$, which has no $\varepsilon$-moves. Claim: $\varepsilon\text{-reach}\big((\delta')^*(q,w)\big) = \delta^*(q,w)$ for **every** state $q$ and string $w$. Induct on $w$. For $w = \varepsilon$ both sides are $\varepsilon\text{-reach}(q)$. For $w = ax$,
> $$
> \begin{aligned}
> \varepsilon\text{-reach}\big((\delta')^*(q,ax)\big) &= \bigcup_{q'\in\delta'(q,a)}\varepsilon\text{-reach}\big((\delta')^*(q',x)\big)\\
> &= \bigcup_{r\in\varepsilon\text{-reach}(q)}\ \bigcup_{q'\in\delta(r,a)}\delta^*(q',x) \;=\; \delta^*(q,ax),
> \end{aligned}
> $$
> by the definition of $(\delta')^*$, then the induction hypothesis for $x$ together with the definition of $\delta'$, then the definition of $\delta^*$. Finally, $(\delta')^*(s,w)$ contains a state of $A'$ iff its $\varepsilon$-reach meets $A$, iff $\delta^*(s,w)$ meets $A$. $\blacksquare$

> [!trap] Where $\varepsilon$-moves bite
> - $\varepsilon\text{-reach}(q)$ always contains $q$ itself, and it follows **chains** of $\varepsilon$-moves ($p\to q\to r$ above), not just single edges.
> - $\varepsilon$-moves count before the first symbol and after the last one: whether $M$ accepts $\varepsilon$ depends on $\varepsilon\text{-reach}(s)$, not on $s$ alone.
> - After removing the $\varepsilon$-moves, every state whose $\varepsilon$-reach meets $A$ must become accepting. Keeping $A' = A = \{r\}$ above would reject $\varepsilon$, `1` and `01`.

## 4.4 Kleene's theorem

> [!key] Theorem 4.1 (Kleene)
> For every regular expression $R$ there is a DFA $M$ with $L(M) = L(R)$, and for every DFA $M$ there is a regular expression $R$ with $L(R) = L(M)$. Consequently a language is regular if and only if some DFA accepts it — equivalently, some NFA, with or without $\varepsilon$-transitions.

This is Theorem 3.3 of [[1-models-of-computation/03-finite-state-machines#37-closure-properties|§3.7]]. With NFAs as the intermediate model, every step of the proof is a short construction, and following the arrows turns any description into any other:

## 4.5 NFA to DFA: the subset construction

Running an NFA by hand was already deterministic: the set of current states is determined by the input read so far, and there are only finitely many sets. Make those sets the states of a DFA.

> [!definition] Definition — subset construction
> For an NFA $M = (\Sigma, Q, s, A, \delta)$, possibly with $\varepsilon$-transitions, define the DFA $M' = (\Sigma, Q', s', A', \delta')$ by
> $$
> Q' := 2^Q,\qquad s' := \{s\},\qquad A' := \{S\subseteq Q \mid \varepsilon\text{-reach}(S)\cap A\ne\varnothing\},
> $$
> $$
> \delta'(S, a) := \bigcup_{p\in S}\ \bigcup_{r\in\varepsilon\text{-reach}(p)}\delta(r,a).
> $$
> Without $\varepsilon$-transitions this is simply $A' = \{S \mid S\cap A\ne\varnothing\}$ and $\delta'(S,a) = \bigcup_{p\in S}\delta(p,a)$.

A DFA state is the set $S$ itself; its $\varepsilon$-reach is computed when needed, for the acceptance test and for the transitions.

> [!proof]- Why it works (click to expand)
> Claim: $\varepsilon\text{-reach}\big((\delta')^*(S,w)\big) = \bigcup_{p\in S}\delta^*(p,w)$ for **every** set $S$ and string $w$. Induct on $w$. For $w = \varepsilon$ both sides are $\varepsilon\text{-reach}(S)$. For $w = ax$, $(\delta')^*(S,ax) = (\delta')^*\big(\delta'(S,a),x\big)$; the induction hypothesis turns the $\varepsilon$-reach of this set into $\bigcup_{q\in\delta'(S,a)}\delta^*(q,x)$, which equals $\bigcup_{p\in S}\delta^*(p,ax)$ by the definitions of $\delta'$ and $\delta^*$. With $S = \{s\}$: $M'$ accepts $w$ iff $\varepsilon\text{-reach}\big((\delta')^*(\{s\},w)\big)$ meets $A$, iff $\delta^*(s,w)$ meets $A$, iff $M$ accepts $w$. $\blacksquare$

Most of the $2^{\lvert Q\rvert}$ subsets can never occur, so build only the ones that can, breadth-first from $\{s\}$:

> [!recipe] Recipe — the incremental subset construction
> Keep a table with one row per DFA state and the columns $S$, $\varepsilon\text{-reach}(S)$, accepting?, and $\delta'(S,a)$ for each symbol $a$.
> 1. Start with the single row $\{s\}$.
> 2. In each row, first compute $\varepsilon\text{-reach}(S)$. The row is accepting iff that set contains an accepting state. For each symbol $a$, $\delta'(S,a)$ collects $\delta(r,a)$ for every $r\in\varepsilon\text{-reach}(S)$.
> 3. Every set that appears in a transition column for the first time gets a row of its own — $\varnothing$ included; it is the dump state.
> 4. Stop when every set in the transition columns has a row. The rows are the states of the DFA.
>
> The classic slips: deciding acceptance from $S$ instead of its $\varepsilon$-reach, reading a symbol before sliding along the $\varepsilon$-moves, dropping the row $\varnothing$, and listing all $2^{\lvert Q\rvert}$ subsets instead of the reachable ones.

For the NFA $E$ of §4.3, with $L(E) = \mathtt{0}^*\mathtt{1}^*\mathtt{0}^*$:

| $S$ | $\varepsilon\text{-reach}(S)$ | accepting? | $\delta'(S,\mathtt{0})$ | $\delta'(S,\mathtt{1})$ | the strings that reach $S$ |
|---|---|---|---|---|---|
| → $\{p\}$ | $\{p,q,r\}$ | yes | $\{p,r\}$ | $\{q\}$ | only $\varepsilon$ |
| $\{p,r\}$ | $\{p,q,r\}$ | yes | $\{p,r\}$ | $\{q\}$ | $\mathtt{0}\mathtt{0}^*$ |
| $\{q\}$ | $\{q,r\}$ | yes | $\{r\}$ | $\{q\}$ | $\mathtt{0}^*\mathtt{1}\mathtt{1}^*$ |
| $\{r\}$ | $\{r\}$ | yes | $\{r\}$ | $\varnothing$ | $\mathtt{0}^*\mathtt{1}\mathtt{1}^*\mathtt{0}\mathtt{0}^*$ |
| $\varnothing$ | $\varnothing$ | no | $\varnothing$ | $\varnothing$ | every string not in $L(E)$ |

Five of the $2^3 = 8$ subsets are reachable. The rows $\{p\}$ and $\{p,r\}$ have the same $\varepsilon$-reach and therefore identical transitions: they are equivalent, and merging them gives the minimal DFA, with 4 states. The construction is correct, but it does not promise a minimal result. The NFA of §4.1 behaves the same way: 5 of its 16 subsets are reachable — $\{s\}$, $\{s,a\}$, $\{s,b\}$, $\{s,a,c\}$, $\{s,b,c\}$ — and the two accepting ones merge, leaving 4 states.

### The price: exponentially many states

A DFA may need exponentially more states than an NFA for the same language — the subset construction is not just being careless.

> [!key] Exponential blow-up
> For $k\ge1$ let $L_k := (\mathtt{0}+\mathtt{1})^*\mathtt{1}(\mathtt{0}+\mathtt{1})^{k-1}$ be the set of binary strings whose $k$th symbol from the end is `1`, where $(\mathtt{0}+\mathtt{1})^{k-1}$ abbreviates $k-1$ copies of $(\mathtt{0}+\mathtt{1})$. Some NFA with $k+1$ states accepts $L_k$, but every DFA for $L_k$ has at least $2^k$ states.

The NFA has states $0, 1, \dots, k$: state $0$ (the start) loops on both symbols and also moves to $1$ on a `1` — the guess "this `1` is the $k$th symbol from the end" — each state $i$ with $1\le i<k$ moves to $i+1$ on either symbol, and only $k$ accepts. A DFA cannot guess; it has to remember the last $k$ symbols.

> [!proof]- Proof of the lower bound, by a fooling set (click to expand)
> Let $F := \{\mathtt{0},\mathtt{1}\}^k$, the $2^k$ strings of length $k$. Let $x\ne y$ be arbitrary strings in $F$, let $i$ be a position with $x_i\ne y_i$, and let $z := \mathtt{0}^{i-1}$. The string $xz$ has length $k+i-1$, so its $k$th symbol from the end is its $i$th symbol, $x_i$; likewise the $k$th symbol from the end of $yz$ is $y_i$. Exactly one of $x_i$, $y_i$ is `1`, so exactly one of $xz$, $yz$ is in $L_k$. Hence $F$ is a fooling set of size $2^k$, and every DFA for $L_k$ has at least $2^k$ states ([[1-models-of-computation/03-finite-state-machines#38-proving-a-language-is-not-regular|§3.8]]). $\blacksquare$

On this NFA the subset construction builds exactly $2^k$ states — every subset that contains state $0$ — and the lower bound says that none of them is redundant. Most NFAs are much kinder: §4.6 turns a 14-state NFA into 5 DFA states, not $2^{14}$.

## 4.6 Regular expression to NFA: Thompson's algorithm

> [!key] Lemma 4.2
> Every regular language is accepted by an NFA — in fact by an NFA with exactly one accepting state, which is different from its start state.

The proof is an algorithm due to Ken Thompson (1968): build the NFA bottom-up along the expression tree ([[1-models-of-computation/02-regular-languages#25-regular-expression-trees|§2.5]]), with a two-state gadget for each leaf and $\varepsilon$-transitions as glue. The single accepting state $t\ne s$ is what makes the gluing easy, and it is exactly what the induction has to maintain.

> [!proof]- Proof (click to expand)
> Let $R$ be a regular expression for the language, and assume that every proper subexpression of $R$ has an NFA with one accepting state, different from its start state. There are six cases.
> - $R = \varnothing$: two states $s\ne t$, no transitions. $R = \varepsilon$: $s\xrightarrow{\varepsilon}t$. $R = a$ for a symbol $a$: $s\xrightarrow{a}t$. (A longer string is a concatenation of symbols.)
> - $R = S+T$: new states $s$ and $t$, and the $\varepsilon$-transitions $s\to s_S$, $s\to s_T$, $t_S\to t$, $t_T\to t$.
> - $R = ST$: the $\varepsilon$-transition $t_S\to s_T$; the start state is $s_S$ and the accepting state is $t_T$.
> - $R = S^*$: new states $s$ and $t$, and the $\varepsilon$-transitions $s\to s_S$, $t_S\to t$, $s\to t$ (zero copies of $S$) and $t\to s$ (one more copy).
>
> The old start and accepting states lose their roles, and new edges enter each old machine only at its start state and leave it only from its accepting state. So the walks from the new $s$ to the new $t$ spell exactly the strings of $L(R)$. $\blacksquare$

Many textbooks close the loop of $S^*$ from $t_S$ back to $s_S$ instead of from $t$ back to $s$; that version is just as correct, and it changes only some of the $\varepsilon$-reaches in the table below. Either way the algorithm creates two states for each leaf, each $+$ and each $^*$, and none for a concatenation: the NFA has at most twice as many states as the expression has symbols and operators.

> [!trap] Do not "optimize" the gadgets
> Two tempting shortcuts, both from the book's exercises, break the construction:
> - Identifying $t_S$ with $s_T$ for $ST$, instead of joining them with an $\varepsilon$-edge: for $\mathtt{0}^*\mathtt{1}^*$ the result accepts `10`, because the loop of $\mathtt{1}^*$ now returns to a state from which the loop of $\mathtt{0}^*$ can be re-entered.
> - Building $S^*$ without new states, by adding $\varepsilon$-edges $s_S\to t_S$ and $t_S\to s_S$: for $(\mathtt{0}^*\mathtt{1})^*$ the result accepts `0`, by jumping from the middle of $S$ straight to its accepting state.
>
> Both break because the shortcut lets a walk leave a gadget in the middle, or come back into it. A larger correct NFA loses nothing.

## 4.7 Another example

The book runs the whole pipeline again on $(\mathtt{0}+\mathtt{1})^*(\mathtt{00}+\mathtt{11})(\mathtt{0}+\mathtt{1})^*$, which describes the same language as the NFA of §4.1: the strings that contain `00` or `11`.

- **Thompson's algorithm** creates 2 states for each of the 8 symbols, 3 unions and 2 stars: **26 states**, named $a$ to $z$ in the book's figure and table (start state $s$). The book's text calls it an "18-state monster" — the count you get by drawing each $\mathtt{0}+\mathtt{1}$ as one two-state gadget with an edge per symbol.
- **The incremental subset construction** finds a **9-state DFA** with **6 accepting states**.
- **Minimization** merges the six accepting states, which all mean "`00` or `11` has appeared": **4 states**.

| $S$ | accepting? | $\delta'(S,\mathtt{0})$ | $\delta'(S,\mathtt{1})$ | the strings that reach $S$ |
|---|---|---|---|---|
| → $\{s\}$ | no | $\{c,j\}$ | $\{e,n\}$ | only $\varepsilon$ |
| $\{c,j\}$ | no | $\{c,j,l\}$ | $\{e,n\}$ | no pair yet, last symbol `0` |
| $\{e,n\}$ | no | $\{c,j\}$ | $\{e,n,p\}$ | no pair yet, last symbol `1` |
| $\{c,j,l\}$ | yes | $\{c,j,l,v\}$ | $\{e,n,x\}$ | the first pair, `00`, ends here |
| $\{e,n,p\}$ | yes | $\{c,j,v\}$ | $\{e,n,p,x\}$ | the first pair, `11`, ends here |
| $\{c,j,l,v\}$ | yes | $\{c,j,l,v\}$ | $\{e,n,x\}$ | a pair before the last symbol; ends in `00` |
| $\{e,n,x\}$ | yes | $\{c,j,v\}$ | $\{e,n,p,x\}$ | a pair before the last symbol; ends in `01` |
| $\{c,j,v\}$ | yes | $\{c,j,l,v\}$ | $\{e,n,x\}$ | a pair before the last symbol; ends in `10` |
| $\{e,n,p,x\}$ | yes | $\{c,j,v\}$ | $\{e,n,p,x\}$ | a pair before the last symbol; ends in `11` |

In the NFA, $c$ and $e$ are the states entered by a `0` or a `1` in the first $(\mathtt{0}+\mathtt{1})^*$, $j$ and $l$ those entered by the two 0s of $\mathtt{00}$, $n$ and $p$ by the two 1s of $\mathtt{11}$, and $v$ and $x$ by a `0` or a `1` in the last $(\mathtt{0}+\mathtt{1})^*$. The lesson: every conversion works, and none promises a small result. Thompson plus subsets produced 9 states where 4 suffice — and the hand-made NFA of §4.1 needs only 4.

## 4.8 NFA to regular expression: state elimination

The last arrow turns an automaton back into an expression. Label the edges with regular expressions, then remove the states one at a time, recording on the remaining edges every detour through the removed state. The book credits this formulation to McNaughton and Yamada (1960) — C. Y. Lee published a similar one the same year — as a modern version of Kleene's own 1951 argument; you may also meet it as Han and Wood's algorithm.

> [!definition] Definition — expression automaton
> An **expression automaton** has a start state $s$ with no incoming edges, a target state $t\ne s$ with no outgoing edges, and a regular expression $R(p\to q)$ on every edge from a state $p\ne t$ to a state $q\ne s$; a missing edge has label $\varnothing$. It accepts $w$ iff $w = x_1x_2\cdots x_\ell$ for some walk $s = q_0\to q_1\to\cdots\to q_\ell = t$ with $x_i\in L\big(R(q_{i-1}\to q_i)\big)$ for every $i$.

Every NFA becomes an expression automaton: add a new start state with an $\varepsilon$-edge to the old one, a new target with an $\varepsilon$-edge from each old accepting state, and merge parallel edges with $+$. (An old start state without incoming edges can serve as $s$ itself.)

> [!key] Lemma 4.3
> Every expression automaton accepts a regular language.

> [!proof]- Proof (click to expand)
> Induction on the number of states. If $Q = \{s,t\}$, the automaton accepts $L\big(R(s\to t)\big)$. Otherwise choose any state $q\notin\{s,t\}$, delete it, and for every remaining pair $p\ne t$, $r\ne s$ — including $p = r$ — set
> $$
> R'(p\to r) := R(p\to r) + R(p\to q)\,R(q\to q)^*\,R(q\to r).
> $$
> An accepting walk of the old automaton visits $q$ in maximal runs. Each run is entered from some $p\ne q$ and left to some $r\ne q$ (neither $s$ nor $t$ is $q$), and the part of the input it reads matches $R(p\to q)R(q\to q)^*R(q\to r)$; replacing every run by the new edge $p\to r$ gives an accepting walk of the new automaton for the same string. Conversely, every new edge expands back into the old edge or a run through $q$. So the language does not change, the automaton has one state fewer, and the induction hypothesis applies. $\blacksquare$

> [!recipe] Recipe — state elimination by hand
> 1. Add the new $s$ and $t$ (unless the old ones already qualify), and merge parallel edges with $+$.
> 2. Eliminate the other states one at a time, in any order. For each eliminated $q$, list its predecessors and successors and update **every** pair $p$, $r$ — including $p = r$, which changes a loop.
> 3. Simplify only with identities you can name: $\varnothing$ terms vanish, $\varepsilon R = R$, $\varnothing^* = \varepsilon$.
> 4. The answer is $R(s\to t)$. Test $\varepsilon$ and a few short strings before you trust it.

**Example: binary multiples of 3.** The book's DFA has states $0$, $1$, $2$ — the remainder mod 3 of the number read so far, with $\delta(q,a) = (2q+a)\bmod 3$ — plus a separate start state $s$ that behaves like $0$ but does not accept, so that the empty string is rejected:

| state | `0` | `1` |
|---|---|---|
| → $s$ | $0$ | $1$ |
| $0$ \* | $0$ | $1$ |
| $1$ | $2$ | $0$ |
| $2$ | $1$ | $2$ |

No edge enters $s$, so it can serve as the start of the expression automaton; add a target $t$ with $0\xrightarrow{\varepsilon}t$. Then eliminate $2$, $0$ and $1$:

| step | eliminate | its loop | new labels |
|---|---|---|---|
| 1 | $2$ | $\mathtt{1}$ | $R(1\to1) = \mathtt{01}^*\mathtt{0}$ |
| 2 | $0$ | $\mathtt{0}$ | $R(s\to1) = \mathtt{1}+\mathtt{00}^*\mathtt{1}$, $R(s\to t) = \mathtt{00}^*$, $R(1\to1) = \mathtt{01}^*\mathtt{0}+\mathtt{10}^*\mathtt{1}$, $R(1\to t) = \mathtt{10}^*$ |
| 3 | $1$ | $\mathtt{01}^*\mathtt{0}+\mathtt{10}^*\mathtt{1}$ | $R(s\to t) = \mathtt{00}^*+(\mathtt{1}+\mathtt{00}^*\mathtt{1})(\mathtt{01}^*\mathtt{0}+\mathtt{10}^*\mathtt{1})^*\mathtt{10}^*$ |

The result is the book's $\mathtt{00}^*+(\mathtt{00}^*\mathtt{1}+\mathtt{1})(\mathtt{10}^*\mathtt{1}+\mathtt{01}^*\mathtt{0})^*\mathtt{10}^*$ with the terms of two unions swapped. Since $\mathtt{00}^* = \mathtt{0}^*\mathtt{0}$ and $\mathtt{1}+\mathtt{00}^*\mathtt{1} = \mathtt{0}^*\mathtt{1}$, it simplifies to the expression of [[1-models-of-computation/02-regular-languages#23-regular-languages-and-regular-expressions|§2.3]],
$$
\mathtt{0}^*\mathtt{0}+\mathtt{0}^*\mathtt{1}(\mathtt{10}^*\mathtt{1}+\mathtt{01}^*\mathtt{0})^*\mathtt{10}^*,
$$
and like it, it describes the **non-empty** binary numerals of multiples of 3, leading 0s allowed.

> [!trap] Mind the empty string
> The 3-state DFA that starts in its accepting state $0$ reads $\varepsilon$ as the number 0, like the mod-5 machine of [[1-models-of-computation/03-finite-state-machines#31-intuition-a-dfa-is-a-loop-with-constant-memory|§3.1]], and accepts it. Eliminating its states (after adding a new start state) gives expressions with $\varepsilon$: the order $2, 0, 1$ yields $\mathtt{0}^*+\mathtt{0}^*\mathtt{1}(\mathtt{01}^*\mathtt{0}+\mathtt{10}^*\mathtt{1})^*\mathtt{10}^*$ — note $\mathtt{0}^*$ where the book has $\mathtt{00}^*$ — and the order $2, 1, 0$ the compact $(\mathtt{0}+\mathtt{1}(\mathtt{01}^*\mathtt{0})^*\mathtt{1})^*$. Both describe $\varepsilon$ plus the language above — and a missing or extra $\varepsilon$ is the typical one-mistake deduction on a graded expression.

**How big?** With $n$ states, state elimination performs $O(n^3)$ operations on expressions, but each new label combines four old ones, so the expressions can grow by a factor of about 4 per eliminated state: length $\Theta(4^n)$ in the worst case. The order matters in practice: on the 4-state DFA above, the six elimination orders give equivalent expressions with between 12 and 31 occurrences of symbols (the order used above gives 14).

## 4.9 Regular language transformations

The most exam-relevant use of NFAs is proving that a language built from $L$ is regular **whenever** $L$ is. There are two ways:

- transform a regular expression for $L$ by structural recursion, as for reversal in [[1-models-of-computation/02-regular-languages#27-proofs-about-regular-languages|§2.7]]; or
- transform a **DFA** for $L$ into an **NFA** for the new language.

The asymmetry is deliberate: a DFA is the easiest input to reason about (exactly one state per prefix), and an NFA with $\varepsilon$-transitions is the most flexible output. Two kinds of transformed language come up, for a function $f$ from strings to strings:

- **Strings whose transform is in $L$**, $\{w \mid f(w)\in L\}$: the new machine reads $w$ and **simulates $M$ on $f(w)$** — often deterministically.
- **Transforms of strings in $L$**, $\{f(w) \mid w\in L\}$: the new machine reads $y$, **guesses a string $w$ with $f(w) = y$**, and simulates $M$ on it. Nondeterministic choices guess symbols that $f$ changed; $\varepsilon$-transitions guess symbols that $f$ deleted.

> [!template] Template — regular language transformation
> Let $M = (\Sigma, Q, s, A, \delta)$ be a DFA that accepts $L$. \
> We construct an NFA $M' = (\Sigma, Q', s', A', \delta')$ with $\varepsilon$-transitions that accepts *[the new language]*. \
> **In English:** $M'$ remembers *[each component of its state, and what it means]*, guesses *[what, and when]*, and accepts when *[…]*. \
> **Formally:** $Q' = $ *[…]*, $s' = $ *[…]*, $A' = $ *[…]*, \
> $\delta'(q', a) = $ *[…]* for every state $q'$ and every symbol $a$, \
> $\delta'(q', \varepsilon) = $ *[…]* for every state $q'$ (write $\varnothing$ where there are none). \
> **Why:** $M'$ can be in state *[…]* after reading $x$ if and only if *[…]*; so it accepts exactly *[the new language]*.

### Reversal

> [!key] Lemma 4.4
> If $L$ is regular, then so is $L^R := \{w^R \mid w\in L\}$.

**Proof 1, by regular expressions.** Reverse an expression recursively: $\textsf{rev}(\varnothing) := \varnothing$, $\textsf{rev}(w) := w^R$ for a string $w$, $\textsf{rev}(S+T) := \textsf{rev}(S)+\textsf{rev}(T)$, $\textsf{rev}(ST) := \textsf{rev}(T)\,\textsf{rev}(S)$ — the order swaps — and $\textsf{rev}(S^*) := \textsf{rev}(S)^*$. A structural induction, using $(xy)^R = y^Rx^R$ from [[1-models-of-computation/01-strings#more-recursive-functions|Chapter 1]], shows $L(\textsf{rev}(R)) = L(R)^R$; §2.7 works an example.

**Proof 2, by automata.** Run $M$ backwards:

> [!example] Proof 2 of Lemma 4.4 — the reversed NFA
> Let $M = (\Sigma, Q, s, A, \delta)$ be a DFA for $L$. Define the NFA $M^R = (\Sigma,\ Q\cup\{s^R\},\ s^R,\ \{s\},\ \delta^R)$, where $s^R$ is a new state and
> $$
> \delta^R(s^R,\varepsilon) := A,\qquad \delta^R(q, a) := \{p\in Q \mid \delta(p,a) = q\}\quad\text{for } q\in Q,\ a\in\Sigma,
> $$
> with no other transitions: $s^R$ has no symbol transitions, and no other state has $\varepsilon$-transitions.
>
> **In English:** $M^R$ follows the edges of $M$ backwards. With its first move it guesses the accepting state in which $M$'s walk on $w$ ends; reading $w^R$, it retraces that walk from the end; and it accepts iff it arrives at $M$'s start state $s$.
>
> **Why:** $M^R$ has a walk from $q$ to $p$ labeled $x^R$ iff $\delta^*(p,x) = q$ (induction on $x$). So $M^R$ accepts $y$ iff $y = w^R$ for some $w$ that leads $M$ from $s$ into $A$ — iff $y\in L^R$. $\blacksquare$

Reversing the edges of a DFA does not give a DFA: a state can have several incoming edges with the same symbol, or none. That is one reason the target of a transformation is an NFA.

### Half of a language

> [!key] Lemma 4.5
> If $L$ is regular, then so is $\textsf{half}(L) := \{w \mid ww\in L\}$.

This is the first kind of transformation, with $f(w) = ww$, but simulating $M$ on $ww$ while reading $w$ only once needs a trick. $M$ processes the second copy of $w$ starting from the state $h := \delta^*(s,w)$ that it reaches in the middle — and $h$ is known only at the end. So guess $h$ at the start, run both halves side by side, and check the guess at the end.

> [!example] Proof of Lemma 4.5 — the model to copy
> Let $M = (\Sigma, Q, s, A, \delta)$ be a DFA that accepts $L$. We construct an NFA $M' = (\Sigma, Q', s', A', \delta')$ with $\varepsilon$-transitions that accepts $\textsf{half}(L)$.
>
> **In English:** $M'$ first guesses the middle state $h$. After that it remembers a triple $(p, h, q)$: $p$ is the state of a copy of $M$ started at $s$, which plays the first copy of $w$; $h$ is the guess, which never changes; and $q$ is the state of a copy of $M$ started at $h$, which plays the second copy. $M'$ accepts iff the first copy has arrived exactly at $h$ — the guess was right — and the second copy is in an accepting state.
>
> **Formally:** $s'$ is a new state, and
> $$
> \begin{aligned}
> Q' &:= \{s'\}\cup(Q\times Q\times Q),\\
> \delta'(s',\varepsilon) &:= \{(s,h,h) \mid h\in Q\},\\
> \delta'\big((p,h,q),a\big) &:= \big\{\big(\delta(p,a),\,h,\,\delta(q,a)\big)\big\}\quad\text{for all } p, h, q\in Q,\ a\in\Sigma,\\
> A' &:= \{(h,h,q) \mid h\in Q,\ q\in A\},
> \end{aligned}
> $$
> with no other transitions.
>
> **Why:** after reading $w$, $M'$ can be in $(p,h,q)$ iff $p = \delta^*(s,w)$ and $q = \delta^*(h,w)$. So $M'$ accepts $w$ iff $\delta^*(s,w) = h$ and $\delta^*(h,w)\in A$ for some $h$ — iff $\delta^*(s,ww) = \delta^*\big(\delta^*(s,w),w\big)\in A$, iff $ww\in L$. $\blacksquare$

$M'$ has $\lvert Q\rvert^3+1$ states, and its only nondeterministic move is the first one.

### Two more examples

> [!example] Strings whose double is in $L$ — a DFA suffices
> Let $\textsf{double}(w)$ repeat every symbol of $w$: $\textsf{double}(\varepsilon) := \varepsilon$ and $\textsf{double}(ax) := aa\cdot\textsf{double}(x)$, so $\textsf{double}(\mathtt{011}) = \mathtt{001111}$. For a DFA $M = (\Sigma, Q, s, A, \delta)$ that accepts $L$, the **DFA** $M' = (\Sigma, Q, s, A, \delta')$ with
> $$
> \delta'(q,a) := \delta\big(\delta(q,a),a\big)
> $$
> accepts $\{w \mid \textsf{double}(w)\in L\}$. **In English:** $M'$ feeds every input symbol to $M$ twice, so its state after reading $w$ is $\delta^*\big(s,\textsf{double}(w)\big)$, and it accepts exactly when $\textsf{double}(w)\in L$. No guessing, no new states.
>
> For the binary multiples of 3 ($\delta(q,a) = (2q+a)\bmod 3$, start and accepting state $0$), $\delta'(q,a) = (4q+3a)\bmod 3 = q$: $M'$ never moves, so it accepts every string. Indeed $\textsf{double}(w)$, read in binary, is 3 times the number that $w$ denotes in base 4.

> [!example] Transforms of strings in $L$ — guess the preimage
> Let $\textsf{ones}(w) := \mathtt{1}^{\lvert w\rvert}$ replace every symbol of a binary string by `1`. For a DFA $M = (\Sigma, Q, s, A, \delta)$ that accepts $L$, the **NFA** $M' = (\Sigma, Q, s, A, \delta')$ with
> $$
> \delta'(q,\mathtt{1}) := \{\delta(q,\mathtt{0}),\ \delta(q,\mathtt{1})\},\qquad \delta'(q,\mathtt{0}) := \varnothing,
> $$
> and no $\varepsilon$-transitions accepts $\textsf{ones}(L) := \{\textsf{ones}(w) \mid w\in L\}$. **In English:** reading $\mathtt{1}^n$, $M'$ guesses a string $w$ of length $n$, one symbol per input `1`, and runs $M$ on it: $M'$ can be in state $q$ after reading $\mathtt{1}^i$ iff some string of length $i$ leads $M$ from $s$ to $q$. So it accepts $\mathtt{1}^n$ iff some string of length $n$ is in $L$. An input `0` kills every thread, because no $\textsf{ones}(w)$ contains a `0`.
>
> Edge cases: $\textsf{ones}$ maps $\varnothing$, $\{\varepsilon\}$, $\mathtt{1}^*$ and $\Sigma^*$ to $\varnothing$, $\{\varepsilon\}$, $\mathtt{1}^*$ and $\mathtt{1}^*$; and $(\mathtt{01})^*$ to $(\mathtt{11})^*$.

> [!trap] Where transformation proofs go wrong
> - **One example is not a proof.** Start from an **arbitrary** DFA $M$ for $L$; a machine for one particular language proves nothing about the others.
> - **Mixing up the two kinds.** $\{w \mid \textsf{double}(w)\in L\}$ and $\{\textsf{double}(w) \mid w\in L\}$ are different languages that need different machines: for $L = \Sigma^*$ the first is $\Sigma^*$ and the second is $(\mathtt{00}+\mathtt{11})^*$.
> - **Not every transformation preserves regularity.** $\textsf{half}(L)$ is always regular, but $\{ww \mid w\in L\}$ need not be: for $L = \mathtt{0}^*\mathtt{1}$ it is $\{\mathtt{0}^n\mathtt{1}\mathtt{0}^n\mathtt{1} \mid n\ge0\}$, and $\mathtt{0}^*$ is an infinite fooling set for it — the suffix $\mathtt{1}\mathtt{0}^i\mathtt{1}$ separates $\mathtt{0}^i$ from $\mathtt{0}^j$.
> - **Unstated cases.** Define $\delta'$ for every state and symbol, and say exactly which $\varepsilon$-transitions exist; "$\varepsilon$-moves where needed" describes no machine.

> [!exam] How a transformation is graded
> Midterm-1-style exams devote a whole problem, in two parts, to transformations. Each construction is graded out of 10: **2** for a formal, complete description of $M'$ built from an arbitrary DFA $M$ — say whether $M'$ is a DFA or an NFA, and list its $\varepsilon$-transitions; **2** for an English explanation of what its states and its accepting states mean; **6** for correctness — **1** for the states, **1** for the start state, **1** for the accepting states and **3** for the transitions. Graders try the edge cases $L = \varnothing$, $\{\varepsilon\}$, $\mathtt{1}^*$ and $\Sigma^*$, so run your construction on them before handing it in.

## Summary

- An NFA's transition function returns a set of states (possibly empty), and $\varepsilon$-transitions move without reading; the NFA accepts iff **some** walk labeled $w$ ends in $A$. Run it by tracking the set of current states, closed under $\varepsilon$-moves.
- Three pictures of nondeterminism: clairvoyant guessing, parallel threads, and verifying a proof supplied by a prover.
- $\varepsilon$-removal keeps the states: $A'$ is the set of states whose $\varepsilon$-reach meets $A$, and $\delta'(q,a) = \delta(\varepsilon\text{-reach}(q),a)$.
- Subset construction: DFA states are sets $S$, accepting iff $\varepsilon\text{-reach}(S)$ meets $A$; build only the reachable sets, $\varnothing$ included. Up to $2^n$ states — and "the $k$th symbol from the end is 1" really needs $2^k$.
- Thompson's algorithm glues two-state gadgets with $\varepsilon$-edges (one accepting state $\ne$ start, Lemma 4.2). State elimination applies $R(p\to r) + R(p\to q)R(q\to q)^*R(q\to r)$ to every pair, $p = r$ included (Lemma 4.3); expressions can reach length $\Theta(4^n)$.
- Kleene's theorem (Theorem 4.1): regular expressions, DFAs and NFAs describe the same languages. Every conversion works; none promises a small result.
- Transformations: from an arbitrary DFA for $L$, build an NFA — simulate $M$ on $f(w)$ for $\{w \mid f(w)\in L\}$, guess a preimage for $\{f(w) \mid w\in L\}$. Reversal (Lemma 4.4) and $\textsf{half}(L)$ (Lemma 4.5) are the models.
