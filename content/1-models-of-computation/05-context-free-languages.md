> [!abstract] In one breath
> A **context-free grammar** is a finite set of recursive rules such as $C\to\varepsilon\mid\mathtt{0}C\mathtt{1}$: each nonterminal names a language, and each rule is one way to build a string of that language from strings of others. Grammars generate every regular language and more — $C$ generates $\{\mathtt{0}^n\mathtt{1}^n\mid n\ge0\}$, which is not regular — and **recursive automata**, NFAs that call each other like subroutines, accept exactly the same languages. Every generated string has a **parse tree**; a grammar in which some string has two is **ambiguous**. Proving $L(G) = L$ takes two inductions — everything in $L$ is generated, everything generated is in $L$ — with extra care for $\varepsilon$-rules and for nonterminals that refer to each other. Every grammar can be put in **Chomsky normal form**, and a counting argument shows that most languages are still not context-free.

## 5.1 Definitions

Regular languages are built from single strings by union, concatenation and Kleene star. Context-free languages replace the star by **arbitrary recursion**: a language may be defined in terms of itself, anywhere inside a rule.

> [!definition] Definition — context-free grammar
> A **context-free grammar** (CFG) $G = (\Sigma, \Gamma, R, S)$ consists of
> - $\Sigma$ — a finite set of **terminals**: the alphabet of the strings being generated;
> - $\Gamma$ — a finite set of **nonterminals** (variables), disjoint from $\Sigma$;
> - $R$ — a finite set of **production rules** $A\to\omega$, where $A\in\Gamma$ and $\omega\in(\Sigma\cup\Gamma)^*$;
> - $S\in\Gamma$ — the **start symbol**.
>
> Rules with the same left side are combined with a bar: $C\to\varepsilon\mid\mathtt{0}C\mathtt{1}$ is two rules. Conventions: $a, b, c$ are terminals, upper-case letters are nonterminals, and $w, x, y, z$ are strings over $\Sigma\cup\Gamma$.

> [!definition] Definition — derivation, $L(w)$, $L(G)$, context-free language
> - If $A\to y$ is a rule, then $xAz\rightsquigarrow xyz$: one **derivation step** replaces one occurrence of a nonterminal by the right side of one of its rules. The surrounding $x$ and $z$ play no role — that is what *context-free* means.
> - $x\rightsquigarrow^* z$ ("$z$ derives from $x$") if $x = z$, or $x\rightsquigarrow y$ and $y\rightsquigarrow^* z$ for some string $y$: a **derivation** is a sequence of zero or more steps.
> - $L(w) := \{x\in\Sigma^* \mid w\rightsquigarrow^* x\}$ for any string $w\in(\Sigma\cup\Gamma)^*$, and the **language of the grammar** is $L(G) := L(S)$.
> - A language is **context-free** if it is $L(G)$ for some context-free grammar $G$.

Because steps ignore their surroundings, a derivation can be carried out inside any context: if $x\rightsquigarrow^* y$, then $wxz\rightsquigarrow^* wyz$. The book's running example is

$$
S\to A\mid B \qquad A\to\mathtt{0}A\mid\mathtt{0}C \qquad B\to B\mathtt{1}\mid C\mathtt{1} \qquad C\to\varepsilon\mid\mathtt{0}C\mathtt{1}
$$

with terminals $\mathtt{0}, \mathtt{1}$, nonterminals $S, A, B, C$ and start symbol $S$. Every nonterminal generates its own language:

| nonterminal | its language | why |
|---|---|---|
| $C$ | $\{\mathtt{0}^n\mathtt{1}^n \mid n\ge0\}$ | $C\to\mathtt{0}C\mathtt{1}$ wraps a $C$-string in one more `0`…`1` pair |
| $A$ | $\{\mathtt{0}^m\mathtt{1}^n \mid m>n\}$ | one or more extra `0`s in front of a $C$-string |
| $B$ | $\{\mathtt{0}^m\mathtt{1}^n \mid m<n\}$ | a $C$-string followed by one or more extra `1`s |
| $S$ | $\{\mathtt{0}^m\mathtt{1}^n \mid m\ne n\}$ | $L(A)\cup L(B)$ |

For example, $\mathtt{00011}\in L(S)$:
$$
S\rightsquigarrow A\rightsquigarrow\mathtt{0}C\rightsquigarrow\mathtt{00}C\mathtt{1}\rightsquigarrow\mathtt{000}C\mathtt{11}\rightsquigarrow\mathtt{00011}.
$$

> [!intuition] A grammar is a recursive definition
> Read each nonterminal as the name of a language and each rule as one way to build its strings. $C\to\varepsilon\mid\mathtt{0}C\mathtt{1}$ says "a string of $C$ is empty, or a string of $C$ with a `0` in front and a `1` behind": $L(C) = \{\varepsilon\}\cup\mathtt{0}\,L(C)\,\mathtt{1}$. A regular expression can recurse only through the star, which repeats pieces *side by side*; a grammar can put the recursive call *between* two symbols, and that nesting is exactly what lets $C$ match every `0` with a `1`.

## 5.2 Parse trees and ambiguity

> [!definition] Definition — parse tree
> A **parse tree** for a string $w\in\Sigma^*$ (from the nonterminal $A$) is an ordered rooted tree in which
> - the root is labeled $A$ — the start symbol $S$ for a parse tree of $L(G)$ — and every internal node is labeled with a nonterminal;
> - the children of a node labeled $B$ spell, from left to right, the right side of some rule $B\to\omega$ (a single leaf $\varepsilon$ when the rule is $B\to\varepsilon$);
> - the leaves are labeled with terminals or $\varepsilon$, and read from left to right they spell $w$.

A parse tree records *which* rules were used where, but not in which order. A derivation fixes an order, so one tree usually corresponds to many derivations — but to exactly one **leftmost derivation**, the one that always expands the leftmost nonterminal. The derivation of `00011` in §5.1 is the leftmost derivation of the right-hand tree above.

> [!definition] Definition — ambiguity
> A string $w$ is **ambiguous** (with respect to $G$) if it has more than one parse tree — equivalently, more than one leftmost derivation. A grammar is **ambiguous** if some string is ambiguous. A context-free *language* is **inherently ambiguous** if *every* grammar that generates it is ambiguous.

The grammar $S\to\mathtt{1}\mid S{+}S$ generates the sums $\mathtt{1}{+}\mathtt{1}{+}\cdots{+}\mathtt{1}$, and it is ambiguous: `1+1+1` has two parse trees, with leftmost derivations
$$
\begin{aligned}
&S\rightsquigarrow S{+}S\rightsquigarrow S{+}S{+}S\rightsquigarrow\mathtt{1}{+}S{+}S\rightsquigarrow\mathtt{1}{+}\mathtt{1}{+}S\rightsquigarrow\mathtt{1}{+}\mathtt{1}{+}\mathtt{1} && \text{(left tree)}\\
&S\rightsquigarrow S{+}S\rightsquigarrow\mathtt{1}{+}S\rightsquigarrow\mathtt{1}{+}S{+}S\rightsquigarrow\mathtt{1}{+}\mathtt{1}{+}S\rightsquigarrow\mathtt{1}{+}\mathtt{1}{+}\mathtt{1} && \text{(right tree)}
\end{aligned}
$$

A sum of $k$ ones has one parse tree for each way to fully parenthesize it: $1, 1, 2, 5, 14, 42, \dots$ trees for $k = 1, 2, 3, \dots$ (the Catalan numbers) — so `1+1+1+1` has five. The grammar $S\to\mathtt{1}\mid\mathtt{1}{+}S$ generates the same language, $(\mathtt{1}{+})^*\mathtt{1}$, with exactly one parse tree per string: it groups every sum from the right, as $\mathtt{1}{+}(\mathtt{1}{+}(\mathtt{1}{+}\mathtt{1}))$. So ambiguity is a property of a **grammar**; this language is not inherently ambiguous. Inherently ambiguous languages do exist; the standard example is $\{\mathtt{a}^i\mathtt{b}^j\mathtt{c}^k \mid i = j \text{ or } j = k\}$. Its natural grammar $S\to XC\mid AY$, with $L(X) = \{\mathtt{a}^i\mathtt{b}^i\}$, $L(Y) = \{\mathtt{b}^j\mathtt{c}^j\}$, $L(A) = \mathtt{a}^*$ and $L(C) = \mathtt{c}^*$, gives every $\mathtt{a}^n\mathtt{b}^n\mathtt{c}^n$ two parse trees, and every other grammar for this language also has some ambiguous string (a proof beyond this course).

> [!trap] Two derivations are not two parse trees
> To show that a grammar is ambiguous, exhibit **one string with two different parse trees** (or two different *leftmost* derivations). Derivations that merely expand nonterminals in another order build the same tree: $S\rightsquigarrow S{+}S\rightsquigarrow\mathtt{1}{+}S\rightsquigarrow\mathtt{1}{+}\mathtt{1}$ and $S\rightsquigarrow S{+}S\rightsquigarrow S{+}\mathtt{1}\rightsquigarrow\mathtt{1}{+}\mathtt{1}$ are two derivations of `1+1`, which has only one parse tree.

## 5.3 From grammar to language

To prove that a grammar generates a language $L$, prove two inclusions, each by induction:

- $L\subseteq L(G)$: **everything in $L$ is generated** — build a derivation;
- $L(G)\subseteq L$: **everything generated is in $L$** — take a derivation apart.

For $L(C) = \{\mathtt{0}^n\mathtt{1}^n\mid n\ge0\}$ these are Lemmas 5.1 and 5.2.

> [!key] Lemma 5.1
> $C\rightsquigarrow^*\mathtt{0}^n\mathtt{1}^n$ for every integer $n\ge0$.

> [!example] Proof of Lemma 5.1 — the model to copy
> Let $n$ be an arbitrary non-negative integer, and assume that $C\rightsquigarrow^*\mathtt{0}^k\mathtt{1}^k$ for every integer $k$ with $0\le k<n$. There are two cases.
>
> **Case $n = 0$.** The rule $C\to\varepsilon$ gives $C\rightsquigarrow\varepsilon = \mathtt{0}^0\mathtt{1}^0$.
>
> **Case $n\ge1$.** Then $0\le n-1<n$, so the induction hypothesis gives $C\rightsquigarrow^*\mathtt{0}^{n-1}\mathtt{1}^{n-1}$, and
> $$
> \begin{aligned}
> C &\rightsquigarrow \mathtt{0}C\mathtt{1} && \text{by the rule } C\to\mathtt{0}C\mathtt{1}\\
> &\rightsquigarrow^* \mathtt{0}\bullet\mathtt{0}^{n-1}\mathtt{1}^{n-1}\bullet\mathtt{1} && \text{by the induction hypothesis, inside the context } \mathtt{0}\,\underline{\ \ }\,\mathtt{1}\\
> &= \mathtt{0}^n\mathtt{1}^n.
> \end{aligned}
> $$
> In both cases, $C\rightsquigarrow^*\mathtt{0}^n\mathtt{1}^n$. $\blacksquare$

> [!key] Lemma 5.2
> Every string in $L(C)$ is equal to $\mathtt{0}^n\mathtt{1}^n$ for some integer $n\ge0$.

> [!example] Proof of Lemma 5.2 — the model to copy
> Let $w$ be an arbitrary string in $L(C)$, and fix a derivation $C\rightsquigarrow^* w$. Assume that every string $x\in L(C)$ with $\lvert x\rvert<\lvert w\rvert$ is equal to $\mathtt{0}^k\mathtt{1}^k$ for some $k\ge0$. The derivation starts with one of the two rules for $C$.
>
> **Case $C\to\varepsilon$.** Then the derivation is $C\rightsquigarrow\varepsilon$, so $w = \varepsilon = \mathtt{0}^0\mathtt{1}^0$.
>
> **Case $C\to\mathtt{0}C\mathtt{1}$.** Then the derivation is $C\rightsquigarrow\mathtt{0}C\mathtt{1}\rightsquigarrow^* w$. The `0` and the `1` are terminals, so every later step rewrites something derived from the middle $C$: $w = \mathtt{0}x\mathtt{1}$ for some string $x$ with $C\rightsquigarrow^* x$. So $x\in L(C)$ and $\lvert x\rvert = \lvert w\rvert-2<\lvert w\rvert$, and the induction hypothesis gives $x = \mathtt{0}^k\mathtt{1}^k$ for some $k\ge0$. Therefore $w = \mathtt{0}\bullet\mathtt{0}^k\mathtt{1}^k\bullet\mathtt{1} = \mathtt{0}^{k+1}\mathtt{1}^{k+1}$.
>
> In both cases, $w = \mathtt{0}^n\mathtt{1}^n$ for some $n\ge0$. $\blacksquare$

Together the two lemmas say $L(C) = \{\mathtt{0}^n\mathtt{1}^n\mid n\ge0\}$. Note the asymmetry: Lemma 5.1 inducts on the *parameter* $n$ and builds a derivation; Lemma 5.2 inducts on the *string* and has one case per rule.

> [!template] Template — proving $L(G) = L$
> 1. **State the language of every nonterminal.** If nonterminals use each other, the claims must be proved together, in one induction (mutual induction, below).
> 2. **$L\subseteq L(G)$.** Let $w\in L$ be arbitrary; assume every shorter string of $L$ is generated (or induct on a parameter, like $n$ above). Split $w$ into pieces that match the right side of one rule, apply the hypothesis to the pieces, and assemble a derivation $S\rightsquigarrow\omega\rightsquigarrow^* w$.
> 3. **$L(G)\subseteq L$.** Let $w\in L(G)$ be arbitrary and fix a derivation of $w$; assume every shorter generated string is in $L$. Write one case per rule the derivation can start with; in each case $w$ splits into pieces derived from the symbols of the right side, the hypothesis applies to each piece, and the pieces together satisfy the definition of $L$.
> 4. **If the grammar has $\varepsilon$-rules,** fix a *shortest* derivation of $w$ (next subsection), or induct on the length of the derivation instead of the string.

### Careful with those epsilons

The grammar $S\to\varepsilon\mid SS\mid\mathtt{0}S\mathtt{1}\mid\mathtt{1}S\mathtt{0}$ generates exactly the strings with equally many 0s and 1s. In the case $S\to SS$, the naive proof writes $w = xy$ with $S\rightsquigarrow^* x$ and $S\rightsquigarrow^* y$ — but nothing forces $x$ and $y$ to be shorter than $w$: one of them may be $\varepsilon$ and the other $w$ itself. Derivations can be arbitrarily long without making the string longer, as in $S\rightsquigarrow SS\rightsquigarrow S\rightsquigarrow SS\rightsquigarrow S\rightsquigarrow\cdots\rightsquigarrow\mathtt{0}S\mathtt{1}\rightsquigarrow\mathtt{01}$, and even $\varepsilon$ has infinitely many parse trees. The fix is to pick the derivation carefully.

> [!key] Lemma 5.3
> For the grammar $S\to\varepsilon\mid SS\mid\mathtt{0}S\mathtt{1}\mid\mathtt{1}S\mathtt{0}$, every string $w\in L(S)$ satisfies $\#(\mathtt{0},w) = \#(\mathtt{1},w)$.

> [!proof]- Proof (click to expand) — induction with a shortest derivation
> Let $w$ be an arbitrary string in $L(S)$, and fix a derivation $S\rightsquigarrow^* w$ with the **fewest possible steps**. Assume that $\#(\mathtt{0},x) = \#(\mathtt{1},x)$ for every string $x\in L(S)$ with $\lvert x\rvert<\lvert w\rvert$. There are four cases, by the first rule of the derivation.
> - **$S\to\varepsilon$.** Then $w = \varepsilon$, and $\#(\mathtt{0},\varepsilon) = 0 = \#(\mathtt{1},\varepsilon)$.
> - **$S\to\mathtt{0}S\mathtt{1}$.** Then $w = \mathtt{0}x\mathtt{1}$ with $S\rightsquigarrow^* x$ and $\lvert x\rvert<\lvert w\rvert$, so the hypothesis gives $\#(\mathtt{0},x) = \#(\mathtt{1},x)$, and $\#(\mathtt{0},w) = \#(\mathtt{0},x)+1 = \#(\mathtt{1},x)+1 = \#(\mathtt{1},w)$.
> - **$S\to\mathtt{1}S\mathtt{0}$.** Symmetric.
> - **$S\to SS$.** Every later step rewrites a symbol derived from the left $S$ or one derived from the right $S$, so the remaining steps split into a derivation $S\rightsquigarrow^* x$ and a derivation $S\rightsquigarrow^* y$ with $w = xy$. If $x$ were $\varepsilon$, the derivation $S\rightsquigarrow^* y = w$ alone would be a derivation of $w$ with fewer steps (it skips at least the first step), contradicting our choice. So $x\ne\varepsilon$, and likewise $y\ne\varepsilon$. Hence $\lvert x\rvert<\lvert w\rvert$ and $\lvert y\rvert<\lvert w\rvert$, the hypothesis applies to both, and $\#(\mathtt{0},w) = \#(\mathtt{0},x)+\#(\mathtt{0},y) = \#(\mathtt{1},x)+\#(\mathtt{1},y) = \#(\mathtt{1},w)$.
>
> In every case, $\#(\mathtt{0},w) = \#(\mathtt{1},w)$. $\blacksquare$

The difficulty comes only from **nullable** nonterminals ($A\rightsquigarrow^*\varepsilon$) and **cycles of unit rules** ($A\rightsquigarrow^* B\rightsquigarrow^* A$): they are what let a derivation grow longer without the string growing. Inducting on the length of the derivation instead of the length of the string sidesteps the issue in every grammar. The other inclusion — every balanced string is generated — uses the decomposition in §5.4.

### Mutual induction

When nonterminals refer to each other, no claim about one of them can be proved alone.

> [!key] Lemma 5.4
> For the grammar $S\to\mathtt{0}A\mathtt{1}\mid\varepsilon$, $A\to\mathtt{1}S\mathtt{0}\mid\varepsilon$: $L(S) = (\mathtt{01})^*$ and $L(A) = (\mathtt{10})^*$.

> [!proof]- Proof (click to expand) — both claims in one induction
> Let $w$ be an arbitrary string, and assume both claims for every shorter string: for every $x$ with $\lvert x\rvert<\lvert w\rvert$, $x\in L(S)\iff x\in(\mathtt{01})^*$ and $x\in L(A)\iff x\in(\mathtt{10})^*$. We use $(\mathtt{01})^n = \mathtt{0}(\mathtt{10})^{n-1}\mathtt{1}$ and $(\mathtt{10})^n = \mathtt{1}(\mathtt{01})^{n-1}\mathtt{0}$ for $n\ge1$.
> - **$w\in L(S)\Rightarrow w\in(\mathtt{01})^*$.** A derivation of $w$ from $S$ starts with $S\to\varepsilon$ (then $w = \varepsilon$) or with $S\to\mathtt{0}A\mathtt{1}$ (then $w = \mathtt{0}x\mathtt{1}$ with $x\in L(A)$; by the hypothesis **about $A$**, $x = (\mathtt{10})^k$, so $w = \mathtt{0}(\mathtt{10})^k\mathtt{1} = (\mathtt{01})^{k+1}$).
> - **$w\in(\mathtt{01})^*\Rightarrow w\in L(S)$.** If $w = \varepsilon$, use $S\to\varepsilon$. Otherwise $w = (\mathtt{01})^n = \mathtt{0}(\mathtt{10})^{n-1}\mathtt{1}$ with $n\ge1$; the hypothesis about $A$ gives $A\rightsquigarrow^*(\mathtt{10})^{n-1}$, so $S\rightsquigarrow\mathtt{0}A\mathtt{1}\rightsquigarrow^* w$.
> - **The two claims about $A$** are the same arguments with $0$ and $1$ exchanged, using the hypothesis **about $S$**.
>
> So both claims hold for $w$. $\blacksquare$

## 5.4 More examples

The book's grammars, each with the language of every nonterminal:

| language | grammar (and what its other nonterminals generate) |
|---|---|
| palindromes, $w = w^R$ | $S\to\mathtt{0}S\mathtt{0}\mid\mathtt{1}S\mathtt{1}\mid\mathtt{0}\mid\mathtt{1}\mid\varepsilon$ |
| non-palindromes, $w\ne w^R$ | $S\to\mathtt{0}S\mathtt{0}\mid\mathtt{1}S\mathtt{1}\mid\mathtt{0}Z\mathtt{1}\mid\mathtt{1}Z\mathtt{0}$, $\ Z\to\varepsilon\mid\mathtt{0}Z\mid\mathtt{1}Z$ ($Z$: every string) |
| $\#(\mathtt{0},w) = \#(\mathtt{1},w)$ | $S\to\mathtt{0}S\mathtt{1}\mid\mathtt{1}S\mathtt{0}\mid SS\mid\varepsilon$, or $S\to\mathtt{0}S\mathtt{1}S\mid\mathtt{1}S\mathtt{0}S\mid\varepsilon$ |
| $\#(\mathtt{0},w)\ge\#(\mathtt{1},w)$ | $S\to\mathtt{0}S\mathtt{1}\mid\mathtt{1}S\mathtt{0}\mid SS\mid\mathtt{0}\mid\varepsilon$ |
| $\#(\mathtt{0},w)\ne\#(\mathtt{1},w)$ | $S\to O\mid I$, $\ O\to E\mathtt{0}O\mid E\mathtt{0}E$, $\ I\to E\mathtt{1}I\mid E\mathtt{1}E$, $\ E\to\mathtt{0}E\mathtt{1}E\mid\mathtt{1}E\mathtt{0}E\mid\varepsilon$ ($O$: more 0s than 1s; $I$: more 1s; $E$: equally many) |
| balanced parentheses | $S\to\mathtt{(}S\mathtt{)}\mid SS\mid\varepsilon$ (ambiguous), or $S\to\mathtt{(}S\mathtt{)}S\mid\varepsilon$ (unambiguous) |
| arithmetic expressions over $\mathtt{X}, \mathtt{Y}$ | $E\to E{+}T\mid T$, $\ T\to T{\times}F\mid F$, $\ F\to\mathtt{(}E\mathtt{)}\mid\mathtt{X}\mid\mathtt{Y}$ ($E$: sums of one or more terms; $T$: products of one or more factors; $F$: a variable or a parenthesized expression) |

Each grammar comes from **decomposing a typical string** of the language:

- **Non-palindromes.** Compare $w$ with $w^R$ from the outside in; at the first (outermost) mismatch, $w = x\,a\,z\,b\,x^R$ with $a\ne b$. The rules $S\to\mathtt{0}S\mathtt{0}\mid\mathtt{1}S\mathtt{1}$ build the matching outside $x\cdots x^R$, $\mathtt{0}Z\mathtt{1}$ and $\mathtt{1}Z\mathtt{0}$ place the mismatch, and $Z$ fills in an arbitrary middle $z$.
- **Equally many 0s and 1s.** A non-empty such string splits after its **shortest non-empty prefix with equal counts**. That prefix starts and ends with different symbols, and its middle and the rest of $w$ are again balanced — for example $\mathtt{00111001} = \mathtt{0}\cdot\mathtt{01}\cdot\mathtt{1}\cdot\mathtt{1001}$. That is the rule $S\to\mathtt{0}S\mathtt{1}S\mid\mathtt{1}S\mathtt{0}S$, and it proves the missing inclusion of Lemma 5.3. (The rules do not force the *shortest* prefix, so this grammar is still ambiguous: `0101` splits as $\mathtt{0}\cdot\varepsilon\cdot\mathtt{1}\cdot\mathtt{01}$ or $\mathtt{0}\cdot\mathtt{10}\cdot\mathtt{1}\cdot\varepsilon$.)
- **More 0s than 1s.** Cut $w$ after the first prefix with exactly one more 0 than 1s: $w = x\mathtt{0}y$ with $x$ balanced and $\#(\mathtt{0},y)\ge\#(\mathtt{1},y)$. That is $O\to E\mathtt{0}O\mid E\mathtt{0}E$.
- **Expressions.** Sums of terms, products of factors: the grammar is unambiguous, and its parse trees respect precedence and grouping — $\mathtt{X+Y}\times\mathtt{X}$ parses as $\mathtt{X}+(\mathtt{Y}\times\mathtt{X})$, $\mathtt{X}\times\mathtt{Y+X}$ as $(\mathtt{X}\times\mathtt{Y})+\mathtt{X}$, and $\mathtt{X+Y+X}$ as $(\mathtt{X+Y})+\mathtt{X}$.

### Designing a grammar

> [!recipe] Recipe — from a description to a grammar
> 1. **List short strings** in and out of the language, including $\varepsilon$.
> 2. **Decompose a typical string**: by an outer pair of matching symbols (nesting), at the first point where some count balances, or **by cases** — a union gets one nonterminal per case.
> 3. **Give each piece a nonterminal and describe its language in English**, in a sentence that makes sense on its own.
> 4. **Write the rules and check each one against the descriptions:** the strings a rule builds must be in the left side's language (nothing extra), and every string of that language must be buildable by some rule (nothing missing).
> 5. **Test:** derive a few strings, and check $\varepsilon$ and the short strings that should be rejected.

> [!example] Example 1 — $\{\mathtt{0}^i\mathtt{1}^j \mid i\le j\le 2i\}$: every 0 is matched by one or two 1s
> **Idea.** Match the outer 0s with one 1 each and the inner 0s with two 1s each: $\mathtt{0}^i\mathtt{1}^j = \mathtt{0}^a\,(\mathtt{0}^b\mathtt{1}^{2b})\,\mathtt{1}^a$ with $a = 2i-j$ and $b = j-i$, and both are non-negative exactly when $i\le j\le 2i$.
>
> **Answer:** $S\to\mathtt{0}S\mathtt{1}\mid T$, $\quad T\to\mathtt{0}T\mathtt{11}\mid\varepsilon$.
>
> **In English:** $T$ generates $\{\mathtt{0}^b\mathtt{1}^{2b}\mid b\ge0\}$, the strings in which every 0 is matched by exactly two 1s. $S$ generates the strings $\mathtt{0}^a x\mathtt{1}^a$ with $x\in L(T)$, that is, $\mathtt{0}^{a+b}\mathtt{1}^{a+2b}$ for $a, b\ge0$ — exactly the language.
>
> **Test:** $\varepsilon$, `01`, `011`, `0011`, `00111`, `001111` are generated; `0`, `1`, `001`, `0111`, `0101` are not, and none of them is in the language.
>
> **Variants.** $S\to\mathtt{0}S\mathtt{1}\mid\mathtt{0}S\mathtt{11}\mid\varepsilon$ is also correct, but ambiguous (`00111` has two parse trees) — which costs nothing. $S\to\mathtt{0}S\mathtt{1}\mid\mathtt{0}S\mathtt{11}\mid\mathtt{01}\mid\mathtt{011}$ misses only $\varepsilon$: one mistake. $S\to\mathtt{0}S\mathtt{1}\mid S\mathtt{1}\mid\varepsilon$ generates all of $\{\mathtt{0}^i\mathtt{1}^j\mid j\ge i\}$, including `0111`, `01111`, …: infinitely many wrong strings.

> [!example] Example 2 — binary strings that are *not* of the form $\mathtt{0}^n\mathtt{1}^n$
> **Idea.** By cases: a string that is not $\mathtt{0}^n\mathtt{1}^n$ is either $\mathtt{0}^m\mathtt{1}^n$ with $m\ne n$ — the running example — or not of the form $\mathtt{0}^*\mathtt{1}^*$ at all, which means it contains the substring `10` somewhere.
>
> **Answer:** $S\to A\mid B\mid N$, with $A$, $B$, $C$ as in §5.1, $\quad N\to X\mathtt{10}X$, $\quad X\to\varepsilon\mid\mathtt{0}X\mid\mathtt{1}X$.
>
> **In English:** $X$ generates every binary string; $N$ the strings containing `10`, which are exactly the strings not in $\mathtt{0}^*\mathtt{1}^*$; $C$, $A$, $B$ the strings $\mathtt{0}^m\mathtt{1}^n$ with $m = n$, $m>n$, $m<n$; and $S$ the union of $L(A)$, $L(B)$, $L(N)$ — every string except $\mathtt{0}^n\mathtt{1}^n$.
>
> **Test:** `0`, `1`, `10`, `001`, `0110` are generated; $\varepsilon$, `01`, `0011` are not. Forgetting $N$ is the classic error: $S\to A\mid B$ alone misses `10`, `110`, `0110` and every other string containing `10`.
>
> So the complement of $\{\mathtt{0}^n\mathtt{1}^n\}$ is context-free too — but complements do not always behave this well (§5.6).

> [!trap] Describe every nonterminal — and mind the tree, not just the strings
> - On homework, every nonterminal needs a **self-contained description of its language** ("$E$ generates the strings with equally many 0s and 1s"), not of its role ("$E$ is the middle part"). Writing the descriptions is also how you find your own bugs.
> - A grammar can generate exactly the right strings and still be wrong for an application, because its parse trees have the wrong **structure**. The simple grammar $S\to\mathtt{0}\mid\mathtt{1}\mid S{+}S\mid SS\mid S^*\mid\mathtt{(}S\mathtt{)}$ generates exactly the regular expressions over $\{\mathtt{0},\mathtt{1}\}$ that do not use $\varnothing$ or $\varepsilon$ — yet it also parses $\mathtt{0}^*{+}\mathtt{1}^*$ as if it were $(\mathtt{0}^*{+}\mathtt{1})^*$.

The fix builds precedence into the grammar, exactly like the expression grammar: a regular expression is a sum of terms, a term is a concatenation of factors, and a factor is a starred atom.
$$
S\to S{+}T\mid T \qquad T\to TF\mid F \qquad F\to F^*\mid\mathtt{(}S\mathtt{)}\mid\mathtt{0}\mid\mathtt{1}
$$
generates the same strings, has one parse tree per string, and parses $\mathtt{0}^*{+}\mathtt{1}^*$ as $(\mathtt{0}^*){+}(\mathtt{1}^*)$. Here $S$ generates all the expressions, $T$ the expressions with no `+` outside parentheses, and $F$ the single atoms — `0`, `1` or a parenthesized expression — followed by zero or more stars.

> [!exam] How a grammar is graded
> Grammars are graded like regular expressions: out of 10 points, **2** for syntax and **8** for correctness, with exam deductions twice the homework ones — **2** for one mistake (typically a missing or extra $\varepsilon$), **4** for a few wrong strings, **all 8** if infinitely many strings are wrong, as in the last variant of Example 1. A grammar for $\varnothing$ or $\Sigma^*$ earns nothing. Homework also requires the English description of **every nonterminal's language**. **Ambiguity is not penalized**: an ambiguous grammar that generates the right language gets full credit.

## 5.5 Regular languages are context-free

> [!key] Every regular language is context-free
> Induct on a regular expression $R$ for the language ([[1-models-of-computation/02-regular-languages#26-proofs-about-regular-expressions|structural induction]]). Build grammars for the subexpressions first, with **disjoint** sets of nonterminals and start symbols $S_1$, $S_2$, and add a new start symbol $S$:
>
> | expression | new rules |
> |---|---|
> | $\varnothing$ | $S\to S$ (no derivation from $S$ ever ends) |
> | a string $w$ | $S\to w$ |
> | $R_1+R_2$ | $S\to S_1\mid S_2$ |
> | $R_1R_2$ | $S\to S_1S_2$ |
> | $R_1^*$ | $S\to\varepsilon\mid S_1S$ |

On the expression $\mathtt{0}+\mathtt{1}(\mathtt{0}+\mathtt{1})^*\mathtt{00}$ (the multiples of 4 from [[1-models-of-computation/02-regular-languages#25-regular-expression-trees|Chapter 2]]), with one nonterminal per node of the expression tree, named in preorder, the construction gives
$$
\begin{aligned}
&S\to A\mid B && A\to\mathtt{0} && B\to CD && C\to\mathtt{1} && D\to EI\\
&E\to\varepsilon\mid FE && F\to G\mid H && G\to\mathtt{0} && H\to\mathtt{1} && I\to\mathtt{00},
\end{aligned}
$$
a correct but wordy grammar; by hand, $S\to\mathtt{0}\mid\mathtt{1}X\mathtt{00}$, $X\to\varepsilon\mid\mathtt{0}X\mid\mathtt{1}X$ says the same thing.

The inclusion is **strict**: $\{\mathtt{0}^n\mathtt{1}^n\mid n\ge0\}$ is context-free (it is $L(C)$) but not regular — $\mathtt{0}^*$ is an infinite [[concepts/fooling-sets|fooling set]] for it (Lemma 3.6, [[1-models-of-computation/03-finite-state-machines#38-proving-a-language-is-not-regular|§3.8]]).

The same three constructions work for **any** two grammars with disjoint nonterminals, so context-free languages are closed under **union, concatenation and Kleene star**. Reversing the right side of every rule reverses the language — the running example becomes a grammar for $\{\mathtt{1}^n\mathtt{0}^m\mid m\ne n\}$ — so they are closed under **reversal** as well.

## 5.6 Not every language is context-free

The counting argument of [[1-models-of-computation/02-regular-languages#28-not-every-language-is-regular|§2.8]] works for grammars too. Write a grammar as a string — terminals, nonterminals numbered in binary, arrows, bars and separators — and encode each character in binary: different grammars become different binary strings and hence, with a leading 1, different positive integers. So there are only **countably many** context-free languages over a fixed alphabet, but **uncountably many** languages: almost every language is not context-free.

A *specific* non-context-free language needs a specific proof, and those proofs are beyond this course. The canonical example is
$$
\{\mathtt{0}^n\mathtt{1}^n\mathtt{0}^n \mid n\ge0\}.
$$

> [!intuition] Why $\mathtt{0}^n\mathtt{1}^n\mathtt{0}^n$ is out of reach
> Grammars match symbols by nesting ($C\to\mathtt{0}C\mathtt{1}$ pairs each 0 with a 1), and recursive automata (§5.7) do the same with a stack. Once the 1s have been matched against the first block of 0s, the count is used up — nothing is left to compare with the last block. (A Turing machine can go back and check; [[1-models-of-computation/06-turing-machines|Chapter 6]] opens with one for exactly this language.)

> [!key] Closure: intersection and complement fail
> $\{\mathtt{0}^i\mathtt{1}^i\mathtt{0}^j\mid i\ge1, j\ge0\}$ ($S\to CR$, $C\to\mathtt{0}C\mathtt{1}\mid\mathtt{01}$, $R\to\mathtt{0}R\mid\varepsilon$) and $\{\mathtt{0}^i\mathtt{1}^j\mathtt{0}^j\mid i\ge0, j\ge1\}$ ($S\to PD$, $P\to\mathtt{0}P\mid\varepsilon$, $D\to\mathtt{1}D\mathtt{0}\mid\mathtt{10}$) are context-free. A string in both contains a 1, so it is $\mathtt{0}^a\mathtt{1}^b\mathtt{0}^c$ with $b\ge1$, $a = b$ and $b = c$: the intersection is $\{\mathtt{0}^n\mathtt{1}^n\mathtt{0}^n\mid n\ge1\}$, which is not context-free (a grammar for it plus $S'\to S\mid\varepsilon$ would generate the canonical example). So **context-free languages are not closed under intersection** — and therefore not under **complement** either, since they are closed under union and $L_1\cap L_2 = \overline{\overline{L_1}\cup\overline{L_2}}$.
>
> The forced 1s matter: without them, both languages contain every string $\mathtt{0}^k$, and so does their intersection.

## 5.7 Recursive automata

Grammars have a machine model too. Think of each nonterminal as a **subroutine**: an NFA that may, in the middle of its run, call another NFA (or itself) and continue when the call returns.

> [!definition] Definition — recursive automaton
> A **recursive automaton** has an input alphabet $\Sigma$, a finite set $N$ of **module names** with a main name $S\in N$, and for each $A\in N$ a **module** $M_A$: an NFA whose edges are labeled with symbols of $\Sigma$, with $\varepsilon$, or with module names, with a start state $s_A$ and a **single** accepting state $t_A$. Different modules have disjoint sets of states.
>
> A **configuration** is a triple $(x, q, \sigma)$: the unread input $x$, the current state $q$, and a **stack** $\sigma$ of states to return to, written as a string with its top first. Writing $q\xrightarrow{\ell}p$ for an edge from $q$ to $p$ labeled $\ell$, one move from $(x, q, \sigma)$ is
> - **read:** if $x = ax'$ and $q\xrightarrow{a}p$, go to $(x', p, \sigma)$;
> - **$\varepsilon$-move:** if $q\xrightarrow{\varepsilon}p$, go to $(x, p, \sigma)$;
> - **call:** if $q\xrightarrow{A}p$ for a module name $A$, push $p$ and jump to $A$'s start state: $(x, s_A, p\,\sigma)$;
> - **return:** if $q = t_A$ for some module $A$ and $\sigma = p\,\sigma'$, pop: $(x, p, \sigma')$.
>
> It **accepts** $w$ if some sequence of moves leads from $(w, s_S, \varepsilon)$ to $(\varepsilon, t_S, \varepsilon)$.

| $(\mathtt{001},\ s_S,\ \varepsilon)$ | start |

| $(\mathtt{1},\ c,\ t_S)$ | read `0` |
| $(\mathtt{1},\ s_E,\ d\ t_S)$ | call $E$ on the edge $c\to d$: push $d$ |
| $(\mathtt{1},\ t_E,\ d\ t_S)$ | $\varepsilon$-move |
| $(\mathtt{1},\ d,\ t_S)$ | return: pop $d$ |
| $(\varepsilon,\ t_E,\ t_S)$ | read `1` |
| $(\varepsilon,\ t_S,\ \varepsilon)$ | return: pop $t_S$ — accept |

The stack of return states is what lets the machine count, and why recursive automata are more powerful than NFAs. (Most other textbooks use **pushdown automata**, NFAs with an explicit stack; they accept the same languages.)

> [!key] Lemma 5.5
> Every context-free language is accepted by a recursive automaton.

**Construction.** One module per nonterminal $A$. For each rule $A\to X_1X_2\cdots X_k$, add a path of $k$ edges from $s_A$ to $t_A$ labeled $X_1, \dots, X_k$ — an edge labeled with a terminal reads it, an edge labeled with a nonterminal calls that module — and for each rule $A\to\varepsilon$ an $\varepsilon$-edge from $s_A$ to $t_A$. Module $E$ in the figure is exactly this construction for $E\to\mathtt{0}E\mathtt{1}\mid\varepsilon$. An accepting run then traces a parse tree: each call is a node, and its module's path spells the node's children.

> [!key] Lemma 5.6
> Every recursive automaton accepts a context-free language.

**Construction.** One nonterminal $[q]$ for every state $q$, generating the strings that take $q$'s module from $q$ to its accepting state, with every call along the way completed:

| move | rule |
|---|---|
| read: $q\xrightarrow{a}p$ | $[q]\to a\,[p]$ |
| $\varepsilon$-move: $q\xrightarrow{\varepsilon}p$ | $[q]\to[p]$ |
| call: $q\xrightarrow{A}p$ | $[q]\to[s_A]\,[p]$ — run all of $M_A$, then continue from $p$ |
| return: $t_A$, for every module $A$ | $[t_A]\to\varepsilon$ |

The start symbol is $[s_S]$. For the automaton in the figure:
$$
\begin{aligned}
&[s_S]\to\mathtt{0}[a]\mid[s_E][b] && [a]\to\mathtt{0}[a]\mid[s_E][t_S] && [b]\to\mathtt{1}[b]\mid\mathtt{1}[t_S] && [t_S]\to\varepsilon\\
&[s_E]\to\mathtt{0}[c]\mid[t_E] && [c]\to[s_E][d] && [d]\to\mathtt{1}[t_E] && [t_E]\to\varepsilon
\end{aligned}
$$
where $[s_S]$ generates $\{\mathtt{0}^m\mathtt{1}^n\mid m\ne n\}$, $[a]$ generates $\{\mathtt{0}^m\mathtt{1}^n\mid m\ge n\}$, $[b]$ generates $\mathtt{1}^+$, $[s_E]$ generates $\{\mathtt{0}^n\mathtt{1}^n\}$, $[c]$ generates $\{\mathtt{0}^n\mathtt{1}^{n+1}\}$, $[d]$ generates $\{\mathtt{1}\}$, and $[t_S]$, $[t_E]$ generate $\{\varepsilon\}$. On an ordinary NFA (one module, no calls) the same rules turn the parity DFA of [[1-models-of-computation/03-finite-state-machines#33-proving-a-dfa-correct|§3.3]] into $[s]\to\mathtt{0}[s]\mid\mathtt{1}[t]$, $[t]\to\mathtt{0}[t]\mid\mathtt{1}[s]\mid\varepsilon$.

Together, Lemmas 5.5 and 5.6 say: **a language is context-free if and only if some recursive automaton accepts it.**

## 5.8 Chomsky normal form

> [!definition] Definition — Chomsky normal form (CNF)
> A grammar is in **Chomsky normal form** if the start symbol $S$ appears on the right side of no rule, the rule $S\to\varepsilon$ is allowed, and every other rule has one of two forms:
> $$
> A\to BC \quad\text{(two nonterminals)}\qquad\text{or}\qquad A\to a \quad\text{(one terminal)}.
> $$

**Parse trees in CNF are binary.** In a parse tree of a string of length $n\ge1$, each of the $n$ leaves hangs below its own node $A\to a$, and the nodes $A\to BC$ form a full binary tree whose leaves are those $n$ nodes — so there are $n-1$ of them, and **$2n-1$ nonterminal nodes** in all. Each derivation step expands one nonterminal node, so **every derivation of a string of length $n\ge1$ has exactly $2n-1$ steps.**

So membership is decidable by brute force: try every derivation with $2n-1$ steps. Much better is **dynamic programming**. For every substring $w[i..j]$, shortest first, compute the set of nonterminals that derive it: $A$ derives the single symbol $w_i$ if $A\to w_i$ is a rule, and $A$ derives $w[i..j]$ with $i<j$ if some rule $A\to BC$ and some split $i\le k<j$ have $B\rightsquigarrow^* w[i..k]$ and $C\rightsquigarrow^* w[k+1..j]$. Then $w\in L(G)$ if and only if $S$ derives $w[1..n]$ (or $w = \varepsilon$ and $S\to\varepsilon$ is a rule). There are $O(n^2)$ substrings with $O(n)$ splits each, so this **CYK algorithm** (Cocke–Younger–Kasami) takes $O(n^3)$ time for a fixed grammar — dynamic programming, as in the algorithms half of the course.

## 5.9 The CNF conversion algorithm

> [!key] Theorem 5.7
> Every context-free grammar of total length $L$ can be converted, in $O(L^2)$ time, into an equivalent grammar in Chomsky normal form of total length $O(L^2)$.

> [!recipe] The conversion, step by step
> 0. **New start symbol.** Add $S'\to S$, so that the start symbol appears on no right side. (Needed only if $S$ appears on a right side or derives $\varepsilon$; otherwise $S'\to S$ is dropped again after step 2, as in the example below. The book drops $S'$ after step 2 whenever $S'$ is not nullable, but if $S$ is on a right side, as in $S\to\mathtt{0}S\mid\mathtt{1}$, that leaves the start symbol on a right side, which CNF forbids.)
> 1. **Split long rules.** Replace $A\to X\alpha$, where $X$ is one symbol and $\lvert\alpha\rvert\ge2$, by $A\to XB$ and $B\to\alpha$ for a new nonterminal $B$; repeat until every right side has length at most 2.
> 2. **Find the nullable nonterminals** ($A\rightsquigarrow^*\varepsilon$): $A$ is nullable if some rule $A\to\omega$ has only nullable symbols on the right (in particular if $A\to\varepsilon$); repeat until nothing changes.
> 3. **Remove $\varepsilon$-rules.** For each rule, add every non-empty variant obtained by deleting some occurrences of nullable nonterminals; then delete every rule $A\to\varepsilon$, and add $S'\to\varepsilon$ if $S'$ is nullable (the only $\varepsilon$-rule of the result).
> 4. **Merge equivalent nonterminals:** those that derive each other by unit rules ($A\rightsquigarrow^* B\rightsquigarrow^* A$) — the strong components of the graph of unit rules $A\to B$ — and delete every rule $A\to A$ (merging creates them, and so does step 3, e.g. $S\to S$ from $S\to SS$).
> 5. **Remove unit rules.** The unit-rule graph is now acyclic. Process the nonterminals so that $B$ comes before $A$ whenever $A\to B$ (reverse topological order), replacing each $A\to B$ by copies of all of $B$'s rules. Copying can cost $\Theta(nL)$ time for $n$ nonterminals, and this step dominates the $O(L^2)$ of Theorem 5.7.
> 6. **Protect terminals.** For each terminal $a$, add a new nonterminal $T_a\to a$ and replace $a$ by $T_a$ in every right side of length 2.

On the running example (the grammar after each step):

| step | grammar |
|---|---|
| 0 | $S'\to S$; $\ S\to A\mid B$; $\ A\to\mathtt{0}A\mid\mathtt{0}C$; $\ B\to B\mathtt{1}\mid C\mathtt{1}$; $\ C\to\varepsilon\mid\mathtt{0}C\mathtt{1}$ |
| 1 | $C\to\mathtt{0}C\mathtt{1}$ becomes $C\to\mathtt{0}D$ and $D\to C\mathtt{1}$: $\ S'\to S$; $\ S\to A\mid B$; $\ A\to\mathtt{0}A\mid\mathtt{0}C$; $\ B\to B\mathtt{1}\mid C\mathtt{1}$; $\ C\to\varepsilon\mid\mathtt{0}D$; $\ D\to C\mathtt{1}$ |
| 2 | only $C$ is nullable; $S'$ is not, and $S$ is on no right side, so $S'\to S$ is dropped again: $\ S\to A\mid B$; $\ A\to\mathtt{0}A\mid\mathtt{0}C$; $\ B\to B\mathtt{1}\mid C\mathtt{1}$; $\ C\to\varepsilon\mid\mathtt{0}D$; $\ D\to C\mathtt{1}$ |
| 3 | $S\to A\mid B$; $\ A\to\mathtt{0}A\mid\mathtt{0}C\mid\mathtt{0}$; $\ B\to B\mathtt{1}\mid C\mathtt{1}\mid\mathtt{1}$; $\ C\to\mathtt{0}D$; $\ D\to C\mathtt{1}\mid\mathtt{1}$ |
| 4 | no cycles of unit rules: nothing to merge |
| 5 | $S\to\mathtt{0}A\mid\mathtt{0}C\mid B\mathtt{1}\mid C\mathtt{1}\mid\mathtt{0}\mid\mathtt{1}$; $\ A\to\mathtt{0}A\mid\mathtt{0}C\mid\mathtt{0}$; $\ B\to B\mathtt{1}\mid C\mathtt{1}\mid\mathtt{1}$; $\ C\to\mathtt{0}D$; $\ D\to C\mathtt{1}\mid\mathtt{1}$ |
| 6 | $E\to\mathtt{0}$ and $F\to\mathtt{1}$ (the $T_{\mathtt{0}}$ and $T_{\mathtt{1}}$ of step 6, named as in the book) protect the terminals; the result is below |

Removing $\varepsilon$-rules changes what the nonterminals mean, but not the language of $S$: after step 3, $C$ generates $\{\mathtt{0}^n\mathtt{1}^n\mid n\ge1\}$ and $D$ generates $\{\mathtt{0}^n\mathtt{1}^{n+1}\mid n\ge0\}$. The final grammar, in Chomsky normal form, still generates $\{\mathtt{0}^m\mathtt{1}^n\mid m\ne n\}$:
$$
\begin{aligned}
S&\to EA\mid EC\mid BF\mid CF\mid\mathtt{0}\mid\mathtt{1} & A&\to EA\mid EC\mid\mathtt{0} & B&\to BF\mid CF\mid\mathtt{1}\\
C&\to ED & D&\to CF\mid\mathtt{1} & E&\to\mathtt{0}\qquad F\to\mathtt{1}
\end{aligned}
$$

> [!trap] Steps 3 and 5 are where conversions go wrong
> - Step 3 adds a variant for **every subset** of nullable occurrences: from $A\to BC$ with both nullable, add $A\to B$ and $A\to C$ (never $A\to\varepsilon$).
> - Step 5 copies the rules of $B$ **as they are after $B$ has been processed**; in the wrong order, a unit rule can be copied into $A$ and survive.

## Summary

- A grammar $(\Sigma, \Gamma, R, S)$ is a recursive definition; $L(G)$ is the set of terminal strings derivable from $S$.
- Each parse tree corresponds to one leftmost derivation. A grammar is ambiguous if some string has two parse trees; a language is inherently ambiguous if every grammar for it is.
- $L(G) = L$ takes two inductions: build derivations ($L\subseteq L(G)$) and take them apart, one case per rule ($L(G)\subseteq L$). With $\varepsilon$-rules use a shortest derivation; with mutually recursive nonterminals prove all claims together.
- Design by decomposing a typical string — nesting, first balance point, or cases — and describe the language of every nonterminal in English.
- Regular ⊊ context-free; context-free languages are closed under union, concatenation, star and reversal, but not under intersection or complement.
- Counting: only countably many context-free languages. $\{\mathtt{0}^n\mathtt{1}^n\mathtt{0}^n\}$ is the canonical language that is not context-free.
- Recursive automata (NFAs that call each other) accept exactly the context-free languages.
- Every grammar converts to Chomsky normal form ($A\to BC$, $A\to a$), where every parse tree of a length-$n$ string has $2n-1$ nonterminal nodes and membership takes $O(n^3)$ time by dynamic programming.
