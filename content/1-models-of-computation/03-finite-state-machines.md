> [!abstract] In one breath
> A DFA is an algorithm that reads its input once, left to right, and remembers only a constant amount of information: its current state. DFAs accept exactly the regular languages (Kleene's theorem, proved in Chapter 4). Running two DFAs in parallel — the **product construction** — shows that regular languages are closed under every boolean operation. To show a language is *not* regular, exhibit an infinite **fooling set**; the Myhill–Nerode theorem says this method always works, and Moore's algorithm finds the smallest DFA.

## 3.1 Intuition: a DFA is a loop with constant memory

Is a bit string a binary multiple of 5? Scan it once, keeping only the value of the prefix read so far, **mod 5**. Reading bit $a$ turns the value $v$ into $2v + a$, so the remainder $q$ becomes $(2q + a) \bmod 5$:

```
rem ← 0
for each bit a of w, left to right:
    rem ← (2·rem + a) mod 5
return rem = 0
```

The variable $\mathit{rem}$ has five possible values. Those five values *are* the states of a DFA, one loop iteration *is* the transition function $\delta(q,a) = (2q+a)\bmod 5$, and the return condition *is* the set of accepting states $\{0\}$.

## 3.2 Formal definitions

> [!definition] Definition — deterministic finite-state automaton (DFA)
> A DFA is a tuple $M = (\Sigma, Q, s, A, \delta)$:
> - $\Sigma$ — the input alphabet (finite);
> - $Q$ — a finite set of **states**;
> - $s\in Q$ — the **start state**;
> - $A\subseteq Q$ — the **accepting states**;
> - $\delta\colon Q\times\Sigma\to Q$ — the **transition function**, defined for *every* state and *every* symbol.
>
> The extended transition function $\delta^*\colon Q\times\Sigma^*\to Q$ follows the recursive definition of strings:
> $$
> \delta^*(q, w) := \begin{cases} q & \text{if } w = \varepsilon\\ \delta^*(\delta(q,a),\,x) & \text{if } w = ax.\end{cases}
> $$
> $M$ **accepts** $w$ iff $\delta^*(s,w)\in A$, and the **language** of $M$ is $L(M) := \{w\in\Sigma^* \mid \delta^*(s,w)\in A\}$. A language is **automatic** if it is $L(M)$ for some DFA $M$.

As a graph, a DFA is a directed graph whose vertices are the states and in which every state has **exactly one** outgoing edge per symbol. Every string traces exactly one walk from $s$; the DFA accepts if the walk ends in $A$. Two identities, each a short [[concepts/induction-on-strings|string induction]], get used constantly:
$$
\delta^*(q, xy) = \delta^*\big(\delta^*(q,x),\,y\big), \qquad \delta^*(q, xa) = \delta\big(\delta^*(q,x),\,a\big).
$$

> [!trap] A DFA's transition function is total
> Every state needs an outgoing edge for *every* symbol. Drawings usually omit the **dump state** (a non-accepting state that loops to itself on every symbol); that is fine on an exam only if you *say* so — "all missing transitions go to a dump state". An automaton with missing edges and no such sentence is an incomplete DFA (or an NFA, which earns half credit where a DFA was asked for).

The two-state DFA above should accept exactly the strings with an odd number of 1s. To prove that, give **every state a meaning** and prove all the meanings at once. Here the meaning of $s$ is "even number of 1s so far" and of $t$ is "odd so far". The claim needs both start states, because peeling the first symbol of $w$ moves the machine to a different state:

> [!key] Claim (stronger than needed)
> For every string $w$: if $\#(\mathtt{1},w)$ is even, then $\delta^*(s,w) = s$ and $\delta^*(t,w) = t$; if $\#(\mathtt{1},w)$ is odd, then $\delta^*(s,w) = t$ and $\delta^*(t,w) = s$.

> [!proof]- Proof (click to expand) — a model string induction
> Let $w$ be an arbitrary string, and assume the claim for every string shorter than $w$. There are three cases.
> - **$w = \varepsilon$.** $\#(\mathtt{1},\varepsilon) = 0$ is even, and $\delta^*(s,\varepsilon) = s$, $\delta^*(t,\varepsilon) = t$ by the definition of $\delta^*$.
> - **$w = \mathtt{0}x$.** Then $\#(\mathtt{1},w) = \#(\mathtt{1},x)$, and $\delta^*(s,w) = \delta^*(\delta(s,\mathtt{0}),x) = \delta^*(s,x)$, $\delta^*(t,w) = \delta^*(t,x)$. The induction hypothesis for $x$ (shorter than $w$) gives exactly the claim for $w$.
> - **$w = \mathtt{1}x$.** Then $\#(\mathtt{1},w) = \#(\mathtt{1},x)+1$ has the opposite parity, and $\delta^*(s,w) = \delta^*(t,x)$, $\delta^*(t,w) = \delta^*(s,x)$. If $\#(\mathtt{1},x)$ is even, the hypothesis gives $\delta^*(t,x)=t$ and $\delta^*(s,x)=s$, so $\delta^*(s,w)=t$ and $\delta^*(t,w)=s$ — correct, because $\#(\mathtt{1},w)$ is odd. The odd case is symmetric.
>
> In every case the claim holds for $w$. Since $A = \{t\}$, $M$ accepts $w$ iff $\delta^*(s,w) = t$ iff $\#(\mathtt{1},w)$ is odd. $\blacksquare$

> [!template] Template — proving $L(M) = L$ for a DFA
> 1. **Give each state $q$ a meaning** $P_q$, and claim: "$\delta^*(s,w) = q$ if and only if $w$ has property $P_q$."
> 2. **Induct on $w$.** Either peel the *first* symbol ($w = ax$) — then state the claim for every possible start state, as above — or peel the *last* symbol ($w = xa$) and use $\delta^*(s,xa) = \delta(\delta^*(s,x),a)$, which needs the claim only from $s$.
> 3. **Conclude:** $w\in L(M) \iff \delta^*(s,w)\in A \iff w$ has one of the accepting properties $\iff w\in L$.

On exams that ask only for a DFA ("no proof required"), the state meanings still matter: they are what the **mnemonic state names** are supposed to convey.

## 3.4 Real-world examples

Anything with finitely many configurations that changes in response to discrete inputs is a finite-state machine: a railway clock (720 states, one input "tick"), a Rubik's cube (about $5.2\times10^{20}$ states, one input symbol per quarter turn, start and accept in the solved state), a vending machine, a traffic light. The number of states may be astronomical; what matters is that it is **finite and fixed in advance**, independent of the input length.

## 3.5 Designing DFAs: DFAs are algorithms

> [!recipe] Recipe — design a DFA by writing the algorithm first
> 1. Write a **single left-to-right loop** over the input that uses a fixed number of variables, each with a fixed, finite set of possible values (known before the input arrives — no counters that grow with $n$).
> 2. **States** = all combinations of variable values. **Start state** = their initial values.
> 3. **Transition function** = one iteration of the loop body.
> 4. **Accepting states** = the combinations for which the final test returns true.
> 5. Drop states that are unreachable; merge states only when it makes the machine *clearer*.
> 6. **Name each state after what it remembers** ("last symbol was 1", "seen 11", "remainder 3").

**Example: strings containing `11`.** A first algorithm keeps a flag $\mathit{found}\in\{\textsf{F},\textsf{T}\}$ and the last two symbols read ($\varepsilon$, `0`, `1`, `00`, `01`, `10`, `11`): $2\times7 = 14$ states, start $(\textsf{F},\varepsilon)$, accepting every $(\textsf{T},\cdot)$. It is correct but wasteful — only 10 of those states are reachable, and only the *previous* symbol matters (keeping just the last symbol leaves 5 reachable states). Clarity beats minimality. A larger DFA whose states have obvious meanings is easier to get right, easier to explain, and earns the same credit; there is no prize for hand-minimizing.

> [!intuition] What can a DFA *not* remember?
> Anything that grows with the input: a count of 0s, the first half of the string, a stack of open parentheses. "Read once, constant memory" is the whole model — if your algorithm needs an unbounded counter, the language is probably not regular, and §3.8 shows how to prove it.

## 3.6 The product construction

Two DFAs over the same alphabet can run **in parallel**: the combined machine remembers one state of each.

> [!definition] Definition — product construction
> Given DFAs $M_1 = (\Sigma, Q_1, s_1, A_1, \delta_1)$ and $M_2 = (\Sigma, Q_2, s_2, A_2, \delta_2)$, define $M = (\Sigma, Q, s, A, \delta)$ with
> $$
> Q := Q_1\times Q_2,\qquad s := (s_1, s_2),\qquad \delta\big((p,q),a\big) := \big(\delta_1(p,a),\,\delta_2(q,a)\big).
> $$
> Only the accepting set depends on what you want:
>
> | language | accepting states $A$ |
> |---|---|
> | $L_1\cap L_2$ | $\{(p,q) \mid p\in A_1 \text{ and } q\in A_2\}$ |
> | $L_1\cup L_2$ | $\{(p,q) \mid p\in A_1 \text{ or } q\in A_2\}$ |
> | $L_1\setminus L_2$ | $\{(p,q) \mid p\in A_1 \text{ and } q\notin A_2\}$ |
> | $L_1\oplus L_2$ | $\{(p,q) \mid p\in A_1 \text{ xor } q\in A_2\}$ |
>
> The complement needs only one machine: keep $M_1$ and accept $Q_1\setminus A_1$.

> [!key] Lemma 3.1
> $\delta^*\big((p,q),w\big) = \big(\delta_1^*(p,w),\,\delta_2^*(q,w)\big)$ for every string $w$ and all states $p\in Q_1$, $q\in Q_2$.

> [!proof]- Proof (click to expand)
> Induction on $w$. If $w = \varepsilon$, both sides equal $(p,q)$. If $w = ax$, then
> $$
> \delta^*\big((p,q),ax\big) = \delta^*\big(\delta((p,q),a),\,x\big) = \delta^*\big((\delta_1(p,a),\delta_2(q,a)),\,x\big) = \big(\delta_1^*(\delta_1(p,a),x),\ \delta_2^*(\delta_2(q,a),x)\big),
> $$
> by the definitions of $\delta^*$ and $\delta$ and then the induction hypothesis for $x$ (which holds for *every* pair of states — that is why the lemma quantifies over all $p, q$). The last expression is $\big(\delta_1^*(p,ax),\,\delta_2^*(q,ax)\big)$ by the definition of $\delta^*$. $\blacksquare$

## 3.7 Closure properties

> [!key] Theorem 3.2
> If $L$ and $L'$ are automatic (over the same alphabet), then so are $\overline{L} = \Sigma^*\setminus L$, $L\cup L'$, $L\cap L'$, $L\setminus L'$ and $L\oplus L'$.

> [!key] Theorem 3.3 (Kleene)
> For every regular expression $R$ there is a DFA $M$ with $L(M) = L(R)$, and for every DFA $M$ there is a regular expression $R$ with $L(R) = L(M)$. *(Proved in [[1-models-of-computation/04-nondeterministic-automata#44-kleenes-theorem|Chapter 4]].)*

So "automatic" is just another word for **regular**, and the two theorems combine:

- **Corollary 3.4.** Regular languages are closed under complement, intersection, difference and symmetric difference. (Regular expressions have no symbol for $\cap$ or complement — the DFA view proves it.)
- **Corollary 3.5.** Automatic languages are closed under concatenation and Kleene star. (Easy for regular expressions, awkward for DFAs — until NFAs arrive.)

> [!recipe] Three ways to prove that a language is regular
> 1. Give a **regular expression** for it ([[1-models-of-computation/02-regular-languages|Chapter 2]]).
> 2. Give a **DFA** — or an **NFA** ([[1-models-of-computation/04-nondeterministic-automata|Chapter 4]]) — for it.
> 3. Build it from languages already known to be regular with **closure properties**: boolean operations, concatenation, star, reversal, and the [[concepts/language-transformations|transformations]] of §4.9.

The conversions between the three descriptions always exist but can be exponential (and sometimes must be). Full table: [[concepts/closure-properties]].

## 3.8 Proving a language is not regular

A DFA has no memory except its state. If two strings $x$ and $y$ lead to the same state, then every continuation $z$ leads $xz$ and $yz$ to the same final state:
$$
\delta^*(s,x) = \delta^*(s,y)\ \Longrightarrow\ \delta^*(s,xz) = \delta^*(s,yz)\ \text{ for every } z\ \Longrightarrow\ \big(xz\in L \iff yz\in L\big).
$$

> [!definition] Definition — distinguishing suffix, fooling set
> A **distinguishing suffix** for $x$ and $y$ (with respect to $L$) is a string $z$ such that **exactly one** of $xz$ and $yz$ is in $L$. A **fooling set** for $L$ is a set $F$ of strings such that **every pair of distinct strings** in $F$ has a distinguishing suffix.

> [!key] Fooling sets give lower bounds
> If $F$ is a fooling set for $L$, then every DFA for $L$ has at least $\lvert F\rvert$ states, because no two strings of $F$ can end in the same state. In particular: **if $L$ has an infinite fooling set, then $L$ is not regular.**

**A finite example.** $F = \{\mathtt{0}, \mathtt{1}, \mathtt{10}, \mathtt{11}, \mathtt{100}\}$ (the numbers 0–4) is a fooling set for the binary multiples of 5: for instance $z = \mathtt{01}$ distinguishes `1` and `11`, because `101` $=5$ is a multiple of 5 and `1101` $=13$ is not. So the 5-state DFA of §3.1 is as small as possible.

> [!template] Template — fooling-set proof (as in Lemma 3.6)
> Let $F = $ *[an explicit infinite set, e.g. $\mathtt{0}^*$]*. \
> Let $x$ and $y$ be arbitrary distinct strings in $F$. \
> The definition of $F$ implies $x = $ *[…]* and $y = $ *[…]* for some integers $i\ne j$. \
> Let $z = $ *[a suffix that may depend on $i$ and $j$]*. \
> Then $xz = $ *[…]* $\in L$, because *[…]*. \
> And $yz = $ *[…]* $\notin L$, because *[…]*. \
> So $z$ distinguishes $x$ and $y$. We conclude that $F$ is a fooling set for $L$. \
> Because $F$ is infinite, $L$ cannot be regular. $\blacksquare$

> [!example] Lemma 3.6 — $\{\mathtt{0}^n\mathtt{1}^n \mid n\ge0\}$ is not regular
> Let $F = \mathtt{0}^*$. Let $x$ and $y$ be arbitrary distinct strings in $F$; then $x = \mathtt{0}^i$ and $y = \mathtt{0}^j$ for some integers $i\ne j$. Let $z = \mathtt{1}^i$. Then $xz = \mathtt{0}^i\mathtt{1}^i\in L$. And $yz = \mathtt{0}^j\mathtt{1}^i\notin L$, because $j\ne i$. So $F$ is a fooling set for $L$, and since $F$ is infinite, $L$ is not regular.

The same skeleton handles the standard examples; only $F$ and $z$ change. (For $x\ne y$ written with $i\ne j$.)

| language $L$ | fooling set $F$ | distinguishing suffix |
|---|---|---|
| $\{\mathtt{0}^n\mathtt{1}^n \mid n\ge0\}$ (Lemma 3.6) | $\mathtt{0}^*$ | $x = \mathtt{0}^i$: $z = \mathtt{1}^i$ |
| $\{ww^R \mid w\in\Sigma^*\}$ (Lemma 3.7) | $\mathtt{0}^*\mathtt{1}$ | $x = \mathtt{0}^i\mathtt{1}$: $z = \mathtt{1}\mathtt{0}^i$ |
| $\{\mathtt{0}^{2^n} \mid n\ge0\}$ (Lemma 3.8) | $L$ itself | $x = \mathtt{0}^{2^i}$: $z = \mathtt{0}^{2^i}$ (then $2^i+2^j$ is not a power of 2) |
| $\{w \mid \#(\mathtt{0},w) = \#(\mathtt{1},w)\}$ | $\mathtt{0}^*$ | $x = \mathtt{0}^i$: $z = \mathtt{1}^i$ |
| $\{\mathtt{0}^n\mathtt{1}^n\mathtt{2}^n \mid n\ge0\}$ | $\mathtt{0}^*$ | $x = \mathtt{0}^i$: $z = \mathtt{1}^i\mathtt{2}^i$ |
| $\{\mathtt{0}^p \mid p \text{ prime}\}$ (Lemma 3.9) | $\mathtt{0}^*$ | a cleverer $z$ — see the book |

**Choosing $F$.** The fooling set usually comes from the unbounded quantity that any algorithm for $L$ "obviously" has to remember — a count, a prefix, a position. Good candidates are a simple regular language with one star and no union ($\mathtt{0}^*$, $\mathtt{1}\mathtt{0}^*\mathtt{1}$, $(\mathtt{01})^*$) or $L$ itself. *You* choose $F$, so you may impose structure that $L$ lacks: for "equally many 0s and 1s" we only ever use strings of the form $\mathtt{0}^i\mathtt{1}^j$.

**The closure alternative.** If $L$ were regular, then $L\cap\mathtt{0}^*\mathtt{1}^*$ would be regular too (Corollary 3.4). For $L = \{w \mid \#(\mathtt{0},w) = \#(\mathtt{1},w)\}$ that intersection is $\{\mathtt{0}^n\mathtt{1}^n\}$, which is not regular — so neither is $L$. This only works in that direction: a *regular* intersection proves nothing about $L$.

> [!trap] Where fooling-set proofs lose points
> 1. **One example pair is not a proof.** The argument must work for *arbitrary* distinct $x, y\in F$, written with parameters $i\ne j$.
> 2. **Check both halves:** $xz\in L$ *and* $yz\notin L$, each with a reason. "Clearly" is not a reason.
> 3. **$i < j$ needs a justification.** Assume it only if you say "without loss of generality" *and* the argument really is symmetric — the suffix $z = \mathtt{1}^i$ above is built from $x$, so swapping $x$ and $y$ changes it.
> 4. **The set must be infinite and explicit.** "Let $F$ be the set of all prefixes we need" is not a set; a finite fooling set proves only a lower bound on the number of states.
> 5. **$z$ may depend on $x$ and $y$,** but not on anything else (in particular not on a DFA you are trying to rule out).

> [!exam] How a fooling-set proof is graded
> 4 points for an explicit infinite set that really is a fooling set (a finite set earns nothing); 6 for the argument with arbitrary distinct $x, y$: 2 for an explicit suffix, 2 for showing one of $xz, yz$ is in $L$, 2 for showing the other is not.

## 3.9 The Myhill–Nerode theorem

Write $x\equiv_L y$ when **no** suffix distinguishes $x$ and $y$: $xz\in L\iff yz\in L$ for every string $z$. This is an equivalence relation, and its classes are exactly "what an algorithm for $L$ must remember".

> [!key] The Myhill–Nerode theorem
> For every language $L$, the following three numbers are equal (possibly all infinite):
> 1. the minimum number of states of a DFA that accepts $L$;
> 2. the maximum size of a fooling set for $L$;
> 3. the number of equivalence classes of $\equiv_L$.
>
> In particular, **$L$ is regular if and only if every fooling set for $L$ is finite.** So a non-regularity proof by fooling set always exists — the only question is finding it.

> [!proof]- Proof sketch (click to expand)
> (1) ≥ (2) is the fooling-set argument above. (2) = (3): a fooling set is exactly a set containing at most one string from each class. (1) ≤ (3): build a DFA whose states are the classes, $Q = \{[w] \mid w\in\Sigma^*\}$, with start $[\varepsilon]$, accepting states $\{[w] \mid w\in L\}$, and $\delta([w],a) = [wa]$. This is well defined because $x\equiv_L y$ implies $xa\equiv_L ya$, and $\delta^*([\varepsilon],w) = [w]$ by induction, so the machine accepts exactly $L$. $\blacksquare$

Concept page: [[concepts/myhill-nerode-theorem]].

## 3.10 Minimal automata: Moore's algorithm

Two states $p$ and $q$ are **distinguishable** if some string $z$ leads exactly one of them to an accepting state. Recursively: $p$ and $q$ are distinguishable if exactly one of them is accepting, or if $\delta(p,a)$ and $\delta(q,a)$ are distinguishable for some symbol $a$.

> [!recipe] Moore's algorithm (table filling)
> 1. Delete every state that is unreachable from $s$ (graph search, $O(n\sigma)$ time for $n = \lvert Q\rvert$, $\sigma = \lvert\Sigma\rvert$).
> 2. **Mark** every pair $\{p, q\}$ with exactly one accepting state.
> 3. **Repeat passes:** mark $\{p,q\}$ whenever $\{\delta(p,a),\delta(q,a)\}$ is already marked for some symbol $a$. Stop after a pass that marks nothing (at most $n$ passes, $O(\sigma n^3)$ time in all).
> 4. **Merge** each group of mutually unmarked (equivalent) states. The result is the minimal DFA.
>
> This is dynamic programming for "some string of length $\le k$ distinguishes $p$ and $q$". Faster versions exist: $O(\sigma n^2)$, and Hopcroft's $O(\sigma n\log n)$.

**Example.** Counting 1s mod 6 and accepting counts 0 and 3 decides "the number of 1s is a multiple of 3" with six states. Step 2 marks the 8 pairs between $\{0,3\}$ and $\{1,2,4,5\}$. The first pass marks $\{1,2\}$, $\{1,5\}$, $\{2,4\}$ and $\{4,5\}$ (for example, reading `1` sends $\{1,2\}$ to the marked pair $\{2,3\}$). The second pass marks nothing: $\{0,3\}$, $\{1,4\}$ and $\{2,5\}$ only ever lead to each other. Merging them leaves three states.

## Summary

- A DFA $(\Sigma, Q, s, A, \delta)$ is a one-pass algorithm with a fixed, finite memory; $\delta$ is total.
- Prove a DFA correct by giving every state a meaning and proving all meanings together by induction.
- Design by brute force: states = values of the loop's variables; name them by what they remember.
- Product construction: $Q_1\times Q_2$, run in parallel; the accepting set chooses $\cap, \cup, \setminus, \oplus$. Regular languages are closed under all boolean operations.
- Not regular ⇔ an infinite fooling set exists (Myhill–Nerode). Write the proof with arbitrary $x\ne y$, an explicit $z$, and both membership checks.
- Moore's algorithm merges indistinguishable states; the minimal DFA is unique up to renaming.

> [!exam] On the exams
> Midterm-1-style exams test this chapter three ways. **DFA design** (usually alongside a regular expression for the same language): mnemonic state names, a start arrow, double circles, and an explicit sentence about any omitted dump state; no proof needed unless asked. **Non-regularity** by fooling set, often paired with a context-free grammar for the same language ([[1-models-of-computation/05-context-free-languages|Chapter 5]]). **True/false** items such as "if $L$ has a fooling set of size 5, every DFA for $\overline{L}$ has at least 5 states" (true — the same suffixes distinguish the strings for $\overline L$).
