> [!abstract] In one breath
> A model of computation is **universal** if it can simulate every Turing machine. Anything that can simulate a Turing machine inherits both its power — it computes everything computable — and its undecidability: basic questions about the model, such as "does this run ever stop?", become undecidable by a reduction from the halting problem. Astonishingly little suffices: two stacks, two counters, a list of fractions, a set of string dominoes, a few integer matrices, a system of mirrors, a set of square tiles, or three rewriting rules on strings of $\mathsf{S}$, $\mathsf{K}$ and $\mathsf{I}$. Each section below names a model, the encoding trick that lets it simulate a Turing machine, and what becomes undecidable.

The book presents this chapter as a rough sketch rather than a finished chapter, so this page is shorter than the others and fills in a few standard facts where the sketch is silent.

> [!recipe] How universality spreads undecidability
> 1. **Simulate.** Give an algorithm that turns any machine $M$ and input $w$ into an object $P_{M,w}$ of the new model (a program, an instance, a term) that "halts" if and only if $M$ halts on $w$.
> 2. **Reduce.** A decider for "does $P$ halt?" would then decide the halting problem ([[1-models-of-computation/07-undecidability#79-the-halting-problem-via-reduction|§7.9]]), which is impossible. So halting is undecidable for the new model.
> 3. **Conversely**, a Turing machine can usually simulate the new model, so the model computes exactly the computable functions — more evidence for the [[concepts/church-turing-thesis|Church–Turing thesis]].

## 8.1 Universal Turing machines

The first universal model is a single Turing machine: the universal machine $U$ of [[1-models-of-computation/06-turing-machines#68-universal-turing-machines|§6.8]] accepts $\langle M,w\rangle$ if and only if $M$ accepts $w$, and rejects it if and only if $M$ rejects $w$. It stores $M$'s tape as a list of equal-length cells $[\langle q\rangle{\bullet}\langle a\rangle]$ in which only the cell under the head carries a state other than $\textit{reject}$. To take one step of $M$ it finds that cell, looks up the matching block of $\langle\delta\rangle$, rewrites the cell, and passes the state code to a neighboring cell. Every other model on this page is shown universal the same way: by simulating an arbitrary Turing machine, or a model already known to be universal.

Concept page: [[concepts/universal-turing-machine]].

## 8.2 Two-stack machines

A **two-stack machine** is a finite-state control with two stacks, with the input initially on one of them: in each step it may pop the top symbol of each stack, push symbols, and change state, depending on its state and the popped symbols. A Turing machine's tape *is* two stacks — cut it at the head.

So one step of a Turing machine is a pop, a state change and a push — plus, for a move left, moving the top symbol of the left stack over to the right stack — and a move left with an empty left stack is a crash. Hence two-stack machines accept and decide exactly the same languages as Turing machines.

> [!trap] One stack is not enough
> A finite-state machine that reads its input once, left to right, with **one** stack is essentially a [[1-models-of-computation/05-context-free-languages#57-recursive-automata|recursive automaton]]: it accepts only context-free languages, so it cannot even recognize $\{\mathtt{0}^n\mathtt{1}^n\mathtt{0}^n \mid n\ge0\}$. Going from one stack to two jumps from the context-free languages straight to everything computable.

## 8.3 Counter machines

> [!definition] Definition — counter machine
> A **$k$-counter machine** has a finite set of states and $k$ counters, each holding a non-negative integer. In each step it looks at its state and at which counters are zero, then changes state and adds $-1$, $0$ or $+1$ to each counter (never making one negative).

- **Three counters simulate a Turing machine.** Read each half of the tape as a number in base $\lvert\Gamma\rvert$, with $\square$ as the digit 0 and the cells nearest the head as the least significant digits: one counter holds the part left of the head (with an extra leading digit 1, so that the machine can tell when that part is empty), another the head cell and everything to its right. Reading the head symbol is "right counter mod $\lvert\Gamma\rvert$". A move right multiplies the left counter by $\lvert\Gamma\rvert$ and adds the written digit, and divides the right counter by $\lvert\Gamma\rvert$; a move left is symmetric. Multiplying and dividing by a constant (with the remainder remembered in the state) are loops of $\pm1$ steps that use the third counter as scratch space.
- **Two counters simulate three.** Store three counters $(a, b, c)$ as the single number $2^a3^b5^c$. Adding 1 to $b$ multiplies it by 3, subtracting 1 from $c$ divides it by 5, and "$c = 0$?" asks whether 5 fails to divide it — each again a $\pm1$ loop, with the second counter as scratch. So **two counters are universal**; in particular, it is undecidable whether a given two-counter machine, started with both counters at 0, ever halts.
- **But the input format matters.** To compute a function $f$ with three counters, turn $(n,0,0)$ into $(2^n,0,0)$, run the simulation to reach $(2^{f(n)},0,0)$, and turn that into $(f(n),0,0)$. With only two counters, even turning $(n,0)$ into $(2^n,0)$ is impossible — a hard theorem; the book cites Barzdin (1963), Yao (1971) and Schroeppel (1972). Two counters are universal only for suitably encoded inputs.

## 8.4 FRACTRAN

> [!definition] Definition — FRACTRAN (Conway, 1987)
> A **FRACTRAN program** is a finite list of positive fractions $f_1, \dots, f_k$. Its state is one positive integer $N$. In each step, find the **first** $f_i$ for which $N f_i$ is an integer and replace $N$ by $N f_i$; if there is none, halt.

The exponents in the prime factorization of $N$ are counters in disguise: multiplying by $\tfrac32$ subtracts 1 from the exponent of 2 and adds 1 to the exponent of 3, and it applies only when the exponent of 2 is positive — a built-in zero test. Extra primes can play the role of a counter machine's states, so FRACTRAN is universal.

> [!example] Two tiny programs
> - $[\tfrac32]$ turns $2^a3^b$ into $3^{a+b}$, in $a$ steps: it adds two counters.
> - $[\tfrac{455}{33}, \tfrac{11}{13}, \tfrac{1}{11}, \tfrac{3}{7}, \tfrac{11}{2}, \tfrac{1}{3}]$ turns $2^a3^b$ into $5^{ab}$: it multiplies, with the primes 7, 11 and 13 doing the bookkeeping.

For every computable function $f$ there is a FRACTRAN program that turns $2^{n+1}$ into $3^{f(n)+1}$. Again the encoding is unavoidable. Started at $N = 1$, a program either halts at once, with output 1 (if none of its fractions is an integer, none applies to 1), or runs forever (an integer fraction applies to every $N$, so some fraction always applies). So no FRACTRAN program turns every $n$ directly into $n+1$.

## 8.5 Post's correspondence problem

> [!definition] Definition — Post's correspondence problem (PCP)
> Given a finite list of **dominoes** $(x_1/y_1), \dots, (x_n/y_n)$, each a pair of strings (top/bottom), is there a sequence of indices $i_1, i_2, \dots, i_k$ with $k\ge1$, repetitions allowed, such that
> $$
> x_{i_1}x_{i_2}\cdots x_{i_k} = y_{i_1}y_{i_2}\cdots y_{i_k}\,?
> $$

> [!example] An instance and its shortest solution
> With $a = (\mathtt{0}/\mathtt{100})$, $b = (\mathtt{01}/\mathtt{00})$ and $c = (\mathtt{110}/\mathtt{11})$, the sequence $c, b, c, a$ is a solution: the tops give $\mathtt{110}\cdot\mathtt{01}\cdot\mathtt{110}\cdot\mathtt{0}$ and the bottoms $\mathtt{11}\cdot\mathtt{00}\cdot\mathtt{11}\cdot\mathtt{100}$, and both spell `110011100` (the book prints `110110100` here, a typo). No solution is shorter: every solution must start with $c$, because the top and bottom of $a$ and of $b$ already disagree, and no sequence of one, two or three dominoes works. Repeating a solution gives another one ($cbcacbca$), so a solvable instance has infinitely many solutions.

- **PCP is undecidable.** Dominoes can be designed so that every solution spells out a halting computation of a given machine, one configuration after another, with the bottom row always one configuration ahead of the top; the book notes that the simplest proof simulates a *tag machine*, another universal model.
- **PCP is acceptable:** try all sequences in order of length, and accept when one works. Since PCP is acceptable but undecidable, its complement is not even acceptable ([[1-models-of-computation/07-undecidability#73-useful-properties|§7.3]]).
- **Shortest solutions can be enormous.** The book lists the three-domino instance $(\mathtt{0}/\mathtt{001})$, $(\mathtt{001}/\mathtt{1})$, $(\mathtt{1}/\mathtt{0})$, whose shortest solution uses 75 dominoes, and others whose shortest solutions use hundreds. No computable function of the instance bounds the length of its shortest solution: with such a bound, searching up to it would decide PCP.

## 8.6 Matrix mortality

> [!definition] Definition — matrix mortality
> Given square integer matrices $A_1, \dots, A_k$, all of the same size, is some product $A_{i_1}A_{i_2}\cdots A_{i_m}$ of them, with repetitions allowed, equal to the zero matrix?

Strings can be encoded as integer matrices so that concatenation becomes matrix multiplication, and a careful construction turns any PCP instance into a set of matrices that has a zero product if and only if the instance has a solution. So mortality is undecidable — even for two $15\times15$ matrices, or for six $3\times3$ matrices (Cassaigne, Halava, Harju and Nicolas, 2014). With a single matrix the question is easy: some power of an $n\times n$ matrix is zero if and only if its $n$th power is. The order of the factors matters:
$$
A = \begin{bmatrix}1&0\\0&0\end{bmatrix},\quad B = \begin{bmatrix}0&0\\1&1\end{bmatrix}:\qquad AB = \begin{bmatrix}0&0\\0&0\end{bmatrix},\quad BA = \begin{bmatrix}0&0\\1&0\end{bmatrix},\quad A^2 = A,\quad B^2 = B.
$$

## 8.7 Dynamical systems

Continuous physical systems can be universal too. Reif, Tygar and Yoshida (1994) encode a Turing machine's configuration as the coordinates of the point where a light ray crosses a unit square — one coordinate encodes the tape left of the head, the other the tape right of the head, just like the two stacks of §8.2 — and build a system of mirrors with quadratic surfaces (or of lenses) that carries the ray from one configuration's point to the next one's. So "does a ray starting here ever reach that region?" is undecidable: ray tracing, in general, is undecidable.

## 8.8 Wang tiles

A **Wang tile** is a unit square with a color on each edge. Given a finite set of tile types, with unlimited copies of each, can the plane be covered without rotating any tile, so that tiles that share an edge give it the same color?

A Turing machine's run can be drawn as a tiling: row $t$ spells out the configuration after $t$ steps, and the colors on the horizontal edges carry each cell's symbol (and, at the head, the state) up to the next row, so that the only way to complete a row is to compute the next configuration. If a special starting tile must sit in the corner and write the initial configuration, then a quarter of the plane can be tiled if and only if the machine never halts — so this version of the tiling problem is undecidable. Wang conjectured that every tile set that tiles the plane also tiles it periodically, which would make the unrestricted problem (no starting tile) decidable; Berger (1966) refuted the conjecture and proved the unrestricted problem undecidable, using tile sets that tile the plane only aperiodically.

## 8.9 Combinator calculus

> [!definition] Definition — combinator terms and evaluation
> A **term** is one of the **combinators** $\mathsf{S}$, $\mathsf{K}$, $\mathsf{I}$ (or a variable $x, y, \dots$), or a pair $(X, Y)$ of terms, meaning "$X$ applied to $Y$". Application associates to the left, and the parentheses that this makes redundant are dropped: $\mathsf{SKK(IS)}$ abbreviates $(((\mathsf{S},\mathsf{K}),\mathsf{K}),(\mathsf{I},\mathsf{S}))$. **Evaluation** rewrites any subterm with one of the three rules
> $$
> \mathsf{I}x\ \to\ x,\qquad \mathsf{K}xy\ \to\ x,\qquad \mathsf{S}xyz\ \to\ xz(yz).
> $$
> A subterm that matches a left-hand side is a **redex**; a term with no redex is in **normal form**.

(Schönfinkel introduced combinators in the 1920s.) Several redexes may be available at once, so a reduction sequence depends on the order in which they are chosen.

> [!example] Reversing two arguments
> $\mathsf{R} := \mathsf{S(K(SI))K}$ swaps its two arguments. Rewriting the leftmost outermost redex at each step:
> $$
> \mathsf{S(K(SI))K}xy \to \mathsf{K(SI)}x(\mathsf{K}x)y \to \mathsf{SI}(\mathsf{K}x)y \to \mathsf{I}y(\mathsf{K}xy) \to y(\mathsf{K}xy) \to yx.
> $$
> Similarly $\mathsf{SKK}x \to \mathsf{K}x(\mathsf{K}x) \to x$, so $\mathsf{SKK}$ does the job of $\mathsf{I}$: the two combinators $\mathsf{S}$ and $\mathsf{K}$ suffice.

> [!example] A term that runs forever
> Let $T := \mathsf{S(KI)(SII)}$. Rewriting at each step the leftmost $\mathsf{I}$- or $\mathsf{K}$-redex if there is one, and otherwise the leftmost $\mathsf{S}$-redex:
> $$
> \begin{aligned}
> \mathsf{SII}T &\to \mathsf{I}T(\mathsf{I}T) \to T(\mathsf{I}T) \to TT = \mathsf{S(KI)(SII)}T\\
> &\to \mathsf{KI}T(\mathsf{SII}T) \to \mathsf{I}(\mathsf{SII}T) \to \mathsf{SII}T,
> \end{aligned}
> $$
> back where it started after six steps. Rewriting the leftmost outermost redex instead, the term never returns to itself but never stops either: it passes through $\mathsf{SII}(\mathsf{I}T)$, $\mathsf{SII}(\mathsf{I}(\mathsf{I}T))$, … forever.

Combinator calculus is universal: it is equivalent to Church's λ-calculus, and so to Turing machines. In particular, it is undecidable whether a given term has a normal form — whether evaluation can ever stop.

## Summary

- **Universal** means "can simulate every Turing machine", and universality brings undecidability with it, by a reduction from the halting problem.
- A tape is two stacks cut at the head, so two stacks are universal; one stack with a single pass over the input gives only the context-free languages.
- Three counters simulate a tape (its halves as numbers); two counters simulate three via $2^a3^b5^c$. But two counters cannot even compute $n\mapsto2^n$: universality needs suitably encoded inputs.
- FRACTRAN is a counter machine in disguise: prime exponents are the counters. $[\tfrac32]$ adds.
- PCP is undecidable but acceptable. Example: $c,b,c,a$ spells `110011100` on both rows, and no shorter sequence works.
- Matrix mortality (even two $15\times15$ or six $3\times3$ matrices), ray tracing with mirrors and tiling the plane with Wang tiles are undecidable for the same reason.
- Three rewriting rules, $\mathsf{I}x\to x$, $\mathsf{K}xy\to x$ and $\mathsf{S}xyz\to xz(yz)$, are universal; $\mathsf{SII}(\mathsf{S(KI)(SII)})$ can rewrite forever.
