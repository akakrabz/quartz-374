> [!abstract] In one breath
> A Turing machine **accepts** a language if it accepts exactly the strings in it, and **decides** it if it also halts — rejecting — on every other input; a language is decidable exactly when both it and its complement are acceptable. Running a machine built from a supposed decider on its own encoding — **diagonalization** — proves that $\textsf{SelfReject}$ is undecidable, and the same idea (Cantor's theorem) shows that most languages are not even acceptable. **Reductions** spread undecidability: assume a decider for $L$, use it as a black box to decide a language already known to be undecidable, and conclude that the decider cannot exist. **Rice's theorem** packages the most common reduction: every non-trivial property of the *language* $\textsf{Accept}(M)$ is undecidable. Questions about a machine's *behavior*, rather than its language, can go either way.

## 7.1 Acceptable versus decidable

A [[concepts/turing-machines|Turing machine]] ([[1-models-of-computation/06-turing-machines#62-formal-definitions|§6.2]]) can do three things with an input: accept it, reject it, or run forever — **diverge**. Sorting the inputs by outcome gives four languages.

> [!definition] Definition — the four languages of a machine; accepting and deciding
> For a Turing machine $M$ with input alphabet $\Sigma$:
> $$
> \begin{aligned}
> \textsf{Accept}(M) &:= \{w\in\Sigma^* \mid M \text{ accepts } w\}, & \textsf{Halt}(M) &:= \textsf{Accept}(M)\cup\textsf{Reject}(M),\\
> \textsf{Reject}(M) &:= \{w\in\Sigma^* \mid M \text{ rejects } w\}, & \textsf{Diverge}(M) &:= \Sigma^*\setminus\textsf{Halt}(M).
> \end{aligned}
> $$
> $M$ **accepts** a language $L$ if $\textsf{Accept}(M) = L$. $M$ **decides** $L$ if moreover $\textsf{Diverge}(M) = \varnothing$ — equivalently, $\textsf{Accept}(M) = L$ and $\textsf{Reject}(M) = \Sigma^*\setminus L$.
>
> A language is **acceptable** (also called semi-computable, semi-decidable, recognizable, listable, or recursively enumerable) if some Turing machine accepts it, and **decidable** (computable, recursive) if some Turing machine decides it.

Every decidable language is acceptable; this chapter shows that the converse fails. *Acceptable* and *decidable* are properties of a **language**, while *accepts* and *decides* relate a **machine** to a language: a machine that accepts the strings starting with `1` and loops on all others does not decide $\mathtt{1}(\mathtt{0}+\mathtt{1})^*$, but another machine does, so the language is decidable.

> [!trap] "Does not accept" is not "rejects"
> - $w\notin\textsf{Accept}(M)$ means that $M$ rejects $w$ **or diverges** on $w$. Every proof in this chapter has to handle both.
> - A decider must halt on **every** string, including strings that do not encode anything; a decider for a language of encodings rejects such garbage.
> - A machine that crashes (moves left off the end of the tape) neither accepts nor rejects, so by the definition the input lands in $\textsf{Diverge}(M)$.

## 7.2 Decidable without knowing the algorithm

Decidability asks whether an algorithm **exists**, not whether anyone can write it down. The book's example: let
$$
\Pi := \{w \mid \text{the binary expansion of } \pi \text{ contains the string } \mathtt{1}^{\lvert w\rvert}\}.
$$
Membership depends only on the length of $w$: $w\in\Pi$ if and only if $\pi$ has a run of at least $\lvert w\rvert$ consecutive 1s.

> [!example] $\Pi$ is decidable — by one of infinitely many machines
> Either the runs of 1s in $\pi$ have bounded length, or they do not.
> - If $\mathtt{1}^N$ appears in $\pi$ but $\mathtt{1}^{N+1}$ does not, then $\Pi = \{w \mid \lvert w\rvert\le N\}$. A machine with $N+3$ states — counting states $0,1,\dots,N$, accept, reject — decides it: it moves right, counting symbols, accepts when it reaches the blank, and rejects if it reads a symbol in state $N$ (the input is too long).
> - Otherwise $\Pi = \Sigma^*$, which the machine that accepts immediately decides.
>
> One of these machines decides $\Pi$, so $\Pi$ is decidable. We just do not know which one. Since $\pi = 11.0010010000111111011\ldots_2$ shows $\mathtt{1}^6$ within 16 bits after the point, every string of length at most 6 is in $\Pi$; the first 4000 bits after the point contain a run of ten 1s, and none longer. Whether the runs are unbounded is an open question.

> [!intuition] "Unknown" is not "undecidable"
> Undecidability says that no single algorithm answers all of infinitely many questions correctly. Every finite language is decidable, whatever its strings are — even if nobody knows them.

## 7.3 Useful properties

> [!key] Lemma 1
> For every Turing machine $M$ there are Turing machines $M^R$, $M^A$ and $M^H$ such that
> - (a) $\textsf{Accept}(M^R) = \textsf{Reject}(M)$ and $\textsf{Reject}(M^R) = \textsf{Accept}(M)$ — swap the accept and reject states;
> - (b) $\textsf{Accept}(M^A) = \textsf{Accept}(M)$ and $\textsf{Reject}(M^A) = \varnothing$ — redirect every transition into the reject state to a new state $\mathit{hang}$ that moves right forever;
> - (c) $\textsf{Accept}(M^H) = \textsf{Halt}(M)$ and $\textsf{Reject}(M^H) = \varnothing$ — redirect every transition into the reject state to the accept state.
>
> (First make the "missing transitions reject" convention explicit, so that every rejection is a transition into the reject state.)

So "rejectable" and "haltable" languages are just the acceptable ones: $\textsf{Reject}(M) = \textsf{Accept}(M^R)$, $\textsf{Halt}(M) = \textsf{Accept}(M^H)$, and $\textsf{Accept}(M) = \textsf{Reject}(M^R) = \textsf{Halt}(M^A)$.

> [!key] Lemma 2
> If $L$ and $L'$ are decidable, then so are $L\cup L'$, $L\cap L'$, $L\setminus L'$ and $L'\setminus L$.

Run the two deciders one after the other on two copies of the input — each halts — and combine the answers. With Lemma 1(a), the complement $\Sigma^*\setminus L$ of a decidable language is decidable too. The contrapositive is a tool for later:

> [!key] Corollary 3
> Let $L'$ be decidable. If $L\cap L'$, $L\cup L'$, $L\setminus L'$ or $L'\setminus L$ is undecidable, then $L$ is undecidable.

> [!key] Lemma 4
> If $L$ and $L'$ are acceptable, then so are $L\cup L'$ and $L\cap L'$.

For $L\cap L'$, run an acceptor $M$ for $L$ and then, if it accepts, an acceptor $M'$ for $L'$; if $M$ never halts, the input is not in $L$ anyway. For $L\cup L'$ this **serial** plan fails: if $M$ accepts the strings starting with `1` and runs forever on all others, and $M'$ decides the strings ending in `0`, then "run $M$, then $M'$" never answers on `00`. Instead run the two machines **in parallel**, one step of each in turn (on two tapes, or on the product of their state sets, as in the [[1-models-of-computation/03-finite-state-machines#36-the-product-construction|product construction]]), and accept as soon as either accepts.

> [!key] Lemma 5
> An acceptable language $L$ is decidable if and only if $\Sigma^*\setminus L$ is also acceptable.

> [!proof]- Proof (click to expand)
> ($\Rightarrow$) If $M$ decides $L$, then $M^R$ (Lemma 1) decides, and in particular accepts, $\Sigma^*\setminus L$.
>
> ($\Leftarrow$) Let $M$ accept $L$ and $\overline{M}$ accept $\Sigma^*\setminus L$. The machine $D$ copies its input $w$ to a second tape and runs $M$ and $\overline{M}$ in parallel, one step each in turn; it accepts as soon as $M$ accepts and rejects as soon as $\overline{M}$ accepts. Every string $w$ lies in exactly one of $L$ and $\Sigma^*\setminus L$, so exactly one of the two machines eventually accepts $w$ (the other may reject or run forever; $D$ ignores that). So $D$ halts on every input with the right answer: it decides $L$. $\blacksquare$

Call $L$ **co-acceptable** if $\Sigma^*\setminus L$ is acceptable. Lemma 5 says: **decidable = acceptable and co-acceptable.** Read backwards, it gives the chapter's first way to prove a language unacceptable:

> [!key] Consequence of Lemma 5
> If $L$ is acceptable but undecidable, then $\Sigma^*\setminus L$ is **not** acceptable.

## 7.4 Code is data; data is code

A Turing machine is a finite object, so it can be written as a string $\langle M\rangle$, and a machine with an input as a string $\langle M, w\rangle$ ([[1-models-of-computation/06-turing-machines#68-universal-turing-machines|§6.8]]). Every argument in this chapter treats machines as inputs to other machines, and relies on three properties of the encoding:

- **Unique.** Different machines get different encodings, and an algorithm can tell whether a string encodes a machine.
- **Modifiable.** An algorithm can turn $\langle M\rangle$ into the encoding $\langle M'\rangle$ of a related machine: swap accept and reject, redirect transitions, first erase the input and write a fixed string $w$, run $M$ as a subroutine or in parallel with other machines.
- **Executable.** The [[concepts/universal-turing-machine|universal machine]] $U$ accepts, rejects or diverges on $\langle M, w\rangle$ exactly as $M$ does on $w$.

> [!key] The fact every reduction uses
> Computing $\langle M'\rangle$ from $\langle M\rangle$ (and a string $w$) is a simple algorithm that always halts — even if $M'$ itself would run forever on every input. Writing a program down is not running it.

## 7.5 Self-haters gonna self-hate

Feed machines their own encodings. Let
$$
\textsf{SelfReject} := \{\langle M\rangle \mid M \text{ rejects } \langle M\rangle\}.
$$

> [!key] Theorem 6
> $\textsf{SelfReject}$ is undecidable.

> [!example] Proof of Theorem 6 — the model diagonal argument
> Suppose for the sake of argument that some Turing machine $\textsf{SR}$ decides $\textsf{SelfReject}$. Then $\textsf{SR}$ halts on every input, and for **every** Turing machine $M$,
> $$
> \textsf{SR} \text{ accepts } \langle M\rangle \iff \langle M\rangle\in\textsf{SelfReject} \iff M \text{ rejects } \langle M\rangle.
> $$
> In particular this holds for $M = \textsf{SR}$. Run $\textsf{SR}$ on its own encoding. Because $\textsf{SR}$ halts on every input, there are two cases.
> - If $\textsf{SR}$ accepts $\langle\textsf{SR}\rangle$, the equivalence with $M = \textsf{SR}$ says that $\textsf{SR}$ rejects $\langle\textsf{SR}\rangle$ — a contradiction.
> - If $\textsf{SR}$ rejects $\langle\textsf{SR}\rangle$, the equivalence says that $\textsf{SR}$ accepts $\langle\textsf{SR}\rangle$ — a contradiction.
>
> Both cases are impossible, so $\textsf{SR}$ does not exist. $\blacksquare$

> - The contradiction comes from running the machine **built from the hypothetical decider** on **its own encoding**. Plugging in some other machine proves nothing.

## 7.6 Aside: uncountable barbers

> [!key] Cantor's theorem
> For every set $X$, no function $f\colon X\to 2^X$ is onto.

> [!proof]- Proof (click to expand)
> Call $x$ *sad* if $x\notin f(x)$, and let $Y := \{x\in X \mid x\notin f(x)\}$ be the set of sad elements. If $Y = f(y)$ for some $y\in X$, then $y\in Y \iff y\notin f(y) \iff y\notin Y$, which is impossible. So $Y$ is not in the image of $f$. $\blacksquare$

Apply it with $X = \Sigma^*$ and $f(w) := \textsf{Accept}(M)$ if $w = \langle M\rangle$, $f(w) := \varnothing$ otherwise. Every acceptable language is in the image of $f$, so **not every language is acceptable**. The proof even names one: $Y = \Sigma^*\setminus\textsf{SelfAccept}$ (every non-encoding, and every $\langle M\rangle$ that $M$ does not accept). In counting terms ([[1-models-of-computation/02-regular-languages#28-not-every-language-is-regular|§2.8]], [[concepts/counting-arguments]]): countably many machines, uncountably many languages. Russell's barber — who cuts the hair of exactly those who do not cut their own — is the same argument, with "cuts the hair of" for "accepts the encoding of".

## 7.7 More self-referential languages

$$
\begin{aligned}
\textsf{SelfAccept} &:= \{\langle M\rangle \mid M \text{ accepts } \langle M\rangle\},\\
\textsf{SelfHalt} &:= \{\langle M\rangle \mid M \text{ halts on } \langle M\rangle\},\\
\textsf{SelfDiverge} &:= \{\langle M\rangle \mid M \text{ diverges on } \langle M\rangle\}.
\end{aligned}
$$

Each proof builds a **wrapper** machine from the hypothetical one with Lemma 1 and runs it on its own encoding.

> [!key] Theorem 7
> $\textsf{SelfAccept}$ is undecidable.

> [!proof]- Proof (click to expand)
> Suppose $\textsf{SA}$ decides $\textsf{SelfAccept}$, and let $\textsf{SA}^R$ be $\textsf{SA}$ with its accept and reject states swapped. Then $\textsf{SA}^R$ halts on every input, and for every machine $M$, $\textsf{SA}^R$ rejects $\langle M\rangle$ if and only if $M$ accepts $\langle M\rangle$. Take $M = \textsf{SA}^R$. If $\textsf{SA}^R$ accepts $\langle\textsf{SA}^R\rangle$, the equivalence says that $\textsf{SA}^R$ rejects $\langle\textsf{SA}^R\rangle$; if $\textsf{SA}^R$ rejects $\langle\textsf{SA}^R\rangle$, the equivalence says that $\textsf{SA}^R$ accepts $\langle\textsf{SA}^R\rangle$. Both are contradictions, so $\textsf{SA}$ does not exist. $\blacksquare$

> [!key] Theorem 8
> $\textsf{SelfHalt}$ is undecidable.

> [!proof]- Proof (click to expand)
> Suppose $\textsf{SH}$ decides $\textsf{SelfHalt}$. Build $\textsf{SHX}$ from $\textsf{SH}$ by redirecting every transition into the accept state to a looping state $\mathit{hang}$, and every transition into the reject state to the accept state. On input $\langle M\rangle$, $\textsf{SH}$ halts; so $\textsf{SHX}$ runs forever if $M$ halts on $\langle M\rangle$, and accepts if $M$ diverges on $\langle M\rangle$. For $M = \textsf{SHX}$: $\textsf{SHX}$ halts on $\langle\textsf{SHX}\rangle$ if and only if $\textsf{SHX}$ diverges on $\langle\textsf{SHX}\rangle$ — a contradiction. $\blacksquare$

> [!key] Theorem 9
> $\textsf{SelfDiverge}$ is not acceptable (and therefore not decidable).

> [!proof]- Proof (click to expand)
> Suppose $\textsf{SD}$ *accepts* $\textsf{SelfDiverge}$ — it need not halt on other inputs. Let $\textsf{SDA} := \textsf{SD}^A$ (Lemma 1(b): rejections become endless loops). Then $\textsf{SDA}$ accepts exactly $\textsf{SelfDiverge}$ and rejects nothing, so $\textsf{SDA}$ halts on an input exactly when it accepts it. For the input $\langle\textsf{SDA}\rangle$:
> $$
> \textsf{SDA} \text{ halts on } \langle\textsf{SDA}\rangle \iff \langle\textsf{SDA}\rangle\in\textsf{SelfDiverge} \iff \textsf{SDA} \text{ diverges on } \langle\textsf{SDA}\rangle,
> $$
> a contradiction. The proof never needed $\textsf{SD}$ to halt, which is why it rules out an acceptor, not just a decider. $\blacksquare$

> [!template] Template — undecidability by diagonalization
> Suppose for the sake of argument that some Turing machine $\textsf{Dec}$ decides $L$. \
> Build a new machine $\textsf{Wrap}$ from $\textsf{Dec}$: *[swap $\textsf{Dec}$'s accept and reject states / redirect its accepting transitions to a looping state / …]*. \
> Then for every Turing machine $M$: $\textsf{Wrap}$ *[accepts, or halts on]* $\langle M\rangle$ if and only if $M$ *[does not …]* $\langle M\rangle$. \
> In particular, take $M = \textsf{Wrap}$. \
> If $\textsf{Wrap}$ *[accepts]* $\langle\textsf{Wrap}\rangle$, then by the line above $\textsf{Wrap}$ does not *[accept]* $\langle\textsf{Wrap}\rangle$ — a contradiction. \
> If $\textsf{Wrap}$ does not *[accept]* $\langle\textsf{Wrap}\rangle$, then by the line above $\textsf{Wrap}$ *[accepts]* $\langle\textsf{Wrap}\rangle$ — a contradiction. \
> So $\textsf{Dec}$ does not exist, and $L$ is undecidable. $\blacksquare$

> [!exam] How a diagonalization proof is graded
> Out of 10: **4** for the wrapper machine — built from the hypothetical decider, with its behavior on $\langle M\rangle$ stated — and **6** for the contradiction, **3** for each of the two cases.

## 7.8 Nevertheless, acceptable

> [!key] Theorem 10
> $\textsf{SelfAccept}$ is acceptable.

> [!key] Theorem 11
> $\textsf{SelfReject}$ is acceptable.

On input $w$, reject if $w$ is not the encoding of a machine; otherwise $w = \langle M\rangle$, so write $\langle M, \langle M\rangle\rangle$ and run the universal machine $U$ on it (for Theorem 10), or $U^R$, with accept and reject swapped (for Theorem 11). $U$ accepts exactly when $M$ accepts $\langle M\rangle$, and $U^R$ exactly when $M$ rejects $\langle M\rangle$. Then $\textsf{SelfHalt} = \textsf{SelfAccept}\cup\textsf{SelfReject}$ is acceptable by Lemma 4.

| language | decidable? | acceptable? |
|---|---|---|
| $\textsf{SelfReject}$ | no (Theorem 6) | yes (Theorem 11) |
| $\textsf{SelfAccept}$ | no (Theorem 7) | yes (Theorem 10) |
| $\textsf{SelfHalt}$ | no (Theorem 8) | yes (Lemma 4) |
| $\textsf{SelfDiverge}$ | no | no (Theorem 9) |

By the consequence of Lemma 5, the complements of $\textsf{SelfAccept}$, $\textsf{SelfReject}$ and $\textsf{SelfHalt}$ are not acceptable. The last gives Theorem 9 again: $\Sigma^*\setminus\textsf{SelfHalt}$ is $\textsf{SelfDiverge}$ plus the (decidable) set of non-encodings, so $\textsf{SelfDiverge}$ cannot be acceptable either (Lemma 4).

## 7.9 The halting problem via reduction

Now let the input carry the machine and the string separately:
$$
\begin{aligned}
\textsf{Accept} &:= \{\langle M, w\rangle \mid M \text{ accepts } w\}, & \textsf{Halt} &:= \{\langle M, w\rangle \mid M \text{ halts on } w\},\\
\textsf{Reject} &:= \{\langle M, w\rangle \mid M \text{ rejects } w\}, & \textsf{Diverge} &:= \{\langle M, w\rangle \mid M \text{ diverges on } w\}.
\end{aligned}
$$
The universal machine shows that $\textsf{Accept}$, $\textsf{Reject}$ and $\textsf{Halt}$ are acceptable (run $U$, $U^R$, $U^H$).

> [!key] Theorem 12
> $\textsf{Halt}$ is undecidable.

> [!proof]- Proof (click to expand)
> Suppose some machine $\textsf{H}$ decides $\textsf{Halt}$. Build $\textsf{SH}$: on input $w$, reject if $w$ is not the encoding of a machine; otherwise $w = \langle M\rangle$, so write $\langle M, \langle M\rangle\rangle$ on the tape and run $\textsf{H}$ on it, returning its answer. $\textsf{SH}$ halts on every input, and it accepts $\langle M\rangle$ exactly when $M$ halts on $\langle M\rangle$. So $\textsf{SH}$ decides $\textsf{SelfHalt}$, contradicting Theorem 8. $\blacksquare$

The same argument with $\textsf{SelfAccept}$, $\textsf{SelfReject}$ or $\textsf{SelfDiverge}$ shows that $\textsf{Accept}$, $\textsf{Reject}$ and $\textsf{Diverge}$ are undecidable; $\textsf{Diverge}$ is not even acceptable, since its complement is (Lemma 5). The proof **reduces** $\textsf{SelfHalt}$ to $\textsf{Halt}$: it solves $\textsf{SelfHalt}$ with a solver for $\textsf{Halt}$ as a subroutine. That is the general method.

> [!key] The direction of a reduction
> To prove that $L$ is undecidable, **reduce a known undecidable language to $L$**: assume that some machine decides $L$, and use it as a black-box subroutine in a machine that decides a language already known to be undecidable. Then the assumed machine cannot exist.
>
> Reducing $L$ *to* a known undecidable language — deciding $L$ with the help of a decider for $\textsf{Halt}$ — proves nothing: every decidable language reduces to $\textsf{Halt}$ too.

> [!template] Template — undecidability by reduction from $\textsf{Accept}$
> Suppose for the sake of argument that some Turing machine $\textsf{DecideL}$ decides $L$. \
> Consider the following machine $\textsf{DecideAccept}$. Given $\langle M, w\rangle$, it writes the encoding $\langle M'\rangle$ of the machine \
> $\quad M'(x)$: *[for example: ignore $x$; run $M$ on $w$; then …]* \
> and then runs $\textsf{DecideL}$ on $\langle M'\rangle$ and returns its answer. \
> $\Rightarrow$ Suppose $M$ accepts $w$. Then $M'$ *[…]*, so $\langle M'\rangle\in L$. So $\textsf{DecideL}$ accepts $\langle M'\rangle$, and $\textsf{DecideAccept}$ accepts $\langle M, w\rangle$. \
> $\Leftarrow$ Suppose $M$ does not accept $w$ — it rejects or diverges. Then $M'$ *[…]*, so $\langle M'\rangle\notin L$. So $\textsf{DecideL}$ rejects $\langle M'\rangle$, and $\textsf{DecideAccept}$ rejects $\langle M, w\rangle$. \
> In both cases $\textsf{DecideAccept}$ is correct, and it always halts. So $\textsf{DecideAccept}$ decides $\textsf{Accept}$, which is impossible. \
> We conclude that $\textsf{DecideL}$ does not exist: $L$ is undecidable. $\blacksquare$

> [!trap] Reductions juggle four machines
> - **Name every machine** and never write "it" or "the machine": the hypothetical decider ($\textsf{DecideL}$), the decider you build ($\textsf{DecideAccept}$), its input machine ($M$), and the machine whose encoding you write down ($M'$).
> - $\textsf{DecideAccept}$ **never runs** $M'$; it only writes $\langle M'\rangle$. $M'$ may run forever — that is usually the point — but $\textsf{DecideAccept}$ must always halt.
> - **"Does not accept" means rejects or diverges**, and the second direction must cover both. If $M'$ runs $M$ on $w$ and $M$ diverges, $M'$ is stuck forever.
> - **Wrong direction:** building a decider for $L$ out of a decider for $\textsf{Accept}$ proves nothing.

> [!exam] How a reduction proof is graded
> Out of 10: **4** for the reduction itself — a correct description of the new decider and of $M'$, in the right direction — **3** for showing that a yes-instance ($M$ accepts $w$) leads to acceptance, and **3** for showing that a no-instance ($M$ rejects *or diverges*) leads to rejection.

## 7.10 More undecidable languages

$$
\textsf{NeverAccept} := \{\langle M\rangle \mid \textsf{Accept}(M) = \varnothing\}.
$$

> [!key] Theorem 13
> $\textsf{NeverAccept}$ is undecidable.

> [!example] Proof of Theorem 13 — the model reduction
> Suppose for the sake of argument that some Turing machine $\textsf{NA}$ decides $\textsf{NeverAccept}$. Consider the following machine $\textsf{DecideAccept}$. Given $\langle M, w\rangle$, it writes the encoding $\langle M_w\rangle$ of the machine
> $$
> M_w(x)\colon \text{ erase } x;\ \text{write } w \text{ on the tape};\ \text{run } M \text{ (on } w).
> $$
> Then $\textsf{DecideAccept}$ runs $\textsf{NA}$ on $\langle M_w\rangle$ and returns the **opposite** answer (equivalently, it runs $\textsf{NA}^R$). $\textsf{DecideAccept}$ always halts: writing $\langle M_w\rangle$ is an algorithm, and $\textsf{NA}$ halts on every input.
> - Suppose $M$ accepts $w$. Then $M_w$ accepts every input $x$, so $\textsf{Accept}(M_w) = \Sigma^*\ne\varnothing$, so $\langle M_w\rangle\notin\textsf{NeverAccept}$. So $\textsf{NA}$ rejects $\langle M_w\rangle$, and $\textsf{DecideAccept}$ accepts $\langle M, w\rangle$.
> - Suppose $M$ does not accept $w$. Then on every input $x$, $M_w$ either rejects (if $M$ rejects $w$) or runs forever (if $M$ diverges on $w$); either way $\textsf{Accept}(M_w) = \varnothing$, so $\langle M_w\rangle\in\textsf{NeverAccept}$. So $\textsf{NA}$ accepts $\langle M_w\rangle$, and $\textsf{DecideAccept}$ rejects $\langle M, w\rangle$.
>
> In both cases $\textsf{DecideAccept}$ answers correctly, so it decides $\textsf{Accept}$ — which is impossible. Hence $\textsf{NA}$ does not exist. $\blacksquare$

$M_w$ is the workhorse of reductions: $\textsf{Accept}(M_w)$ is $\Sigma^*$ or $\varnothing$, depending on what $M$ does with $w$. $\textsf{NeverAccept}$ is not even acceptable, by Lemma 5: its complement ($\textsf{Accept}(M)\ne\varnothing$, plus garbage) is acceptable — in round $t = 1, 2, \dots$ run $M$ for $t$ steps on each of the first $t$ strings of $\Sigma^*$.

The same reduction with $\textsf{Reject}(M_w)$, $\textsf{Halt}(M_w)$ or $\textsf{Diverge}(M_w)$ in place of $\textsf{Accept}(M_w)$ shows that
$$
\begin{aligned}
\textsf{NeverReject} &:= \{\langle M\rangle \mid \textsf{Reject}(M) = \varnothing\},\\
\textsf{NeverHalt} &:= \{\langle M\rangle \mid \textsf{Halt}(M) = \varnothing\},\\
\textsf{NeverDiverge} &:= \{\langle M\rangle \mid \textsf{Diverge}(M) = \varnothing\}
\end{aligned}
$$
are undecidable too (reduce from $\textsf{Reject}$, from $\textsf{Halt}$, and from $\textsf{Halt}$ again: $\textsf{Diverge}(M_w) = \varnothing$ exactly when $M$ halts on $w$). Each new undecidable language becomes a starting point for further reductions:

> [!key] Theorem 14
> $\textsf{DivergeSame} := \{\langle M_1\rangle\langle M_2\rangle \mid \textsf{Diverge}(M_1) = \textsf{Diverge}(M_2)\}$ is undecidable.

> [!proof]- Proof (click to expand)
> Suppose $\textsf{DS}$ decides $\textsf{DivergeSame}$. Fix a machine $Y$ that accepts every input at once, so $\textsf{Diverge}(Y) = \varnothing$. The machine $\textsf{ND}$ that, given $\langle M\rangle$, runs $\textsf{DS}$ on $\langle M\rangle\langle Y\rangle$ accepts exactly when $\textsf{Diverge}(M) = \varnothing$. So $\textsf{ND}$ decides $\textsf{NeverDiverge}$ — impossible. $\blacksquare$

## 7.11 Rice's theorem

Most of these reductions follow one pattern, and Rice's theorem does it once and for all. A **property of languages** is a set $\mathcal{L}$ of languages; define
$$
\textsf{AcceptIn}(\mathcal{L}) := \{\langle M\rangle \mid \textsf{Accept}(M)\in\mathcal{L}\}.
$$
For example, $\textsf{NeverAccept} = \textsf{AcceptIn}(\{\varnothing\})$.

> [!key] Rice's theorem
> Let $\mathcal{L}$ be a set of languages such that $\textsf{Accept}(Y)\in\mathcal{L}$ for some Turing machine $Y$, and $\textsf{Accept}(N)\notin\mathcal{L}$ for some Turing machine $N$. Then $\textsf{AcceptIn}(\mathcal{L})$ is undecidable.
>
> **Form closer to the proof:** if $\varnothing\notin\mathcal{L}$ and $\textsf{Accept}(Y)\in\mathcal{L}$ for some Turing machine $Y$, then $\textsf{AcceptIn}(\mathcal{L})$ is undecidable.

> [!proof]- Proof sketch (click to expand)
> *The form with $\varnothing\notin\mathcal{L}$.* Suppose $\textsf{AL}$ decides $\textsf{AcceptIn}(\mathcal{L})$. Build $\textsf{DecideHalt}$: given $\langle M, w\rangle$, write the encoding of
> $$
> \textsf{WTF}(x)\colon \text{ run } M \text{ on } w \text{ and ignore the result};\ \text{then run } Y \text{ on } x \text{ and return its answer},
> $$
> run $\textsf{AL}$ on $\langle\textsf{WTF}\rangle$, and return its answer. If $M$ halts on $w$, then $\textsf{WTF}$ behaves exactly like $Y$, so $\textsf{Accept}(\textsf{WTF}) = \textsf{Accept}(Y)\in\mathcal{L}$, and $\textsf{AL}$ accepts. If $M$ diverges on $w$, then $\textsf{WTF}$ diverges on every input, so $\textsf{Accept}(\textsf{WTF}) = \varnothing\notin\mathcal{L}$, and $\textsf{AL}$ rejects. So $\textsf{DecideHalt}$ decides $\textsf{Halt}$, which is impossible.
>
> *The general form.* If $\varnothing\notin\mathcal{L}$, use the first form with $Y$. If $\varnothing\in\mathcal{L}$, apply the first form to the complementary property $\mathcal{L}'$ (all languages not in $\mathcal{L}$), which does not contain $\varnothing$ and does contain $\textsf{Accept}(N)$. Then $\textsf{AcceptIn}(\mathcal{L}')$ is undecidable; it is the set of encodings minus $\textsf{AcceptIn}(\mathcal{L})$, so $\textsf{AcceptIn}(\mathcal{L})$ is undecidable by Corollary 3. $\blacksquare$

> [!recipe] Using Rice's theorem
> 1. **Name the property.** Write the language as $\textsf{AcceptIn}(\mathcal{L})$ with an explicit set of languages $\mathcal{L}$, and check that membership of $\langle M\rangle$ depends **only on $\textsf{Accept}(M)$**: two machines with the same language must be both in or both out.
> 2. **Give a machine $Y$ with $\textsf{Accept}(Y)\in\mathcal{L}$**, concretely.
> 3. **Give a machine $N$ with $\textsf{Accept}(N)\notin\mathcal{L}$**, concretely.
> 4. Conclude: by Rice's theorem, $\textsf{AcceptIn}(\mathcal{L})$ is undecidable.
>
> Handy witnesses: $M_{\textsf{Accept}}$ accepts every input at once ($\textsf{Accept} = \Sigma^*$); $M_{\textsf{Reject}}$ rejects every input at once ($\textsf{Accept} = \varnothing$, $\textsf{Reject} = \Sigma^*$); $M_{\textsf{Diverge}}$ moves right forever ($\textsf{Accept} = \varnothing$, $\textsf{Diverge} = \Sigma^*$).

> [!key] Corollary 15
> Each of the following languages is undecidable:
>
> | | $\{\langle M\rangle \mid \ldots\}$ | a machine with the property | a machine without it |
> |---|---|---|---|
> | (a) | $M$ accepts $\varepsilon$ (starting on an empty tape) | $M_{\textsf{Accept}}$ | $M_{\textsf{Reject}}$ |
> | (b) | $M$ accepts the string $\mathtt{UIUC}$ | $M_{\textsf{Accept}}$ | $M_{\textsf{Reject}}$ |
> | (c) | $M$ accepts exactly three strings | a decider for $\{\mathtt{0},\mathtt{00},\mathtt{000}\}$ | $M_{\textsf{Reject}}$ |
> | (d) | $M$ accepts every palindrome | $M_{\textsf{Accept}}$ | $M_{\textsf{Reject}}$ |
> | (e) | $\textsf{Accept}(M)$ is regular | $M_{\textsf{Reject}}$ ($\varnothing$ is regular) | a decider for $\{\mathtt{0}^n\mathtt{1}^n\}$ |
> | (f) | $\textsf{Accept}(M)$ is not regular | a decider for $\{\mathtt{0}^n\mathtt{1}^n\}$ | $M_{\textsf{Reject}}$ |
> | (g) | $\textsf{Accept}(M)$ is undecidable | an acceptor for $\textsf{SelfReject}$ (Theorem 11) | $M_{\textsf{Reject}}$ |
> | (h) | $\textsf{Accept}(M) = \textsf{Accept}(N)$, for a fixed machine $N$ | $N$ itself | $M_{\textsf{Reject}}$, or $M_{\textsf{Accept}}$ if $\textsf{Accept}(N) = \varnothing$ |

Extra parameters do not get in the way: fix them.

> [!key] Theorem 16
> $\{\langle M, w\rangle \mid M \text{ accepts } w^k \text{ for every integer } k\ge0\}$ is undecidable.

For a fixed string $w$, the property $\mathcal{L}_w := \{L \mid w^k\in L \text{ for every } k\ge0\}$ contains $\textsf{Accept}(M_{\textsf{Accept}}) = \Sigma^*$ but not $\textsf{Accept}(M_{\textsf{Reject}}) = \varnothing$, which does not even contain $w^0 = \varepsilon$. So $\textsf{AcceptIn}(\mathcal{L}_w)$ is undecidable; a decider for the language of pairs would decide it by appending the fixed $w$ to its input.

> [!key] Rice's rejection, halting, divergence and decision theorems
> The same proof works for the other languages of a machine. If $\textsf{Reject}(Y)\in\mathcal{L}$ and $\textsf{Reject}(N)\notin\mathcal{L}$ for some machines $Y$ and $N$, then $\textsf{RejectIn}(\mathcal{L}) := \{\langle M\rangle \mid \textsf{Reject}(M)\in\mathcal{L}\}$ is undecidable. Likewise $\textsf{HaltIn}(\mathcal{L})$ (with $\textsf{Halt}$) and $\textsf{DivergeIn}(\mathcal{L})$ (with $\textsf{Diverge}$); and if some machine $Y$ decides a language in $\mathcal{L}$ and some machine $N$ decides a language not in $\mathcal{L}$, then $\textsf{DecideIn}(\mathcal{L}) := \{\langle M\rangle \mid M \text{ decides a language in } \mathcal{L}\}$ is undecidable.

**Choose the variant that matches the definition**, and describe the witnesses by *that* language: $\textsf{NeverDiverge} = \textsf{DivergeIn}(\{\varnothing\})$ with $Y = M_{\textsf{Accept}}$ ($\textsf{Diverge} = \varnothing$) and $N = M_{\textsf{Diverge}}$ ($\textsf{Diverge} = \Sigma^*$); $\textsf{NeverHalt} = \textsf{HaltIn}(\{\varnothing\})$ with $Y = M_{\textsf{Diverge}}$ and $N = M_{\textsf{Accept}}$.

> [!trap] When Rice's theorem does not apply
> - **Behavior is not language.** $\textsf{ThisIsSparta} := \{\langle M\rangle \mid M \text{ accepts } \mathtt{SPARTA} \text{ after exactly 300 steps}\}$ is *decidable* — simulate 300 steps. Machines that accept every input after exactly 300 and after 301 steps have the same language, but only the first is in it, so it is not a property of $\textsf{Accept}(M)$.
> - **Self-reference.** $\textsf{RevAccept} := \{\langle M\rangle \mid M \text{ accepts } \langle M\rangle^R\}$ depends on $M$'s own encoding, so Rice does not apply; it is undecidable by a reduction. Given $\langle M, w\rangle$, write $\langle M'\rangle$ for "ignore the input; run $M$ on $w$": $M'$ accepts $\langle M'\rangle^R$ (and everything else) if $M$ accepts $w$, and nothing otherwise.
> - **Trivial properties.** If every acceptable language has the property, or none does, there is no $Y$ or no $N$, and the language is decidable: $\{\langle M\rangle \mid \textsf{Accept}(M) \text{ is acceptable}\}$ is just the set of all encodings.
> - **Rice proves undecidability only,** not unacceptability — for that, see §7.12.

> [!exam] How a proof by Rice's theorem is graded
> Out of 10: **4** for a machine whose language has the property, **4** for a machine whose language does not, and **2** for the details — including stating the property as a set of languages and using the right variant of the theorem.

## 7.12 The Rice–McNaughton–Myhill–Shapiro theorem

This section is optional in the book. Rice's theorem says when $\textsf{AcceptIn}(\mathcal{L})$ is undecidable; this theorem says exactly when it is *acceptable*.

> [!definition] Definition — monotone, compact, finitely acceptable
> A set $\mathcal{L}$ of acceptable languages is
> - **monotone** if every acceptable superset of a language in $\mathcal{L}$ is also in $\mathcal{L}$;
> - **compact** if every language in $\mathcal{L}$ has a finite subset that is also in $\mathcal{L}$;
> - **finitely acceptable** if the language $\{\langle L\rangle \mid L\in\mathcal{L} \text{ and } L \text{ is finite}\}$ is acceptable, where $\langle L\rangle$ lists the strings of $L$.

> [!key] The Rice–McNaughton–Myhill–Shapiro theorem
> For every set $\mathcal{L}$ of acceptable languages, $\textsf{AcceptIn}(\mathcal{L})$ is acceptable if and only if $\mathcal{L}$ is monotone, compact and finitely acceptable.

> [!key] Lemma 17
> If $\mathcal{L}$ is not monotone, then $\textsf{AcceptIn}(\mathcal{L})$ is not acceptable.

> [!proof]- Proof sketch (click to expand)
> Pick machines $Y$ and $N$ with $\textsf{Accept}(Y)\in\mathcal{L}$, $\textsf{Accept}(N)\notin\mathcal{L}$ and $\textsf{Accept}(Y)\subseteq\textsf{Accept}(N)$ (that is what "not monotone" provides). Given $\langle M\rangle$, write the encoding of the machine $\textsf{WTF}$ that, on input $x$, runs $Y$ on $x$, $N$ on $x$ and $M$ on $\langle M\rangle$ in parallel, and accepts if $Y$ accepts $x$, or if $N$ accepts $x$ and $M$ halts on $\langle M\rangle$. If $M$ halts on $\langle M\rangle$, then $\textsf{Accept}(\textsf{WTF}) = \textsf{Accept}(Y)\cup\textsf{Accept}(N) = \textsf{Accept}(N)\notin\mathcal{L}$; otherwise $\textsf{Accept}(\textsf{WTF}) = \textsf{Accept}(Y)\in\mathcal{L}$. So $\langle\textsf{WTF}\rangle\in\textsf{AcceptIn}(\mathcal{L})$ exactly when $\langle M\rangle\in\textsf{SelfDiverge}$, and an acceptor for $\textsf{AcceptIn}(\mathcal{L})$ would give an acceptor for $\textsf{SelfDiverge}$, contradicting Theorem 9. $\blacksquare$

> [!key] Corollary 18
> Each of the following languages is not acceptable:
>
> | | $\{\langle M\rangle \mid \ldots\}$ | the condition that fails |
> |---|---|---|
> | (a) | $\textsf{Accept}(M)$ is finite | monotone: $\varnothing$ is finite, $\Sigma^*\supseteq\varnothing$ is not |
> | (b) | $\textsf{Accept}(M)$ is infinite | compact: no finite subset of $\Sigma^*$ is infinite |
> | (c) | $\textsf{Accept}(M)$ is regular | monotone: $\varnothing\subseteq\{\mathtt{0}^n\mathtt{1}^n\}$ |
> | (d) | $\textsf{Accept}(M)$ is not regular | monotone: $\{\mathtt{0}^n\mathtt{1}^n\}\subseteq\Sigma^*$ |
> | (e) | $\textsf{Accept}(M)$ is decidable | monotone: $\varnothing\subseteq\textsf{SelfReject}$ |
> | (f) | $\textsf{Accept}(M)$ is undecidable | monotone: $\textsf{SelfReject}\subseteq\Sigma^*$ |
> | (g) | $M$ accepts at least one string in $\textsf{SelfDiverge}$ | finitely acceptable: $w\in\textsf{SelfDiverge}$ iff the one-string language $\{w\}$ has the property |
> | (h) | $\textsf{Accept}(M) = \textsf{Accept}(N)$, for a fixed machine $N$ | monotone if $\textsf{Accept}(N)\ne\Sigma^*$; compact if $\textsf{Accept}(N) = \Sigma^*$ |

## 7.13 Turing machine behavior: it's complicated

Rice's theorem covers properties of the language. Properties of a machine's **behavior** have no such rule, and examples go both ways.

$$
\textsf{NeverLeft} := \{\langle M, w\rangle \mid M \text{ never moves left when run on input } w\}.
$$

> [!key] Theorem 19
> $\textsf{NeverLeft}$ is decidable.

> [!proof]- Proof (click to expand)
> Simulate $M$ on $w$, one step at a time. **Reject** as soon as $M$ moves left. **Accept** if $M$ halts. **Accept** once $M$ has read more than $\lvert Q\rvert$ blanks, where $Q$ is $M$'s set of states.
>
> The last rule is the heart of the proof. While $M$ moves only right, it reads each cell exactly once; after the input it reads only blanks that it has never written on, so each of its moves there depends on its current state alone. Among more than $\lvert Q\rvert$ blank reads, two happen in the same state $q$. Everything $M$ did between those two moments — all right moves — therefore repeats forever: $M$ never halts and never moves left, and accepting is correct. The simulation stops after at most $\lvert w\rvert + \lvert Q\rvert$ steps, so this is a decider. $\blacksquare$

$$
\textsf{LeftThree} := \{\langle M, w\rangle \mid M \text{ eventually moves left three times in a row when run on input } w\}.
$$

> [!key] Theorem 20
> $\textsf{LeftThree}$ is undecidable.

> [!proof]- Proof sketch (click to expand)
> Reduce from $\textsf{Accept}$. From $\langle M\rangle$, build $M'$ that simulates $M$ step by step with two changes. After each simulated step, $M'$ moves right once and then left once, so it never makes three left moves in a row while simulating. And instead of entering the accept state, $M'$ moves right three times and then left three times (changing nothing), and only then accepts; the right moves first keep it from falling off the left end. So $M'$ moves left three times in a row on $w$ exactly when $M$ accepts $w$, and a decider for $\textsf{LeftThree}$ would decide $\textsf{Accept}$. $\blacksquare$

$\textsf{LeftThree}$ is acceptable (simulate and wait), so it sits with $\textsf{Halt}$ in the left lune of the figure in §7.8; $\textsf{NeverLeft}$ is decidable.

> [!tip] Rules of thumb for behaviors (heuristics, not theorems)
> - **Probably undecidable** if a machine could simulate an arbitrary Turing machine while avoiding the behavior, and show it only when the simulation accepts: reentering the start state, revisiting the left end of the tape, writing a blank, moving left three times in a row.
> - **Probably decidable** if the behavior confines the machine to finitely many configurations, or forces it into an endless loop after finitely many steps: ever leaving the start state, reading the whole input, writing a non-blank symbol over a blank, never moving left.

## Summary

- $\textsf{Accept}(M)$, $\textsf{Reject}(M)$, $\textsf{Diverge}(M)$ partition $\Sigma^*$; deciding means also $\textsf{Diverge}(M) = \varnothing$. "Does not accept" means rejects *or* diverges.
- Decidable languages are closed under boolean operations, acceptable ones under $\cup$ (in parallel) and $\cap$. Decidable = acceptable and co-acceptable (Lemma 5).
- Diagonalization: run the machine built from a hypothetical decider on its own encoding. $\textsf{SelfReject}$, $\textsf{SelfAccept}$, $\textsf{SelfHalt}$ are undecidable but acceptable; $\textsf{SelfDiverge}$ is unacceptable; by Cantor, most languages are.
- Reduction: decide a known undecidable language with a hypothetical decider for $L$ — never the other way round. Writing $\langle M'\rangle$ always halts; running $M'$ need not.
- $\textsf{Halt}$, $\textsf{Accept}$, $\textsf{NeverAccept}$, $\textsf{DivergeSame}$, … are undecidable; $M_w$ ("ignore $x$, run $M$ on $w$") has language $\Sigma^*$ or $\varnothing$.
- Rice: a property of $\textsf{Accept}(M)$ with a yes-machine and a no-machine is undecidable; use the variant that matches the definition. Not for behavior or self-reference. RMMS: non-monotone properties are not even acceptable.
- Behaviors go either way: $\textsf{NeverLeft}$ is decidable ($\lvert Q\rvert$ blanks), $\textsf{LeftThree}$ is not.

An undecidability proof is graded out of 10 with one of three rubrics: **diagonalization** (4 wrapper machine + 6 contradiction, 3 per case), **reduction** (4 reduction + 3 + 3 for the two directions), or **Rice's theorem** (4 yes-machine + 4 no-machine + 2 details, including the right variant). Pick the tool first: a property of $\textsf{Accept}(M)$ calls for Rice; self-reference or behavior calls for a reduction (usually with $M_w$) or a diagonal argument. True/false practice: "every acceptable language is decidable" (false: $\textsf{SelfReject}$); "the complement of an acceptable language is acceptable" (false: $\textsf{SelfDiverge}$); "'$M$ has 374 states' is undecidable by Rice's theorem" (false: decidable — a property of the machine, not its language). Rubric details: [[0-toolkit/06-how-exams-are-graded|how exams are graded]]; review: [[0-toolkit/05-review-turing-machines-and-undecidability|Turing machines and undecidability]].
