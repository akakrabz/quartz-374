*Problem · style of the Midterm 1 DFA-and-regular-expression problem · uses [[1-models-of-computation/02-regular-languages#designing-a-regular-expression|§2.3]], [[1-models-of-computation/03-finite-state-machines#35-designing-dfas-dfas-are-algorithms|§3.5]] · concepts: [[concepts/dfa]], [[concepts/regular-expressions]]*

> [!question] Problem
> Let $L$ be the set of binary strings in which the substring $\mathtt{01}$ occurs **exactly twice**. For example, `0101`, `01010`, `1001101` and `00110011` are in $L$; $\varepsilon$, `01`, `0110`, `1100` and `010101` are not.
>
> (a) Give a DFA that accepts $L$. Use mnemonic state names; no proof is required.
>
> (b) Give a regular expression for $L$, and explain each part in English; no proof is required.

**Look at a typical string first.** Cut it into maximal runs: `1001101` = `1|00|11|0|1`. An occurrence of `01` is exactly a place where a run of 0s ends and a run of 1s begins: two occurrences cannot overlap, and nothing else creates one. So $w\in L$ exactly when $w$ has two such boundaries — an optional run of 1s, then a run of 0s, a run of 1s, a run of 0s, a run of 1s, and an optional run of 0s:
$$
w = \mathtt{1}^{a}\,\mathtt{0}^{b}\,\mathtt{1}^{c}\,\mathtt{0}^{d}\,\mathtt{1}^{e}\,\mathtt{0}^{f}\qquad\text{with } a, f\ge0 \text{ and } b, c, d, e\ge1 .
$$
Both answers come from this picture: the DFA keeps track of which run it is in, and the regular expression writes the runs down one after the other.

## (a) A DFA that counts the occurrences

**Idea.** Scan left to right with two variables: the number $k$ of occurrences of `01` so far (0, 1, 2, or "too many"), and whether the last symbol read was a 0 — a 0 that the next 1 would turn into one more occurrence. That is $3\times2$ states plus one for "too many". Name each state by what it remembers: $\textsf{ones}_k$ and $\textsf{zeros}_k$, where the subscript is the count.

> [!key] Answer (a)
> Start state $\textsf{ones}_0$ (→); accepting states $\textsf{ones}_2$ and $\textsf{zeros}_2$ (\*).
>
> | state | meaning: the input read so far … | on $\mathtt{0}$ | on $\mathtt{1}$ |
> |---|---|---|---|
> | → $\textsf{ones}_0$ | contains no `01`, and is empty or ends in 1 | $\textsf{zeros}_0$ | $\textsf{ones}_0$ |
> | $\textsf{zeros}_0$ | contains no `01`, and ends in 0 | $\textsf{zeros}_0$ | $\textsf{ones}_1$ |
> | $\textsf{ones}_1$ | contains `01` once, and ends in 1 | $\textsf{zeros}_1$ | $\textsf{ones}_1$ |
> | $\textsf{zeros}_1$ | contains `01` once, and ends in 0 | $\textsf{zeros}_1$ | $\textsf{ones}_2$ |
> | $\textsf{ones}_2$ \* | contains `01` twice, and ends in 1 | $\textsf{zeros}_2$ | $\textsf{ones}_2$ |
> | $\textsf{zeros}_2$ \* | contains `01` twice, and ends in 0 | $\textsf{zeros}_2$ | $\textsf{dead}$ |
> | $\textsf{dead}$ | contains `01` three or more times | $\textsf{dead}$ | $\textsf{dead}$ |

The machine is a chain. A 0 moves from $\textsf{ones}_k$ to $\textsf{zeros}_k$ and then keeps it there; a 1 read in $\textsf{zeros}_k$ completes an occurrence and moves on to $\textsf{ones}_{k+1}$. The third occurrence sends the machine to $\textsf{dead}$, which never leaves and never accepts.

**Check.** On `1001101` the machine visits $\textsf{ones}_0$, $\textsf{ones}_0$, $\textsf{zeros}_0$, $\textsf{zeros}_0$, $\textsf{ones}_1$, $\textsf{ones}_1$, $\textsf{zeros}_1$, $\textsf{ones}_2$ and accepts. On `010101` the third 1 arrives in $\textsf{zeros}_2$ and goes to $\textsf{dead}$: reject. On $\varepsilon$ it stays in $\textsf{ones}_0$: reject, correctly — the empty string contains `01` zero times.

**Is it minimal?** Yes, although the problem does not ask. The strings $\varepsilon$, `0`, `01`, `010`, `0101`, `01010`, `010101` reach the seven states in the order of the table, and every two of them have a distinguishing suffix — for example, `101` distinguishes $\varepsilon$ from `0` (`0101` $\in L$, `101` $\notin L$), and `1` distinguishes `01` from `010`. So they form a [[concepts/fooling-sets|fooling set]] of size 7, and no DFA for $L$ has fewer states.

> [!trap] Where DFA answers lose points
> - **No dump state, and no sentence about it.** Leaving out $\textsf{dead}$ is fine *only* together with "all missing transitions go to a dump state". Without that sentence, $\textsf{zeros}_2$ has no transition on 1 and the drawing is not a DFA.
> - **An accepting sink.** Merging $\textsf{ones}_2$, $\textsf{zeros}_2$ and $\textsf{dead}$ into one accepting state that loops on everything is the DFA for "at least twice": it accepts `010101`.
> - **Counting symbol changes.** A machine that counts every switch between 0 and 1 counts `10` boundaries too: `0110` has two switches but only one `01`.
> - **States without meanings.** Names like $q_0,\dots,q_6$ lose the mnemonic-name points even when the machine is right — and make your own mistakes harder to find.

## (b) A regular expression, run by run

**Idea.** Write the runs of the typical string from left to right: an optional run of 1s, then (a run of 0s, a run of 1s) twice, then an optional run of 0s. "A run of 0s" means *at least one* 0, which is $\mathtt{0}\mathtt{0}^*$ — in a regular expression, $+$ means union, so there is no $\mathtt{0}^+$ shorthand.

> [!key] Answer (b)
> $$
> \mathtt{1}^*\ \mathtt{0}\mathtt{0}^*\mathtt{1}\mathtt{1}^*\ \mathtt{0}\mathtt{0}^*\mathtt{1}\mathtt{1}^*\ \mathtt{0}^*
> $$
> - $\mathtt{1}^*$ — the leading 1s, if any. No 0 comes before them, so they contain no `01`. (The DFA sits in $\textsf{ones}_0$.)
> - $\mathtt{0}\mathtt{0}^*\mathtt{1}\mathtt{1}^*$ — a non-empty run of 0s followed by a non-empty run of 1s; the boundary between the two runs is the **first** `01`. ($\textsf{zeros}_0$, then $\textsf{ones}_1$.)
> - $\mathtt{0}\mathtt{0}^*\mathtt{1}\mathtt{1}^*$ again — the **second** `01`. ($\textsf{zeros}_1$, then $\textsf{ones}_2$.)
> - $\mathtt{0}^*$ — the trailing 0s, if any. No 1 follows them, so they create no third `01`. ($\textsf{zeros}_2$.)

**Check, both directions.** *Nothing extra:* inside a run there is no `01`, and every other run boundary is a `10`, so a matching string contains exactly the two marked occurrences. *Nothing missing:* the run decomposition above writes every string of $L$ in exactly this shape. On examples: `1001101` matches as `1`·`00`·`11`·`0`·`1`·$\varepsilon$; `0101` as $\varepsilon$·`0`·`1`·`0`·`1`·$\varepsilon$; $\varepsilon$ does not match (the middle needs at least four symbols), and neither does `010101`.

> [!trap] Four tempting wrong answers
> | expression | what it actually describes | wrong on |
> |---|---|---|
> | $(\mathtt{0}+\mathtt{1})^*\mathtt{01}(\mathtt{0}+\mathtt{1})^*\mathtt{01}(\mathtt{0}+\mathtt{1})^*$ | `01` occurs at least twice | `010101`, and every $(\mathtt{01})^n$ with $n\ge3$ |
> | $\mathtt{1}^*\mathtt{0}^*\mathtt{1}^*\mathtt{0}^*\mathtt{1}^*\mathtt{0}^*$ | `01` occurs at most twice | $\varepsilon$, and every $\mathtt{1}^n$ |
> | $\mathtt{0}\mathtt{0}^*\mathtt{1}\mathtt{1}^*\mathtt{0}\mathtt{0}^*\mathtt{1}\mathtt{1}^*\mathtt{0}^*$ | the strings of $L$ that start with 0 | misses `10101`, and every $\mathtt{1}^n\mathtt{0101}$ |
> | $\mathtt{1}^*\mathtt{0}\mathtt{0}^*\mathtt{1}\mathtt{1}^*\mathtt{0}\mathtt{0}^*\mathtt{1}\mathtt{1}^*$ | the strings of $L$ that end in 1 | misses `01010`, and every $\mathtt{0101}\mathtt{0}^n$ |
>
> Each one is wrong on infinitely many strings, so each would get no correctness credit at all. The second is the "$\mathtt{0}^*$ where $\mathtt{0}\mathtt{0}^*$ is needed" slip: a run of length zero is no run, and its "boundary" is no occurrence. The last two each leave out one of the optional runs at the ends.

> [!exam] How the two answers are graded
> On Midterm-1-style exams this is one problem: a DFA and a regular expression for the same language, with mnemonic state names and no proof. **The DFA** (rubric out of 10): **2** for an unambiguous, complete description — start arrow, double circles, every transition, or an explicit sentence about the omitted dump state; **6** for correctness; **2** for mnemonic state names. An NFA where a DFA was asked earns half credit. **The regular expression** (rubric out of 10): **2** for syntax and **8** for correctness, with exam deductions twice the homework ones — **2** for one mistake (typically a missing or extra $\varepsilon$), **4** for a few wrong strings, and all **8** when infinitely many strings are wrong, as for every expression in the trap above; $\varnothing$ or $\Sigma^*$ earns nothing. On homework, the English explanation of each part is required as well. See [[0-toolkit/06-how-exams-are-graded|how exams are graded]].
