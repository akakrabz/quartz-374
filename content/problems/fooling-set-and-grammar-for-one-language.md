*Problem · style of the Midterm 1 non-regularity-and-grammar problem · uses [[1-models-of-computation/03-finite-state-machines#38-proving-a-language-is-not-regular|§3.8]], [[1-models-of-computation/05-context-free-languages#53-from-grammar-to-language|§5.3]] · concepts: [[concepts/fooling-sets]], [[concepts/context-free-grammars]]*

> [!question] Problem
> Let $L = \{\mathtt{0}^i\mathtt{1}^j\mathtt{0}^k \mid i, j, k\ge0 \text{ and } j = i+k\}$: a run of 0s, a run of 1s and a run of 0s (each possibly empty), with exactly as many 1s as 0s in total. For example, $\varepsilon$, `01`, `10`, `0110` and `001110` are in $L$; `0`, `1`, `0101` and `1001` are not.
>
> (a) Prove that $L$ is not regular.
>
> (b) Give a context-free grammar for $L$. Describe the language of each nonterminal, and argue briefly that the grammar generates exactly $L$.

**What any algorithm for $L$ must remember.** Reading `0000…`, a machine for $L$ has to remember how many 0s it has seen: after $\mathtt{0}^m$ the continuation $\mathtt{1}^m$ must be accepted, and $\mathtt{1}^n$ for $n\ne m$ must not. An unbounded count is exactly what a fooling set exploits. A grammar, on the other hand, can match symbols from the outside in, and every string of $L$ splits into two such nested pieces:
$$
\mathtt{0}^i\mathtt{1}^{j}\mathtt{0}^k = \mathtt{0}^i\mathtt{1}^{i+k}\mathtt{0}^k = \big(\mathtt{0}^i\mathtt{1}^i\big)\big(\mathtt{1}^k\mathtt{0}^k\big).
$$

## (a) Not regular: a fooling set

**Idea.** Take $F = \mathtt{0}^*$: different numbers of leading 0s need different numbers of 1s. For $x = \mathtt{0}^m$, the suffix $z = \mathtt{1}^m$ completes $x$ to a string of $L$ (with $k = 0$). To show that $yz$ is *not* in $L$, do not fight with the decomposition of $yz$ into runs; use a property that **every** string of $L$ has: equally many 0s and 1s, since $\#(\mathtt{0},w) = i+k = j = \#(\mathtt{1},w)$.

> [!example] Proof of (a) — model answer
> Let $F = \mathtt{0}^* = \{\mathtt{0}^n \mid n\ge0\}$. Let $x$ and $y$ be arbitrary distinct strings in $F$. Then $x = \mathtt{0}^m$ and $y = \mathtt{0}^n$ for some integers $m, n\ge0$ with $m\ne n$. Let $z = \mathtt{1}^m$.
> - $xz = \mathtt{0}^m\mathtt{1}^m\in L$: take $i = m$, $j = m$ and $k = 0$; then $j = i+k$.
> - $yz = \mathtt{0}^n\mathtt{1}^m\notin L$: every string $\mathtt{0}^i\mathtt{1}^j\mathtt{0}^k$ of $L$ contains $i+k$ 0s and $j = i+k$ 1s, equally many; but $yz$ contains $n$ 0s and $m\ne n$ 1s.
>
> So $z$ distinguishes $x$ and $y$, and $F$ is a fooling set for $L$. Because $F$ is infinite, $L$ is not regular. $\blacksquare$

> [!trap] Where (a) loses points
> - **Ruling out one decomposition instead of all of them.** "$yz = \mathtt{0}^n\mathtt{1}^m\mathtt{0}^0$ and $m\ne n+0$" checks just one way to write $yz$ as $\mathtt{0}^i\mathtt{1}^j\mathtt{0}^k$. When $m = 0$, $yz = \mathtt{0}^n$ splits as $\mathtt{0}^i\mathtt{1}^0\mathtt{0}^k$ in $n+1$ ways, and the proof must show that none of them has $j = i+k$ (each has $j = 0 < n = i+k$). The counting argument handles every decomposition at once.
> - **Reusing the statement's letters.** Writing $x = \mathtt{0}^i$ and $y = \mathtt{0}^j$ collides with the $i$ and $j$ in the definition of $L$, and "$j = i+k$" then means two different things. Pick fresh names.
> - **One example pair.** "`0` and `00` are distinguished by `1`" proves nothing about the other pairs; the argument must work for arbitrary $m\ne n$.
> - **A finite set.** $\{\varepsilon, \mathtt{0}, \mathtt{00}\}$ is a fooling set, but it only proves that every DFA for $L$ has at least 3 states — and earns no credit as a non-regularity proof.

**An alternative: closure.** If $L$ were regular, then $L\cap\mathtt{0}^*\mathtt{1}^*$ would be regular too ([[1-models-of-computation/03-finite-state-machines#37-closure-properties|Corollary 3.4]]). A string of $L$ with no 0 after a 1 has $k = 0$ (or it has no 1 at all, and then $i = k = 0$), so $L\cap\mathtt{0}^*\mathtt{1}^* = \{\mathtt{0}^n\mathtt{1}^n \mid n\ge0\}$, which is not regular by Lemma 3.6. That proof is correct too — but when the exam asks for a fooling set, give the fooling set.

## (b) A grammar: two nested halves side by side

**Idea.** Split the run of 1s: the first $i$ 1s match the leading 0s, and the last $k$ match the trailing 0s. Each half is a nested language like the book's $\{\mathtt{0}^n\mathtt{1}^n\}$, and one start rule puts the halves next to each other.

> [!key] Answer (b)
> $$
> S\to AB\qquad\qquad A\to\mathtt{0}A\mathtt{1}\mid\varepsilon\qquad\qquad B\to\mathtt{1}B\mathtt{0}\mid\varepsilon
> $$
> - $A$ generates $\{\mathtt{0}^i\mathtt{1}^i \mid i\ge0\}$: some 0s followed by equally many 1s.
> - $B$ generates $\{\mathtt{1}^k\mathtt{0}^k \mid k\ge0\}$: some 1s followed by equally many 0s.
> - $S$ generates $L$: a string generated by $A$ followed by a string generated by $B$.

**Why the grammar is right.**
- *The nonterminals.* $A$ is the book's grammar $C\to\varepsilon\mid\mathtt{0}C\mathtt{1}$ under another name, so $L(A) = \{\mathtt{0}^i\mathtt{1}^i \mid i\ge0\}$ by Lemmas 5.1 and 5.2. $B$ is the same grammar with 0 and 1 exchanged, so the same two lemmas (with the symbols exchanged) give $L(B) = \{\mathtt{1}^k\mathtt{0}^k \mid k\ge0\}$.
- *$L(S)\subseteq L$.* Every derivation from $S$ begins $S\rightsquigarrow AB$, and from then on $A$ and $B$ derive their parts independently; so $L(S) = L(A)\bullet L(B)$. Each such string is $\mathtt{0}^i\mathtt{1}^i\bullet\mathtt{1}^k\mathtt{0}^k = \mathtt{0}^i\mathtt{1}^{i+k}\mathtt{0}^k$, which is in $L$ with $j = i+k$.
- *$L\subseteq L(S)$.* If $w = \mathtt{0}^i\mathtt{1}^j\mathtt{0}^k\in L$, then $j = i+k$, so $w = \mathtt{0}^i\mathtt{1}^i\bullet\mathtt{1}^k\mathtt{0}^k$, and $S\rightsquigarrow AB\rightsquigarrow^*\mathtt{0}^i\mathtt{1}^iB\rightsquigarrow^*\mathtt{0}^i\mathtt{1}^i\mathtt{1}^k\mathtt{0}^k = w$.

**Check.** $\varepsilon$: both halves empty. `10`: $A\rightsquigarrow\varepsilon$ and $B\rightsquigarrow\mathtt{1}B\mathtt{0}\rightsquigarrow\mathtt{10}$. `0110` = `01`·`10`. And `0101` cannot be generated: every generated string has the shape $\mathtt{0}^*\mathtt{1}^*\mathtt{0}^*$.

> [!trap] Where (b) loses points
> - **Nesting instead of concatenating.** $S\to\mathtt{0}S\mathtt{1}\mid T$, $T\to\mathtt{1}T\mathtt{0}\mid\varepsilon$ puts the $\mathtt{1}^k\mathtt{0}^k$ block *inside* the $\mathtt{0}^i\cdots\mathtt{1}^i$ block, so it generates $\mathtt{0}^i\mathtt{1}^k\mathtt{0}^k\mathtt{1}^i$: it produces `0101` $\notin L$ and misses `0110` $\in L$. Wrong on infinitely many strings, so no correctness credit.
> - **Losing the empty halves.** With $A\to\mathtt{0}A\mathtt{1}\mid\mathtt{01}$ and $B\to\mathtt{1}B\mathtt{0}\mid\mathtt{10}$ neither half can be empty, so the grammar misses $\varepsilon$, `01`, `10` and every $\mathtt{0}^n\mathtt{1}^n$ — again infinitely many strings.
> - **A grammar for a bigger language.** $S\to\mathtt{0}S\mathtt{1}\mid\mathtt{1}S\mathtt{0}\mid SS\mid\varepsilon$ generates every string with equally many 0s and 1s, including `0101` and `1001`. Equal counts are necessary for $L$, not sufficient: the shape $\mathtt{0}^*\mathtt{1}^*\mathtt{0}^*$ matters too.
> - **Descriptions that are not self-contained.** "$B$ does the second part" says nothing. "$B$ generates exactly the strings $\mathtt{1}^k\mathtt{0}^k$ with $k\ge0$" does.

> [!exam] How the problem is graded
> Midterm-1-style exams pair a non-regularity proof with a grammar for the same language. **The fooling-set proof** (out of 10): **4** for an explicit infinite set that really is a fooling set — a finite set earns nothing — and **6** for the argument with arbitrary distinct $x$ and $y$: **2** for an explicit suffix $z$, **2** for showing that one of $xz$, $yz$ is in $L$, and **2** for showing that the other is not. **The grammar** (out of 10): **2** for syntax and **8** for correctness, with the same deductions as for regular expressions (one mistake, a few wrong strings, or all 8 points for infinitely many wrong strings). Homework also requires a self-contained description of every nonterminal's language; ambiguity is not penalized. See [[0-toolkit/06-how-exams-are-graded|how exams are graded]].
