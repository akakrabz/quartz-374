*Problem · an NFA-to-DFA conversion by hand, the computation behind many Midterm 1 answers · uses [[1-models-of-computation/04-nondeterministic-automata#43-epsilon-transitions|§4.3]], [[1-models-of-computation/04-nondeterministic-automata#45-nfa-to-dfa-the-subset-construction|§4.5]] · concepts: [[concepts/subset-construction]], [[concepts/nfa]], [[concepts/dfa-minimization]]*

> [!question] Problem
> The NFA $N$ has alphabet $\{\mathtt{0},\mathtt{1}\}$, states $s, p, q, t$, start state $s$, accepting states $\{t\}$, and the transitions below (empty cells are $\varnothing$).
>
> | $\delta$ | $\mathtt{0}$ | $\mathtt{1}$ | $\varepsilon$ |
> |---|---|---|---|
> | → $s$ | $\{s\}$ | | $\{p\}$ |
> | $p$ | $\{q\}$ | | $\{t\}$ |
> | $q$ | | $\{p\}$ | |
> | $t$ \* | | $\{t\}$ | |
>
> (a) Describe $L(N)$.
>
> (b) Convert $N$ to a DFA with the incremental subset construction. Show the full table: for each DFA state $S$, its $\varepsilon$-reach, whether it is accepting, and its transitions.
>
> (c) Is the resulting DFA minimal? If not, find the number of states of a minimal DFA, and prove your answer.

## (a) The language: three phases

**Idea.** The $\varepsilon$-transitions only go forward, $s\to p\to t$, so every run of $N$ has three phases and never returns to an earlier one: in $s$ it reads 0s; around the cycle $p\xrightarrow{\mathtt{0}}q\xrightarrow{\mathtt{1}}p$ it reads blocks `01`; in $t$ it reads 1s.

> [!key] Answer (a)
> $L(N) = \mathtt{0}^*(\mathtt{01})^*\mathtt{1}^* = \{\mathtt{0}^i(\mathtt{01})^j\mathtt{1}^k \mid i, j, k\ge0\}$. For example `0011` $= \mathtt{0}\cdot\mathtt{01}\cdot\mathtt{1}$, $\varepsilon$, `0` and `1` are in $L(N)$; `010` and `10` are not.

## (b) The incremental subset construction

**The recipe, as in the book.** A DFA state is a *set* $S$ of NFA states, and everything is computed from its $\varepsilon$-reach, the set of states reachable from $S$ by $\varepsilon$-transitions alone:
- the start state is $\{s\}$ itself (its $\varepsilon$-reach goes in its own column);
- $S$ is accepting iff $\varepsilon\text{-reach}(S)$ contains an accepting state of $N$;
- $\delta'(S,a) = \bigcup_{r\,\in\,\varepsilon\text{-reach}(S)}\delta(r,a)$: slide along $\varepsilon$-moves first, then read $a$.

Start a table with the row $\{s\}$. Whenever a set appears in a transition column that has no row yet, give it the next row. Stop when every set in the transition columns has a row. Here the $\varepsilon$-reaches of single states are $\varepsilon\text{-reach}(s) = \{s,p,t\}$, $\varepsilon\text{-reach}(p) = \{p,t\}$, $\varepsilon\text{-reach}(q) = \{q\}$ and $\varepsilon\text{-reach}(t) = \{t\}$.

**Row 1, in full.** $\varepsilon\text{-reach}(\{s\}) = \{s,p,t\}$, which contains $t$, so $\{s\}$ is accepting. Then
$$
\begin{aligned}
\delta'(\{s\},\mathtt{0}) &= \delta(s,\mathtt{0})\cup\delta(p,\mathtt{0})\cup\delta(t,\mathtt{0}) = \{s\}\cup\{q\}\cup\varnothing = \{s,q\},\\
\delta'(\{s\},\mathtt{1}) &= \delta(s,\mathtt{1})\cup\delta(p,\mathtt{1})\cup\delta(t,\mathtt{1}) = \varnothing\cup\varnothing\cup\{t\} = \{t\}.
\end{aligned}
$$
Both sets are new, so they become rows 2 and 3, in that order. The other rows are computed the same way:

> [!key] Answer (b)
> | row | $S$ | $\varepsilon\text{-reach}(S)$ | accepting? | $\delta'(S,\mathtt{0})$ | $\delta'(S,\mathtt{1})$ |
> |---|---|---|---|---|---|
> | 1 | → $\{s\}$ | $\{s,p,t\}$ | yes | $\{s,q\}$ | $\{t\}$ |
> | 2 | $\{s,q\}$ | $\{s,p,q,t\}$ | yes | $\{s,q\}$ | $\{p,t\}$ |
> | 3 | $\{t\}$ | $\{t\}$ | yes | $\varnothing$ | $\{t\}$ |
> | 4 | $\{p,t\}$ | $\{p,t\}$ | yes | $\{q\}$ | $\{t\}$ |
> | 5 | $\varnothing$ | $\varnothing$ | no | $\varnothing$ | $\varnothing$ |
> | 6 | $\{q\}$ | $\{q\}$ | no | $\varnothing$ | $\{p\}$ |
> | 7 | $\{p\}$ | $\{p,t\}$ | yes | $\{q\}$ | $\{t\}$ |
>
> The DFA has these 7 states (of the $2^4 = 16$ subsets of $\{s,p,q,t\}$, only these are reachable), start state $\{s\}$, the five accepting states marked "yes", and the transitions in the last two columns. $\varnothing$ is a genuine state — the dump state, reached when no thread of $N$ survives.

**Check.** On `0011`: $\{s\}\xrightarrow{\mathtt{0}}\{s,q\}\xrightarrow{\mathtt{0}}\{s,q\}\xrightarrow{\mathtt{1}}\{p,t\}\xrightarrow{\mathtt{1}}\{t\}$, accept. On `010`: $\{s\}\to\{s,q\}\to\{p,t\}\to\{q\}$, reject — halfway through a block. On `10`: $\{s\}\to\{t\}\to\varnothing$, reject — after a trailing 1, a 0 kills every thread.

> [!trap] Where subset constructions go wrong
> - **Accepting $S$ only when $S$ itself contains an accepting state.** Acceptance looks at $\varepsilon\text{-reach}(S)$. Without it, rows 1, 2 and 7 become non-accepting, and the DFA rejects $\varepsilon$, `0`, `00` and `0101` — all in $L(N)$.
> - **Reading before sliding.** $\delta'(\{s\},\mathtt{1})$ is not $\delta(s,\mathtt{1}) = \varnothing$: the NFA can slide $s\to p\to t$ by $\varepsilon$-moves and *then* read the 1. Forgetting the $\varepsilon$-reach in the transitions sends `1` and `01` to $\varnothing$.
> - **Dropping the $\varnothing$ row.** The empty set is reachable (on `10`), and a DFA needs a transition from every state on every symbol. Keep the row, or say explicitly that missing transitions go to a dump state.
> - **Tabulating all 16 subsets.** Only reachable sets get rows; the incremental construction never creates the other nine. (A table of all 16 still describes a correct DFA, with nine unreachable states, but it is not what was asked and it wastes exam time.)

**A second convention.** Some textbooks name each DFA state by its $\varepsilon$-reach instead: the start state is $\varepsilon\text{-reach}(\{s\}) = \{s,p,t\}$ and $\delta'(S,a) = \varepsilon\text{-reach}\big(\bigcup_{r\in S}\delta(r,a)\big)$. That also gives a correct DFA — here a 6-state one, because rows 4 and 7 have the same $\varepsilon$-reach and become a single state. On this site, as in the book, the table keeps $S$ and its $\varepsilon$-reach in separate columns.

## (c) Not minimal: two twin rows

**Idea.** Look for rows that agree in everything. Rows 4 and 7, $\{p,t\}$ and $\{p\}$, are both accepting, both go to $\{q\}$ on 0, and both go to $\{t\}$ on 1. States with identical rows are equivalent: both accept or both reject the empty suffix, and after any first symbol the two are in the same state. They agree because they have the same $\varepsilon$-reach $\{p,t\}$, and the construction computes everything from the $\varepsilon$-reach. In terms of the language: `01` reaches $\{p,t\}$ and `0101` reaches $\{p\}$, and both mean "a block 01 has just been completed; more blocks or the trailing 1s may follow".

Merging the twins leaves 6 states. To show that no DFA for $L(N)$ has fewer, take one string reaching each of them:
$$
F = \{\varepsilon,\ \mathtt{0},\ \mathtt{1},\ \mathtt{01},\ \mathtt{10},\ \mathtt{010}\},\quad\text{which reach } \{s\},\ \{s,q\},\ \{t\},\ \{p,t\},\ \varnothing,\ \{q\}.
$$
For each pair, the table gives a distinguishing suffix $z$ — exactly one of $xz$ and $yz$ is in $L(N)$ (row $x$, column $y$):

| | $\mathtt{0}$ | $\mathtt{1}$ | $\mathtt{01}$ | $\mathtt{10}$ | $\mathtt{010}$ |
|---|---|---|---|---|---|
| $\varepsilon$ | `101` | `0` | `0` | $\varepsilon$ | $\varepsilon$ |
| $\mathtt{0}$ | | `0` | `0` | $\varepsilon$ | $\varepsilon$ |
| $\mathtt{1}$ | | | `01` | $\varepsilon$ | $\varepsilon$ |
| $\mathtt{01}$ | | | | $\varepsilon$ | $\varepsilon$ |
| $\mathtt{10}$ | | | | | `1` |

For instance, `101` separates $\varepsilon$ from `0`: `0101` $\in L(N)$ but `101` $\notin L(N)$. And `1` separates the dump state from $\{q\}$: `0101` $\in L(N)$ but `101` $\notin L(N)$. Every $\varepsilon$ entry pairs a string of $L(N)$ with one outside it.

> [!key] Answer (c)
> Not minimal: $\{p\}$ and $\{p,t\}$ are equivalent. Merging them gives a 6-state DFA, and the 6-element fooling set $F$ shows that **6 is the minimum**.

> [!exam] How this is graded
> Midterm-1-style exams have no separate subset-construction problem; the construction is a tool — for turning an NFA you designed into the DFA a problem asks for (an NFA where a DFA was asked earns half credit), and for true/false items about state counts. A DFA built this way is graded like any DFA: a complete description (start state, accepting states, every transition, including those into $\varnothing$), correctness, and mnemonic names. A set like $\{s,q\}$ is a meaningful name only if you have said what each NFA state means — "still among the leading 0s, or halfway through a block". See [[0-toolkit/06-how-exams-are-graded|how exams are graded]].
