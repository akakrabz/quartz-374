*Problem · style of the Midterm 1 language-transformation problem · uses [[1-models-of-computation/04-nondeterministic-automata#49-regular-language-transformations|§4.9]], [[1-models-of-computation/04-nondeterministic-automata#43-epsilon-transitions|§4.3]] · concepts: [[concepts/language-transformations]], [[concepts/nfa]]*

> [!question] Problem
> Let $L$ be an arbitrary regular language over $\Sigma = \{\mathtt{0},\mathtt{1}\}$. Prove that the following languages are regular.
>
> (a) $\textsf{Insert1}(L) := \{x\mathtt{1}y \mid x, y\in\Sigma^* \text{ and } xy\in L\}$ — the strings obtained from a string of $L$ by inserting one `1`, anywhere.
>
> (b) $\textsf{Delete1}(L) := \{xy \mid x, y\in\Sigma^* \text{ and } x\mathtt{1}y\in L\}$ — the strings obtained from a string of $L$ by deleting one of its `1`s.
>
> In each part, give a formal description of an NFA ($\varepsilon$-transitions allowed) in terms of an arbitrary DFA $M = (\Sigma, Q, s, A, \delta)$ that accepts $L$, and explain in English what its states mean.

**Which kind of transformation?** In both parts the input $w$ is the *result* of an edit applied to some string of $L$, and the machine must check that *some* string of $L$ produces $w$. That is the "transforms of strings in $L$" kind of [[concepts/language-transformations|transformation]]: an NFA reads $w$, **guesses** where the edit happened, and simulates $M$ on the unedited string. Both NFAs need one extra bit of memory — has the edit been handled yet? — so their states are pairs $(q, f)$ with $q\in Q$ and $f\in\{0, 1\}$: two copies of $M$, a "before" copy and an "after" copy, and the only way down is the guess.

## (a) Inserting a 1

**Idea.** $M'$ reads $w = x\mathtt{1}y$ and runs $M$ on $xy$: it must **skip exactly one input 1** without showing it to $M$. Before the skip ($f = 0$) every symbol goes to $M$. On reading a 1, $M'$ may guess "this is the inserted 1": it leaves $M$'s state alone and sets $f = 1$. After that every symbol goes to $M$ again.

> [!key] Answer (a)
> $M' = (\Sigma, Q', s', A', \delta')$, an NFA without $\varepsilon$-transitions:
> $$
> Q' = Q\times\{0,1\},\qquad s' = (s,0),\qquad A' = \{(q,1) \mid q\in A\},
> $$
> $$
> \begin{aligned}
> \delta'\big((q,0),\mathtt{0}\big) &= \big\{(\delta(q,\mathtt{0}),0)\big\}\\
> \delta'\big((q,0),\mathtt{1}\big) &= \big\{(\delta(q,\mathtt{1}),0),\ (q,1)\big\}\\
> \delta'\big((q,1),a\big) &= \big\{(\delta(q,a),1)\big\}\qquad\text{for each } a\in\{\mathtt{0},\mathtt{1}\}.
> \end{aligned}
> $$
> **In English.** $(q,0)$: the inserted 1 has not been read yet, and $M$, run on the input read so far, is in state $q$. $(q,1)$: the inserted 1 has been read and skipped, and $M$, run on the input read so far *without that 1*, is in state $q$. The transition $(q,0)\xrightarrow{\mathtt{1}}(q,1)$ is the guess. $M'$ accepts if the skip has happened ($f = 1$) and $M$ accepts what is left ($q\in A$).

**Why it works.** A short induction on the input, of the kind behind Lemma 3.1, shows: $M'$ can be in $(q,0)$ after reading $w$ iff $q = \delta^*(s,w)$, and it can be in $(q,1)$ iff $w = x\mathtt{1}y$ for some strings $x, y$ with $q = \delta^*(s, xy)$. So $M'$ accepts $w$ iff some way of writing $w = x\mathtt{1}y$ has $xy\in L$ — which is the definition of $\textsf{Insert1}(L)$.

**Example.** In the figure (left), $M$ accepts the strings with an odd number of 1s. On input `0110`, $M'$ can go $(\textsf{E},0)\xrightarrow{\mathtt{0}}(\textsf{E},0)\xrightarrow{\mathtt{1}}(\textsf{O},0)\xrightarrow{\mathtt{1}}(\textsf{O},1)\xrightarrow{\mathtt{0}}(\textsf{O},1)$, skipping the second 1, and accept: `0110` is `01`·`1`·`0`, and `010` has one 1. In general this $M'$ accepts exactly the strings with an even, positive number of 1s.

> [!trap] Where (a) loses points
> - **Accepting before the insertion.** With $A' = A\times\{0,1\}$ the machine also accepts the strings of $L$ themselves, with nothing inserted. For $L = \{\varepsilon\}$ it accepts $\varepsilon$, but $\textsf{Insert1}(\{\varepsilon\}) = \{\mathtt{1}\}$.
> - **Guessing on the wrong symbol.** An extra $(q,0)\xrightarrow{\mathtt{0}}(q,1)$ inserts an arbitrary symbol: for $L = \{\varepsilon\}$ it accepts `0`.
> - **Showing the inserted 1 to $M$.** $(q,0)\xrightarrow{\mathtt{1}}(\delta(q,\mathtt{1}),1)$ instead of $(q,1)$ just reads a 1 of a string of $L$: for $L = \{\varepsilon\}$ the machine accepts nothing at all, not even `1`.
> - **No flag.** One copy of $M$ with an extra loop $q\xrightarrow{\mathtt{1}}q$ at every state skips *any* number of 1s, including none: for $L = \{\varepsilon\}$ it accepts all of $\mathtt{1}^*$.

## (b) Deleting a 1

**Idea.** Now $M''$ reads $w = xy$ and runs $M$ on $x\mathtt{1}y$: somewhere — between two input symbols, or before the first, or after the last — it must **feed $M$ one 1 that is not in the input**. That is what an $\varepsilon$-transition is for: it changes $M$'s state as if a 1 had been read, without consuming any input, and sets $f = 1$ so that it happens exactly once.

> [!key] Answer (b)
> $M'' = (\Sigma, Q'', s'', A'', \delta'')$, an NFA with $\varepsilon$-transitions: $Q'' = Q\times\{0,1\}$, $s'' = (s,0)$, $A'' = \{(q,1) \mid q\in A\}$, and for every $q\in Q$ and $a\in\{\mathtt{0},\mathtt{1}\}$
> $$
> \begin{aligned}
> \delta''\big((q,0),a\big) &= \big\{(\delta(q,a),0)\big\}, & \delta''\big((q,0),\varepsilon\big) &= \big\{(\delta(q,\mathtt{1}),1)\big\},\\
> \delta''\big((q,1),a\big) &= \big\{(\delta(q,a),1)\big\}, & \delta''\big((q,1),\varepsilon\big) &= \varnothing.
> \end{aligned}
> $$
> **In English.** $(q,0)$: the deleted 1 has not been put back yet, and $M$, run on the input read so far, is in state $q$. $(q,1)$: it has been put back, and $M$, run on the input read so far *with that 1 inserted where the $\varepsilon$-move happened*, is in state $q$. The $\varepsilon$-move $(q,0)\xrightarrow{\varepsilon}(\delta(q,\mathtt{1}),1)$ is the guess "the deleted 1 was here". $M''$ accepts if the 1 has been put back and $M$ accepts.

**Why it works.** The same kind of induction shows that $M''$ can be in $(q,1)$ after reading $w$ iff $w = xy$ for some strings $x, y$ with $q = \delta^*(s, x\mathtt{1}y)$. An $\varepsilon$-move may be taken at any time, including before the first symbol ($x = \varepsilon$) and after the last one ($y = \varepsilon$), so every position of the deleted 1 is covered.

**Example.** In the figure (right), the $\varepsilon$-move from $(\textsf{E},0)$ goes to $(\textsf{O},1)$, not to $(\textsf{E},1)$: $M$ sees the extra 1. On input $\varepsilon$, $M''$ takes that $\varepsilon$-move and accepts, correctly — deleting the only 1 of `1` $\in L$ gives $\varepsilon$. In general this $M''$ accepts exactly the strings with an even number of 1s.

> [!trap] Where (b) loses points
> - **Reading the 1 instead of inventing it.** $(q,0)\xrightarrow{\mathtt{1}}(\delta(q,\mathtt{1}),1)$ consumes an input 1, so nothing is deleted: the machine accepts the strings of $L$ that contain a 1. For $L = \mathtt{1}^*$ it rejects $\varepsilon$, but $\varepsilon\in\textsf{Delete1}(\mathtt{1}^*)$.
> - **Forgetting to feed the 1 to $M$.** $(q,0)\xrightarrow{\varepsilon}(q,1)$ only flips the flag, and the machine accepts $L$ itself. For $L = \{\varepsilon\}$ it accepts $\varepsilon$, but $\textsf{Delete1}(\{\varepsilon\}) = \varnothing$: the empty string has no 1 to delete.
> - **No flag.** One copy of $M$ with $\varepsilon$-moves $q\xrightarrow{\varepsilon}\delta(q,\mathtt{1})$ deletes *any* number of 1s, including none. For $L = \{\mathtt{11}\}$ it accepts $\varepsilon$, `1` and `11`, but $\textsf{Delete1}(\{\mathtt{11}\}) = \{\mathtt{1}\}$.
> - **Unstated $\varepsilon$-transitions.** The description must list exactly which $\varepsilon$-transitions exist; "$\varepsilon$-moves where needed" describes no machine.

## Edge cases

Run both constructions on the languages the graders try first. Each line below is what the NFAs above actually accept:

| $L$ | $\textsf{Insert1}(L)$ | $\textsf{Delete1}(L)$ | why |
|---|---|---|---|
| $\varnothing$ | $\varnothing$ | $\varnothing$ | $A = \varnothing$, so no state of either NFA accepts |
| $\{\varepsilon\}$ | $\{\mathtt{1}\}$ | $\varnothing$ | $\varepsilon$ has no 1 to delete |
| $\mathtt{1}^*$ | $\mathtt{1}\mathtt{1}^*$ | $\mathtt{1}^*$ | deleting the only 1 of `1` gives $\varepsilon$ |
| $\mathtt{0}^*$ | $\mathtt{0}^*\mathtt{1}\mathtt{0}^*$ | $\varnothing$ | no string of $\mathtt{0}^*$ contains a 1 |
| $\Sigma^*$ | $\Sigma^*\mathtt{1}\Sigma^*$ | $\Sigma^*$ | every $xy$ comes from $x\mathtt{1}y\in\Sigma^*$ |

The two operations are not inverses: $\textsf{Delete1}(\textsf{Insert1}(L))$ always contains $L$ (delete the 1 you inserted), but it can be larger — $\textsf{Delete1}(\textsf{Insert1}(\{\mathtt{01}\})) = \textsf{Delete1}(\{\mathtt{101},\mathtt{011}\}) = \{\mathtt{01},\mathtt{10}\}$.

> [!exam] How a transformation problem is graded
> The standard rubric, out of 10 for a construction: **2** for a formal, complete description of $M'$ built from an *arbitrary* DFA $M$ — say whether it is a DFA or an NFA, and list its $\varepsilon$-transitions; **2** for an English explanation of the states and of the accepting states; **6** for correctness: **1** for the states, **1** for the start state, **1** for the accepting states, **3** for the transitions. Graders test the edge cases $\varnothing$, $\{\varepsilon\}$, $\mathtt{1}^*$ and $\Sigma^*$, so run your construction on them before handing it in, as in the table above. A construction for one particular DFA, like the parity example above, proves nothing about other regular languages. See [[0-toolkit/06-how-exams-are-graded|how exams are graded]].

The method — guess, simulate $M$ on the unedited string, use $\varepsilon$-transitions for symbols that are not in the input — follows Erickson, *Models of Computation*, §4.9. Checked by `tools/checks/problems_1.py`: both constructions implemented as functions of an arbitrary DFA and compared with the definitions of $\textsf{Insert1}$ and $\textsf{Delete1}$ on 300 random DFAs with 2–4 states (exactly, on every string of length at most 8); the edge-case table and the parity example by exact DFA equivalence; the run on `0110`; and every wrong construction in the traps on its counterexample.
