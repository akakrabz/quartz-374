> [!abstract] In one breath
> Every language in the course sits in one of five nested regions. **Regular** languages are the ones a single left-to-right pass with a fixed amount of memory can decide; regular expressions, DFAs and NFAs describe exactly them. **Context-free** languages add unbounded nesting: grammars, or NFAs that call each other like recursive subroutines. **Decidable** languages are the ones some algorithm decides — a Turing machine that halts on every input. **Acceptable** languages are the ones whose members an algorithm can confirm: a Turing machine accepts exactly them and may run forever on everything else. Every inclusion is strict, and each boundary has its own tool for proving that a language lies outside it.

| inclusion | why it holds | why it is strict |
|---|---|---|
| regular ⊆ context-free | every regular expression becomes a grammar, by structural induction ([[1-models-of-computation/05-context-free-languages#55-regular-languages-are-context-free\|§5.5]]) | $\{\mathtt{0}^n\mathtt{1}^n\}$ has the grammar $C\to\varepsilon\mid\mathtt{0}C\mathtt{1}$ and the infinite fooling set $\mathtt{0}^*$ (Lemma 3.6) |
| context-free ⊆ decidable | in Chomsky normal form, dynamic programming decides membership in $O(n^3)$ time ([[1-models-of-computation/05-context-free-languages#58-chomsky-normal-form\|§5.8]]) | $\{\mathtt{0}^n\mathtt{1}^n\mathtt{0}^n\}$ is decided in $O(n^2)$ steps ([[1-models-of-computation/06-turing-machines#63-a-first-example\|§6.3]]) but is not context-free ([[1-models-of-computation/05-context-free-languages#56-not-every-language-is-context-free\|§5.6]], proof beyond the course) |
| decidable ⊆ acceptable | a machine that decides $L$ also accepts it ([[1-models-of-computation/06-turing-machines#62-formal-definitions\|§6.2]]) | $\textsf{Halt}$ is accepted by the universal machine but undecidable (Theorem 12, [[1-models-of-computation/07-undecidability#79-the-halting-problem-via-reduction\|§7.9]]) |
| acceptable ⊆ all languages | — | $\textsf{SelfDiverge}$ is not acceptable (Theorem 9, [[1-models-of-computation/07-undecidability#77-more-self-referential-languages\|§7.7]]); in fact almost no language is, since there are countably many machines and uncountably many languages ([[1-models-of-computation/07-undecidability#76-aside-uncountable-barbers\|§7.6]]) |

The same counting argument shows that almost every language is not regular ([[1-models-of-computation/02-regular-languages#28-not-every-language-is-regular|§2.8]]) and not context-free ([[1-models-of-computation/05-context-free-languages#56-not-every-language-is-context-free|§5.6]]), but it never names one: [[concepts/counting-arguments]].

## 2. Equivalent models

Each class has several descriptions that are interchangeable, because each converts into the others by an algorithm.

| class | described exactly by | why they agree |
|---|---|---|
| regular | [[concepts/regular-expressions\|regular expressions]] · [[concepts/dfa\|DFAs]] (the book's *automatic* languages) · [[concepts/nfa\|NFAs]], with or without $\varepsilon$-transitions | [[concepts/kleenes-theorem\|Kleene's theorem]] (Theorems 3.3 and 4.1): Thompson's algorithm, the subset construction, state elimination ([[1-models-of-computation/04-nondeterministic-automata#44-kleenes-theorem\|§4.4]]) |
| context-free | [[concepts/context-free-grammars\|context-free grammars]] · grammars in [[concepts/chomsky-normal-form\|Chomsky normal form]] · [[concepts/recursive-automata\|recursive automata]] (other books use pushdown automata, which accept the same languages) | Theorem 5.7; Lemmas 5.5 and 5.6 ([[1-models-of-computation/05-context-free-languages#57-recursive-automata\|§5.7]]) |
| decidable | Turing machines that halt on every input, in any variant · nondeterministic Turing machines that decide · languages $L$ with $L$ and $\overline{L}$ both acceptable | the simulations of [[1-models-of-computation/06-turing-machines#64-variations\|§6.4]]–[[1-models-of-computation/06-turing-machines#66-tracks-heads-and-tapes\|§6.6]]; Theorem 1 of Chapter 9; Lemma 5 ([[1-models-of-computation/07-undecidability#73-useful-properties\|§7.3]]) |
| acceptable | [[concepts/turing-machines\|Turing machines]] with any number of tapes, heads and tracks, one- or two-way infinite tapes, stay-put moves · [[concepts/nondeterministic-turing-machines\|nondeterministic Turing machines]] · two-stack machines · counter machines (inputs suitably encoded) · the sets $\textsf{Reject}(M)$, and the sets $\textsf{Halt}(M)$, of Turing machines | §6.4–§6.6; Theorem 1 ([[1-models-of-computation/09-nondeterministic-turing-machines#94-deterministic-simulation-via-dovetailing\|§9.4]]); [[1-models-of-computation/08-universal-models#82-two-stack-machines\|§8.2]], [[1-models-of-computation/08-universal-models#83-counter-machines\|§8.3]]; Lemma 1 ([[1-models-of-computation/07-undecidability#73-useful-properties\|§7.3]]) |

Other names: *acceptable* = recognizable = semi-decidable = recursively enumerable; *decidable* = computable = recursive. The [[concepts/church-turing-thesis|Church–Turing thesis]] — a claim about the world, not a theorem — says that the last two rows capture every algorithm, so "decidable" means "some program in any language decides it".

## 4. Closure at a glance

"Yes" means: for *every* $L$, $L'$ in the class, the result is in the class. "No" means some languages of the class give a result outside it. Constructions, counterexamples and the facts the book leaves unproved: [[concepts/closure-properties]].

| operation | regular | context-free | decidable | acceptable |
|---|---|---|---|---|
| $L\cup L'$ | yes | yes | yes | yes — run both in parallel |
| $L\cap L'$ | yes — product DFA | **no** | yes | yes |
| $\overline{L}$ | yes — accept $Q\setminus A$ | **no** | yes — swap accept and reject | **no** — $\overline{\textsf{Halt}}$ |
| $L\setminus L'$ | yes | **no** | yes | **no** |
| $LL'$ and $L^*$ | yes | yes | yes | yes |
| $L^R$ | yes — Lemma 4.4 | yes | yes | yes |
| $L\cap R$, $R$ regular | yes | yes | yes | yes |
| $\textsf{half}(L) = \{w \mid ww\in L\}$ | yes — Lemma 4.5 | **no** | yes | yes |
| $h(L)$, $h$ a string homomorphism | yes | yes | **no** | yes |

The standard witnesses for the "no" entries: the context-free languages $\{\mathtt{0}^i\mathtt{1}^i\mathtt{0}^j \mid i\ge1, j\ge0\}$ and $\{\mathtt{0}^i\mathtt{1}^j\mathtt{0}^j \mid i\ge0, j\ge1\}$ intersect in $\{\mathtt{0}^n\mathtt{1}^n\mathtt{0}^n \mid n\ge1\}$ ([[1-models-of-computation/05-context-free-languages#56-not-every-language-is-context-free|§5.6]]), and De Morgan turns that into a failure of complement; $\textsf{Halt}$ is acceptable but its complement is not (Lemma 5); and erasing the $\#$s from the decidable language $\{\langle M,w\rangle\#^t \mid M \text{ halts on } w \text{ within } t \text{ steps}\}$ leaves $\textsf{Halt}$.

## 5. How to prove that a language is, or is not, in a class

| class | to prove $L$ **is** in it | to prove $L$ is **not** in it |
|---|---|---|
| regular | a regular expression; a DFA or an NFA; or closure — build $L$ from regular languages by finitely many closed operations ([[1-models-of-computation/03-finite-state-machines#37-closure-properties\|§3.7]], [[concepts/language-transformations\|transformations]]) | an infinite [[concepts/fooling-sets\|fooling set]] ([[1-models-of-computation/03-finite-state-machines#38-proving-a-language-is-not-regular\|§3.8]]; by Myhill–Nerode one always exists); or closure backwards — if $\overline{L}$ or $L\cap R$ with $R$ regular is known to be non-regular, so is $L$ |
| context-free | a grammar, with the language of every nonterminal described ([[1-models-of-computation/05-context-free-languages#54-more-examples\|§5.4]]); a recursive automaton ([[1-models-of-computation/05-context-free-languages#57-recursive-automata\|§5.7]]); closure under $\cup$, concatenation, $^*$, reversal and $\cap$ regular | beyond this course: know that $\{\mathtt{0}^n\mathtt{1}^n\mathtt{0}^n\}$ is not context-free; then if $L\cap R$ with $R$ regular is that language, $L$ is not context-free either |
| decidable | an algorithm that halts on every input — a Turing machine, or pseudocode by the Church–Turing thesis; $L$ and $\overline{L}$ both acceptable (Lemma 5); closure (Lemma 2) | [[concepts/diagonalization\|diagonalization]] ([[1-models-of-computation/07-undecidability#75-self-haters-gonna-self-hate\|§7.5]]); a [[concepts/undecidability-reductions\|reduction]] *from* a known undecidable language ([[1-models-of-computation/07-undecidability#79-the-halting-problem-via-reduction\|§7.9]]); [[concepts/rices-theorem\|Rice's theorem]] for a property of $\textsf{Accept}(M)$ ([[1-models-of-computation/07-undecidability#711-rices-theorem\|§7.11]]); Corollary 3 |
| acceptable | a machine that accepts exactly $L$ and may run forever elsewhere: simulate with $U$, dovetail over inputs and step counts, or guess nondeterministically (Theorem 1 of Chapter 9); closure under $\cup$ and $\cap$ (Lemma 4) | $L$ undecidable but $\overline{L}$ acceptable (Lemma 5); a diagonal argument (Theorem 9); $L = \textsf{AcceptIn}(\mathcal{L})$ for a property $\mathcal{L}$ that is not monotone (Lemma 17) — in general, not monotone, compact and finitely acceptable (RMMS, [[1-models-of-computation/07-undecidability#712-the-ricemcnaughtonmyhillshapiro-theorem\|§7.12]]) |

Write-ups for each of these proofs, with the boilerplate: [[0-toolkit/02-proof-templates|proof templates]].

## 6. Placing a new language

> [!recipe] Recipe — four questions, in order (rules of thumb, then a proof)
> 1. **One pass with fixed memory?** If a left-to-right loop with finitely many finite-valued variables decides $L$, give a DFA, NFA or regular expression. If every algorithm you can think of keeps an unbounded count or an unbounded prefix, that quantity suggests an infinite fooling set.
> 2. **Is the unbounded memory a stack?** Nested matching — $\mathtt{0}^n\mathtt{1}^n$, parentheses, palindromes, counts that go up and come back down — suggests a grammar. Comparing a string with a copy of itself, or three blocks with each other ($w\mathtt{\#}w$, $\mathtt{0}^n\mathtt{1}^n\mathtt{0}^n$), is out of reach of grammars, but a Turing machine decides it.
> 3. **Is it a question about machines?** If membership of $\langle M\rangle$ depends only on $\textsf{Accept}(M)$ and the property is non-trivial, Rice's theorem makes it undecidable. If it asks about a bounded run (exactly 300 steps), or about a behavior that confines the machine to finitely many configurations (never moving left), simulate: it is decidable. Otherwise look for a reduction from $\textsf{Accept}$ or $\textsf{Halt}$, usually with the machine $M_w$ that ignores its input and runs $M$ on $w$.
> 4. **Can a "yes" be confirmed in finite time?** If every member has a certificate that simulation, dovetailing or guessing eventually finds — a step at which $M$ accepts, a PCP solution — $L$ is acceptable. If only the "no" answers have certificates, $\overline{L}$ is acceptable, and an undecidable $L$ is then not acceptable (Lemma 5).

## 7. Where running time fits

> [!note] P and NP inside the picture
> [[1-models-of-computation/09-nondeterministic-turing-machines#93-time-and-space-complexity|Chapter 9]] measures time on multi-tape Turing machines: $\textsf{P}$ is the class of languages decided in polynomial time, $\textsf{NP}$ the class decided in polynomial time by nondeterministic machines. Then
> $$
> \text{regular}\ \subsetneq\ \text{context-free}\ \subsetneq\ \textsf{P}\ \subseteq\ \textsf{NP}\ \subseteq\ \text{decidable}.
> $$
> Dynamic programming decides every context-free language in polynomial time (§5.8), $\{\mathtt{0}^n\mathtt{1}^n\mathtt{0}^n\}$ takes $O(n^2)$ steps (§6.3), and Theorem 1 of Chapter 9 simulates a nondeterministic decider deterministically in exponential time. Whether $\textsf{P} = \textsf{NP}$ is open; the [[concepts/cook-levin-theorem|Cook–Levin theorem]] reduces the question to the single language $\textsf{SAT}$ ([[1-models-of-computation/09-nondeterministic-turing-machines#96-the-cooklevin-theorem|§9.6]]).

## 8. Traps

> [!trap] The mistakes that cost points on true/false questions
> 1. **A subset or a superset of a regular language need not be regular:** $\varnothing\subseteq\{\mathtt{0}^n\mathtt{1}^n\}\subseteq\Sigma^*$. No class is closed under taking subsets.
> 2. **Infinite unions are not closed operations.** Every language is the union of its one-string subsets, and each of those is regular. Closure covers *finitely many* operations.
> 3. **Every finite language is regular**, however it is described: $\{\mathtt{0}^n\mathtt{1}^n \mid n\le374\}$ is regular. And every finite language is decidable, even when nobody knows which strings it contains ([[1-models-of-computation/07-undecidability#72-decidable-without-knowing-the-algorithm|§7.2]]).
> 4. **Closure arguments run one way.** If $L\cap R$ is not regular for a regular $R$, then $L$ is not regular; if $L\cap R$ or $L\cup L'$ is regular, nothing follows: $\{\mathtt{0}^n\mathtt{1}^n\}\cup\overline{\{\mathtt{0}^n\mathtt{1}^n\}} = \Sigma^*$.
> 5. **A grammar does not prove that $L$ is not regular** — every regular language has a grammar. Non-regularity needs a fooling set or closure.
> 6. **Context-free ∩ context-free can fail; context-free ∩ regular cannot.** So $L\setminus R$ is context-free whenever $L$ is context-free and $R$ is regular.
> 7. **Rice's theorem applies only to properties of $\textsf{Accept}(M)$** — or of $\textsf{Reject}(M)$, $\textsf{Halt}(M)$, $\textsf{Diverge}(M)$ with the matching variant. Not to behavior: $\textsf{ThisIsSparta}$ and "$M$ has 374 states" are decidable, and $\textsf{LeftThree}$ is undecidable only by a reduction. Not to self-reference ($\textsf{RevAccept}$). Not to trivial properties. And it proves undecidability, never unacceptability.
> 8. **Undecidable is not unacceptable:** $\textsf{Halt}$ is acceptable. Unacceptability needs Lemma 5, a diagonal argument or Lemma 17.
> 9. **Swapping accept and reject** complements a DFA and a deterministic decider — not an NFA, not a nondeterministic Turing machine, and not a machine that may run forever.
> 10. **The class belongs to the language, not to its description.** A Turing machine for $(\mathtt{0}+\mathtt{1})^*\mathtt{00}$ does not make that language non-regular; "the smallest class" is what a question asks about. And counting arguments name no language: they show that languages outside a class exist, never that a given one is outside.
