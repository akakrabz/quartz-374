> [!abstract] In one breath
> A **matroid** is a finite ground set with a family of **independent** subsets that contains $\varnothing$, is closed under taking subsets, and satisfies the **exchange property**: a smaller independent set can always be enlarged by some element of a larger one. Linearly independent columns, forests of a graph and sets of at most $k$ elements are the standard examples. For any matroid and any weights, the greedy algorithm that scans the elements from heaviest to lightest and keeps each one that preserves independence returns a **maximum-weight basis** (Theorem E.1) — Kruskal's algorithm is the case of forests. Conversely, if a hereditary family is *not* a matroid, some non-negative weights make that greedy algorithm fail (Theorem E.2), so the exchange property is exactly what greedy needs. The note ends with a matroid in disguise: which unit tasks to finish by their deadlines so that the penalties for the late ones are smallest.

## E.1 Definitions

> [!definition] Definition — matroid
> A **matroid** $M = (S, \mathcal{I})$ is a finite **ground set** $S$ and a family $\mathcal{I}$ of subsets of $S$ (the note says "of $X$") such that
> 1. **non-emptiness:** $\varnothing\in\mathcal{I}$;
> 2. **heredity:** if $X\in\mathcal{I}$ and $Y\subseteq X$, then $Y\in\mathcal{I}$;
> 3. **exchange:** if $X, Y\in\mathcal{I}$ and $\lvert X\rvert > \lvert Y\rvert$, then $Y\cup\{x\}\in\mathcal{I}$ for some $x\in X\setminus Y$.
>
> Sets in $\mathcal{I}$ are **independent**, the others **dependent**. A **basis** is an independent set that is not a proper subset of another independent set; a **circuit** is a dependent set whose proper subsets are all independent; the **rank** of $X\subseteq S$ is the size of its largest independent subset. A family with 1 and 2 only is a **subset system** (or hereditary family).

**All bases have the same size**, the rank of $S$: if $\lvert B_1\rvert < \lvert B_2\rvert$, exchange would add an element of $B_2$ to $B_1$, and $B_1$ would not be maximal.

The note lists six families (it leaves the proofs that the last four are matroids as Exercises 1–4):

| matroid | ground set | $X$ is independent if | bases | circuits |
|---|---|---|---|---|
| uniform $U_{k,n}$ | $\{1, \ldots, n\}$ | $\lvert X\rvert\le k$ | the $k$-subsets | the $(k+1)$-subsets |
| linear | the columns of a matrix $A$ | its columns are linearly independent | bases of the column space | minimal dependent sets of columns |
| graphic $M(G)$ | the edges of a graph $G$ | $X$ is a forest | spanning trees (spanning forests if $G$ is disconnected) | cycles |
| cographic $M^*(G)$ | the edges of a connected $G$ | $(V, E\setminus X)$ is connected | complements of spanning trees | bonds: minimal disconnecting edge sets |
| matching | the vertices of $G$ | some matching covers $X$ | maximal coverable vertex sets | — |
| edge-disjoint paths | the vertices of a digraph $G$, fixed $s$ | edge-disjoint paths lead from $s$ to every vertex of $X$ | — | — |

Two corrections to the note's list (p. 2): an $n\times m$ matrix has columns $1, \ldots, m$, not $1, \ldots, n$; and the cographic definition needs $G$ connected — otherwise not even $\varnothing$ is independent. ("Removing $X$ does not increase the number of components" works for every graph.)

**The matroid optimization problem.** Give every element $x$ a weight $w(x)\ge 0$ and find a basis of maximum total weight $w(X) = \sum_{x\in X} w(x)$. With the elements in an array $S[1\,..\,n]$:

```text
GreedyBasis(S[1 .. n], I, w[1 .. n]):
    sort S in decreasing order of weight w
    G ← ∅
    for i ← 1 to n
        if G ∪ {S[i]} ∈ I
            add S[i] to G
    return G
```

If independence can be tested in $F(n)$ time, GreedyBasis runs in $O(n\log n + n\cdot F(n))$ time. Its output is a basis: an element that could still be added was considered earlier and rejected while $G$ was smaller, which heredity rules out.

> [!key] Theorem E.1
> For every matroid $M = (S, \mathcal{I})$ and every weight function $w$, GreedyBasis returns a maximum-weight basis of $M$.

> [!proof]- Proof (click to expand)
> Let $G = \{g_1, \ldots, g_k\}$ be the output and $H = \{h_1, \ldots, h_k\}$ any other basis (same size), both indexed in order of decreasing weight. Suppose $w(g_i) < w(h_i)$ for some $i$, and take the smallest such $i$. The independent sets $G_{i-1} = \{g_1, \ldots, g_{i-1}\}$ and $H_i = \{h_1, \ldots, h_i\}$ have sizes $i-1 < i$, so by exchange $G_{i-1}\cup\{h_j\}\in\mathcal{I}$ for some $h_j\in H_i\setminus G_{i-1}$, and $w(h_j)\ge w(h_i) > w(g_i)$. So GreedyBasis considered $h_j$ before $g_i$, when its set was a subset of $G_{i-1}$; adding $h_j$ to that subset keeps it independent (heredity), so $h_j$ would have been kept — but $h_j\notin G_{i-1}$, a contradiction. Hence $w(g_i)\ge w(h_i)$ for every $i$, and $w(G)\ge w(H)$. $\square$
>
> (The note compares $G$ with a heavier independent set $H$ and assumes "without loss of generality" that $H$ is a basis, which needs non-negative weights. Compared with bases, as here, the theorem holds for weights of any sign; but with negative weights the best *independent set* stops before the first negative element.)

The proof shows more: the greedy basis beats every basis **rank by rank** — its $i$th heaviest element is at least as heavy as any basis's $i$th heaviest. In the examples GreedyBasis computes the $k$ heaviest elements (uniform), a heaviest set of columns spanning the column space (linear), a maximum spanning tree — [[2-algorithms/07-minimum-spanning-trees#75-kruskals-algorithm|Kruskal's algorithm]] on decreasing weights (graphic) — or the complement of a minimum spanning tree (cographic); with equal weights, a largest vertex set covered by one matching, which is $V$ exactly when a perfect matching exists (matching), or a largest vertex set reachable from $s$ by edge-disjoint paths. For the last two, the independence test is itself a matching or flow computation.

**The exchange property is exactly what greedy needs.** A subset system need not satisfy exchange, and then greedy can fail.

> [!key] Theorem E.2
> For every subset system $(S, \mathcal{I})$ that is not a matroid, there are non-negative weights for which GreedyBasis does not return a maximum-weight set of $\mathcal{I}$.

> [!proof]- Proof (click to expand)
> Take $X, Y\in\mathcal{I}$ that violate exchange: $\lvert X\rvert > \lvert Y\rvert = m$, and $Y\cup\{x\}\notin\mathcal{I}$ for every $x\in X\setminus Y$. (Then $m\ge 1$, since every singleton $\{x\}\subseteq X$ is independent.) Give the elements of $Y$ weight $m+2$, those of $X\setminus Y$ weight $m+1$, and all others weight 0. Greedy first scans $Y$ and keeps all of it (any subset of $Y$ is independent), then rejects every element of $X\setminus Y$, and whatever it adds later weighs 0: its output weighs $m(m+2) = m^2 + 2m$. But $X$ has at least $m+1$ elements, each of weight at least $m+1$, so $w(X)\ge(m+1)^2 = m^2 + 2m + 1$. $\square$

Together the two theorems say: **a hereditary family is a matroid if and only if GreedyBasis is optimal for every choice of non-negative weights.** (Erickson does not name it; this is the Rado–Edmonds theorem.)

> [!example] Example — weighted class scheduling is not a matroid
> Call a set of classes independent if no two overlap ([[2-algorithms/04-greedy-algorithms#42-scheduling-classes|§4.2]]). Heredity holds, exchange does not: for $[0,2]$, $[3,5]$, $[1,4]$, the sets $X = \{[0,2], [3,5]\}$ and $Y = \{[1,4]\}$ violate it ($m = 1$). With the proof's weights, 3 for $[1,4]$ and 2 for the others, greedy takes only $[1,4]$ (weight 3) and misses $X$ (weight 4). The note promises an easy counterexample with only two classes; for heaviest-first greedy none exists (with two classes it is always optimal) — the two-class example, $[0,2]$ worth 1 and $[1,10]$ worth 5, defeats Chapter 4's earliest-finish rule. With equal weights earliest finish is still correct (Theorem 4.4): Theorem E.2 promises only that *some* weights defeat greedy.

> [!trap] Matroid traps
> - **Heredity alone is not enough.** Matchings as sets of *edges* are hereditary but not a matroid: on the path $a\,b\,c\,d$, $\{ab, cd\}$ cannot exchange into $\{bc\}$. (The matching matroid's ground set is the *vertices*.)
> - **"Maximal" is not "maximum"** — except in a matroid, where all maximal independent sets have the same size.
> - **Theorem E.1 is about heaviest-first**; another scanning order or greedy rule needs its own proof.

## E.2 Scheduling with deadlines

There are $n$ tasks, each taking one full day, to be done on days $1, \ldots, n$. Task $i$ has a **deadline** $D[i]\in\{1, \ldots, n\}$ and a **penalty** $P[i]\ge 0$, paid if it is finished after day $D[i]$. A **schedule** is a permutation $\pi$, where $\pi(i)$ is the day of task $i$; the problem is to minimize
$$
\textsf{cost}(\pi) = \sum_{i=1}^n P[i]\cdot\big[\pi(i) > D[i]\big].
$$
Tasks with $\pi(i)\le D[i]$ are **on time**, the others **late**. The cost depends only on *which* tasks are on time, so the question is really about sets. Call a set $X$ of tasks **realistic** if some schedule finishes every task of $X$ on time, and let $X(t) = \{i\in X\mid D[i]\le t\}$ be its tasks due by day $t$.

> [!key] Lemma E.3
> $X$ is realistic if and only if $\lvert X(t)\rvert\le t$ for every $t$.

> [!proof]- Proof (click to expand)
> If a schedule finishes all of $X$ on time, let $i_t$ be the $t$th task of $X$ it performs. Then $\pi(i_t)\ge t$, and $\pi(i_t)\le D[i_t]$ because $i_t$ is on time (the note writes $D[i]$, p. 5); so $D[i_t]\ge t$. Every task of $X$ due by day $t$ is therefore among $i_1, \ldots, i_t$, and $\lvert X(t)\rvert\le t$. Conversely, if $\lvert X(t)\rvert\le t$ for all $t$, perform the tasks of $X$ first, in order of deadline: the tasks due by day $t$ come first and number at most $t$, so they are all done by day $t$. $\square$

The proof's schedule — the tasks of $X$ by increasing deadline, then the rest in any order — is the **canonical schedule** of $X$; $X$ is realistic exactly when its canonical schedule finishes $X$ on time. So the problem is: **find a realistic set $X$ of maximum total penalty $\sum_{i\in X} P[i]$**, and pay the penalties of the rest.

> [!key] Lemma E.4
> The realistic sets of tasks form a matroid.

> [!proof]- Proof (click to expand)
> $\varnothing$ is realistic and subsets of realistic sets are realistic. For exchange, let $X$ and $Y$ be realistic with $\lvert X\rvert > \lvert Y\rvert$, and let $t^*$ be the largest $t$ with $\lvert X(t)\rvert\le\lvert Y(t)\rvert$; it exists because $\lvert X(0)\rvert = 0 = \lvert Y(0)\rvert$, and $t^* < n$ because $\lvert X(n)\rvert = \lvert X\rvert > \lvert Y\rvert = \lvert Y(n)\rvert$. Since $\lvert X(t^*+1)\rvert > \lvert Y(t^*+1)\rvert$, $X$ has more tasks with deadline exactly $t^*+1$ than $Y$, so some $j\in X\setminus Y$ has $D[j] = t^*+1$. Let $Z = Y\cup\{j\}$. For $t\le t^*$, $\lvert Z(t)\rvert = \lvert Y(t)\rvert\le t$. For $t > t^*$, $\lvert Y(t)\rvert < \lvert X(t)\rvert$ by the choice of $t^*$, so $\lvert Z(t)\rvert = \lvert Y(t)\rvert + 1\le\lvert X(t)\rvert\le t$. By Lemma E.3, $Z$ is realistic. $\square$
>
> (The note ends that chain with $\lvert X(t)\rvert < t$, p. 6; realism only gives $\le t$, and equality happens — for example $Y = \varnothing$ and $X$ one task due on day 1.)

So GreedyBasis solves the problem: consider the tasks by **decreasing** penalty and keep each one that leaves the kept set realistic.

```text
GreedySchedule(D[1 .. n], P[1 .. n]):
    sort P in decreasing order, and permute D to match
    X ← ∅                         ⟨⟨kept sorted by deadline⟩⟩
    for i ← 1 to n
        if Realistic?(X ∪ {i}, D)  ⟨⟨i inserted by deadline⟩⟩
            X ← X ∪ {i}
    return the canonical schedule for X

Realistic?(X[1 .. m], D[1 .. n]):      ⟨⟨X sorted by increasing deadline⟩⟩
    N ← 0;  j ← 1
    for t ← 1 to n
        while j ≤ m and D[X[j]] = t
            N ← N + 1;  j ← j + 1
        ⟨⟨now N = |X(t)|⟩⟩
        if N > t
            return False
    return True
```

Realistic? takes $O(n)$ time, so GreedySchedule takes $O(n^2)$; an $O(n\log n)$ version is the note's Exercise 6. The pseudocode corrects the note's (pp. 6–7), which sorts the penalties in **increasing** order (in the example below: penalty 17 instead of 11), starts Realistic? at the undefined $X[0]$, tests "**if** $D[X[j]] = t$" where several tasks can share a deadline and a **while** is needed (with "if", $\{a, b, c\}$ below — three tasks due by day 2 — passes), and appends new tasks at the end of $X$, which Realistic? needs sorted by deadline.

> [!example] Example — six tasks
> | task | $a$ | $b$ | $c$ | $d$ | $e$ | $f$ |
> |---|---|---|---|---|---|---|
> | deadline $D$ | 2 | 1 | 2 | 3 | 1 | 4 |
> | penalty $P$ | 9 | 8 | 7 | 5 | 4 | 2 |
>
> By decreasing penalty: keep $a$; keep $b$ ($\lvert X(1)\rvert = 1$, $\lvert X(2)\rvert = 2$); reject $c$ ($\lvert X(2)\rvert$ would be 3); keep $d$; reject $e$ ($\lvert X(1)\rvert$ would be 2); keep $f$. The canonical schedule is $b, a, d, f$ on days 1–4, then $c$ and $e$, late: total penalty $7 + 4 = 11$, the minimum over all $6! = 720$ schedules. The note's increasing order keeps $f, e, d, c$ and then has to reject $b$ and $a$: penalty $9 + 8 = 17$.

## Summary

- A matroid: $\varnothing$ independent, heredity, exchange (a smaller independent set can be extended from a larger one); all bases have the same size.
- Examples: uniform, linear (independent columns), graphic (forests), cographic (complement connected), matching (coverable vertex sets), edge-disjoint paths from $s$. Non-examples: non-overlapping classes, matchings as edge sets.
- GreedyBasis (heaviest first, keep if still independent) returns a maximum-weight basis of every matroid in $O(n\log n + nF(n))$ time (Theorem E.1); Kruskal is the graphic case. For a non-matroid, the weights $m+2$ on $Y$, $m+1$ on $X\setminus Y$, 0 elsewhere defeat it (Theorem E.2).
- Unit tasks with deadlines and penalties: a set is realistic iff $\lvert X(t)\rvert\le t$ for all $t$ (Lemma E.3), realistic sets form a matroid (Lemma E.4), so greedy by **decreasing** penalty is optimal: $O(n^2)$ with a linear-time realism test.
- The note ends with 6 exercises (the graphic, cographic, matching and disjoint-path matroids are matroids; cycle bases; an $O(n\log n)$ GreedySchedule).

> Not on the exams: the note is not assigned this semester, and matroids are CS 473 material. What transfers is the proof pattern. Theorem E.1's proof is the [[2-algorithms/04-greedy-algorithms#43-the-general-pattern|inductive exchange argument]] in its "first difference" form — the same shape as the proof of Theorem 4.4 and of the cut property for minimum spanning trees ([[2-algorithms/07-minimum-spanning-trees#72-the-only-minimum-spanning-tree-algorithm|§7.2]]) — and Theorem E.2 is the reason to look for a small counterexample before trusting any greedy rule.
