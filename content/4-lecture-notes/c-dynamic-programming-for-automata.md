> [!abstract] In one breath
> Questions about automata and grammars are recursive, so they become dynamic programs once the recursion is written over **indices into the input string** instead of over strings. **NFA acceptance:** $\textsf{Accepts?}(q,i)$ — does the machine, started in state $q$, accept the suffix $w[i\,..\,n]$? — depends only on the column $i+1$, so a table filled from right to left decides membership in $O(n\lvert Q\rvert^2)$ time, where backtracking over the nondeterministic choices takes $\Theta(\lvert Q\rvert^n)$ in the worst case. **CFG parsing:** for a grammar in **Chomsky normal form**, $\textsf{Gen?}(A,i,j)$ — does $A$ derive $w[i\,..\,j]$? — is decided by trying every rule $A\to BC$ and every split point; this is the **CYK algorithm**, $O(n^3L)$ time for a grammar with $L$ rules. CNF is what makes the recursion well founded: without $\varepsilon$-rules and unit rules, every recursive call is on a strictly shorter substring. ## C.1 DFA minimization

The note's section is a placeholder: its whole text is "Write this." So there is nothing of the note's to summarize. The textbook's algorithm — Moore's table filling, [[1-models-of-computation/03-finite-state-machines#310-minimal-automata-moores-algorithm|§3.10]] — is itself a dynamic program; here it is in the rubric's format.

### Moore's algorithm as a dynamic program (not in the note)

Fix a DFA $M = (\Sigma, Q, s, A, \delta)$ with $n$ states and $\sigma$ symbols, with its unreachable states already deleted. Two states are **distinguishable** if some string $z$ sends exactly one of them to an accepting state.

> [!definition] Function — $\textsf{Dist}(k, p, q)$
> For $k\ge0$ and states $p, q$, $\textsf{Dist}(k,p,q)$ is $\textsf{True}$ if and only if some string of length **at most $k$** distinguishes $p$ and $q$. States $p$ and $q$ are equivalent if and only if $\textsf{Dist}(k,p,q) = \textsf{False}$ for every $k$; it suffices to compute layers until one equals the previous one.

$$
\textsf{Dist}(k,p,q) = \begin{cases} [\,p\in A\,] \ne [\,q\in A\,] & \text{if } k = 0\\ \textsf{Dist}(k-1,p,q)\ \vee\ \displaystyle\bigvee_{a\in\Sigma}\textsf{Dist}\big(k-1,\ \delta(p,a),\ \delta(q,a)\big) & \text{if } k\ge1\end{cases}
$$

The recursive case is the textbook's recursive description of distinguishability: a string $az$ of length $\le k$ distinguishes $p$ and $q$ exactly when $z$, of length $\le k-1$, distinguishes $\delta(p,a)$ and $\delta(q,a)$.

- **Memoization:** one boolean $n\times n$ table per layer $k$; only the previous layer is ever read, so two tables suffice.
- **Evaluation order:** $k = 0, 1, 2, \ldots$ (outer loop); the pairs $\{p,q\}$ in any order (inner loop). Stop at the first layer equal to the one before; every later layer would be the same. The layers stop changing after at most $n-2$ rounds (so the stop comes by layer $n-1$), because each round that changes something splits a class of equivalent-so-far states, and two classes (accepting and non-accepting) are there from the start.
- **Time:** at most $n$ layers $\times$ $O(n^2)$ pairs $\times$ $O(\sigma)$ per pair $= O(\sigma n^3)$, as in §3.10. Merging each class of pairwise non-distinguishable states then gives the minimal DFA.

Table filling as §3.10 states it is the same computation done **in place**: a pass may already use pairs marked earlier in the same pass, so it can finish in fewer passes, never more.

## C.2 NFA acceptance

An NFA is a directed graph whose vertices are states and whose edges are labeled with symbols, with a start state $s$ and a set $A$ of accepting states; it accepts $w$ if some walk from $s$ to a state in $A$ is labeled $w$. (The note says "whose **edges** are called states"; it means the vertices.) Formally $\delta\colon Q\times\Sigma\to 2^Q$, extended to strings by $\delta^*(q,\varepsilon) = \{q\}$ and $\delta^*(q, ax) = \bigcup_{r\in\delta(q,a)}\delta^*(r,x)$, exactly as in [[1-models-of-computation/04-nondeterministic-automata#41-nondeterministic-state-machines|§4.1]]; the NFA accepts $w$ iff $\delta^*(s,w)\cap A\ne\varnothing$. The note's NFAs have no $\varepsilon$-transitions.

The same condition, written directly in terms of $\delta$: let $\textsf{Accepts?}(q,w)$ be $\textsf{True}$ iff the NFA would accept $w$ if it started in state $q$. Then $\textsf{Accepts?}(q,\varepsilon) = [q\in A]$ and $\textsf{Accepts?}(q, ax) = \bigvee_{r\in\delta(q,a)}\textsf{Accepts?}(r,x)$, and the NFA accepts $w$ iff $\textsf{Accepts?}(s,w)$.

### Backtracking

**Input.** Number the symbols $1, \ldots, \lvert\Sigma\rvert$ and the states $1,\ldots,\lvert Q\rvert$, with start state 1. The input is three arrays: $A[1\,..\,\lvert Q\rvert]$, with $A[q] = \textsf{True}$ iff $q$ is accepting; $\delta[1\,..\,\lvert Q\rvert, 1\,..\,\lvert\Sigma\rvert, 1\,..\,\lvert Q\rvert]$, with $\delta[p,a,q] = \textsf{True}$ iff $q\in\delta(p,a)$; and the string $w[1\,..\,n]$. (The note's bullet says "iff $p\in\delta(q,a)$" — the transitions reversed. Its pseudocode reads $\delta[q, w[i], r]$ as "$r\in\delta(q,w[i])$", the meaning above; with the bullet's meaning the algorithm answers a different question and is wrong on many inputs.)

Fixing $w$ lets the second argument be an index: $\textsf{Accepts?}(q,i)$ asks about the suffix $w[i\,..\,n]$, and the recursion passes integers instead of strings — the move that makes memoization easy. Translated directly:

```text
Accepts?(q, i):
    if i > n
        return A[q]
    for r ← 1 to |Q|
        if δ[q, w[i], r] and Accepts?(r, i + 1)
            return True
    return False
```

This explores the nondeterministic choices one at a time. On an NFA in which every state has an edge to every state on every symbol and no state accepts, it makes $1 + \lvert Q\rvert + \cdots + \lvert Q\rvert^n$ calls: $\Theta(\lvert Q\rvert^n)$ time in the worst case. But there are only $\lvert Q\rvert(n+1)$ different subproblems.

### Dynamic programming

> [!definition] Function — $\textsf{Accepts?}(q, i)$
> For a state $q$ and $1\le i\le n+1$, $\textsf{Accepts?}(q, i)$ is $\textsf{True}$ if and only if the NFA, started in state $q$, accepts the suffix $w[i\,..\,n]$ — some walk from $q$ labeled $w[i\,..\,n]$ ends in an accepting state. We need $\textsf{Accepts?}(s, 1)$.

$$
\textsf{Accepts?}(q,i) = \begin{cases} \textsf{True} & \text{if } i = n+1 \text{ and } q\in A\\ \textsf{False} & \text{if } i = n+1 \text{ and } q\notin A\\ \displaystyle\bigvee_{r\in\delta(q,\,w[i])}\textsf{Accepts?}(r, i+1) & \text{if } i\le n\end{cases}
$$

(The note's display writes $\delta(q,a)$ with $a$ undefined; the symbol read is $w[i]$. An empty $\delta(q,w[i])$ gives $\textsf{False}$.)

- **Memoization:** a boolean array $\textit{Accepts?}[1\,..\,\lvert Q\rvert,\ 1\,..\,n+1]$.
- **Evaluation order:** entry $(q,i)$ reads only column $i+1$, so $i$ from $n+1$ **down** to 1 (outer loop), states $q$ in any order (inner loop).
- **Time:** $n\lvert Q\rvert$ entries outside the base column, each an OR over $\lvert Q\rvert$ states $r$: $O(n\lvert Q\rvert^2)$ time, $O(n\lvert Q\rvert)$ space (two columns suffice for the yes/no answer).

```text
NFAaccepts?(A[1 .. |Q|], δ[1 .. |Q|, 1 .. |Σ|, 1 .. |Q|], w[1 .. n]):
    for q ← 1 to |Q|
        Accepts?[q, n + 1] ← A[q]
    for i ← n down to 1
        for q ← 1 to |Q|
            Accepts?[q, i] ← False
            for r ← 1 to |Q|
                if δ[q, w[i], r] and Accepts?[r, i + 1]
                    Accepts?[q, i] ← True
    return Accepts?[1, 1]
```

**Example.** For the NFA of §4.1 (strings containing `00` or `11`) and $w = $ `0110`, the table in the figure has the answer $\textsf{True}$ in entry $(s,1)$. ## C.4 CFG parsing

**The problem.** Given a context-free grammar $G$ — terminals $\Sigma$, a finite set $\Gamma$ of nonterminals, rules $A\to\omega$ with $\omega\in(\Sigma\cup\Gamma)^*$, start symbol $S$ ([[1-models-of-computation/05-context-free-languages#51-definitions|§5.1]]) — and a string $w$, is $w\in L(G)$? Applications usually want more than one bit — a parse tree (compilers), the number of parse trees, or the most likely parse tree when rules have probabilities — but the decision algorithm extends to all of these.

**Why the obvious recursion fails.** Let $\textsf{Gen?}(A,x)$ be $\textsf{True}$ iff $A\rightsquigarrow^* x$. Reading it off the rules does not work in general:
- With $S\to\varepsilon\mid SS\mid (S)$ (balanced parentheses), trying every split $x = y\bullet z$ for the rule $S\to SS$ includes $y = \varepsilon$, $z = x$, so $\textsf{Gen?}(S,x)$ calls $\textsf{Gen?}(S,x)$: an infinite loop.
- With unit rules $S\to A$, $A\to B$, $B\to S$, $\textsf{Gen?}(S,x)$ calls $\textsf{Gen?}(A,x)$, which calls $\textsf{Gen?}(B,x)$, which calls $\textsf{Gen?}(S,x)$.

The same subtleties trouble induction proofs about grammars ([[1-models-of-computation/05-context-free-languages#careful-with-those-epsilons|§5.3]]). The cure is to assume the grammar is in **Chomsky normal form** ([[concepts/chomsky-normal-form]]): the start symbol $S$ appears on no right side; $S\to\varepsilon$ is allowed but no other $\varepsilon$-rule; every other rule is $A\to BC$ or $A\to a$. Every grammar can be converted (Theorem 5.7, [[1-models-of-computation/05-context-free-languages#59-the-cnf-conversion-algorithm|§5.9]]); a grammar of total length $L$ becomes one of total length $O(L^2)$, in $O(L^2)$ time. (The note measures a grammar by its **number of rules**; with that measure the bound cannot hold — the one-rule grammars $S\to w$ generate infinitely many different languages, while there are only finitely many CNF grammars over $\{\mathtt{0},\mathtt{1}\}$ with at most $c$ rules, up to renaming. The bound is for total length, as in §5.9.)

> [!example] Example — the note's parenthesis grammar, and a correct one
> The note's CNF grammar for balanced parentheses, $S\to\varepsilon\mid AA\mid BC$, $A\to AA\mid BC$, $B\to LA$, $C\to RA$, $L\to\mathtt{(}$, $R\to\mathtt{)}$, is followed by the author's own marker "This is incorrect." Indeed $A$, $B$ and $C$ derive **no** string at all: every right side of their rules contains $A$ or $B$, so no derivation from them can ever finish. The grammar generates only $\varepsilon$. A correct CNF grammar, with $A$ generating the **non-empty** balanced strings:
> $$
> S\to\varepsilon\mid AA\mid LR\mid LB\qquad A\to AA\mid LR\mid LB\qquad B\to AR\qquad L\to\mathtt{(}\qquad R\to\mathtt{)}
> $$
> A non-empty balanced string is either two non-empty balanced strings in a row ($AA$), or $\mathtt{(}x\mathtt{)}$ with $x$ balanced — $LR$ when $x = \varepsilon$, and $L\,B$ with $B\to AR$ deriving $x\mathtt{)}$ when $x\ne\varepsilon$.

**The recurrence.** In CNF, $\textsf{Gen?}(A,x)$ is decided directly when $\lvert x\rvert\le1$ (is $A\to x$ a rule? — this covers $A\to a$ and $S\to\varepsilon$), and otherwise by trying every rule $A\to BC$ and every split of $x$ into a **non-empty** prefix $y$ and a **non-empty** suffix $z$, checking $\textsf{Gen?}(B,y)\wedge\textsf{Gen?}(C,z)$. Every recursive call is on a strictly shorter string, so the recursion terminates. The resulting dynamic program was found by Tadao Kasami (1965), again by Daniel Younger (1967) and again by John Cocke (1970), and is named after them in reverse chronological order: the **Cocke–Younger–Kasami** or **CYK algorithm**.

> [!definition] Function — $\textsf{Gen?}(A, i, j)$
> Fix $w[1\,..\,n]$ with $n\ge1$. For a nonterminal $A$ and $1\le i\le j\le n$, $\textsf{Gen?}(A,i,j)$ is $\textsf{True}$ if and only if $A\rightsquigarrow^* w[i\,..\,j]$. Then $w\in L(G)$ iff $\textsf{Gen?}(S,1,n)$; the empty string is in $L(G)$ iff $S\to\varepsilon$ is a rule. (The note writes $\textsf{Gen?}(A,1,n)$ in this sentence; it must be the start symbol $S$ — another nonterminal deriving $w$ proves nothing.)

$$
\textsf{Gen?}(A,i,j) = \begin{cases} [\,A\to w[i] \text{ is a rule}\,] & \text{if } i = j\\[2pt] \displaystyle\bigvee_{A\to BC}\ \bigvee_{k=i}^{j-1}\Big(\textsf{Gen?}(B,i,k)\wedge\textsf{Gen?}(C,k+1,j)\Big) & \text{if } i<j\end{cases}
$$

- **Memoization:** a boolean array $\textit{Gen}[1\,..\,\lvert\Gamma\rvert,\ 1\,..\,n,\ 1\,..\,n]$ (only $i\le j$ is used).
- **Evaluation order:** entry $(A,i,j)$ reads entries $(\cdot,i,k)$ with $k<j$ and $(\cdot,k+1,j)$ with $k+1>i$. So $j$ **increasing** (outer loop), $i$ **decreasing** from $j-1$ to 1 (middle loop), rules innermost. (Increasing length $j-i$, the order of [[1-models-of-computation/05-context-free-languages#58-chomsky-normal-form|§5.8]], works too.)
- **Time:** $O(n^2)$ substrings $\times$ $L$ rules $\times$ $O(n)$ split points $= O(n^3L)$; precisely, the innermost test runs $r\cdot(n^3-n)/6$ times for $r$ rules of the form $A\to BC$. Space $O(n^2\lvert\Gamma\rvert)$. For a fixed grammar, $O(n^3)$.

```text
CYKParse(w[1 .. n], G):
    if n = 0
        return True if G contains S → ε, else False
    for i ← 1 to n
        for all nonterminals A
            Gen[A, i, i] ← (G contains the rule A → w[i])
    for j ← 1 to n
        for i ← j − 1 down to 1          ⟨⟨the note prints: n down to j + 1⟩⟩
            for all nonterminals A
                Gen[A, i, j] ← False
            for all rules A → BC
                for k ← i to j − 1
                    if Gen[B, i, k] and Gen[C, k + 1, j]
                        Gen[A, i, j] ← True
    return Gen[S, 1, n]
```

As printed, the middle loop runs $i$ from $n$ down to $j+1$, over pairs with $i>j$, where the split loop is empty; the entries $i<j$, including $\textit{Gen}[S,1,n]$, are never computed, and with a table initialized to $\textsf{False}$ every string of length $\ge2$ is rejected. The text's evaluation order ("increasing $j$ and decreasing $i$") is the right one. (The base-case loop is condensed from the note's if/else.)

> [!trap] CYK traps
> - **Convert to CNF first.** With $\varepsilon$-rules or unit rules the recurrence may call itself on the same substring and never stop.
> - **Both pieces are non-empty:** $k$ runs from $i$ to $j-1$. The empty string is handled separately, by the rule $S\to\varepsilon$.
> - **The answer is $\textsf{Gen?}(S,1,n)$**, for the start symbol only.
> - **Fill by length** (or $j$ up, $i$ down). Row by row with $i$ increasing reads cells not yet computed.
> - **The grammar counts:** $O(n^3)$ hides a factor $L$; when the grammar is part of the input, say $O(n^3L)$, and remember that CNF conversion can square the grammar's size.

## Summary

- Index the input: a recursion over suffixes $w[i\,..\,n]$ or substrings $w[i\,..\,j]$ has polynomially many subproblems, so it memoizes.
- **NFA acceptance:** $\textsf{Accepts?}(q,i)$ = "from $q$, accept $w[i\,..\,n]$"; base $[q\in A]$ at $i = n+1$; OR over $r\in\delta(q,w[i])$ of $\textsf{Accepts?}(r,i+1)$; fill $i$ from $n+1$ down; $O(n\lvert Q\rvert^2)$ time versus $\Theta(\lvert Q\rvert^n)$ for backtracking.
- **CFG parsing (CYK):** grammar in CNF; $\textsf{Gen?}(A,i,j)$ = "$A\rightsquigarrow^* w[i\,..\,j]$"; base: the rule $A\to w[i]$; OR over rules $A\to BC$ and splits $i\le k<j$; fill $j$ up, $i$ down; answer $\textsf{Gen?}(S,1,n)$, and $\varepsilon$ separately; $O(n^3L)$ time, $O(n^3)$ for a fixed grammar.
- CNF is what makes the parsing recursion terminate: no $\varepsilon$-rules (except $S\to\varepsilon$) and no unit rules, so every call is on a shorter substring.
- **DFA minimization** (not in the note): Moore's algorithm is the DP "some string of length $\le k$ distinguishes $p$ and $q$", layer by layer in $k$, $O(\sigma n^3)$.
- The note's sections C.1 and C.3 are unwritten, and it has no exercises yet.
