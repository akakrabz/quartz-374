In one breath

Every language in the course sits in one of five nested regions. Regular languages are the ones a single left-to-right pass with a fixed amount of memory can decide; regular expressions, DFAs and NFAs describe exactly them. Context-free languages add unbounded nesting: grammars, or NFAs that call each other like recursive subroutines. Decidable languages are the ones some algorithm decides — a Turing machine that halts on every input. Acceptable languages are the ones whose members an algorithm can confirm: a Turing machine accepts exactly them and may run forever on everything else. Every inclusion is strict, and each boundary has its own tool for proving that a language lies outside it.

Other names: acceptable = recognizable = semi-decidable = recursively enumerable; decidable = computable = recursive. The Church–Turing thesis — a claim about the world, not a theorem — says that the last two rows capture every algorithm, so “decidable” means “some program in any language decides it”.

4. Closure at a glance

6. Placing a new language

Recipe — four questions, in order (rules of thumb, then a proof)

  1. One pass with fixed memory? If a left-to-right loop with finitely many finite-valued variables decides L, give a DFA, NFA or regular expression. If every algorithm you can think of keeps an unbounded count or an unbounded prefix, that quantity suggests an infinite fooling set.
  2. Is the unbounded memory a stack? Nested matching — 0n1n, parentheses, palindromes, counts that go up and come back down — suggests a grammar. Comparing a string with a copy of itself, or three blocks with each other (w#w, 0n1n0n), is out of reach of grammars, but a Turing machine decides it.
  3. Is it a question about machines? If membership of ⟨M⟩ depends only on Accept(M) and the property is non-trivial, Rice’s theorem makes it undecidable. If it asks about a bounded run (exactly 300 steps), or about a behavior that confines the machine to finitely many configurations (never moving left), simulate: it is decidable. Otherwise look for a reduction from Accept or Halt, usually with the machine Mw​ that ignores its input and runs M on w.
  4. Can a “yes” be confirmed in finite time? If every member has a certificate that simulation, dovetailing or guessing eventually finds — a step at which M accepts, a PCP solution — L is acceptable. If only the “no” answers have certificates, L is acceptable, and an undecidable L is then not acceptable (Lemma 5).

7. Where running time fits

P and NP inside the picture

Chapter 9 measures time on multi-tape Turing machines: P is the class of languages decided in polynomial time, NP the class decided in polynomial time by nondeterministic machines. Then

regular ⊊ context-free ⊊ P ⊆ NP ⊆ decidable.

Dynamic programming decides every context-free language in polynomial time (§5.8), {0n1n0n} takes O(n2) steps (§6.3), and Theorem 1 of Chapter 9 simulates a nondeterministic decider deterministically in exponential time. Whether P=NP is open; the Cook–Levin theorem reduces the question to the single language SAT (§9.6).

8. Traps

The mistakes that cost points on true/false questions

  1. A subset or a superset of a regular language need not be regular: ∅⊆{0n1n}⊆Σ∗. No class is closed under taking subsets.
  2. Infinite unions are not closed operations. Every language is the union of its one-string subsets, and each of those is regular. Closure covers finitely many operations.
  3. Every finite language is regular, however it is described: {0n1n∣n≤374} is regular. And every finite language is decidable, even when nobody knows which strings it contains (§7.2).
  4. Closure arguments run one way. If L∩R is not regular for a regular R, then L is not regular; if L∩R or L∪L′ is regular, nothing follows: {0n1n}∪{0n1n}​=Σ∗.
  5. A grammar does not prove that L is not regular — every regular language has a grammar. Non-regularity needs a fooling set or closure.
  6. Context-free ∩ context-free can fail; context-free ∩ regular cannot. So L∖R is context-free whenever L is context-free and R is regular.
  7. Rice’s theorem applies only to properties of Accept(M) — or of Reject(M), Halt(M), Diverge(M) with the matching variant. Not to behavior: ThisIsSparta and ”M has 374 states” are decidable, and LeftThree is undecidable only by a reduction. Not to self-reference (RevAccept). Not to trivial properties. And it proves undecidability, never unacceptability.
  8. Undecidable is not unacceptable: Halt is acceptable. Unacceptability needs Lemma 5, a diagonal argument or Lemma 17.
  9. Swapping accept and reject complements a DFA and a deterministic decider — not an NFA, not a nondeterministic Turing machine, and not a machine that may run forever.
  10. The class belongs to the language, not to its description. A Turing machine for (0+1)∗00 does not make that language non-regular; “the smallest class” is what a question asks about. And counting arguments name no language: they show that languages outside a class exist, never that a given one is outside.
