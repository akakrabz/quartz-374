How to use this page

1. The exam and how to attack each problem

The Midterm 1 practice exams have five problems in 120 minutes, one of each type below. Any result from lecture, the lecture notes, labs or homework solutions may be cited without proof. Words like “clearly”, “trivial” and “obviously” draw scrutiny, and an ambiguous answer is read unfavorably. Full rubrics: how exams are graded.

Type 1 — true or false, with a one-sentence justification (10 parts)

  • Test the claim on tiny cases before deciding: ∅, {ε}, Σ∗, 0∗, {0n1n}, strings of length 0, 1 and 2.
  • True needs a reason that covers every case: name the closure property, construction or theorem. False needs one concrete counterexample.
  • Practice: §7 below, the traps in §8, and the “On the exams” box at the end of each chapter page.

Type 2 — regular language transformations (two parts)

  • Which direction? For {w∣f(w)∈L}, read w and simulate M on f(w) — often a DFA. For {f(w)∣w∈L}, read the output and guess a preimage while simulating M on it — an NFA, with ε-transitions for symbols that f deletes.
  • Start from an arbitrary DFA M=(Σ,Q,s,A,δ) for L. Describe M′ in English (what each component of a state remembers, what it guesses, when it accepts) and formally: Q′, s′, A′, and δ′(q,a), δ′(q,ε) in every case.
  • Check the edge cases L=∅, {ε}, 1∗, Σ∗.
  • Graded: 2 for a formal, complete description (say DFA or NFA, with or without ε-transitions) + 2 for the English explanation + 6 for correctness (1 states, 1 start, 1 accepting states, 3 transitions).
  • Templates: language transformation, §4.9 · model answer: Two language transformations · practice: Chapter 4 practice.

Type 3 — induction on a recursively defined string function

  • Write the boilerplate first: an arbitrary string; a hypothesis for every shorter string, quantified over every other argument the proof changes; one case per case of the definition.
  • Induct on the argument the function takes apart, and peel what the definition peels (two symbols for a function defined on w=abx).
  • Justify every equation: a definition, the hypothesis (and why the string is shorter), a lemma, or arithmetic. If a case gets stuck, prove a small lemma first or strengthen the claim.
  • Graded: 1 arbitrary object + 2 explicit strong hypothesis + 2 exhaustive cases + 1 base cases + 2 correct use of the hypothesis + 2 other details.
  • Templates: induction on strings, §1.3 · model answer: Induction on a recursive string function · practice: Chapter 1 practice.

Type 4 — not regular (fooling set), plus a grammar for the same language

  • Fooling set: choose F from the unbounded quantity an algorithm would have to remember (usually 0∗ or 0∗1). Write arbitrary distinct x,y∈F with parameters i=j, build z from x‘s parameter, and prove xz∈L and yz∈/L, each with a reason. Check the edge case i=0.
  • Grammar: decompose a typical string — an outer matching pair, the first point where a count balances, or cases — give each piece a nonterminal, and describe its language in English. Test ε and short strings that must be rejected.
  • Graded: fooling set 4 for an explicit infinite set that really is a fooling set (a finite set earns 0) + 6 for the proof (2 explicit suffix, 2 one string in, 2 the other out). Grammar 2 syntax + 8 correctness: −2 for one mistake (often ε), −4 for a few wrong strings, all 8 for infinitely many; ∅ or Σ∗ earns nothing; ambiguity costs nothing.
  • Templates: fooling-set proof, writing up a grammar, designing a grammar · model answer: A fooling set and a grammar for one language · practice: Chapter 3 practice, Chapter 5 practice.

Type 5 — a DFA and a regular expression for one language (mnemonic state names, no proof)

  • DFA: write the one-pass algorithm first; states = the values of its variables; name each state after what it remembers. Draw the start arrow and double circles, and if you omit the dump state, say that missing transitions go to it.
  • Regular expression: cut typical strings into blocks; explain each piece; test ε and short strings in both directions. Only +, concatenation, ∗, ε, ∅ and parentheses.
  • Graded: DFA 2 for a complete, unambiguous description + 6 correctness + 2 mnemonic names (an NFA where a DFA was asked earns half). Expression 2 syntax + 8 correctness, with the deductions of type 4.
  • Templates: describing a DFA, writing up an expression, §3.5 · model answer: A regular expression and a DFA for one language · practice: Chapter 2 practice, Chapter 3 practice.

Powers: w0=ε, wn=w∙wn−1.

Numbered results. Lemma 1.1: w∙ε=w. Lemma 1.2: ∣w∙x∣=∣w∣+∣x∣. Lemma 1.3: (w∙x)∙y=w∙(x∙y). Each is an induction on the left argument.

Standard facts, each a short induction: (w∙x)R=xR∙wR (the order flips), (wR)R=w, #(a,xy)=#(a,x)+#(a,y), ∣wR∣=∣w∣, wmwn=wm+n, and cancellation (xz=yz implies x=y). Cite one on an exam only if it comes from lecture, the notes, labs or homework; otherwise prove it first.

Pieces of a string. A substring is contiguous; a prefix starts at the beginning, a suffix ends at the end; a subsequence deletes symbols anywhere; proper excludes w itself. A string of length n has n+1 prefixes and n+1 suffixes.

Other splits (§1.4): w=a or w=u∙v with u,v non-empty (two base cases), or peel the last symbol, w=xa. Any split works if the cases cover every string and the hypothesis is applied only to shorter strings.

5. Chapter 4 — Nondeterministic automata

Chapter 4 · concepts: nfa, subset-construction, thompsons-algorithm, state-elimination, kleenes-theorem, language-transformations

NFA, epsilon-reach, epsilon-removal and the subset construction

NFA: δ:Q×(Σ∪{ε})→2Q; M accepts w iff some walk from s to an accepting state spells w. The ε-reach of q is everything reachable from q by zero or more ε-transitions, and

δ∗(q,ε)=ε-reach(q),δ∗(q,ax)=r∈ε-reach(q)⋃​ p∈δ(r,a)⋃​δ∗(p,x).

Removing ε-transitions (same states and start): A′={q∣ε-reach(q)∩A=∅} and δ′(q,a)=⋃r∈ε-reach(q)​δ(r,a).

Subset construction (NFA to DFA, §4.5):

Q′=2Q,s′={s},A′={S∣ε-reach(S)∩A=∅},δ′(S,a)=p∈S⋃​ r∈ε-reach(p)⋃​δ(r,a).​

By hand, build only the reachable subsets, breadth-first from {s}, in a table with columns S, ε-reach(S), accepting?, and δ′(S,a) for each a; ∅ gets a row if it appears.

Thompson's gadgets (expression to NFA, §4.6)

Every gadget has one start state s and one accepting state t=s (Lemma 4.2).

expressiongadget
∅, ε, a symbol astates s, t with no transition, sε​t, or sa​t
STin series: tS​ε​sT​; start sS​, accept tT​

Two states per leaf, per + and per ∗, none per concatenation: (0+10∗1)∗ gets 2×(4+1+2)=14.

State elimination (NFA to expression, §4.8)

Add a new start s with sε​ (old start) and a new target t with (every accepting state) ε​t; a missing edge is ∅. Remove the old states one at a time; removing q sets, for every pair of remaining states p, r — including p=r,

R′(p→r)=R(p→r)+R(p→q)R(q→q)∗R(q→r).

At the end, R(s→t) is the expression (Lemma 4.3). O(n3) operations, but the expression can reach length Θ(4n).

Kleene’s theorem (Theorem 4.1) is the cycle expression → NFA (Thompson) → DFA (subsets) → NFA (a DFA already is one) → expression (elimination). Every arrow preserves the language, not the size: subsets can cost 2∣Q∣ states, elimination exponential length. The book’s runs: (0+10∗1)∗ gives 14 NFA states, 5 DFA states, 2 after minimization; (0+1)∗(00+11)(0+1)∗ gives 18 (26 if each 0+1 is built literally), 9, and 4.

The two transformation lemmas ( §4.9)

Let M=(Σ,Q,s,A,δ) be a DFA for L.

Lemma 4.4 — reversal LR={wR∣w∈L}. Reverse every edge, add a new start sR with ε-edges to the old accepting states, and accept only at s:

QR=Q∪{sR},AR={s},δR(sR,ε)=A,δR(q,a)={p∣δ(p,a)=q}.

(Or by expressions: reverse every string and swap the factors of every concatenation.)

Lemma 4.5 — half half(L)={w∣ww∈L}. Guess the halfway state h, then run a left copy of M from s and a right copy from h side by side:

Q′=Q3∪{s′},δ′(s′,ε)={(s,h,h)∣h∈Q},δ′((p,h,q),a)={(δ(p,a),h,δ(q,a))},A′={(h,h,q)∣h∈Q, q∈A}.​

CNF conversion, steps 0–6 (§5.9)

  1. Add a new start S′→S if S is on a right side or derives ε.
  2. Split long rules: A→Xα with ∣α∣≥2 becomes A→XB, B→α.
  3. Find the nullable nonterminals, repeating until nothing changes.
  4. Remove ε-rules: add every variant with some nullable occurrences deleted, delete every A→ε, then add S′→ε if S′ is nullable.
  5. Merge the nonterminals on a cycle of unit rules A→B, and delete every rule A→A.
  6. Remove unit rules in reverse topological order, copying the target’s rules after the target is processed.
  7. Replace each terminal a in a right side of length 2 by a new Ta​→a.

Worked problems: Proving what a grammar generates, CNF conversion, step by step, A fooling set and a grammar for one language.

8. The traps that cost the most points

Across Chapters 1–5

  1. The induction hypothesis is too weak — stated only for x, or not quantified over the other arguments the proof changes (§1.4). State it for every shorter string, for all values of the other arguments.
  2. Applying the hypothesis to a string that is not shorter, or without saying why it is shorter.
  3. The missing or extra ε in an expression or grammar: the typical one-mistake deduction. Test ε every time.
  4. Precedence: 10∗=(10)∗ and 0+1∗=(0+1)∗. Regex shorthand (+ for “one or more”, ?, [01]) is not allowed.
  5. An incomplete DFA: missing transitions without the sentence about the dump state, or an NFA where a DFA was asked (half credit).
  6. A fooling-set “proof” with one example pair, a finite set, a suffix chosen for a specific i and j, or only one of the two memberships checked. “Without loss of generality i<j” needs a symmetric argument.
  7. Closure in the wrong direction: a regular intersection or union says nothing about L; a subset of a regular language need not be regular.
  8. The subset construction without ε-reach on every row, accepting only if all states accept, or dropping the reachable ∅.
  9. Transformations built for an example language instead of an arbitrary DFA, with δ′ undefined in some case (in particular δ′(q,ε)), and never tested on ∅, {ε}, 1∗, Σ∗.
  10. State elimination that forgets p=r (the self-loops change) or the old direct term R(p→r).
  11. A grammar whose nonterminals are described by their role (“the middle part”) instead of their language — and two derivations offered as proof of ambiguity when they build the same parse tree.
  12. CNF step 3 or step 5 done carelessly: every subset of the nullable occurrences, and the unit rules removed in the right order.

9. What to put on your cheat sheet

The final allows two double-sided, handwritten letter sheets for the whole course, and Chapters 6–9 and the algorithms half need room too. Writing them is part of the review. For Chapters 1–5:

  • The string-induction boilerplate and the recursive definitions of ∣w∣, ∙, #(a,w), wR; the fact (wx)R=xRwR.
  • ∅ versus {ε}, L+ versus L∗, Arden’s rule, regular-expression precedence.
  • The DFA tuple, δ∗, and the product table of accepting sets.
  • The fooling-set template and the standard fooling-set table of §4; the Myhill–Nerode statement.
  • NFA δ∗ with ε-reach; the ε-removal and subset-construction formulas.
  • Thompson’s gadgets (four small sketches), the elimination rule, and the costs around Kleene’s cycle.
  • The transformation template, the reversal and half constructions, and the edge cases ∅, {ε}, 1∗, Σ∗.
  • The grammars of §6, the regular-to-grammar table, and context-free closure (yes: ∪, concatenation, ∗, reversal, ∩ regular; no: ∩, complement).
  • The CNF definition and the conversion steps 0–6.
  • The rubric numbers of §1 — they tell you what to write down first.

10. A study plan for the final

From now to Dec 11

  1. Until Midterm 2 (Mon Nov 9): keep it warm. The algorithms half comes first. Once a week, do one exam-length problem from Chapters 1–5, rotating through the five types of §1 (hard practice problems).
  2. The first two weeks after Midterm 2: rebuild, chapter by chapter. For each of Chapters 1–5, read the chapter page’s definition, template and trap boxes, rewrite its section of this page from memory, then do the chapter’s easy practice problems and one medium.
  3. Write the cheat sheets while you rebuild, by hand, from §9 here and from the proof templates.
  4. The week after: timed. Work a Midterm 1 practice exam in 120 minutes with only your cheat sheet, and grade it yourself with the rubrics of §1. Redo every lost point a day later, without looking.
  5. The last days: breadth. The true/false table of §7, the traps of §8, and the big picture — then the same routine for Chapters 6–9.
