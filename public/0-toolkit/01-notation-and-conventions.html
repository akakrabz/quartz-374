The site writes everything the way Erickson’s Models of Computation (whole book PDF) does, except for the handful of changes listed in §11. Section and result numbers are the book’s: “§3.8” is section 3.8 of both the book and the chapter page. Results in Chapters 1–5 carry the chapter number (Lemma 3.6, Theorem 5.7); in Chapters 7 and 9 they do not, so “Lemma 5” and “Theorem 12” live in Chapter 7 and “Theorem 1” in Chapter 9.

Three different "empty" things

∅ has no strings, {ε} has one string, and ε is a string, not a language. In a regular expression, ε stands for {ε}. They behave differently: ∅∙L=∅ but {ε}∙L=L.

Accept(M) is not Accept

Accept(M) is a set of strings — the inputs that one machine M accepts. Accept is a set of encodings ⟨M,w⟩ — every machine paired with every input it accepts. The first can be any acceptable language; the second is one particular undecidable language.

11. Where this site departs from the book

The changes are small, but each one shows up when you put a chapter page next to the book.

  • The left-end marker. The Turing machine for {0n1n0n∣n≥0} marks the left end of the tape with #; the book’s machine writes a dollar sign. The site’s machine also checks the format of the input first (extra states block1, block2, block3, rewind, mark0), because the book’s machine, which starts matching at once, also accepts strings such as 001010 (see the trap in §6.3).
  • The shift machine’s states are hold0 and hold1; the book calls them 0 and 1 (§6.5).
  • Chomsky normal form. The nonterminals that protect terminals are Ta​→a; the book calls them Aa​. The final grammar of the running example keeps the book’s names E→0 and F→1 (§5.9).
  • Grammars as tuples. G=(Σ,Γ,R,S) is this site’s shorthand; the book lists the four parts without a tuple (§5.1).
  • The DFA tuple is always (Σ,Q,s,A,δ) here; the book’s order varies from section to section. On an exam, name each component (“start state s, accepting states A”) and the order stops mattering.
  • One word for acceptable. The site says acceptable throughout, where the book’s Chapter 6 says recognizable, and it adds the word co-acceptable (§7.3).
  • Plainer section titles. Numbers always match the book, but some titles are descriptive where the book’s are jokes or generic: §7.2 “Lo, I Have Become Death, Stealer of Pie” is “Decidable without knowing the algorithm”, and §3.3 “Another Example” is “Proving a DFA correct”.
  • Chapter 9. The site defines P and NP explicitly (the book leaves them implicit), states the rejection half of the advice view with an explicit length t, and numbers the Cook–Levin tableau’s cells 0,…,N+2, with the input starting at cell 1 between two empty sentinel cells — unlike a Turing machine’s tape in Chapter 6, which starts at cell 0 (§9.6).
