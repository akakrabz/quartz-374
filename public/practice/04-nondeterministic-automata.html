4.1 Six quick NFA facts

Easy · true or false · NFA design · subset construction

Decide whether each statement is true or false, and give a one-sentence reason (a counterexample when the answer is No). Throughout, N is an NFA over Σ={0,1}, possibly with ε-transitions.

(a) If N has n states, then some DFA with at most 2n states accepts L(N).

(b) If N=(Σ,Q,s,A,δ) accepts L, then (Σ,Q,s,Q∖A,δ) accepts L.

(c) If N has n states and L(N)=∅, then N accepts some string of length at most n−1.

(d) Every regular language is accepted by an NFA without ε-transitions that has exactly one accepting state.

(e) Some language is accepted by an NFA with 4 states but by no DFA with fewer than 8 states.

(f) If L is regular, then so is {sort(w)∣w∈L}, where sort(w)=0#(0,w)1#(1,w) lists the 0s of w before its 1s.

Source: original (statement (e) is a classic example).

Hint

An NFA rejects a string when no path accepts it, and swapping the accepting states does not create new paths. For (d), try a language that contains ε and one more short string. For (e), think of “the third symbol from the end”.

Solution

(a) Yes — the subset construction (§4.5) gives a DFA whose states are subsets of the n states of N, and there are 2n subsets.

(b) No — an NFA can reject a string by having no path for it at all, and then the swapped machine has no path either. The one-state NFA with A={s} and no transitions accepts {ε}; swapping gives A=∅, which accepts nothing, although 0∈{ε}​.

(c) Yes — an accepting walk with the fewest transitions never visits a state twice (otherwise cut out the loop), so it has at most n−1 transitions and spells a string of length at most n−1.

(d) No — for L={ε,0}, accepting ε without ε-transitions forces A={s}, and then a path for 0 is a 0-loop at s, which also accepts 00∈/L. With ε-transitions the statement is true (Lemma 4.2); here sε​f, s0​f, A={f} works.

(e) Yes — “the third symbol from the end is 1”, (0+1)∗1(0+1)(0+1), has a 4-state NFA (loop at s, guess the 1, read two more symbols), and the 8 strings of length 3 form a fooling set: if x=y differ in position i, the suffix 0i−1 moves that position to third from the end.

(f) No — for L=(01)∗ the sorted strings form {0n1n∣n≥0}, which is not regular (Lemma 3.6). The transformations of §4.9 preserve regularity because a finite automaton can carry them out; sorting needs unbounded memory.

Watch out: (b) is the classic trap. To complement an NFA, first convert it to a DFA with the subset construction, then swap.

Answer. (a) Yes. (b) No. (c) Yes. (d) No. (e) Yes. (f) No.

4.3 The last symbol appeared earlier

Easy · NFA design

Let Σ={0,1,2} and let L be the set of strings whose last symbol also appears earlier in the string: L={xa∣a∈Σ, x∈Σ∗, #(a,x)≥1}. For example 0120 and 11 are in L; 012, 1 and ε are not. Give an NFA for L with at most 5 states, as a transition table with a one-line meaning for each state. No proof required.

Source: textbook exercise style.

Hint

Guess the moment you read the earlier copy of the final symbol a. Then skip anything, and guess that the next a ends the string.

Solution

Idea. A DFA would have to remember which symbols it has seen. An NFA guesses the earlier occurrence of the final symbol, and then guesses where the string ends.

Check. 0120: s0​p0​1​p0​2​p0​0​f, accepted. 012: the final 2 would have to be read from p2​, which needs an earlier 2, so it is rejected. 1 and ε: every path to f reads at least two symbols.

Answer. States s,p0​,p1​,p2​,f; s loops on every symbol and sa​pa​; each pa​ loops on every symbol and pa​a​f; start s, accepting {f}.

4.4 Find the error, Kleene star

Easy · find the error · epsilon-transitions · closure properties

Let M=(Σ,Q,s,A,δ) be a DFA for a language L. A student builds an NFA for L∗ as follows.

“Keep all the states and transitions of M. Make s accepting, so that ε is accepted, and add an ε-transition from every accepting state back to s, so that the machine can start a new piece after finishing one: N=(Σ,Q,s,A∪{s},δN​) with δN​(q,a)={δ(q,a)}, and δN​(q,ε)={s} for every q∈A.”

(a) Show that the construction is wrong: give a DFA M and a string that N accepts but that is not in L∗.

(b) Fix the construction.

Source: classic.

Hint

Making s accepting accepts every string that leads M from s back to s, not only ε. Try a DFA with a loop at s.

Solution

(a) The slip is “make s accepting”. It accepts ε, but also every string x with δ∗(s,x)=s, whether or not x∈L∗. Take L=0∗1 with the DFA s0​s, s1​a, a0,1​d, d0,1​d and A={a}. Every non-empty string in L∗ ends in 1, so 0∈/L∗; but N accepts 0 by looping once at the now-accepting state s. (Here N accepts every string: after each 1 it can jump back to s and stop there.)

(b) Add a fresh start state for the empty string instead of reusing s:

N′δ′(s′,ε)δ′(q,a)​=(Σ, Q∪{s′}, s′, A∪{s′}, δ′),={s},δ′(q,ε)={s}  for q∈A,={δ(q,a)}  for q∈Q, a∈Σ.​

No transition enters s′, so making it accepting adds only ε. Every other accepting walk goes from s′ to s, reads a string of L to reach A, possibly jumps back to s and repeats; it spells a concatenation of one or more strings of L, and every such concatenation has a walk.

Check. With the DFA of (a), N′ accepts ε, 01 and 101 =1⋅01, and rejects 0 and 10.

Watch out: the student’s version happens to be correct whenever no transition of M enters s, which is why it can survive a quick test. Thompson’s star gadget avoids the problem the same way, with a fresh start state.

Answer. (a) For L=0∗1 the student’s NFA accepts 0∈/L∗ (in fact it accepts every string). (b) Add a new accepting start state s′ with s′ε​s, keep the ε-transitions from A back to s, and do not make s accepting (unless s∈A).

4.6 Thompson’s NFA by the numbers

Medium · Thompson's algorithm · regex induction

Thompson’s algorithm (§4.6) turns a leaf ∅, ε or a into two states joined by no transition, an ε-transition or an a-transition; it joins the machines for S and T in series by one ε-transition for ST; and for S+T and for S∗ it adds a new start state, a new accepting state and four ε-transitions. A string such as 01 is a concatenation of one-symbol leaves.

(a) For a regular expression R, let ℓ be its number of leaves (occurrences of ∅, ε and symbols), of which e are ε and σ are symbols, and let u, k, c be its numbers of +, ∗ and concatenation nodes. Show that Thompson’s NFA for R has exactly 2(ℓ+u+k) states, e+c+4u+4k ε-transitions and σ symbol transitions.

(b) Use (a) to count the states and transitions for R=(1+01)∗0, then build the NFA.

(c) Compute the ε-reach of its start state and the set of states it can be in after reading 0 and after reading 01. Which of the two strings does it accept?

Source: original.

Hint

(a) is a structural induction: check the three leaves, then see what ST, S+T and S∗ add to the counts for S and T. In (b), 01 contributes two leaves and one concatenation node, and so does (⋯)∗0.

Solution

(a) Structural induction on R. Let #Q(R), #E(R), #S(R) be the numbers of states, ε-transitions and symbol transitions of Thompson’s NFA for R, and assume the formulas for all proper subexpressions of R.

  • Leaves. ∅, ε and a each have 2 states; ε has one ε-transition and a one symbol transition. For a leaf ℓ=1, u=k=c=0, and e (resp. σ) is 1 exactly for ε (resp. a symbol), so the formulas hold.
  • R=ST. The construction keeps both machines and adds one ε-transition: #Q(R)=#Q(S)+#Q(T), #E(R)=#E(S)+#E(T)+1, #S(R)=#S(S)+#S(T). The counts ℓ,e,σ,u,k of R are the sums of those of S and T, and c is one larger, so the induction hypothesis for S and T gives the formulas for R.
  • R=S+T. Two new states and four new ε-transitions; u is one larger than the sum for S and T, which adds exactly 2 to 2(ℓ+u+k) and 4 to e+c+4u+4k.
  • R=S∗. Two new states and four new ε-transitions; k is one larger than for S; the same arithmetic.

(b) The leaves of (1+01)∗0 are 1,0,1,0, so ℓ=σ=4 and e=0; there is one +, one ∗ and two concatenations. Hence 12 states, 0+2+4+4=10 ε-transitions and 4 symbol transitions. Numbering the states in the order the recursion creates them:

The start state is 0 and the only accepting state is 11.

(c) ε-reach(0)={0,1,2,4,9,10}: into the union (1, then 2 and 4) or past the star (9, then 10). Reading 0 uses 40​5 and 100​11, and ε-reach({5,11})={5,6,11}; it contains 11, so 0 is accepted. Reading 1 next uses only 61​7, and ε-reach({7})={1,2,4,7,8,9,10}: back at the top of the loop, without 11, so 01 is rejected.

Check. L(R) is the set of strings that end in 0 and contain no 00: 0 is in it, 01 is not. For comparison, the incremental subset construction turns this 12-state NFA into a 5-state DFA, and the minimal DFA has 3 states.

Answer. (a) 2(ℓ+u+k) states, e+c+4u+4k ε-transitions, one symbol transition per symbol leaf. (b) 12 states, 10 ε-transitions, 4 symbol transitions. (c) ε-reach(0)={0,1,2,4,9,10}; after 0 the set is {5,6,11} (accepted); after 01 it is {1,2,4,7,8,9,10} (rejected).

4.7 Eliminating states, two parities

Medium · state elimination · regular expressions

The DFA M below tracks the parity of the number of 0s and of the number of 1s read so far (E even, O odd; OE means “odd number of 0s, even number of 1s”). Its start state and only accepting state is EE, so L(M) is the set of strings with an even number of 0s and an even number of 1s.

state01
→ EE *OEEO
OEEEOO
EOOOEE
OOEOOE

Use state elimination (§4.8) to find a regular expression for L(M): add a new start state and a new accepting state, then eliminate OE, EO, OO and EE in this order, giving the changed edge labels after each step.

Source: textbook exercise style.

Hint

Eliminating q replaces, for every predecessor p and every successor r of q (including p=r), the label R(p→r) by R(p→r)+R(p→q)R(q→q)∗R(q→r). Neither OE nor EO has a self-loop, and both sit between EE and OO.

Solution

Setup. Add s with sε​EE and t with EEε​t. All other labels are single symbols; missing edges are labeled ∅.

Eliminate OE. No loop; it is entered from EE on 0 and from OO on 1, and left to EE on 0 and to OO on 1. One new label per predecessor–successor pair:

R(EE→EE)R(OO→EE)​=00,=10,​R(EE→OO)R(OO→OO)​=01,=11.​

Eliminate EO. No loop; entered from EE on 1 and from OO on 0, left to EE on 1 and to OO on 0. Each label gains one term:

R(EE→EE)R(OO→EE)​=00+11,=10+01,​R(EE→OO)R(OO→OO)​=01+10,=11+00.​

Eliminate OO. Its loop is 00+11, and its only other neighbor is EE:

R(EE→EE)=00+11+(01+10)(00+11)∗(10+01)=:X.

Eliminate EE. Its loop is X, entered from s on ε and left to t on ε: R(s→t)=εX∗ε=X∗.

Reading the result. Cut the string into pairs. A pair 00 or 11 keeps both parities; a mixed pair 01 or 10 flips both, so after one mixed pair the machine is in OO and needs a second mixed pair, with only 00 and 11 pairs in between, to return to EE.

Check. 0110 =01⋅10 and 0101 =01⋅01 each match X once (a mixed pair, no unmixed pairs, a mixed pair); both have two 0s and two 1s. 011 has odd length, while every string matching X∗ has even length; indeed it has an odd number of 1s.

Watch out: each elimination must update every predecessor–successor pair, including p=r — here the new loops at EE and OO are exactly those pairs, and forgetting them is the most common slip.

Answer. (00+11+(01+10)(00+11)∗(10+01))∗ (the order of the terms inside a union does not matter).

4.8 Rotating the first symbol

Hard · language transformations · DFA design · NFA design

For a string w, let rot(w) move the first symbol of w to the end: rot(ε)=ε and rot(ax)=xa for every symbol a and string x. For example rot(0110)=1100 and rot(1)=1. Let L be an arbitrary regular language over an alphabet Σ, and let M=(Σ,Q,s,A,δ) be a DFA for L.

(a) Prove that RotPre(L):={w∣rot(w)∈L} is regular: give a formal description of a DFA or NFA for it in terms of M, and explain in English what its states mean and why its accepting states are the right ones.

(b) Do the same for RotImg(L):={rot(w)∣w∈L}.

Source: original.

Hint

(a) Reading w=ax, the machine must feed M the string xa. It can postpone the first symbol: remember a, simulate M on x, and apply a at the very end, in the accepting condition.

(b) Now the input is xa and M must read ax. The symbol a is needed first but arrives last: guess it at the start, and check the guess when the last symbol arrives.

Solution

Idea. Both parts move one symbol between the two ends of the string. A finite machine can remember one symbol (part a), or guess one symbol and verify it later (part b). See §4.9 for the general pattern.

(a) Let M1​=(Σ,Q1​,s1​,A1​,δ1​) be the DFA with

Q1​δ1​(s1​,a)A1​​={s1​}∪(Σ×Q),s1​ a new state,=(a,s),δ1​((a,q),b)=(a,δ(q,b)),={(a,q)∣δ(q,a)∈A}∪{s1​∣s∈A}.​

In English: s1​ means “nothing read yet”. The state (a,q) means “the first symbol was a, and M, started at s and fed everything after the first symbol, is in state q”. After reading w=ax the state is (a,δ∗(s,x)), and rot(w)=xa takes M to δ(δ∗(s,x),a); so (a,q) must accept exactly when δ(q,a)∈A. The empty input stays in s1​, and rot(ε)=ε, so s1​ accepts iff ε∈L, that is, iff s∈A.

(b) A string y is in RotImg(L) iff y=ε∈L, or y=xa for a symbol a with ax∈L. Let M2​=(Σ,Q2​,s2​,A2​,δ2​) be the NFA with

Q2​δ2​(s2​,ε)δ2​((a,q),b)A2​​={s2​,f}∪(Σ×Q),s2​,f new states,={(a,δ(s,a))∣a∈Σ},={(a,δ(q,b))}∪{f∣b=a and q∈A},={f}∪{s2​∣s∈A},​

and no other transitions: none out of f, no symbol transitions out of s2​, and no other ε-transitions.

In English: M2​ guesses the last symbol a of its input before reading anything, and feeds it to M first (the ε-move to (a,δ(s,a))). The state (a,q) means “the guess is a, and M has read a followed by the input so far and is in state q”. When the input symbol b equals a, the machine may also guess that it is the last symbol: it does not feed it to M, and moves to f if M is accepting. So f means “the guessed symbol has arrived, and the preimage ax is in L”; nothing may follow it. Finally, s2​ accepts only the empty input, which is in RotImg(L) iff ε∈L.

Check. For L=1(0+1)∗ (strings starting with 1), RotPre(L)=1+(0+1)1(0+1)∗ (the string 1, or second symbol 1) and RotImg(L)=(0+1)∗1 (strings ending in 1), and these are exactly what M1​ and M2​ accept. The edge cases behave: ∅, {ε} and Σ∗ are mapped to themselves by both constructions; for {ε} the only reachable accepting state is s1​, resp. s2​.

Watch out: leaving s1​ (or s2​) out of the accepting set loses ε exactly when ε∈L. In (b), accepting in (a,q) whenever q∈A, instead of moving to f, never checks that the input really ends with the guessed a.

Grading. The course rubric for a transformation gives 2 points for a complete formal description (say whether it is a DFA or an NFA, and list the ε-transitions), 2 for the English explanation of the states and the accepting states, and 6 for correctness (1 for the states, 1 for the start state, 1 for the accepting states, 3 for the transitions). See how exams are graded.

Answer. (a) DFA on {s1​}∪(Σ×Q): remember the first symbol a, run M on the rest, and accept (a,q) iff δ(q,a)∈A (and s1​ iff s∈A). (b) NFA that guesses the last symbol a and feeds it to M first; on reading a in a state (a,q) with q∈A it may move to the accepting dead end f (and s2​ accepts iff s∈A).

4.9 Switching off the last 1

Hard · language transformations · DFA design · NFA design

For a binary string w, let off(w) be w with its last 1 changed to 0; if w has no 1, then off(w)=w. For example off(0110)=0100, off(1011)=1010 and off(000)=000. (Read as a binary number, off clears the lowest set bit.) Let L⊆{0,1}∗ be an arbitrary regular language with DFA M=(Σ,Q,s,A,δ).

(a) Prove that OffPre(L):={w∣off(w)∈L} is regular: a formal description of a DFA or NFA in terms of M, and an English explanation of its states and accepting states.

(b) Do the same for OffImg(L):={off(w)∣w∈L}.

Source: original.

Hint

(a) Check that off(x0)=off(x)0 and off(x1)=x0. A machine reading w that knows where M is after w and after off(w) can update both. (Alternatively: guess which 1 is the last one.)

(b) Reading y=off(w), guess which 0 of y was the last 1 of w; after it only 0s may follow. Do not forget the strings w with no 1 at all.

Solution

Idea. off changes one symbol, but while reading w we cannot tell which 1 is the last. A DFA can hedge by running M on two strings at once; an NFA guesses the position and then checks the guess.

(a) By definition, off(ε)=ε; off(x0)=off(x)0, because appending a 0 does not change which 1 is last; and off(x1)=x0, because the new 1 is the last one. Let M1​=(Σ,Q1​,s1​,A1​,δ1​) be the DFA with

Q1​δ1​((p,q),0)δ1​((p,q),1)A1​​=Q×Q,s1​=(s,s),=(δ(p,0), δ(q,0)),=(δ(p,1), δ(p,0)),={(p,q)∣q∈A}.​

In English: after reading w, the state is (p,q) with p=δ∗(s,w) (“where M is on w itself”) and q=δ∗(s,off(w)) (“where M is on off(w)”). The transitions are the three identities: a 0 extends both strings; a 1 extends w, while off(w1)=w0, so the new second component is δ(p,0), the state of M on w0. A string is accepted iff off(w)∈L, that is, iff q∈A. (A short induction on w proves the invariant.)

Alternative (NFA). Guess the last 1, with states (q,none) (no 1 read yet), (q,some) (a 1 read, the last one still to come) and (q,done) (the guessed last 1 was fed to M as a 0; only 0s may follow). Accept (q,none) and (q,done) with q∈A, but never (q,some): there the input contained a 1 that was not switched off.

(b) y∈OffImg(L) iff either y has no 1 and y∈L (take w=y), or y=x00k with x10k∈L. Let M2​=(Σ,Q2​,s2​,A2​,δ2​) be the NFA with Q2​=Q×{none,some,done}, s2​=(s,none), no ε-transitions, and for π∈{none,some}:

δ2​((q,π),0)δ2​((q,π),1)δ2​((q,done),0)δ2​((q,done),1)A2​​={(δ(q,0),π), (δ(q,1),done)},={(δ(q,1),some)},={(δ(q,0),done)},=∅,={(q,none)∣q∈A}∪{(q,done)∣q∈A}.​

In English: in every state, q is M‘s state on the part of the guessed preimage w read so far. none: no guess yet, and no 1 in the input yet. some: no guess yet, but the input has contained a 1. On a 0 the machine may guess “this 0 was the last 1 of w”: it feeds M a 1 and moves to done, where only 0s may follow (a later 1 would have been the last one). Accept in done when q∈A: then w∈L and y=off(w). Accept in none when q∈A: then y has no 1, and w=y∈L with off(y)=y. Never accept in some: there w=y contains a 1, so off(w)=y.

Check. L=Σ∗: OffPre(L)=Σ∗, and OffImg(L)=ε+(0+1)∗0, because off(w) never ends in 1. L=1∗: OffPre(L)={ε} and OffImg(L)=ε+1∗0. ∅ and {ε} are mapped to themselves. M1​ and M2​ accept exactly these languages.

Watch out: the tempting accepting set “every (q,π) with q∈A” also accepts in some. For L=1∗ it would accept 11, which is not of the form off(w) at all.

Answer. (a) DFA on Q×Q that tracks (δ∗(s,w), δ∗(s,off(w))): start (s,s); on 0, (p,q)↦(δ(p,0),δ(q,0)); on 1, (p,q)↦(δ(p,1),δ(p,0)); accept iff q∈A. (b) NFA on Q×{none,some,done} that guesses which 0 was the last 1 (feeding M a 1 there), then allows only 0s; it accepts (q,none) and (q,done) with q∈A.

4.10 Leading zeros to the back

Hard · language transformations · DFA design · NFA design

Every binary string can be written uniquely as w=0kx, where k≥0 and x is empty or starts with 1. Let back(w):=x0k: the leading 0s move to the end. For example back(00101)=10100, back(0011)=1100, back(000)=000 and back(110)=110. Let L⊆{0,1}∗ be an arbitrary regular language with DFA M=(Σ,Q,s,A,δ).

(a) Prove that BackPre(L):={w∣back(w)∈L} is regular: a formal description of a DFA or NFA, and an English explanation of its states and accepting states.

(b) Do the same for BackImg(L):={back(w)∣w∈L}.

Source: original.

Hint

(a) The leading 0s are read first but must be fed to M last. Their number is unbounded, but their effect is not: store the function q↦δ∗(q,0k) from Q to Q. (Or guess the state M will be in when they arrive, as in the proof that half(L) is regular.)

(b) Reading y=x0k, the machine must feed M the final 0k first. Guess p=δ∗(s,0k) at the start, run M from p on x, and verify p on the final 0s.

Solution

Idea. This is the block version of 4.8: an unbounded block of 0s moves from the front to the back. A finite machine cannot store the block, but it can store what the block does to M (a function Q→Q), or guess a state of M and verify the guess later.

(a) Write QQ for the set of all functions τ:Q→Q, id for the identity function, and δ0​(q):=δ(q,0). Let M1​=(Σ,Q1​,s1​,A1​,δ1​) be the DFA with

Q1​δ1​(τ,0)δ1​((τ,q),a)A1​​=QQ∪(QQ×Q),s1​=id,=δ0​∘τ,δ1​(τ,1)=(τ, δ(s,1)),=(τ, δ(q,a))for a∈Σ,={τ∣τ(s)∈A}∪{(τ,q)∣τ(q)∈A}.​

In English: a state τ means “so far only 0s, say k of them, and τ(q)=δ∗(q,0k) is where those 0s will take M from any state q”; each further 0 composes one more δ0​. The first 1 starts x: a state (τ,q) means “the leading 0s act as τ, and M, started at s on the part of x read so far, is in q”. At the end, back(w)=x0k takes M to τ(δ∗(s,x)), so (τ,q) accepts iff τ(q)∈A. If w=0k has no 1, then back(w)=w and τ accepts iff τ(s)=δ∗(s,0k)∈A. Q1​ is finite: at most ∣Q∣∣Q∣(1+∣Q∣) states.

Alternative (NFA). Guess r=δ∗(s,x) at the start; run M from r on the leading 0s; at the first 1 start a second copy of M at s on x. Accept iff the second copy ends at r and the first one ended in A; if the input has no 1, the guess must be r=s.

(b) y∈BackImg(L) iff y∈0∗∩L (take w=y), or y=x0k with x starting with 1 and 0kx∈L. In particular every string in BackImg(L) starts with 1 or has no 1. Let M2​=(Σ,Q2​,s2​,A2​,δ2​) be the NFA with

Q2​={s2​}∪({zeros}×Q)∪({body}×Q×Q)∪({tail}×Q×Q),

start state s2​, the following transitions for all p,q,r∈Q and a∈Σ (all others are ∅),

δ2​(s2​,ε)δ2​(s2​,1)δ2​((zeros,q),0)δ2​((body,p,q),a)δ2​((body,p,q),ε)δ2​((tail,p,r),0)​={(zeros,s)},={(body,p,δ(p,1))∣p∈Q},={(zeros,δ(q,0))},={(body,p,δ(q,a))},={(tail,p,s)}if q∈A,={(tail,p,δ(r,0))},​

and accepting states A2​={(zeros,q)∣q∈A}∪{(tail,p,p)∣p∈Q}.

In English: (zeros,q): the input so far has no 1 and we bet it never will, so the preimage is the input itself; q=δ∗(s,y), and we accept iff q∈A. Alternatively, on a first symbol 1 the machine guesses p, the state of M after the leading 0s of the preimage, and enters (body,p,q): “reading x; M, started at p on the part of x read so far, is in q”. Whenever that copy of M accepts, the machine may guess that x is over (the ε-move). (tail,p,r): “reading the 0s that were the leading 0s of w; M, started at s on them, is in r”. Accept iff r=p: then the guess was right, and δ∗(s,0kx)=δ∗(p,x)∈A.

Check. L=10∗: BackPre(L)=0∗10∗ (exactly one 1) and BackImg(L)=10∗. L=0∗1: BackPre(L)={1} and BackImg(L)=10∗. L=Σ∗: BackImg(L)=0∗+1(0+1)∗. ∅, {ε} and 1∗ are mapped to themselves by both. M1​ and M2​ accept exactly these languages.

Watch out: the split point in (b) must be a guess. The 0s at the end of y need not all be leading 0s of the preimage: back(010)=100, where x=10 itself ends in a 0. And without the zeros branch the machine misses L∩0∗: for L=0∗ it would accept nothing, although BackImg(0∗)=0∗.

Answer. (a) DFA on QQ∪(QQ×Q): while reading the leading 0s keep τ=δ∗(⋅,0k); from the first 1 on keep τ and run M from s on x; accept τ iff τ(s)∈A and (τ,q) iff τ(q)∈A. (b) NFA that either runs M on an all-0 input (the zeros branch), or guesses p=δ∗(s,0k), runs M from p on x, jumps by ε to the tail when M accepts, and accepts iff M from s on the remaining 0s ends exactly at p.
