Easy

2.1 Empty things, products and stars

Easy · true or false · languages · Kleene star

Answer each statement Yes (true for all languages involved) or No, with a one-sentence justification; for a No, give a counterexample.

(a) ∅∙{ε}={ε}.

(b) {0,01}∙{1,11} contains exactly four strings.

(c) (L∗)∗=L∗ for every language L.

(d) (A∪B)∗=A∗∪B∗ for all languages A and B.

(e) ∅+=∅.

(f) If ε∈L, then L∙L=L.

Source: original.

Hint

Keep ∅ (no strings), {ε} (one string) and ε (a string) apart: a concatenation needs a string from each factor. For the “for all” statements, try one-string languages such as {0} and {1} first.

Solution

  • (a) No. A concatenation needs a string from each factor and ∅ has none, so ∅∙{ε}=∅ (Lemma 2.1(c)), which is not {ε}.
  • (b) No. It has three strings, 01, 011 and 0111, because two different pairs give the same string: 0∙11=01∙1=011.
  • (c) Yes. L∗⊆(L∗)∗ because every language is contained in its star, and (L∗)∗⊆L∗ because a concatenation of concatenations of strings of L is itself a concatenation of strings of L.
  • (d) No. With A={0} and B={1}, the string 01 is in (A∪B)∗ but neither in A∗=0∗ nor in B∗=1∗. Only A∗∪B∗⊆(A∪B)∗ holds.
  • (e) Yes. ∅+=∅∙∅∗=∅∙{ε}=∅ by Lemma 2.1(c), even though ∅∗={ε} — as Lemma 2.2(c) predicts, L+=L∗ when ε∈/L.
  • (f) No. L={ε,0} contains ε, but L∙L={ε,0,00}=L. What does hold is L⊆L∙L, since x=x∙ε.

Answer. (a) No. (b) No. (c) Yes. (d) No. (e) Yes. (f) No.

2.2 Read these expressions

Easy · regular expressions

For each regular expression, describe its language in one English sentence, and list every string of length at most 2 that it matches.

(a) (1+01)∗

(b) (0∗10∗10∗)∗

(c) (00+000)∗

(d) (0+∅)∗1∅∗

Source: original.

Hint

Ask what each starred block contributes, and what the empty sequence of blocks gives. In (d), find L(0+∅) and L(∅∗) first.

Solution

  • (a) The blocks are 1 and 01, so every 0 is immediately followed by a 1 (equivalently: no 00, and no final 0). Conversely, a string with that property splits into such blocks by cutting after every 1. Length at most 2: ε, 1, 01, 11.
  • (b) Each block contains exactly two 1s, so every string matched has an even number of 1s; but each block contains at least one 1, so a non-empty string with no 1s is not matched. The language is ε together with the strings that have an even, positive number of 1s. Length at most 2: ε, 11.
  • (c) Strings of 0s whose length is 2i+3j for some i,j≥0 — every length except 1. So the language is {0n∣n=1}, the same as L(ε+000∗). Length at most 2: ε, 00.
  • (d) L(0+∅)={0}∪∅={0} and L(∅∗)={ε}, so the expression is equivalent to 0∗1: any number of 0s followed by a single 1. Length at most 2: 1, 01.

Watch out: (b) is not “an even number of 1s” — that language also contains 0, 00, 000, …, which have zero 1s. And in (d), ∅∗ is {ε}, not ∅, so the expression does not describe the empty language.

Answer. (a) Every 0 is immediately followed by a 1: ε, 1, 01, 11. (b) ε or an even, positive number of 1s: ε, 11. (c) 0n with n=1: ε, 00. (d) 0∗1: 1, 01.

2.3 A missing empty string

Easy · find the error · regular expressions

Let L be the set of binary strings in which every 0 is followed, somewhere later in the string, by at least one 1. A student answers:

”(0+1)∗1. A string is in L exactly when its last symbol is a 1, since that final 1 comes after every 0; (0+1)∗ is everything before it.”

Is the answer correct? If not, say exactly which strings it gets wrong, fix it, and say how the regular-expression rubric treats the slip.

Source: original.

Solution

The slip: ε∈L, but ε does not match. The empty string contains no 0 at all, so “every 0 is followed by a 1” holds for it vacuously. The rest of the explanation is right: a non-empty string is in L if and only if it ends in 1 (if it ends in 0, that last 0 has nothing after it; if it ends in 1, that 1 comes after every 0). So L={ε}∪L((0+1)∗1), and ε is the only string the answer gets wrong.

Fix: ε+(0+1)∗1, or equivalently (0∗1)∗: blocks of 0s each closed by a 1, where the empty sequence of blocks gives ε.

Grading: a single wrong string is the classic “one mistake” — typically a missing or extra ε — and costs the smallest correctness deduction (2 of the 8 correctness points on an exam). An answer that is wrong on infinitely many strings would lose all 8.

Watch out: test ε explicitly, every time. Conditions of the form “every … is …” are true for strings that contain no ”…” at all.

Answer. Not correct: it misses exactly one string, ε. A correct answer is ε+(0+1)∗1 (or (0∗1)∗).

Medium

2.4 Three regular expressions

Medium · regular expressions

Give a regular expression for each language, with a one-sentence explanation of each part. No proof is required.

(a) Strings that contain both 00 and 11 as substrings.

(b) Strings in which the number of 0s between any two consecutive 1s is even. (Two 1s are consecutive if no 1 lies between them; 0s before the first 1 or after the last 1 are unrestricted.)

(c) Strings w with wi​=0 for every position i that is a multiple of 3. (Positions are numbered from 1, so the condition is on w3​, w6​, w9​ and so on.)

Source: original.

Hint

(a) “And” is hard for regular expressions, but here you can split by which of the two substrings occurs first. (b) Describe the first 1, then each later 1 together with the gap of 0s before it. (c) Cut the string into blocks of three symbols; the last block may be incomplete.

Solution

(a) Idea. An occurrence of 00 and an occurrence of 11 cannot overlap (they have no symbol in common), so one of them lies entirely before the other.

(0+1)∗00(0+1)∗11(0+1)∗+(0+1)∗11(0+1)∗00(0+1)∗

The first term is anything, then 00, then anything, then 11, then anything: an occurrence of 00 before an occurrence of 11. The second term is the same with the order reversed. Every string of the language has one of the two orders, and every string matched contains both substrings. Check: 0011, 1100 and 10011 match; 0110 (no 00), 0101 and ε do not.

(b) Idea. The 0s before the first 1 and after the last 1 are free; only the gaps between consecutive 1s are constrained.

0∗+0∗1((00)∗1)∗0∗

The term 0∗ covers the strings with no 1, which have no gap to check. In the second term, 0∗ is the 0s before the first 1; 1 is the first 1; each (00)∗1 is an even gap of 0s followed by the next 1; and the final 0∗ is the 0s after the last 1. Check: ε, 000, 0110, 1001 and 01001100 match; 101, 10001 and 11011 do not.

(c) Idea. Positions 3k−2, 3k−1, 3k form the kth block of three, and only the third symbol of a complete block is constrained.

((0+1)(0+1)0)∗(ε+0+1)(ε+0+1)

Each (0+1)(0+1)0 is a complete block with a 0 in its third position, and the star allows any number of complete blocks; (ε+0+1)(ε+0+1) is the incomplete last block, of length 0, 1 or 2, which contains no position divisible by 3. Check: ε, 11, 110 and 11011 match; 111 and 000001 do not.

Watch out: in (b), 0∗(1(00)∗)∗ looks plausible but forces an even number of 0s after the last 1, so it misses 10, 1000, …; in (c), leaving out the incomplete last block keeps only the strings whose length is divisible by 3. Each of these slips is wrong on infinitely many strings and loses all the correctness points.

Answer. (a) (0+1)∗00(0+1)∗11(0+1)∗+(0+1)∗11(0+1)∗00(0+1)∗. (b) 0∗+0∗1((00)∗1)∗0∗. (c) ((0+1)(0+1)0)∗(ε+0+1)(ε+0+1).

2.5 Equivalent or not

Medium · regular expressions · languages

For each pair, decide whether the two regular expressions are equivalent. If they are, explain why; if not, give a shortest string that matches exactly one of them, and say whether one language contains the other.

(a) (0+1)∗0(0+1)∗1(0+1)∗ and (0+1)∗01(0+1)∗

(b) 1(01)∗ and (10)∗1

(c) (01+10)∗ and (01)∗(10)∗

(d) (0+01)∗ and 0∗(01)∗

Source: original.

Hint

List the short strings each side matches, in order of length, until the lists differ or a pattern appears. For an equivalence, argue both inclusions; in (a), look for a 0 that is immediately followed by a 1.

Solution

Idea. Equivalence needs an argument for both inclusions; non-equivalence needs one string, checked against both expressions.

(a) Equivalent. Both describe the strings with a 0 somewhere before a 1. Right ⊆ left: an occurrence of 01 is a 0 before a 1. Left ⊆ right: if w=x0y1z, then the substring 0y1 begins with 0 and contains a 1; the symbol just before its first 1 is a 0, so w contains 01.

(b) Equivalent. The languages are {1(01)n∣n≥0} and {(10)n1∣n≥0}, and 1(01)n=(10)n1 for every n: both are the alternating string 1010⋯01 of length 2n+1 (by associativity, 10101⋯01 regroups as 1010⋯101). This is the “sliding” identity x(yx)∗=(xy)∗x.

(c) Not equivalent. Shortest witness: 1001=10∙01 matches the left expression but not the right one, whose strings are some copies of 01 followed by some copies of 10. Every string matched by the right expression is a sequence of 01 and 10 blocks, so L((01)∗(10)∗)⊊L((01+10)∗).

(d) Not equivalent. Shortest witness: 010=01∙0 matches the left expression but not the right one, in which no 0 can come after a 01 block. Again L(0∗(01)∗)⊊L((0+01)∗): putting all the 0 blocks first is one particular order of the blocks.

Check: in (c), both sides match exactly ε, 01, 10 among the strings of length at most 3; of length 4, the left side matches 0101, 0110, 1001, 1010 and the right side only 0101, 0110, 1010. In (d), the strings of length at most 2 agree (ε, 0, 00, 01), and 010 is the only difference of length 3.

Watch out: “the two sides agree on every short string I tried” never proves equivalence — (c) agrees on everything shorter than 4.

Answer. (a) Equivalent. (b) Equivalent. (c) Not equivalent: 1001; the right language is a proper subset of the left. (d) Not equivalent: 010; the right language is a proper subset of the left.

2.6 Solving three language equations

Medium · Arden's rule

The languages X, Y, Z satisfy

X=0X∪1Y∪{ε},Y=0X∪1Z∪{ε},Z=1Z∪{ε}.

(a) Use Arden’s rule to find regular expressions for Z, Y and X, and explain why the system has only one solution.

(b) Describe X in one English sentence.

Source: original.

Hint

Solve the last equation first, substitute the result into the second, and then substitute the second into the first. Each time you apply Arden’s rule, check that the language in front of the unknown does not contain ε.

Solution

Idea. Arden’s rule (Lemma 2.3, §2.2): if ε∈/A, then L=AL∪B holds if and only if L=A∗B. Eliminate one unknown at a time, from the bottom up.

(a) Z. The equation Z=1Z∪{ε} has A={1}, and ε∈/A, so its only solution is Z=1∗{ε}=1∗.

Y in terms of X. Substituting, Y=0X∪11∗∪{ε}=0X∪1∗, because 11∗∪{ε}=1+∪{ε}=1∗ (Lemma 2.2(a)).

X. Substituting into the first equation and distributing (Lemma 2.1(f)),

X=0X∪1(0X∪1∗)∪{ε}=(0∪10)X∪(11∗∪{ε})=(0∪10)X∪1∗.

Here A={0,10} does not contain ε, so Arden’s rule gives X=(0+10)∗1∗, and then Y=0(0+10)∗1∗+1∗.

Only one solution. If (X,Y,Z) is any solution, then Z must be 1∗, so Y must be 0X∪1∗, so X satisfies X=(0∪10)X∪1∗ and must be (0+10)∗1∗. Each “must” is the only if half of Arden’s rule, which needs ε∈/A.

(b) X is the set of strings that do not contain 110. In a string of (0+10)∗ every 1 is immediately followed by a 0, so it contains no 11; after it comes a final block of 1s, which has no 0 after it, so no 110 can appear. Conversely, cut a string without 110 just before its final block of 1s, so that the first part is empty or ends in 0. If some 1 in the first part were followed by another 1, the run of 1s containing them would be followed by a 0 (the first part ends in 0), and the last two 1s of that run together with this 0 would form 110. So every 1 of the first part is immediately followed by a 0, and the first part is in (0+10)∗.

Check: 0, 1011, 0101 and 111 are in X; 110 and 01101 are not. The other two unknowns have meanings too: Y is the set of strings y such that 1y contains no 110, and Z the set of strings z such that 11z contains none — which is why Z=1∗.

Watch out: Arden’s rule gives the only solution only when ε∈/A; with ε∈A it gives just the smallest one.

Answer. Z=1∗, Y=0(0+10)∗1∗+1∗, and X=(0+10)∗1∗: the strings with no substring 110. The solution is unique because neither coefficient, 1 or 0+10, contains ε.

Hard

2.7 Two careful regular expressions

Hard · regular expressions

Give a regular expression for each language, with an English explanation of every part, and test it on all strings of length at most 3. No proof is required.

(a) Strings that contain the substring 11 exactly once. (Occurrences may overlap: 111 contains 11 twice.)

(b) Strings in which every 0 has a 1 as a neighbor: wi−1​=1 or wi+1​=1 for every position i with wi​=0.

Source: original.

Hint

(a) Write the string as x11y around its one occurrence. What must x and y avoid, and how may x end and y begin? (b) View the string as blocks of 1s separated by blocks of 0s: which blocks of 0s are allowed between two blocks of 1s, and which at the two ends?

Solution

(a) Idea. Around its only occurrence the string is x11y, where x and y contain no 11, x does not end in 1, and y does not begin with 1 — otherwise a second, overlapping occurrence appears. The strings with no 11 that are empty or end in 0 are exactly the sequences of blocks 0 and 10; symmetrically, those that are empty or begin with 0 are the sequences of blocks 0 and 01.

(0+10)∗11(0+01)∗
  • (0+10)∗ is the part before the occurrence: every 1 in it is immediately followed by a 0, so it contains no 11 and is empty or ends in 0;
  • 11 is the one occurrence;
  • (0+01)∗ is the part after it: every 1 in it is immediately preceded by a 0, so it contains no 11 and is empty or begins with 0.

No other occurrence can straddle a boundary, because the symbol next to 11 on either side is a 0, if there is one. Check: of the 15 strings of length at most 3, the expression matches exactly 11, 011 and 110, which are exactly the ones with one occurrence (111 has two).

(b) Idea. A non-empty string with no 1 has a 0 without a 1 next to it, so ε is the only string of the language without a 1. Otherwise cut the string into blocks of 1s separated by blocks of 0s. A block of 0s between two blocks of 1s may have length 1 or 2, because then each of its 0s is next to one of the two surrounding 1s, while a block of three or more 0s has a middle 0 with no 1 next to it. A block of 0s at the beginning or the end touches a 1 on one side only, so it has length at most 1.

ε+(ε+0)1(1+01+001)∗(ε+0)
  • ε: the string with no 1 (there is no 0 to check);
  • (ε+0): at most one leading 0, which touches the first 1;
  • 1: the first 1;
  • (1+01+001)∗: each later 1, preceded by the zero, one or two 0s that separate it from the previous 1;
  • (ε+0): at most one trailing 0, which touches the last 1.

Check: of the strings of length at most 3, the expression matches ε, 1, 01, 10, 11, 010, 011, 101, 110 and 111, and rejects 0, 00, 000, 001 and 100 — each of which has a 0 with no 1 next to it. Longer: 1001 matches, and 10001 does not (its middle 0 is alone).

Grading notes. The exam rubric gives 2 points for syntax and 8 for correctness (how exams are graded). Typical losses here: in (a), (0+1)∗11(0+1)∗ means “at least once” and matches 111, 1111, …; and (0+10)∗11(0+10)∗ matches 1110 (two occurrences) while missing 1101, 110101 and many more. Both are wrong on infinitely many strings, so no correctness points. In (b), forgetting the term ε is a single wrong string (the small deduction), but allowing 00 at either end matches 001, 0011, … and loses everything.

Answer. (a) (0+10)∗11(0+01)∗. (b) ε+(ε+0)1(1+01+001)∗(ε+0).

2.8 An expression for all prefixes

Hard · regex induction · regular expressions

For a language L, let Pre(L):={x∣xy∈L for some string y} be the set of all prefixes of strings in L. For a regular expression R that does not use the symbol ∅, define the expression pre(R) by recursion on R:

  • pre(w):=ε+w1​+w1​w2​+⋯+w1​w2​⋯wn​ if R is a string w=w1​w2​⋯wn​ (so pre(ε)=ε);
  • pre(S+T):=pre(S)+pre(T);
  • pre(ST):=pre(S)+Spre(T);
  • pre(S∗):=S∗pre(S).

(a) Compute pre((01)∗1) and describe its language in English.

(b) Prove that L(pre(R))=Pre(L(R)) for every regular expression R that does not use ∅.

(c) Where does your proof use the assumption that R does not use ∅? Extend the definition by pre(∅):=∅, and give an expression R for which L(pre(R))=Pre(L(R)).

Source: original.

Hint

Use the five-case template of §2.6 and prove a set equality in each case. A prefix of xy is either a prefix of x, or x followed by a prefix of y; a prefix of x1​x2​⋯xk​ is x1​⋯xi−1​ followed by a prefix of xi​. To go back from a prefix of x to a prefix of some xy, you need a string y∈L(T) — Lemma 2.4 provides one.

Solution

Idea. Follow the cases of the definition and describe, in each case, the prefixes of the strings that case builds. Lemma 2.4 (an expression without ∅ has a non-empty language) is needed twice: to extend a prefix of x∈L(S) to a string xy∈L(S)L(T), and to get ε∈Pre(L(S)) in the star case.

(a) With S=(01)∗ and T=1:

pre((01)∗1)=pre((01)∗)+(01)∗pre(1)=(01)∗(ε+0+01)+(01)∗(ε+1),

which is equivalent to (01)∗(ε+0+1), because (01)∗01 adds nothing to (01)∗. In English: some copies of 01, followed by at most one more symbol. Indeed, L((01)∗1)={1,011,01011,…}, and the prefixes of these strings are exactly the strings just described.

(b) Let R be an arbitrary regular expression that does not use ∅. Assume that L(pre(R′))=Pre(L(R′)) for every proper subexpression R′ of R; each of them is ∅-free too. There are five cases.

  • R=∅. Impossible, because R does not use ∅.
  • R is a string w=w1​⋯wn​. Pre({w}) is the set of prefixes of w, which are exactly w[1..j] for 0≤j≤n (§1.5): the strings of L(pre(w)).
  • R=S+T. A string is a prefix of a string in L(S)∪L(T) if and only if it is a prefix of a string in L(S) or of a string in L(T). So Pre(L(R))=Pre(L(S))∪Pre(L(T))=L(pre(S))∪L(pre(T))=L(pre(R)), by the induction hypothesis for S and T.
  • R=ST. We show Pre(L(S)L(T))=Pre(L(S))∪L(S)Pre(L(T)); the hypothesis for S and T turns the right side into L(pre(S)+Spre(T)).
    • ⊆: let zu=xy with x∈L(S) and y∈L(T). If ∣z∣≤∣x∣, then z is the prefix of x of length ∣z∣, so z∈Pre(L(S)). Otherwise z=xp, where p consists of the next ∣z∣−∣x∣ symbols; then xpu=xy gives pu=y by cancellation, so p∈Pre(L(T)) and z∈L(S)Pre(L(T)).
    • ⊇: if zu=x∈L(S), then L(T) contains some string y, by Lemma 2.4 since T does not use ∅; so z(uy)=xy∈L(R) and z∈Pre(L(R)). If z=xp with x∈L(S) and pu=y∈L(T), then zu=xy∈L(R).
  • R=S∗. We show Pre(L(S)∗)=L(S)∗Pre(L(S)); the hypothesis for S turns the right side into L(S∗pre(S)).
    • ⊆: let zu=x1​x2​⋯xk​ with every xj​∈L(S). If z=ε: L(S) is not empty (Lemma 2.4), and ε is a prefix of each of its strings, so z=ε∙ε∈L(S)∗Pre(L(S)). Otherwise let i be the smallest index with ∣z∣≤∣x1​⋯xi​∣; then z=x1​⋯xi−1​p, where p is a prefix of xi​, so z∈L(S)∗Pre(L(S)).
    • ⊇: if z=x1​⋯xi−1​p with all xj​∈L(S) and pu=xi​∈L(S), then zu=x1​⋯xi​∈L(S)∗.

In all five cases, L(pre(R))=Pre(L(R)). ■

(c) The assumption is used through Lemma 2.4 in two places: in the case ST (⊇), to find a string y∈L(T), and in the case S∗ (⊆, z=ε), to get ε∈Pre(L(S)). Both fail when the language may be empty. For R=0∅: L(R)=∅, so Pre(L(R))=∅, but pre(0∅)=(ε+0)+0∅ denotes {ε,0}. For R=∅∗: Pre({ε})={ε}, but pre(∅∗)=∅∗∅ denotes ∅.

Check: in (a), the strings of length at most 3 of (01)∗(ε+0+1) are ε, 0, 1, 01, 010 and 011 — exactly the prefixes of length at most 3 of the strings 1, 011 and 01011 of L((01)∗1) (longer strings of the language add no new short prefixes).

Watch out: in the star case the hypothesis covers S, not S∗; the argument about x1​x2​⋯xk​ is what handles the star. And since every non-empty regular language has a ∅-free expression (Lemma 2.5), the result shows that Pre(L) is regular for every regular language L (Pre(∅)=∅ is regular too).

Answer. (a) (01)∗(ε+0+01)+(01)∗(ε+1)≡(01)∗(ε+0+1): some copies of 01, then at most one more symbol. (b) Structural induction with the set identities Pre(A∪B)=Pre(A)∪Pre(B), Pre(AB)=Pre(A)∪APre(B) for B=∅, and Pre(A∗)=A∗Pre(A) for A=∅. (c) Through Lemma 2.4, in the cases ST and S∗; R=0∅ and R=∅∗ break the extended definition.
