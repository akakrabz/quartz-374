3.1 Closure and fooling-set verdicts

Easy · true or false · closure properties · fooling sets

Let L, L′, L1​, L2​ be languages over Σ={0,1}. Answer each statement Yes (always true) or No, with a one-sentence reason; for a No, give a counterexample.

(a) If L⊕L′ is regular, then L and L′ are both regular.

(b) If L1​ is regular and L2​ is not, then L1​⊕L2​ is not regular.

(c) If neither L nor L′ is regular, then L∩L′ is not regular.

(d) Every DFA that accepts {w∈Σ∗∣∣w∣=5} has at least 7 states.

(e) If L is not regular, then L∗ is not regular.

(f) If a DFA with n states accepts at least one string, then it accepts some string of length less than n.

Source: original.

Hint

Closure properties say nothing about non-regular inputs, so for a No look for a counterexample built from {0n1n∣n≥0}, its complement, or ∅. For (b), write L2​ in terms of L1​ and L1​⊕L2​.

Solution

(a) No. Take L=L′={0n1n∣n≥0}, which is not regular (Lemma 3.6); then L⊕L′=∅, which is regular.

(b) Yes. L2​=L1​⊕(L1​⊕L2​), so if L1​⊕L2​ were regular, L2​ would be regular by closure under ⊕ (Corollary 3.4).

(c) No. L={0n1n∣n≥0} and L′=L are both non-regular (if L were regular, so would be its complement L), but L∩L′=∅.

(d) Yes. The seven strings ε,0,02,…,06 form a fooling set: for 0≤i<j≤6 the suffix z=05−i makes 0iz exactly 5 symbols long and 0jz longer. (Seven states also suffice: count the symbols up to 5, plus a dump state for longer strings.)

(e) No. L={02n∣n≥0} is not regular (Lemma 3.8), but 0=020∈L and L⊆0∗, so L∗=0∗, which is regular.

(f) Yes. The walk of a shortest accepted string never repeats a state (otherwise cutting out the loop between the two visits would leave a shorter accepted string), so it visits at most n states and reads at most n−1 symbols.

Watch out: in (a), (c) and (e) the closure theorems do not apply — they promise regular outputs only from regular inputs. The useful move is the one in (b): undo the operation with a language you know is regular.

Answer. (a) No (b) Yes (c) No (d) Yes (e) No (f) Yes.

3.2 A bounded counter

Easy · DFA design

Let L be the set of strings w such that every prefix p of w (including ε and w itself) satisfies ∣#(0,p)−#(1,p)∣≤2. For example, 0101 and 001101 are in L, but 0001 is not: its prefix 000 has three more 0s than 1s.

(a) Give a DFA for L with mnemonic state names, as a transition table with a column for the meaning of each state. No proof is required.

(b) In one sentence: why does the same idea not give a DFA for {w∣#(0,w)=#(1,w)}?

Source: textbook exercise style.

Hint

Write the algorithm first: one variable d=#(0,p)−#(1,p) for the prefix p read so far. Which values of d matter before the answer is certainly No?

Solution

Idea. Scan once, keeping d, the number of 0s minus the number of 1s read so far: a 0 adds 1 and a 1 subtracts 1. The first time ∣d∣ reaches 3, some prefix has failed and nothing later can repair that, so from then on the machine only needs to remember “failed”. That is five values of d plus a dump state.

(a)

statemeaning (input read so far)01
*d−2​no prefix has failed; two more 1s than 0sd−1​dead
*d−1​no prefix has failed; one more 1 than 0sd0​d−2​
→ *d0​no prefix has failed; as many 0s as 1sd1​d−1​
*d1​no prefix has failed; one more 0 than 1sd2​d0​
*d2​no prefix has failed; two more 0s than 1sdeadd1​
deadsome prefix has failed (dump state)deaddead

Check. 001101 visits d0​,d1​,d2​,d1​,d0​,d1​,d0​ and is accepted; 0001 visits d0​,d1​,d2​,dead,dead and is rejected. The empty string stays in d0​ and is accepted, as it should be: its only prefix is ε, with difference 0.

(b) There the difference is unbounded, so the counter would need a state for every integer; in fact 0∗ is an infinite fooling set for that language (the suffix 1i separates 0i from 0j).

Answer. Six states: d−2​,…,d2​ (no prefix has failed, and the subscript is the current value of d; all accepting; start d0​) and a dump state dead. Reading 0 moves dk​ to dk+1​, reading 1 moves it to dk−1​, and stepping outside [−2,2] goes to dead.

3.3 Prefixes of a pattern

Easy · fooling sets · Myhill–Nerode

Let L={w∣w contains the substring 0110}.

(a) Prove that every DFA that accepts L has at least 5 states.

(b) A student adds 01101 to your five strings, hoping to prove that 6 states are needed. Why must this fail?

Source: original.

Hint

A DFA hunting for 0110 must remember how much of the pattern it has just seen. Try the prefixes of 0110, and a suffix that completes the longer of the two strings.

Solution

(a) Let F={ε,0,01,011,0110}, the five prefixes of the pattern P=0110. Let x and y be distinct strings in F, named so that ∣x∣=i<j=∣y∣ (a distinguishing suffix works for the pair in either order, so this loses nothing). Let z be the last 4−j symbols of P. Then yz=P∈L. And xz∈/L, because ∣xz∣=i+4−j<4 is too short to contain 0110. So F is a fooling set of size 5, and every DFA for L has at least 5 states.

For instance, z=10 distinguishes 0 and 01: 010 ∈/L but 0110 ∈L.

(b) 0110 and 01101 both contain the pattern, so 0110z and 01101z are both in L for every z: no suffix distinguishes them. In fact no fooling set for L has 6 strings, because the 5-state DFA below accepts L, and by the Myhill–Nerode theorem the largest fooling set is exactly as large as the smallest DFA. State qu​ means “no 0110 yet, and u is the longest suffix of the input that is a prefix of 0110”:

state01
→qε​q0​qε​
q0​q0​q01​
q01​q0​q011​
q011​foundqε​
*foundfoundfound

Answer. (a) F={ε,0,01,011,0110}: for ∣x∣<∣y∣, the suffix that completes y to 0110 leaves xz shorter than 4. (b) 0110 and 01101 stay in L under every extension, so nothing distinguishes them; a 5-state DFA exists, so 5 is the exact minimum.

3.4 The forgotten second branch

Easy · find the error · fooling sets · non-regularity

Let L={0a1b∣a,b≥0 and (b=a or b=2a)}. A student writes:

“Let F=0∗. Let x and y be arbitrary distinct strings in F; then x=0i and y=0j for some integers i=j. Let z=1i. Then xz=0i1i∈L, because b=a. And yz=0j1i∈/L, because j=i. So F is a fooling set for L, and since F is infinite, L is not regular.”

(a) Which sentence is wrong? Give a concrete pair x,y∈F that this z does not distinguish.

(b) Repair the proof. (Its conclusion is true.)

Source: original.

Hint

Read the definition of L again: in how many ways can 0j1i belong to L?

Solution

(a) The slip is ”yz∈/L, because j=i”. That rules out only the branch b=a. The string yz=0j1i is also in L when i=2j. For example, x=00 and y=0 (i=2, j=1) get z=11, and both xz=0011 and yz=011 are in L. (The pair is still distinguishable — by z=1, for instance: 001 ∈/L but 01 ∈L — but not by the suffix the proof chose.)

(b) Fix: shrink F so that the bad case cannot happen. Let F=0(00)∗, the strings of 0s of odd length. Let x and y be arbitrary distinct strings in F; then x=0i and y=0j for some odd integers i=j. Let z=1i. Then xz=0i1i∈L, because b=a. And yz=0j1i∈/L: the branch b=a would need i=j, and the branch b=2a would need i=2j, which is even, while i is odd. So F is a fooling set for L, and since F is infinite, L is not regular.

Another fix: keep F=0∗ and split cases. If i=2j, the student’s z=1i works. If i=2j, then j≥1 (otherwise i=j=0), and z=1j works: yz=0j1j∈L, while xz=02j1j∈/L, because j=2j and j=4j are both false for j≥1.

Watch out: "yz∈/L" must rule out every way of being in L. When the definition contains an “or”, check each branch — a proof that skips one looks complete and still loses the points for that half.

Answer. (a) ”yz∈/L, because j=i” ignores the branch b=2a: for x=00, y=0, z=11, both 0011 and 011 are in L. (b) Use F=0(00)∗ with z=1i, where i=2j is impossible because i is odd; or keep 0∗ and use z=1j when i=2j.

3.5 Read a DFA, then prove it

Medium · DFA proof · string induction

For a string w, let #(01,w) be the number of occurrences of 01 in w as a substring. The DFA M has start state A, accepting states {A,B} and this transition function:

δ01
ABA
BBC
CDC
DDA

Prove that L(M)={w∣#(01,w) is even}:

(a) give each state q a meaning — a property Pq​ of the input read so far — such that δ∗(A,w)=q exactly when w has Pq​;

(b) prove your claim by induction on w, and conclude.

Source: original.

Hint

Two things matter: the parity of #(01,⋅) so far, and whether the last symbol read is a 0 (half of a possible new 01). Peel off the last symbol, w=xa, so that you need the claim only from the start state.

Solution

Idea. The four states record two bits: the parity of #(01,w), and whether w ends in 0. A new 01 appears exactly when a 1 is read right after a 0. The proof follows the template of §3.3.

(a) Meanings.

statePq​: the input w read so far …accepting
Ahas an even #(01,w) and does not end in 0 (it is empty or ends in 1)yes
Bhas an even #(01,w) and ends in 0yes
Chas an odd #(01,w) and does not end in 0no
Dhas an odd #(01,w) and ends in 0no

Every string has exactly one of the four properties, so it is enough to prove: for every string w, δ∗(A,w) is the state whose property w has.

(b) A fact first. For every string x and symbol a: #(01,xa)=#(01,x)+1 if x ends in 0 and a=1, and #(01,xa)=#(01,x) otherwise. Indeed, an occurrence of 01 in xa either lies inside x or uses the last two symbols, and those two symbols are 01 exactly when x ends in 0 and a=1.

Proof. Let w be an arbitrary string, and assume that for every string x shorter than w, δ∗(A,x) is the state whose property x has. There are two cases.

  • w=ε. δ∗(A,ε)=A by the definition of δ∗, and ε has PA​: #(01,ε)=0 is even, and ε does not end in 0.
  • w=xa for some string x and symbol a. Then δ∗(A,w)=δ(δ∗(A,x),a), and by the induction hypothesis δ∗(A,x)=q, where x has Pq​. The fact gives the property of xa in each of the eight combinations of q and a, and in each one δ(q,a) is the matching state:
x hasaso xa hasδ(q,a)
PA​0even, ends in 0: PB​B ✓
PA​1even (no new 01: x does not end in 0), ends in 1: PA​A ✓
PB​0even, ends in 0: PB​B ✓
PB​1odd (one new 01), ends in 1: PC​C ✓
PC​0odd, ends in 0: PD​D ✓
PC​1odd (no new 01), ends in 1: PC​C ✓
PD​0odd, ends in 0: PD​D ✓
PD​1even (one new 01), ends in 1: PA​A ✓

In both cases δ∗(A,w) is the state whose property w has. ■

Conclusion. w∈L(M)⟺δ∗(A,w)∈{A,B}⟺w has PA​ or PB​⟺#(01,w) is even.

Check. 00110 contains one 01: M visits A,B,B,C,C,D and rejects. 0101 contains two: M visits A,B,C,D,A and accepts.

Watch out: peeling the first symbol (w=ax) would need the claim from every state, because δ∗(A,ax)=δ∗(δ(A,a),x) runs x from δ(A,a). And #(01,⋅) is not additive: #(01,xy) is one more than #(01,x)+#(01,y) when the seam is a 01 — that is exactly what the fact keeps track of.

Answer. A: even and not ending in 0; B: even and ending in 0; C: odd and not ending in 0; D: odd and ending in 0 (parity of #(01,w)). Induction on w=xa, using that reading a adds a 01 exactly when x ends in 0 and a=1, proves these meanings; since A and B are the accepting states, L(M)={w∣#(01,w) is even}.

3.6 A product, written formally

Medium · product construction · closure properties · DFA design

Let L1​ be the set of strings that start with 1, let L2​={w∣#(1,w) is even}, and let L=L1​∩L2​.

(a) Give DFAs M1​ for L1​ and M2​ for L2​ with mnemonic state names.

(b) Describe the product DFA M=(Σ,Q,s,A,δ) for L formally. Then give the transition table of its reachable states, and run it on 1001 and on 0110.

(c) Changing only the accepting set, give DFAs for L1​∪L2​ and for L1​∖L2​.

(d) Two reachable states of M can be merged without changing L(M). Which two, and why?

Source: original.

Hint

A product state is a pair (state of M1​, state of M2​), and M runs both machines in lockstep. Only the accepting set depends on whether you want ∩, ∪ or ∖. For (d), look for states from which no accepting state can be reached.

Solution

Idea. M1​ remembers what the first symbol was, M2​ the parity of the number of 1s. Run both at once (§3.6) and accept when both accept.

(a) M1​=(Σ,{new,good,bad},new,{good},δ1​) and M2​=(Σ,{even,odd},even,{even},δ2​):

M1​meaning01
→newnothing read yetbadgood
*goodthe first symbol was 1goodgood
badthe first symbol was 0badbad
M2​meaning01
→ *evenan even number of 1s so farevenodd
oddan odd number of 1s so faroddeven

(b) The product.

Q:={new,good,bad}×{even,odd},s:=(new,even),A:={(good,even)}, δ((p,q),a):=(δ1​(p,a),δ2​(q,a))for every (p,q)∈Q and a∈Σ.

Q has six states, but (new,odd) is unreachable: M1​ is in new only before anything is read, when the number of 1s is 0. The other five:

statemeaning01
→(new,even)nothing read yet(bad,even)(good,odd)
*(good,even)starts with 1, even number of 1s(good,even)(good,odd)
(good,odd)starts with 1, odd number of 1s(good,odd)(good,even)

Check. On 1001, M visits (new,even), (good,odd) three times, then (good,even) and accepts: the string starts with 1 and has two 1s. On 0110 it visits (new,even), (bad,even), (bad,odd), (bad,even), (bad,even) and rejects: two 1s, but it starts with 0. The empty string stays in (new,even) and is rejected, correctly, since it does not start with 1.

(c) Keep Q, s and δ, and change A:

  • L1​∪L2​: A:={(p,q)∣p=good or q=even}={(new,even),(good,even),(good,odd),(bad,even)};
  • L1​∖L2​: A:={(p,q)∣p=good and q=odd}={(good,odd)}.

(d) (bad,even) and (bad,odd). Neither is accepting, and every transition out of them stays between the two, so from either one no string leads to an accepting state: both accept the same set of continuations, namely none. Merging them into a single dump state leaves a 4-state DFA for L, which Moore’s algorithm confirms is minimal. (For L1​∪L2​ the two must stay apart, because there (bad,even) accepts.)

Watch out: the product construction gives a correct DFA, not a minimal one. Define Q as the whole product Q1​×Q2​ with δ on every pair; tabulating only the reachable states is fine, but the formal definition must not leave transitions undefined.

Grading notes. A product construction earns its description points only if each factor is described completely (states, start, accepting states, transitions) and the product’s accepting set is given explicitly; “run both machines in parallel” alone earns little (how exams are graded).

Answer. Q={new,good,bad}×{even,odd}, s=(new,even), δ((p,q),a)=(δ1​(p,a),δ2​(q,a)), A={(good,even)}; five states are reachable. For L1​∪L2​: A={(new,even),(good,even),(good,odd),(bad,even)}; for L1​∖L2​: A={(good,odd)}. The two bad states merge into one dump state.

3.7 Squares need a marker

Medium · fooling sets · non-regularity

Prove that L={ww∣w∈{0,1}∗}, the set of strings that consist of two copies of the same string, is not regular. Use a fooling set, and write the proof in full.

Source: classic.

Hint

Let every string of F end with a marker 1, and try the suffix z=x. To show yz∈/L, count the 1s: how many does each half of a string in L get?

Solution

Idea. A DFA reading the first half must remember all of it. The suffix z=x copies x, so xz=xx∈L for free; a single 1 at the end of each string of F marks where the copy starts, which makes yz easy to rule out.

Proof. Let F=0∗1={0i1∣i≥0}. Let x and y be arbitrary distinct strings in F; then x=0i1 and y=0j1 for some integers i=j. Let z=0i1.

Then xz=0i10i1=ww for w=0i1, so xz∈L.

And yz=0j10i1∈/L. Suppose instead that yz=uu for some string u. The two copies of u contain the same number of 1s, and yz contains exactly two, so u contains exactly one 1. The string yz ends in 1, so u ends in 1; therefore u=0k1 for some k, and yz=0k10k1. Comparing the numbers of 0s before the first 1 and between the two 1s gives j=k and i=k, so i=j, a contradiction.

So z distinguishes x and y, and F is a fooling set for L. Because F is infinite, L is not regular. ■

Check. For i=1, j=2: xz=0101∈L, and yz=00101 has odd length, so it is not in L. For i=1, j=3: yz=000101 has halves 000 and 101.

Watch out: with F=0∗ the suffix z=x fails: then yz=0i+j, which is in L whenever i+j is even. (0∗ can still be made to work, with z=10i1 and the same counting argument.)

Grading notes. 4 points for an explicit infinite set that really is a fooling set, then 2 each for an explicit z, for xz∈L and for yz∈/L — and yz∈/L needs an argument for arbitrary i=j, not an example.

Answer. F=0∗1 with z=x: for x=0i1 and y=0j1, xz=(0i1)(0i1)∈L, while yz=0j10i1 would have to be 0k10k1, forcing i=j.

3.8 No 00 after an 11

Hard · DFA design · regular expressions

Let L be the set of strings w that have no substring of the form 11x00 with x∈{0,1}∗. In words: once 11 has appeared, 00 never appears afterwards. For example, 0010110 and 110101 are in L, but 0110100 is not.

(a) Give a DFA for L with mnemonic state names. No proof is required.

(b) Give a regular expression for L, with a one-sentence explanation of each part.

Source: original.

Hint

(a) Before the first 11, remember whether the last symbol was 1; after it, whether the last symbol was 0. (b) Cut w just before the first 11. What can the part before the cut look like, and the part after it?

Solution

Idea. The scan has two phases. Before the first 11, a 00 is harmless and the machine watches for 11; from then on it watches for 00, which is fatal. Note that 00 before the first 11 is allowed, as in 0010110.

(a)

statemeaning: the input read so far …01
→ *beforehas no 11, and is empty or ends in 0beforebefore1
*before1has no 11, and ends in 1beforeafter1
*after1has a 11 and no 00 after it, and ends in 1after0after1
*after0has a 11 and no 00 after it, and ends in 0deadafter1
deadhas a 00 after a 11 (dump state)deaddead

(b)

(0+10)∗(1+01)∗(ε+0)
  • (0+10)∗ is the part before the first 11: every 1 in it is followed by a 0, so it contains no 11 and does not end in 1 (a 1 just before the first 11 would make an earlier 11).
  • (1+01)∗ is the part from the first 11 on: every 0 in it is followed by a 1, so it contains no 00. (If w has no 11 at all, this part is empty or a single final 1.)
  • (ε+0) allows one final 0 — the only 0 after the first 11 that need not be followed by a 1.

Check. 0010110 splits as 0010 · 11 · 0, and the DFA visits before,before,before,before1,before,before1,after1,after0 and accepts. 110101 is ε · 110101 · ε, since 110101 = 1·1·01·01. On 0110100 the DFA reaches after1 after 011 and falls into dead at the final 00; the expression cannot match it either, because after the first 11 every 0 but a final one must be followed by a 1.

Watch out: (0+10)∗(1+01)∗ without the final (ε+0) looks right but misses 110, 1110, … — infinitely many strings, which on an exam costs all of the correctness points. And “no 00 and no 11 anywhere” describes a much smaller language: 00 is fine before the first 11.

Grading notes. For the DFA: a start arrow, marked accepting states and a sentence about the dump state if you omit it from a drawing (2 points), correctness (6), mnemonic state names (2). For the expression: syntax (2) and correctness (8) (how exams are graded).

Answer. (a) Five states: before (start), before1, after1, after0, all accepting, and the dump state dead, as in the table. (b) (0+10)∗(1+01)∗(ε+0).

3.9 Three look-alike counting languages

Hard · non-regularity · closure properties · fooling sets

For strings u and w, let #(u,w) be the number of occurrences of u in w as a substring; overlapping occurrences count, so #(00,000)=2. For each language below, decide whether it is regular, and prove your answer: a regular expression with a short justification if it is regular, a proof if it is not.

(a) La​={w∣#(00,w)=#(11,w)}

(b) Lb​={w∣#(01,w)=#(10,w)}

(c) Lc​={w∣#(01,w)=#(11,w)}

Source: original; part (b) is a classic exercise.

Hint

(a) Intersect with 0∗1∗ and count 00 and 11 in 0a1b. (b) Cut w into maximal runs of equal symbols; where can 01 and 10 occur? (c) Extra 0s at the front of a string change neither count — so build the fooling set from 1s.

Solution

Idea. All three definitions compare two substring counts, but only some comparisons need an unbounded counter. Before trying to prove anything, ask what a one-pass algorithm would have to remember — and test the definition on short strings.

(a) Not regular — by closure. Suppose La​ were regular. Since 0∗1∗ is regular, La​∩0∗1∗ would be regular too (Corollary 3.4). The string 0a1b contains max(a−1,0) copies of 00 and max(b−1,0) copies of 11; these are equal when a=b, and otherwise only when a≤1 and b≤1. So

La​∩0∗1∗={0n1n∣n≥0}∪{0,1}.

The finite language {0,1} is regular, so (La​∩0∗1∗)∖{0,1}={0n1n∣n≥0} would be regular as well, contradicting Lemma 3.6. So La​ is not regular.

(A fooling set works too, but not 0∗ with z=1i: that suffix fails for the pair ε, 0, which are both in La​. With F={0i∣i≥1} and z=1i, the string yz=0j1i has j−1 copies of 00 but i−1 copies of 11.)

(b) Regular. Lb​ is the language of the expression

ε+0+1+0(0+1)∗0+1(0+1)∗1,

the strings that are empty or start and end with the same symbol: ε, 0 and 1 are the strings of length at most 1, and the last two terms are the longer strings that start and end with 0, respectively 1. Why this is Lb​: cut a non-empty w into its maximal runs of equal symbols, w=r1​r2​⋯rk​ (for example 0110 = 0·11·0). Inside a run adjacent symbols are equal, so the occurrences of 01 and 10 are exactly the k−1 seams between consecutive runs. The runs alternate between 0s and 1s, so the seams alternate between 01 and 10. Hence #(01,w)=#(10,w) exactly when k−1 is even, that is, when r1​ and rk​ consist of the same symbol — when w starts and ends with the same symbol. And ε∈Lb​, since 0=0.

(c) Not regular — by a fooling set. First, 0∗ is useless here: for i,j≥1 and every z, the strings 0iz and 0jz have the same numbers of 01 and 11, because the extra 0s create only copies of 00. So no suffix distinguishes 0i and 0j. The quantity a DFA would have to count is the number of 11s, so use 1s.

Let F={1i∣i≥1}. Let x and y be arbitrary distinct strings in F; then x=1i and y=1j for some integers i,j≥1 with i=j. Let z=(01)i−1. For any m≥1, in 1mz the copies of 11 are the m−1 inside 1m (z alternates and starts with 0), and the copies of 01 are the i−1 inside z (there are none inside 1m, and the seam is 10). So:

  • xz=1i(01)i−1 has i−1 copies of each, so xz∈Lc​;
  • yz=1j(01)i−1 has j−1 copies of 11 but i−1=j−1 copies of 01, so yz∈/Lc​.

So F is a fooling set for Lc​, and since it is infinite, Lc​ is not regular. ■

Check. (b): 0110 has one 01 and one 10; 011 has one 01 and no 10. (c) with i=2, j=3: xz=1101 has one 11 and one 01; yz=11101 has two 11s and one 01.

Watch out: three definitions that look alike, three different arguments — never decide “not regular” from the shape of a definition. In (a) the closure argument must run in the right direction (assume La​ regular and derive a known non-regular language; a regular intersection would prove nothing), and the intersection must be computed exactly: forgetting 0 and 1 is a real error. More on this trick in §3.8.

Answer. (a) Not regular: (La​∩0∗1∗)∖{0,1}={0n1n∣n≥0}. (b) Regular: ε+0+1+0(0+1)∗0+1(0+1)∗1. (c) Not regular: F={1i∣i≥1} with z=(01)i−1.

3.10 Shrink it, then prove it minimal

Hard · minimization · Myhill–Nerode · fooling sets

The DFA M has start state A, accepting states {E,G} and this transition function:

δ01
ADB
BCB
CDE
DAB
EGE
GGE
HAC

(a) Which states are unreachable from A?

(b) Run Moore’s algorithm on the reachable states: list the pairs marked initially and in each pass. (In pass k, mark {p,q} if, for some symbol a, the pair {δ(p,a),δ(q,a)} was marked before pass k began; stop after a pass that marks nothing.)

(c) Give the minimal DFA with mnemonic state names, and describe L(M) in one sentence.

(d) Prove with a fooling set that no DFA with fewer states accepts L(M).

Source: original.

Hint

Pass k marks exactly the pairs whose shortest distinguishing string has length k (the initial marks are the length-0 pairs). For (d), take one string that leads to each state of your minimal DFA.

Solution

Idea. Moore’s algorithm (§3.10) is dynamic programming on “some string of length at most k distinguishes p and q”. Whatever is never marked can be merged; a fooling set then certifies that the result cannot be shrunk further.

(a) From A we reach D and B, then C, then E, then G; no transition enters H. So H is unreachable, and we delete it.

(b) Six states give 15 pairs.

  • Initially: the 8 pairs with exactly one accepting state, {X,Y} for X∈{A,B,C,D} and Y∈{E,G}.
  • Pass 1: {A,C}, {B,C}, {C,D}. In each, reading 1 leads to the marked pair {B,E}, because δ(A,1)=δ(B,1)=δ(D,1)=B and δ(C,1)=E.
  • Pass 2: {A,B} (reading 0 gives {D,C}, marked in pass 1) and {B,D} (reading 0 gives {C,A}, marked in pass 1).
  • Pass 3: nothing. The remaining pairs only lead to themselves or to a single state: {A,D} goes to {D,A} on 0 and to B on 1; {E,G} goes to G on 0 and to E on 1. Stop.

The pass that marked each pair (0 = initially, – = never):

ABCDE
B2
C11
D–21
E0000
G0000–

(c) Merge A with D, and E with G:

statemeaning: the input read so far …01
→ADhas no 101, and does not end in 1 or 10ADB
Bhas no 101, and ends in 1CB
Chas no 101, and ends in 10ADEG
*EGcontains 101EGEG

So L(M) is the set of strings that contain 101 as a substring.

(d) Let S={ε,1,10,101}, one string for each state of the minimal DFA. Every pair has a distinguishing suffix z (shown with the string of the pair that z puts into L(M)):

pairzin L(M)not in L(M)
ε, 10110101
ε, 1011011
1, 10110111
ε, 101ε101ε
1, 101ε1011
10, 101ε10110

So S is a fooling set of size 4: every DFA for L(M) has at least 4 states, and the DFA in (c) is minimal.

Check. The pass numbers agree with shortest distinguishing strings: 1 distinguishes A and C (δ∗(A,1)=B rejects, δ∗(C,1)=E accepts), while A and B need two symbols: 01 takes A to B (reject) and B to E (accept), and no single symbol separates them.

Watch out: if marks made earlier in the same pass are allowed to count, the pass numbers can change (checking pairs in alphabetical order, {B,D} is then marked in pass 1, because {A,C} was marked earlier in that pass), but the final partition cannot. And do not skip step 1: H is equivalent to no other state, so leaving it in the table produces a 5-state “minimal” DFA.

Answer. (a) H. (b) Initially the 8 pairs between {A,B,C,D} and {E,G}; pass 1: {A,C},{B,C},{C,D}; pass 2: {A,B},{B,D}; pass 3: nothing. (c) Four states AD, B, C, EG; L(M) is the set of strings containing 101. (d) S={ε,1,10,101} is a fooling set of size 4.
