Chapter 3 — Finite-State Machines

In one breath

A DFA is an algorithm that reads its input once, left to right, and remembers only a constant amount of information: its current state. DFAs accept exactly the regular languages (Kleene’s theorem, proved in Chapter 4). Running two DFAs in parallel — the product construction — shows that regular languages are closed under every boolean operation. To show a language is not regular, exhibit an infinite fooling set; the Myhill–Nerode theorem says this method always works, and Moore’s algorithm finds the smallest DFA.

3.1 Intuition: a DFA is a loop with constant memory

Is a bit string a binary multiple of 5? Scan it once, keeping only the value of the prefix read so far, mod 5. Reading bit a turns the value v into 2v+a, so the remainder q becomes (2q+a)mod5:

rem ← 0
for each bit a of w, left to right:
    rem ← (2·rem + a) mod 5
return rem = 0

The variable rem has five possible values. Those five values are the states of a DFA, one loop iteration is the transition function δ(q,a)=(2q+a)mod5, and the return condition is the set of accepting states {0}.

On input 00101110110 (which is 374 in binary) the machine visits 0,0,0,1,2,0,1,3,1,3,2,4 and ends in state 4, so it rejects — indeed 374=5⋅74+4. The empty string ends in the start state 0 and is accepted, so the machine treats ε as a numeral for 0.

3.2 Formal definitions

Definition — deterministic finite-state automaton (DFA)

A DFA is a tuple M=(Σ,Q,s,A,δ):

  • Σ — the input alphabet (finite);
  • Q — a finite set of states;
  • s∈Q — the start state;
  • A⊆Q — the accepting states;
  • δ:Q×Σ→Q — the transition function, defined for every state and every symbol.

The extended transition function δ∗:Q×Σ∗→Q follows the recursive definition of strings:

δ∗(q,w):={qδ∗(δ(q,a),x)​if w=εif w=ax.​

M accepts w iff δ∗(s,w)∈A, and the language of M is L(M):={w∈Σ∗∣δ∗(s,w)∈A}. A language is automatic if it is L(M) for some DFA M.

As a graph, a DFA is a directed graph whose vertices are the states and in which every state has exactly one outgoing edge per symbol. Every string traces exactly one walk from s; the DFA accepts if the walk ends in A. Two identities, each a short string induction, get used constantly:

δ∗(q,xy)=δ∗(δ∗(q,x),y),δ∗(q,xa)=δ(δ∗(q,x),a).

A DFA's transition function is total

Every state needs an outgoing edge for every symbol. Drawings usually omit the dump state (a non-accepting state that loops to itself on every symbol); that is fine on an exam only if you say so — “all missing transitions go to a dump state”. An automaton with missing edges and no such sentence is an incomplete DFA (or an NFA, which earns half credit where a DFA was asked for).

3.3 Proving a DFA correct

The two-state DFA above should accept exactly the strings with an odd number of 1s. To prove that, give every state a meaning and prove all the meanings at once. Here the meaning of s is “even number of 1s so far” and of t is “odd so far”. The claim needs both start states, because peeling the first symbol of w moves the machine to a different state:

Claim (stronger than needed)

For every string w: if #(1,w) is even, then δ∗(s,w)=s and δ∗(t,w)=t; if #(1,w) is odd, then δ∗(s,w)=t and δ∗(t,w)=s.

Proof (click to expand) — a model string induction

Let w be an arbitrary string, and assume the claim for every string shorter than w. There are three cases.

  • w=ε. #(1,ε)=0 is even, and δ∗(s,ε)=s, δ∗(t,ε)=t by the definition of δ∗.
  • w=0x. Then #(1,w)=#(1,x), and δ∗(s,w)=δ∗(δ(s,0),x)=δ∗(s,x), δ∗(t,w)=δ∗(t,x). The induction hypothesis for x (shorter than w) gives exactly the claim for w.
  • w=1x. Then #(1,w)=#(1,x)+1 has the opposite parity, and δ∗(s,w)=δ∗(t,x), δ∗(t,w)=δ∗(s,x). If #(1,x) is even, the hypothesis gives δ∗(t,x)=t and δ∗(s,x)=s, so δ∗(s,w)=t and δ∗(t,w)=s — correct, because #(1,w) is odd. The odd case is symmetric.

In every case the claim holds for w. Since A={t}, M accepts w iff δ∗(s,w)=t iff #(1,w) is odd. ■

Template — proving L(M)=L for a DFA

  1. Give each state q a meaning Pq​, and claim: ”δ∗(s,w)=q if and only if w has property Pq​.”
  2. Induct on w. Either peel the first symbol (w=ax) — then state the claim for every possible start state, as above — or peel the last symbol (w=xa) and use δ∗(s,xa)=δ(δ∗(s,x),a), which needs the claim only from s.
  3. Conclude: w∈L(M)⟺δ∗(s,w)∈A⟺w has one of the accepting properties ⟺w∈L.

On exams that ask only for a DFA (“no proof required”), the state meanings still matter: they are what the mnemonic state names are supposed to convey.

3.4 Real-world examples

Anything with finitely many configurations that changes in response to discrete inputs is a finite-state machine: a railway clock (720 states, one input “tick”), a Rubik’s cube (about 5.2×1020 states, one input symbol per quarter turn, start and accept in the solved state), a vending machine, a traffic light. The number of states may be astronomical; what matters is that it is finite and fixed in advance, independent of the input length.

3.5 Designing DFAs: DFAs are algorithms

Recipe — design a DFA by writing the algorithm first

  1. Write a single left-to-right loop over the input that uses a fixed number of variables, each with a fixed, finite set of possible values (known before the input arrives — no counters that grow with n).
  2. States = all combinations of variable values. Start state = their initial values.
  3. Transition function = one iteration of the loop body.
  4. Accepting states = the combinations for which the final test returns true.
  5. Drop states that are unreachable; merge states only when it makes the machine clearer.
  6. Name each state after what it remembers (“last symbol was 1”, “seen 11”, “remainder 3”).

Example: strings containing 11. A first algorithm keeps a flag found∈{F,T} and the last two symbols read (ε, 0, 1, 00, 01, 10, 11): 2×7=14 states, start (F,ε), accepting every (T,⋅). It is correct but wasteful — only 10 of those states are reachable, and only the previous symbol matters (keeping just the last symbol leaves 5 reachable states). Clarity beats minimality. A larger DFA whose states have obvious meanings is easier to get right, easier to explain, and earns the same credit; there is no prize for hand-minimizing.

What can a DFA not remember?

Anything that grows with the input: a count of 0s, the first half of the string, a stack of open parentheses. “Read once, constant memory” is the whole model — if your algorithm needs an unbounded counter, the language is probably not regular, and §3.8 shows how to prove it.

3.6 The product construction

Two DFAs over the same alphabet can run in parallel: the combined machine remembers one state of each.

Definition — product construction

Given DFAs M1​=(Σ,Q1​,s1​,A1​,δ1​) and M2​=(Σ,Q2​,s2​,A2​,δ2​), define M=(Σ,Q,s,A,δ) with

Q:=Q1​×Q2​,s:=(s1​,s2​),δ((p,q),a):=(δ1​(p,a),δ2​(q,a)).

Only the accepting set depends on what you want:

languageaccepting states A
L1​∩L2​{(p,q)∣p∈A1​ and q∈A2​}
L1​∪L2​{(p,q)∣p∈A1​ or q∈A2​}
L1​∖L2​{(p,q)∣p∈A1​ and q∈/A2​}
L1​⊕L2​{(p,q)∣p∈A1​ xor q∈A2​}

The complement needs only one machine: keep M1​ and accept Q1​∖A1​.

Lemma 3.1

δ∗((p,q),w)=(δ1∗​(p,w),δ2∗​(q,w)) for every string w and all states p∈Q1​, q∈Q2​.

Proof (click to expand)

Induction on w. If w=ε, both sides equal (p,q). If w=ax, then

δ∗((p,q),ax)=δ∗(δ((p,q),a),x)=δ∗((δ1​(p,a),δ2​(q,a)),x)=(δ1∗​(δ1​(p,a),x), δ2∗​(δ2​(q,a),x)),

by the definitions of δ∗ and δ and then the induction hypothesis for x (which holds for every pair of states — that is why the lemma quantifies over all p,q). The last expression is (δ1∗​(p,ax),δ2∗​(q,ax)) by the definition of δ∗. ■

Cascading products handles any boolean combination of finitely many regular languages: “contains 11, has even length, and does not end in 0” is a product of three small machines.

How a product construction is graded

The description must define each factor completely (its states, start, accepting states and transitions — or a drawing of it) and then the product’s states, start state, transition function and accepting set. “Run both machines in parallel” alone earns little. Name the product’s states by their components, as in (E,O) above.

3.7 Closure properties

Theorem 3.2

If L and L′ are automatic (over the same alphabet), then so are L=Σ∗∖L, L∪L′, L∩L′, L∖L′ and L⊕L′.

Theorem 3.3 (Kleene)

For every regular expression R there is a DFA M with L(M)=L(R), and for every DFA M there is a regular expression R with L(R)=L(M). (Proved in Chapter 4.)

So “automatic” is just another word for regular, and the two theorems combine:

  • Corollary 3.4. Regular languages are closed under complement, intersection, difference and symmetric difference. (Regular expressions have no symbol for ∩ or complement — the DFA view proves it.)
  • Corollary 3.5. Automatic languages are closed under concatenation and Kleene star. (Easy for regular expressions, awkward for DFAs — until NFAs arrive.)

Three ways to prove that a language is regular

  1. Give a regular expression for it (Chapter 2).
  2. Give a DFA — or an NFA (Chapter 4) — for it.
  3. Build it from languages already known to be regular with closure properties: boolean operations, concatenation, star, reversal, and the transformations of §4.9.

The conversions between the three descriptions always exist but can be exponential (and sometimes must be). Full table: closure-properties.

3.8 Proving a language is not regular

A DFA has no memory except its state. If two strings x and y lead to the same state, then every continuation z leads xz and yz to the same final state:

δ∗(s,x)=δ∗(s,y) ⟹ δ∗(s,xz)=δ∗(s,yz)  for every z ⟹ (xz∈L⟺yz∈L).

Definition — distinguishing suffix, fooling set

A distinguishing suffix for x and y (with respect to L) is a string z such that exactly one of xz and yz is in L. A fooling set for L is a set F of strings such that every pair of distinct strings in F has a distinguishing suffix.

Fooling sets give lower bounds

If F is a fooling set for L, then every DFA for L has at least ∣F∣ states, because no two strings of F can end in the same state. In particular: if L has an infinite fooling set, then L is not regular.

A finite example. F={0,1,10,11,100} (the numbers 0–4) is a fooling set for the binary multiples of 5: for instance z=01 distinguishes 1 and 11, because 101 =5 is a multiple of 5 and 1101 =13 is not. So the 5-state DFA of §3.1 is as small as possible.

Template — fooling-set proof (as in Lemma 3.6)

Let F= [an explicit infinite set, e.g. 0∗].
Let x and y be arbitrary distinct strings in F.
The definition of F implies x= […] and y= […] for some integers i=j.
Let z= [a suffix that may depend on i and j].
Then xz= […] ∈L, because […].
And yz= […] ∈/L, because […].
So z distinguishes x and y. We conclude that F is a fooling set for L.
Because F is infinite, L cannot be regular. ■

Lemma 3.6 — {0n1n∣n≥0} is not regular

Let F=0∗. Let x and y be arbitrary distinct strings in F; then x=0i and y=0j for some integers i=j. Let z=1i. Then xz=0i1i∈L. And yz=0j1i∈/L, because j=i. So F is a fooling set for L, and since F is infinite, L is not regular.

The same skeleton handles the standard examples; only F and z change. (For x=y written with i=j.)

Choosing F. The fooling set usually comes from the unbounded quantity that any algorithm for L “obviously” has to remember — a count, a prefix, a position. Good candidates are a simple regular language with one star and no union (0∗, 10∗1, (01)∗) or L itself. You choose F, so you may impose structure that L lacks: for “equally many 0s and 1s” we only ever use strings of the form 0i1j.

The closure alternative. If L were regular, then L∩0∗1∗ would be regular too (Corollary 3.4). For L={w∣#(0,w)=#(1,w)} that intersection is {0n1n}, which is not regular — so neither is L. This only works in that direction: a regular intersection proves nothing about L.

Where fooling-set proofs lose points

  1. One example pair is not a proof. The argument must work for arbitrary distinct x,y∈F, written with parameters i=j.
  2. Check both halves: xz∈L and yz∈/L, each with a reason. “Clearly” is not a reason.
  3. i<j needs a justification. Assume it only if you say “without loss of generality” and the argument really is symmetric — the suffix z=1i above is built from x, so swapping x and y changes it.
  4. The set must be infinite and explicit. “Let F be the set of all prefixes we need” is not a set; a finite fooling set proves only a lower bound on the number of states.
  5. z may depend on x and y, but not on anything else (in particular not on a DFA you are trying to rule out).

How a fooling-set proof is graded

4 points for an explicit infinite set that really is a fooling set (a finite set earns nothing); 6 for the argument with arbitrary distinct x,y: 2 for an explicit suffix, 2 for showing one of xz,yz is in L, 2 for showing the other is not.

3.9 The Myhill–Nerode theorem

Write x≡L​y when no suffix distinguishes x and y: xz∈L⟺yz∈L for every string z. This is an equivalence relation, and its classes are exactly “what an algorithm for L must remember”.

The Myhill–Nerode theorem

For every language L, the following three numbers are equal (possibly all infinite):

  1. the minimum number of states of a DFA that accepts L;
  2. the maximum size of a fooling set for L;
  3. the number of equivalence classes of ≡L​.

In particular, L is regular if and only if every fooling set for L is finite. So a non-regularity proof by fooling set always exists — the only question is finding it.

Proof sketch (click to expand)

(1) ≥ (2) is the fooling-set argument above. (2) = (3): a fooling set is exactly a set containing at most one string from each class. (1) ≤ (3): build a DFA whose states are the classes, Q={[w]∣w∈Σ∗}, with start [ε], accepting states {[w]∣w∈L}, and δ([w],a)=[wa]. This is well defined because x≡L​y implies xa≡L​ya, and δ∗([ε],w)=[w] by induction, so the machine accepts exactly L. ■

3.10 Minimal automata: Moore’s algorithm

Two states p and q are distinguishable if some string z leads exactly one of them to an accepting state. Recursively: p and q are distinguishable if exactly one of them is accepting, or if δ(p,a) and δ(q,a) are distinguishable for some symbol a.

Moore's algorithm (table filling)

  1. Delete every state that is unreachable from s (graph search, O(nσ) time for n=∣Q∣, σ=∣Σ∣).
  2. Mark every pair {p,q} with exactly one accepting state.
  3. Repeat passes: mark {p,q} whenever {δ(p,a),δ(q,a)} is already marked for some symbol a. Stop after a pass that marks nothing (at most n passes, O(σn3) time in all).
  4. Merge each group of mutually unmarked (equivalent) states. The result is the minimal DFA.

This is dynamic programming for “some string of length ≤k distinguishes p and q”. Faster versions exist: O(σn2), and Hopcroft’s O(σnlogn).

Example. Counting 1s mod 6 and accepting counts 0 and 3 decides “the number of 1s is a multiple of 3” with six states. Step 2 marks the 8 pairs between {0,3} and {1,2,4,5}. The first pass marks {1,2}, {1,5}, {2,4} and {4,5} (for example, reading 1 sends {1,2} to the marked pair {2,3}). The second pass marks nothing: {0,3}, {1,4} and {2,5} only ever lead to each other. Merging them leaves three states.

Concept page: dfa-minimization.

Summary

  • A DFA (Σ,Q,s,A,δ) is a one-pass algorithm with a fixed, finite memory; δ is total.
  • Prove a DFA correct by giving every state a meaning and proving all meanings together by induction.
  • Design by brute force: states = values of the loop’s variables; name them by what they remember.
  • Product construction: Q1​×Q2​, run in parallel; the accepting set chooses ∩,∪,∖,⊕. Regular languages are closed under all boolean operations.
  • Not regular ⇔ an infinite fooling set exists (Myhill–Nerode). Write the proof with arbitrary x=y, an explicit z, and both membership checks.
  • Moore’s algorithm merges indistinguishable states; the minimal DFA is unique up to renaming.

On the exams

Midterm-1-style exams test this chapter three ways. DFA design (usually alongside a regular expression for the same language): mnemonic state names, a start arrow, double circles, and an explicit sentence about any omitted dump state; no proof needed unless asked. Non-regularity by fooling set, often paired with a context-free grammar for the same language (Chapter 5). True/false items such as “if L has a fooling set of size 5, every DFA for L has at least 5 states” (true — the same suffixes distinguish the strings for L). Rubric details: how exams are graded.
