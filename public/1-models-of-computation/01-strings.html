In one breath

A string is either empty or a symbol followed by a string. Because that definition is recursive, every function on strings — length, concatenation, reversal, counting — is defined by the same two cases, and every proof about strings is an induction whose cases mirror the definition: w=ε or w=ax, with a hypothesis that covers every shorter string. Lemmas 1.1–1.3 (w∙ε=w, lengths add, concatenation is associative) state facts you already believe; their proofs are practice for a pattern that returns in every later chapter, for automata, regular expressions, grammars and Turing machines. Midterm-1-style exams devote a whole problem to exactly this kind of proof about a newly defined string function.

1.1 Strings

An alphabet Σ is a finite set; its elements are called symbols — bits, letters, ASCII characters, anything. A string over Σ is then defined the way a linked list is defined in a program:

Definition — string, Σ∗

A string over Σ is either

  • the empty string, written ε, or
  • an ordered pair (a,x), written a⋅x or just ax, where a∈Σ is a symbol and x is a string over Σ.

Σ∗ is the set of all strings over Σ. For a non-empty alphabet it is an infinite set, but every string in it is finite: it is built by finitely many applications of the second rule.

So STRING is shorthand for (S,(T,(R,(I,(N,(G,ε)))))) — six pairs, with the empty string at the end:

Conventions (the book’s, used on every page of this site): a,b,c are symbols; w,x,y,z are strings; explicit symbols and strings are set in monospace, like 0, 1, 0110, STRING. Formally the symbol a and the one-symbol string a⋅ε are different objects, but everyone writes both as a. The difference matters only inside proofs, where a∙z=a⋅(ε∙z)=a⋅z uses both cases of the definition of concatenation below.

1.2 Two recursive functions

Because strings are defined recursively, functions on strings are defined recursively too: one case for ε, and one case for ax that calls the function on the shorter string x.

Definition — length and concatenation

∣w∣:={01+∣x∣​if w=εif w=ax​w∙z:={za⋅(x∙z)​if w=εif w=ax​

The small dot in a⋅x puts one symbol in front of a string: it builds a pair. The big dot in w∙z glues two strings together. Both dots are usually left out.

Unfolding the definition on an example:

NOW∙HERE=N⋅(OW∙HERE)=N⋅(O⋅(W∙HERE))=N⋅(O⋅(W⋅(ε∙HERE)))=NOWHERE.

Three consequences to keep in mind:

  • Concatenation recurses on its left argument. The right argument rides along unchanged until the base case returns it. So a proof about w∙z inducts on w and keeps z fixed (Lemma 1.2 below).
  • ε is a left identity by definition (ε∙z=z is the first case) but a right identity only by proof (w∙ε=w is Lemma 1.1).
  • Concatenation is not commutative — NOW∙HERE=NOWHERE but HERE∙NOW=HERENOW — but it is associative (Lemma 1.3), which is what licenses writing wxyz with no dots and no parentheses.

Chapter 3 defines a DFA’s extended transition function δ∗ by exactly this recursion on the input string (§3.2).

1.3 Induction on strings

Every proof about strings in this course follows two design rules.

  1. The cases mirror the recursive definition. A string is either ε or ax, so the proof has a case w=ε and a case w=ax. (If the function in the claim is defined by other cases, mirror its cases — see swap at the end of this page.)
  2. The induction hypothesis is as strong as possible: assume the claim for every string shorter than w — “there is no counterexample shorter than w”. In the case w=ax we have ∣x∣=∣w∣−1<∣w∣, so the hypothesis applies to x, and to any other shorter string the argument needs.

This strong hypothesis costs nothing compared with the weak one (“assume the claim for x, prove it for ax”), the graders prefer it, and it still works when a proof needs a string two symbols shorter, or half as long.

Template — induction on strings

Let w be an arbitrary string.
Assume, for every string x with ∣x∣<∣w∣, that [the claim holds for x].
There are two cases to consider.
Case w=ε. … Therefore [the claim holds for w].
Case w=ax for some symbol a and string x. The induction hypothesis implies that [the claim holds for x]. … Therefore [the claim holds for w].
In both cases, [the claim holds for w]. ■

Write this boilerplate first, with room in each case; then write out the claim and the hypothesis in full, with variable names that do not clash; only then start on the algebra.

Lemma 1.1

w∙ε=w for every string w.

Lemma 1.2

∣w∙x∣=∣w∣+∣x∣ for all strings w and x.

Lemma 1.3

(w∙x)∙y=w∙(x∙y) for all strings w, x and y.

Proof of Lemma 1.2 — the model to copy

Let w and x be arbitrary strings. Assume that ∣y∙x∣=∣y∣+∣x∣ for every string y with ∣y∣<∣w∣. (We induct on w, the argument that ∙ recurses on, and keep x fixed; the shorter string is called y because x is taken.) There are two cases.

Case w=ε. By the definitions of ∙ and ∣⋅∣,

∣w∙x∣=∣ε∙x∣=∣x∣=0+∣x∣=∣ε∣+∣x∣=∣w∣+∣x∣.

Case w=ay for some symbol a and string y. Then ∣y∣<∣w∣, so the induction hypothesis applies to y, and

∣w∙x∣​=∣a⋅(y∙x)∣=1+∣y∙x∣=1+∣y∣+∣x∣=∣w∣+∣x∣​​by definition of ∙by definition of ∣⋅∣by the induction hypothesisby definition of ∣⋅∣.​

In both cases, ∣w∙x∣=∣w∣+∣x∣. ■

What to copy: an arbitrary w (and x); a hypothesis written out in full, for all shorter strings; cases that cover every string; one justification per equation; and an explicit reason why the hypothesis applies (∣y∣<∣w∣). No step says “clearly”.

Proof of Lemma 1.1 (click to expand)

Let w be an arbitrary string, and assume that x∙ε=x for every string x with ∣x∣<∣w∣.

  • w=ε: w∙ε=ε∙ε=ε=w, by the first case of the definition of ∙.
  • w=ax: w∙ε=a⋅(x∙ε) by the definition of ∙, and x∙ε=x by the induction hypothesis because ∣x∣<∣w∣; so w∙ε=a⋅x=w.

In both cases w∙ε=w. ■

Proof of Lemma 1.3 (click to expand)

Induct on w: both sides then unfold by the definition of ∙. (Inducting on y gets stuck — nothing in the definition takes a right argument apart.) Let w, x, y be arbitrary strings, and assume (z∙x)∙y=z∙(x∙y) for every string z with ∣z∣<∣w∣.

Case w=ε. (ε∙x)∙y=x∙y=ε∙(x∙y), using the definition of ∙ twice.

Case w=az. Then ∣z∣<∣w∣, and

(az∙x)∙y​=(a⋅(z∙x))∙y=a⋅((z∙x)∙y)=a⋅(z∙(x∙y))=az∙(x∙y)​​by definition of ∙by definition of ∙by the induction hypothesisby definition of ∙.​

In both cases (w∙x)∙y=w∙(x∙y). ■

1.4 More than one path up the mountain

The two-case boilerplate is the default, not the law. Any induction works as long as its cases cover every string and every string the hypothesis is applied to is shorter than w. A useful alternative: a string w is non-empty if and only if either

  • w=a for a single symbol a, or
  • w=u∙v for two non-empty strings u and v — and then ∣u∣,∣v∣<∣w∣ by Lemma 1.2, so the hypothesis applies to both pieces.

That split gives a proof with three cases — w=ε, w=a, w=u∙v — and two base cases, because a single symbol cannot be cut into two non-empty pieces. Another common variant peels off the last symbol: every non-empty string is x∙a with ∣x∣=∣w∣−1, which is how a DFA proof can follow the machine as it reads its input (§3.3).

Quantify the hypothesis over the other arguments

In the proof of Lemma 1.2 the second argument x never changed, so the hypothesis could keep it fixed. Proving associativity with w=u∙v is different: each step below applies the claim (z∙x′)∙y′=z∙(x′∙y′) to a shorter z, and three of the four steps use other second and third arguments.

((u∙v)∙x)∙y​=(u∙(v∙x))∙y=u∙((v∙x)∙y)=u∙(v∙(x∙y))=(u∙v)∙(x∙y)​​(z,x′,y′)=(u, v, x)(z,x′,y′)=(u, v∙x, y)(z,x′,y′)=(v, x, y)(z,x′,y′)=(u, v, x∙y)​

So the hypothesis must read: ”(z∙x′)∙y′=z∙(x′∙y′) for all strings x′ and y′ and every string z with ∣z∣<∣w∣.” A hypothesis about the fixed x and y alone justifies only the third step.

Lemma 1.3 again, by the three-case split (click to expand)

Let w be an arbitrary string. Assume that (z∙x′)∙y′=z∙(x′∙y′) for all strings x′, y′ and every string z with ∣z∣<∣w∣. Let x and y be arbitrary strings.

  • w=ε: (ε∙x)∙y=x∙y=ε∙(x∙y) by the definition of ∙.
  • w=a: (a∙x)∙y=(a⋅x)∙y=a⋅(x∙y)=a∙(x∙y), using a∙z=a⋅z (§1.1) and the definition of ∙.
  • w=u∙v with u, v non-empty: ∣u∣,∣v∣<∣w∣ by Lemma 1.2, so each of the four steps in the trap above is a legal use of the hypothesis, and they show (w∙x)∙y=w∙(x∙y).

In all three cases (w∙x)∙y=w∙(x∙y). ■

1.5 Indices, substrings, and subsequences

Definition — pieces of a string

Let w be a string of length n.

  • Index: wi​ is the ith symbol of w. Recursively, if w=ax, then w1​:=a and wi​:=xi−1​ for i>1; wi​ is undefined if i<1 or i>n. We often write w=w1​w2​⋯wn​ or w[1..n] — but n may be 1, or even 0.
  • Substring: y is a substring of w if w=xyz for some strings x and z. The substring from position i to position j is w[i..j]:=ε if j<i, and w[i..j]:=wi​⋅w[i+1..j] otherwise.
  • Prefix, suffix: p is a prefix of w if w=px for some string x (equivalently, p=w[1..j] for some 0≤j≤n); s is a suffix of w if w=xs for some string x (equivalently, s=w[i..n] for some 1≤i≤n+1).
  • Subsequence: a string obtained from w by deleting zero or more symbols, anywhere. Recursively, z is a subsequence of w if and only if z=ε; or w=ax and z is a subsequence of x; or w=ax, z=ay, and y is a subsequence of x.
  • Proper: a proper substring, prefix, suffix or subsequence of w is one that is not w itself.

The recursive definition of subsequence is “delete” spelled out symbol by symbol: the first symbol of w is either deleted (second case) or kept as the first symbol of z (third case).

Every substring is a subsequence, but not conversely: METAL is a subsequence of MEATBALL but not a substring of it, and 00 is a subsequence of 0110 but not a substring. (“Contiguous substring” says the same thing twice: substrings are always contiguous.)

How many? A string of length n has exactly n+1 prefixes and n+1 suffixes (counting ε and w itself), at most n(n+1)/2 distinct non-empty substrings, and at most 2n distinct subsequences (counting ε and w). The bounds are reached when all n symbols are different. At the other extreme, 0000 has just five distinct substrings — ε, 0, 00, 000, 0000 — and these are also its only subsequences.

Substring or subsequence?

“Contains 00” means as a substring unless the problem says subsequence, and the two languages are different: 0110 contains 00 as a subsequence but not as a substring. Read the problem statement twice — a correct answer to the wrong question is a wrong answer.

More recursive functions

The chapter’s exercises define many more functions by the same recursion and ask for proofs of their properties. The standard ones:

Here [a=b] is 1 if a=b and 0 otherwise. For example, #(0,0110)=2, (001)R=100, (001)c=110, and (01)3=010101. Each of the following facts is a short induction on the argument that the definitions recurse on:

  • #(a,x∙y)=#(a,x)+#(a,y), and ∣w∣=∑a∈Σ​#(a,w);
  • ∣wR∣=∣w∣, #(a,wR)=#(a,w), (w∙x)R=xR∙wR, and (wR)R=w;
  • wm∙wn=wm+n, ∣wn∣=n∣w∣, #(a,wn)=n⋅#(a,w), and (wR)n=(wn)R;
  • (x∙y)c=xc∙yc, (wc)c=w, #(1,w)=#(0,wc), and (wR)c=(wc)R;
  • cancellation: x∙z=y∙z implies x=y, and x∙y=x∙z implies y=z.

Model exam answer — (w∙x)R=xR∙wR for all strings w and x

Which variable? Both ∙ and R take strings apart from the front, and the front of w∙x is the front of w: induct on w and keep x fixed. What gets cited? The definitions of ∙ and R, Lemma 1.1 and Lemma 1.3.

Let w and x be arbitrary strings. Assume that (y∙x)R=xR∙yR for every string y with ∣y∣<∣w∣. There are two cases.

Case w=ε. By the definition of ∙, Lemma 1.1, and the definition of R,

(ε∙x)R=xR=xR∙ε=xR∙εR.

Case w=ay for some symbol a and string y. Then ∣y∣<∣w∣, so the induction hypothesis applies to y, and

(ay∙x)R​=(a⋅(y∙x))R=(y∙x)R∙a=(xR∙yR)∙a=xR∙(yR∙a)=xR∙(ay)R​​by definition of ∙by definition of Rby the induction hypothesisby Lemma 1.3by definition of R.​

In both cases, (w∙x)R=xR∙wR. ■

Once proved, a fact like this can be cited. The inductive case of (wR)R=w, for instance, becomes one line: ((ax)R)R=(xR∙a)R=aR∙(xR)R=a∙x=ax, by the definition of R, the fact above, then aR=a together with the induction hypothesis for x, and finally a∙x=a⋅x (§1.1).

Test the identity before you prove it

The order flips: (w∙x)R=xR∙wR, not wR∙xR — with w=0 and x=1, (w∙x)R is 10 while wR∙xR is 01. Trying a two- or three-symbol example takes ten seconds and exposes most false “facts”, on true/false questions too.

When the definition has more cases, so does the proof. The exercise function

swap(w):={wb⋅a⋅swap(x)​if ∣w∣≤1if w=abx​

exchanges adjacent pairs of symbols: swap(0110)=1001 and swap(011)=101. A proof that ∣swap(w)∣=∣w∣, or that swap(swap(w))=w, has three cases — w=ε, w=a, w=abx — and applies the hypothesis to x, which is two symbols shorter than w. The “every shorter string” hypothesis covers that for free.

How the induction problem is graded

Midterm-1-style exams devote a whole problem to proving properties of a newly defined recursive string function, like the ones in the table above. It is graded out of 10: 1 for starting from an arbitrary string; 2 for an explicitly stated, strong induction hypothesis (weak induction is discouraged); 2 for cases that cover every string; 1 for the base case(s); 2 for applying the hypothesis correctly — only to shorter strings, with the right values of the other arguments; 2 for the remaining details. Lemmas 1.1–1.3, and any result from lecture, the lecture notes, labs or homework solutions, may be cited without proof.

Summary

  • A string is ε or a pair a⋅x; Σ∗ is infinite, but every string in it is finite.
  • Functions on strings are defined by the cases ε and ax. Concatenation recurses on its left argument; it is associative but not commutative.
  • String induction: an arbitrary w, a hypothesis for every shorter string, cases that mirror the definition, and a justification on every line.
  • Lemmas 1.1–1.3: w∙ε=w, ∣w∙x∣=∣w∣+∣x∣, and associativity. Induct on the argument the definitions recurse on.
  • Other splits (w=a or w=u∙v; or w=xa) are fine. If the hypothesis is applied with different values of the other arguments, it must say “for all” of them.
  • Substrings are contiguous, subsequences need not be; prefixes and suffixes are special substrings; “proper” excludes w itself.
  • Reversal turns concatenation around: (w∙x)R=xR∙wR. Test any identity on a tiny example before proving it.

On the exams

Midterm 1 (Sep 28) covered induction on strings. Midterm-1-style exams (five problems in two hours) include one induction proof about a recursively defined string function, graded with the rubric above, and true/false items that test the definitions, such as ”(wx)R=wRxR for all strings w and x” (false) or “every subsequence of w is a substring of w” (false).
