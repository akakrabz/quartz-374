In one breath

An NFA may have several transitions — or none — for the same state and symbol, and may move without reading anything (ε-transitions); it accepts a string if some sequence of choices ends in an accepting state. NFAs are no more powerful than DFAs: a DFA can track the set of states the NFA might be in (the subset construction), at a cost of up to 2n states that is sometimes unavoidable. NFAs make Kleene’s theorem easy to prove: Thompson’s algorithm turns a regular expression into an NFA by gluing small gadgets with ε-transitions, and state elimination turns any NFA back into an expression. Above all, NFAs are the tool for proving that transformed languages are regular: start from a DFA for L and let an NFA guess whatever it cannot know. Reversal (Lemma 4.4) and half(L) (Lemma 4.5) are the models, and Midterm-1-style exams devote a whole problem to such constructions.

4.1 Nondeterministic state machines

A DFA has exactly one transition for each state and symbol. An NFA drops that rule: a state may have several transitions on the same symbol, or none at all. The book’s first example accepts the strings that contain 00 or 11:

On input 0110 the walk s0​s1​b1​c0​c ends in the accepting state c, so 0110 is accepted. It does not matter that other walks end elsewhere or get stuck — s0​a is stuck at once, because a has no transition on 1. In general, if the input contains 00, some walk waits in s until the first 0 of the pair and then moves to a and c; if it contains neither 00 nor 11, a walk that moves to a or b gets stuck on the next symbol (if there is one), and no walk reaches c.

Definition — NFA

A nondeterministic finite-state automaton is a tuple M=(Σ,Q,s,A,δ) exactly like a DFA, except that the transition function returns a set of states, possibly empty: δ:Q×Σ→2Q, where 2Q is the set of all subsets of Q. The extended transition function δ∗:Q×Σ∗→2Q collects the ends of all walks labeled w:

δ∗(q,w):=⎩⎨⎧​{q}r∈δ(q,a)⋃​δ∗(r,x)​if w=εif w=ax.​

M accepts w iff δ∗(s,w)∩A=∅ — iff some walk from s labeled w ends in an accepting state. Its language L(M) is the set of strings it accepts.

Every DFA is an NFA: replace δ(q,a) by the one-element set {δ(q,a)}. So NFAs accept every regular language; §4.5 shows that they accept nothing else.

Running an NFA by hand. Keep the set C of states the machine could be in. Start with C={s}; reading a replaces C by δ(C,a):=⋃q∈C​δ(q,a); accept iff the final set contains an accepting state. After reading w, C is exactly δ∗(s,w).

On the second symbol of 10010 the walk in b dies, because δ(b,0)=∅, while s starts a new one in a; the third symbol takes that walk to c, where it stays. So 10010 is accepted. On 0101 no walk ever reaches c, because a walk that moves to a or b dies on the next symbol; the final set {s,b} contains no accepting state, so 0101 is rejected.

"Some walk", not "every walk" — and swapping does not complement

  • An NFA accepts w if at least one walk labeled w ends in A. It rejects w only if every walk fails, by ending outside A or by getting stuck; a string with no complete walk at all is rejected.
  • Exchanging the accepting and non-accepting states does not complement an NFA. With A={s,a,b} the machine above accepts every string, because the walk that never leaves s always exists. To complement an NFA, convert it to a DFA first (§4.5), then swap.

4.2 Intuition

Nobody builds a nondeterministic machine; nondeterminism is a compact way to describe a search. Three equivalent pictures help:

Three ways to think about nondeterminism

  • Clairvoyance. At every choice the machine magically picks a transition that leads to acceptance, if there is one. It still cannot accept a string that has no accepting walk.
  • Parallel threads. Every choice spawns a new thread; a thread with no transition dies; the machine accepts if some thread is in an accepting state when the input ends. The set C of §4.1 is the set of states of the living threads.
  • Proofs. A prover who knows the input supplies the choices, and the machine only verifies them: every step must be a legal transition, and the last state must be accepting. w∈L(M) iff a valid proof for w exists.

The third picture can be made formal. A proof for w=a1​a2​⋯an​ is the sequence of states ω=r1​r2​⋯rn​ that an accepting walk visits after s, and checking it is a job for a DFA over the alphabet Σ×Q of pairs. This DFA starts in s, accepts in A, and from state q the pair (a,r) leads to r if r∈δ(q,a) and to a dump state otherwise. Then M accepts w iff some ω∈Q∣w∣ makes this DFA accept (a1​,r1​)(a2​,r2​)⋯(an​,rn​). For the machine of §4.1, the proof for 0110 is ω=sbcc.

Guessing is the design tool of this chapter. The NFA of §4.1 guesses where the pair begins; the machines of §4.9 guess a state of another machine, or the symbols of a string they never see. Wrong guesses cost nothing, because only one thread has to succeed. The same three pictures return for Turing machines in §9.5.

4.3 Epsilon-transitions

An ε-transition pε​q lets the machine move from p to q without reading anything. Now δ:Q×(Σ∪{ε})→2Q, and M accepts w iff there is a walk s=q0​a1​​q1​a2​​⋯aℓ​​qℓ​ with qℓ​∈A, every ai​∈Σ∪{ε}, and a1​a2​⋯aℓ​=w: the ε‘s vanish from the label.

Definition — ε-reach, and δ∗ with ε-transitions

The ε-reach of a state q is the set of states reachable from q by zero or more ε-transitions: it contains q, and with every state r it contains every state of δ(r,ε). For a set S of states, ε-reach(S):=⋃q∈S​ε-reach(q). The extended transition function takes the ε-reach before every symbol and at the end:

δ∗(p,w):=⎩⎨⎧​ε-reach(p)r∈ε-reach(p)⋃​ q∈δ(r,a)⋃​δ∗(q,x)​if w=εif w=ax,​

and M accepts w iff δ∗(s,w)∩A=∅.

By hand: start with C=ε-reach({s}) instead of {s}, and after each symbol a replace C by ε-reach(δ(C,a)).

Example. The NFA E has states p (start), q and r (accepting); it loops on 0 at p, on 1 at q and on 0 at r, and has the ε-transitions pε​qε​r. It reads some 0s, then some 1s, then some 0s: L(E)=0∗1∗0∗, the strings whose 1s form a single block. Here ε-reach(p)={p,q,r} needs two steps. On 0010 the sets are {p,q,r}, {p,q,r}, {p,q,r}, {q,r}, {r} — accepted; on 01010 the set becomes ∅ at the second 1.

Removing ε-transitions. An ε-move can always be merged into the symbol transition that follows it, or into the acceptance test if no symbol follows — without new states.

Definition — ε-removal

Given an NFA M=(Σ,Q,s,A,δ) with ε-transitions, let M′=(Σ,Q,s,A′,δ′), with the same states and start state and

A′:={q∈Q∣ε-reach(q)∩A=∅},δ′(q,a):=r∈ε-reach(q)⋃​δ(r,a).

Then M′ has no ε-transitions, and L(M′)=L(M).

Why ε-removal is correct (click to expand)

Write (δ′)∗ for the extended transition function of M′, which has no ε-moves. Claim: ε-reach((δ′)∗(q,w))=δ∗(q,w) for every state q and string w. Induct on w. For w=ε both sides are ε-reach(q). For w=ax,

ε-reach((δ′)∗(q,ax))​=q′∈δ′(q,a)⋃​ε-reach((δ′)∗(q′,x))=r∈ε-reach(q)⋃​ q′∈δ(r,a)⋃​δ∗(q′,x)=δ∗(q,ax),​

by the definition of (δ′)∗, then the induction hypothesis for x together with the definition of δ′, then the definition of δ∗. Finally, (δ′)∗(s,w) contains a state of A′ iff its ε-reach meets A, iff δ∗(s,w) meets A. ■

Where ε-moves bite

  • ε-reach(q) always contains q itself, and it follows chains of ε-moves (p→q→r above), not just single edges.
  • ε-moves count before the first symbol and after the last one: whether M accepts ε depends on ε-reach(s), not on s alone.
  • After removing the ε-moves, every state whose ε-reach meets A must become accepting. Keeping A′=A={r} above would reject ε, 1 and 01.

4.4 Kleene’s theorem

Theorem 4.1 (Kleene)

For every regular expression R there is a DFA M with L(M)=L(R), and for every DFA M there is a regular expression R with L(R)=L(M). Consequently a language is regular if and only if some DFA accepts it — equivalently, some NFA, with or without ε-transitions.

This is Theorem 3.3 of §3.7. With NFAs as the intermediate model, every step of the proof is a short construction, and following the arrows turns any description into any other:

Each arrow is labeled with its section and the size of its result: the subset construction can need 2n states, and state elimination can produce expressions of length Θ(4n). The ε-removal step is optional, because the subset construction and state elimination both handle ε-transitions directly.

So “regular”, “automatic” (Chapter 3) and “accepted by an NFA” are three names for one class, and each description is good at something different: expressions at union, concatenation and star; DFAs at complement, intersection (products) and lower bounds (fooling sets); NFAs at guessing — and at the transformations of §4.9.

4.5 NFA to DFA: the subset construction

Running an NFA by hand was already deterministic: the set of current states is determined by the input read so far, and there are only finitely many sets. Make those sets the states of a DFA.

Definition — subset construction

For an NFA M=(Σ,Q,s,A,δ), possibly with ε-transitions, define the DFA M′=(Σ,Q′,s′,A′,δ′) by

Q′:=2Q,s′:={s},A′:={S⊆Q∣ε-reach(S)∩A=∅}, δ′(S,a):=p∈S⋃​ r∈ε-reach(p)⋃​δ(r,a).

Without ε-transitions this is simply A′={S∣S∩A=∅} and δ′(S,a)=⋃p∈S​δ(p,a).

A DFA state is the set S itself; its ε-reach is computed when needed, for the acceptance test and for the transitions.

Why it works (click to expand)

Claim: ε-reach((δ′)∗(S,w))=⋃p∈S​δ∗(p,w) for every set S and string w. Induct on w. For w=ε both sides are ε-reach(S). For w=ax, (δ′)∗(S,ax)=(δ′)∗(δ′(S,a),x); the induction hypothesis turns the ε-reach of this set into ⋃q∈δ′(S,a)​δ∗(q,x), which equals ⋃p∈S​δ∗(p,ax) by the definitions of δ′ and δ∗. With S={s}: M′ accepts w iff ε-reach((δ′)∗({s},w)) meets A, iff δ∗(s,w) meets A, iff M accepts w. ■

Most of the 2∣Q∣ subsets can never occur, so build only the ones that can, breadth-first from {s}:

Recipe — the incremental subset construction

Keep a table with one row per DFA state and the columns S, ε-reach(S), accepting?, and δ′(S,a) for each symbol a.

  1. Start with the single row {s}.
  2. In each row, first compute ε-reach(S). The row is accepting iff that set contains an accepting state. For each symbol a, δ′(S,a) collects δ(r,a) for every r∈ε-reach(S).
  3. Every set that appears in a transition column for the first time gets a row of its own — ∅ included; it is the dump state.
  4. Stop when every set in the transition columns has a row. The rows are the states of the DFA.

The classic slips: deciding acceptance from S instead of its ε-reach, reading a symbol before sliding along the ε-moves, dropping the row ∅, and listing all 2∣Q∣ subsets instead of the reachable ones.

The price: exponentially many states

A DFA may need exponentially more states than an NFA for the same language — the subset construction is not just being careless.

Exponential blow-up

For k≥1 let Lk​:=(0+1)∗1(0+1)k−1 be the set of binary strings whose kth symbol from the end is 1, where (0+1)k−1 abbreviates k−1 copies of (0+1). Some NFA with k+1 states accepts Lk​, but every DFA for Lk​ has at least 2k states.

The NFA has states 0,1,…,k: state 0 (the start) loops on both symbols and also moves to 1 on a 1 — the guess “this 1 is the kth symbol from the end” — each state i with 1≤i<k moves to i+1 on either symbol, and only k accepts. A DFA cannot guess; it has to remember the last k symbols.

Proof of the lower bound, by a fooling set (click to expand)

Let F:={0,1}k, the 2k strings of length k. Let x=y be arbitrary strings in F, let i be a position with xi​=yi​, and let z:=0i−1. The string xz has length k+i−1, so its kth symbol from the end is its ith symbol, xi​; likewise the kth symbol from the end of yz is yi​. Exactly one of xi​, yi​ is 1, so exactly one of xz, yz is in Lk​. Hence F is a fooling set of size 2k, and every DFA for Lk​ has at least 2k states (§3.8). ■

On this NFA the subset construction builds exactly 2k states — every subset that contains state 0 — and the lower bound says that none of them is redundant. Most NFAs are much kinder: §4.6 turns a 14-state NFA into 5 DFA states, not 214.

4.6 Regular expression to NFA: Thompson’s algorithm

Lemma 4.2

Every regular language is accepted by an NFA — in fact by an NFA with exactly one accepting state, which is different from its start state.

The proof is an algorithm due to Ken Thompson (1968): build the NFA bottom-up along the expression tree (§2.5), with a two-state gadget for each leaf and ε-transitions as glue. The single accepting state t=s is what makes the gluing easy, and it is exactly what the induction has to maintain.

Proof (click to expand)

Let R be a regular expression for the language, and assume that every proper subexpression of R has an NFA with one accepting state, different from its start state. There are six cases.

  • R=∅: two states s=t, no transitions. R=ε: sε​t. R=a for a symbol a: sa​t. (A longer string is a concatenation of symbols.)
  • R=S+T: new states s and t, and the ε-transitions s→sS​, s→sT​, tS​→t, tT​→t.
  • R=ST: the ε-transition tS​→sT​; the start state is sS​ and the accepting state is tT​.
  • R=S∗: new states s and t, and the ε-transitions s→sS​, tS​→t, s→t (zero copies of S) and t→s (one more copy).

The old start and accepting states lose their roles, and new edges enter each old machine only at its start state and leave it only from its accepting state. So the walks from the new s to the new t spell exactly the strings of L(R). ■

Many textbooks close the loop of S∗ from tS​ back to sS​ instead of from t back to s; that version is just as correct, and it changes only some of the ε-reaches in the table below. Either way the algorithm creates two states for each leaf, each + and each ∗, and none for a concatenation: the NFA has at most twice as many states as the expression has symbols and operators.

The three accepting states all mean “an even number of 1s so far” and the two others “odd”, so minimization merges them into the familiar two-state parity DFA. Thompson’s NFAs are full of redundant states and ε-transitions, but the waste costs little, because the incremental construction only ever creates reachable sets.

Do not "optimize" the gadgets

Two tempting shortcuts, both from the book’s exercises, break the construction:

  • Identifying tS​ with sT​ for ST, instead of joining them with an ε-edge: for 0∗1∗ the result accepts 10, because the loop of 1∗ now returns to a state from which the loop of 0∗ can be re-entered.
  • Building S∗ without new states, by adding ε-edges sS​→tS​ and tS​→sS​: for (0∗1)∗ the result accepts 0, by jumping from the middle of S straight to its accepting state.

Both break because the shortcut lets a walk leave a gadget in the middle, or come back into it. A larger correct NFA loses nothing.

4.8 NFA to regular expression: state elimination

The last arrow turns an automaton back into an expression. Label the edges with regular expressions, then remove the states one at a time, recording on the remaining edges every detour through the removed state. The book credits this formulation to McNaughton and Yamada (1960) — C. Y. Lee published a similar one the same year — as a modern version of Kleene’s own 1951 argument; you may also meet it as Han and Wood’s algorithm.

Definition — expression automaton

An expression automaton has a start state s with no incoming edges, a target state t=s with no outgoing edges, and a regular expression R(p→q) on every edge from a state p=t to a state q=s; a missing edge has label ∅. It accepts w iff w=x1​x2​⋯xℓ​ for some walk s=q0​→q1​→⋯→qℓ​=t with xi​∈L(R(qi−1​→qi​)) for every i.

Every NFA becomes an expression automaton: add a new start state with an ε-edge to the old one, a new target with an ε-edge from each old accepting state, and merge parallel edges with +. (An old start state without incoming edges can serve as s itself.)

Lemma 4.3

Every expression automaton accepts a regular language.

Proof (click to expand)

Induction on the number of states. If Q={s,t}, the automaton accepts L(R(s→t)). Otherwise choose any state q∈/{s,t}, delete it, and for every remaining pair p=t, r=s — including p=r — set

R′(p→r):=R(p→r)+R(p→q)R(q→q)∗R(q→r).

An accepting walk of the old automaton visits q in maximal runs. Each run is entered from some p=q and left to some r=q (neither s nor t is q), and the part of the input it reads matches R(p→q)R(q→q)∗R(q→r); replacing every run by the new edge p→r gives an accepting walk of the new automaton for the same string. Conversely, every new edge expands back into the old edge or a run through q. So the language does not change, the automaton has one state fewer, and the induction hypothesis applies. ■

Recipe — state elimination by hand

  1. Add the new s and t (unless the old ones already qualify), and merge parallel edges with +.
  2. Eliminate the other states one at a time, in any order. For each eliminated q, list its predecessors and successors and update every pair p, r — including p=r, which changes a loop.
  3. Simplify only with identities you can name: ∅ terms vanish, εR=R, ∅∗=ε.
  4. The answer is R(s→t). Test ε and a few short strings before you trust it.

Mind the empty string

The 3-state DFA that starts in its accepting state 0 reads ε as the number 0, like the mod-5 machine of §3.1, and accepts it. Eliminating its states (after adding a new start state) gives expressions with ε: the order 2,0,1 yields 0∗+0∗1(01∗0+10∗1)∗10∗ — note 0∗ where the book has 00∗ — and the order 2,1,0 the compact (0+1(01∗0)∗1)∗. Both describe ε plus the language above — and a missing or extra ε is the typical one-mistake deduction on a graded expression.

How big? With n states, state elimination performs O(n3) operations on expressions, but each new label combines four old ones, so the expressions can grow by a factor of about 4 per eliminated state: length Θ(4n) in the worst case. The order matters in practice: on the 4-state DFA above, the six elimination orders give equivalent expressions with between 12 and 31 occurrences of symbols (the order used above gives 14).

4.9 Regular language transformations

The most exam-relevant use of NFAs is proving that a language built from L is regular whenever L is. There are two ways:

  • transform a regular expression for L by structural recursion, as for reversal in §2.7; or
  • transform a DFA for L into an NFA for the new language.

The asymmetry is deliberate: a DFA is the easiest input to reason about (exactly one state per prefix), and an NFA with ε-transitions is the most flexible output. Two kinds of transformed language come up, for a function f from strings to strings:

  • Strings whose transform is in L, {w∣f(w)∈L}: the new machine reads w and simulates M on f(w) — often deterministically.
  • Transforms of strings in L, {f(w)∣w∈L}: the new machine reads y, guesses a string w with f(w)=y, and simulates M on it. Nondeterministic choices guess symbols that f changed; ε-transitions guess symbols that f deleted.

Template — regular language transformation

Let M=(Σ,Q,s,A,δ) be a DFA that accepts L.
We construct an NFA M′=(Σ,Q′,s′,A′,δ′) with ε-transitions that accepts [the new language].
In English: M′ remembers [each component of its state, and what it means], guesses [what, and when], and accepts when […].
Formally: Q′= […], s′= […], A′= […],
δ′(q′,a)= […] for every state q′ and every symbol a,
δ′(q′,ε)= […] for every state q′ (write ∅ where there are none).
Why: M′ can be in state […] after reading x if and only if […]; so it accepts exactly [the new language].

Reversal

Lemma 4.4

If L is regular, then so is LR:={wR∣w∈L}.

Proof 1, by regular expressions. Reverse an expression recursively: rev(∅):=∅, rev(w):=wR for a string w, rev(S+T):=rev(S)+rev(T), rev(ST):=rev(T)rev(S) — the order swaps — and rev(S∗):=rev(S)∗. A structural induction, using (xy)R=yRxR from Chapter 1, shows L(rev(R))=L(R)R; §2.7 works an example.

Proof 2, by automata. Run M backwards:

Proof 2 of Lemma 4.4 — the reversed NFA

Let M=(Σ,Q,s,A,δ) be a DFA for L. Define the NFA MR=(Σ, Q∪{sR}, sR, {s}, δR), where sR is a new state and

δR(sR,ε):=A,δR(q,a):={p∈Q∣δ(p,a)=q}for q∈Q, a∈Σ,

with no other transitions: sR has no symbol transitions, and no other state has ε-transitions.

In English: MR follows the edges of M backwards. With its first move it guesses the accepting state in which M‘s walk on w ends; reading wR, it retraces that walk from the end; and it accepts iff it arrives at M‘s start state s.

Why: MR has a walk from q to p labeled xR iff δ∗(p,x)=q (induction on x). So MR accepts y iff y=wR for some w that leads M from s into A — iff y∈LR. ■

Reversing the edges of a DFA does not give a DFA: a state can have several incoming edges with the same symbol, or none. That is one reason the target of a transformation is an NFA.

Half of a language

Lemma 4.5

If L is regular, then so is half(L):={w∣ww∈L}.

This is the first kind of transformation, with f(w)=ww, but simulating M on ww while reading w only once needs a trick. M processes the second copy of w starting from the state h:=δ∗(s,w) that it reaches in the middle — and h is known only at the end. So guess h at the start, run both halves side by side, and check the guess at the end.

Proof of Lemma 4.5 — the model to copy

Let M=(Σ,Q,s,A,δ) be a DFA that accepts L. We construct an NFA M′=(Σ,Q′,s′,A′,δ′) with ε-transitions that accepts half(L).

In English: M′ first guesses the middle state h. After that it remembers a triple (p,h,q): p is the state of a copy of M started at s, which plays the first copy of w; h is the guess, which never changes; and q is the state of a copy of M started at h, which plays the second copy. M′ accepts iff the first copy has arrived exactly at h — the guess was right — and the second copy is in an accepting state.

Formally: s′ is a new state, and

Q′δ′(s′,ε)δ′((p,h,q),a)A′​:={s′}∪(Q×Q×Q),:={(s,h,h)∣h∈Q},:={(δ(p,a),h,δ(q,a))}for all p,h,q∈Q, a∈Σ,:={(h,h,q)∣h∈Q, q∈A},​

with no other transitions.

Why: after reading w, M′ can be in (p,h,q) iff p=δ∗(s,w) and q=δ∗(h,w). So M′ accepts w iff δ∗(s,w)=h and δ∗(h,w)∈A for some h — iff δ∗(s,ww)=δ∗(δ∗(s,w),w)∈A, iff ww∈L. ■

M′ has ∣Q∣3+1 states, and its only nondeterministic move is the first one.

Two more examples

Strings whose double is in L — a DFA suffices

Let double(w) repeat every symbol of w: double(ε):=ε and double(ax):=aa⋅double(x), so double(011)=001111. For a DFA M=(Σ,Q,s,A,δ) that accepts L, the DFA M′=(Σ,Q,s,A,δ′) with

δ′(q,a):=δ(δ(q,a),a)

accepts {w∣double(w)∈L}. In English: M′ feeds every input symbol to M twice, so its state after reading w is δ∗(s,double(w)), and it accepts exactly when double(w)∈L. No guessing, no new states.

For the binary multiples of 3 (δ(q,a)=(2q+a)mod3, start and accepting state 0), δ′(q,a)=(4q+3a)mod3=q: M′ never moves, so it accepts every string. Indeed double(w), read in binary, is 3 times the number that w denotes in base 4.

Transforms of strings in L — guess the preimage

Let ones(w):=1∣w∣ replace every symbol of a binary string by 1. For a DFA M=(Σ,Q,s,A,δ) that accepts L, the NFA M′=(Σ,Q,s,A,δ′) with

δ′(q,1):={δ(q,0), δ(q,1)},δ′(q,0):=∅,

and no ε-transitions accepts ones(L):={ones(w)∣w∈L}. In English: reading 1n, M′ guesses a string w of length n, one symbol per input 1, and runs M on it: M′ can be in state q after reading 1i iff some string of length i leads M from s to q. So it accepts 1n iff some string of length n is in L. An input 0 kills every thread, because no ones(w) contains a 0.

Edge cases: ones maps ∅, {ε}, 1∗ and Σ∗ to ∅, {ε}, 1∗ and 1∗; and (01)∗ to (11)∗.

Where transformation proofs go wrong

  • One example is not a proof. Start from an arbitrary DFA M for L; a machine for one particular language proves nothing about the others.
  • Mixing up the two kinds. {w∣double(w)∈L} and {double(w)∣w∈L} are different languages that need different machines: for L=Σ∗ the first is Σ∗ and the second is (00+11)∗.
  • Not every transformation preserves regularity. half(L) is always regular, but {ww∣w∈L} need not be: for L=0∗1 it is {0n10n1∣n≥0}, and 0∗ is an infinite fooling set for it — the suffix 10i1 separates 0i from 0j.
  • Unstated cases. Define δ′ for every state and symbol, and say exactly which ε-transitions exist; “ε-moves where needed” describes no machine.

How a transformation is graded

Midterm-1-style exams devote a whole problem, in two parts, to transformations. Each construction is graded out of 10: 2 for a formal, complete description of M′ built from an arbitrary DFA M — say whether M′ is a DFA or an NFA, and list its ε-transitions; 2 for an English explanation of what its states and its accepting states mean; 6 for correctness — 1 for the states, 1 for the start state, 1 for the accepting states and 3 for the transitions. Graders try the edge cases L=∅, {ε}, 1∗ and Σ∗, so run your construction on them before handing it in.

Summary

  • An NFA’s transition function returns a set of states (possibly empty), and ε-transitions move without reading; the NFA accepts iff some walk labeled w ends in A. Run it by tracking the set of current states, closed under ε-moves.
  • Three pictures of nondeterminism: clairvoyant guessing, parallel threads, and verifying a proof supplied by a prover.
  • ε-removal keeps the states: A′ is the set of states whose ε-reach meets A, and δ′(q,a)=δ(ε-reach(q),a).
  • Subset construction: DFA states are sets S, accepting iff ε-reach(S) meets A; build only the reachable sets, ∅ included. Up to 2n states — and “the kth symbol from the end is 1” really needs 2k.
  • Thompson’s algorithm glues two-state gadgets with ε-edges (one accepting state = start, Lemma 4.2). State elimination applies R(p→r)+R(p→q)R(q→q)∗R(q→r) to every pair, p=r included (Lemma 4.3); expressions can reach length Θ(4n).
  • Kleene’s theorem (Theorem 4.1): regular expressions, DFAs and NFAs describe the same languages. Every conversion works; none promises a small result.
  • Transformations: from an arbitrary DFA for L, build an NFA — simulate M on f(w) for {w∣f(w)∈L}, guess a preimage for {f(w)∣w∈L}. Reversal (Lemma 4.4) and half(L) (Lemma 4.5) are the models.

On the exams

Midterm 1 (Sep 28) covered NFAs and regular language transformations; the final (Dec 11) covers everything again. On Midterm-1-style exams this chapter appears as the two-part transformation problem, graded as in §4.9; as a tool in the DFA problem, where an NFA handed in instead of the requested DFA earns at most half credit — determinize it (§4.5) or design the DFA directly; in the regular-expression half of that problem, where state elimination (§4.8) is a reliable fallback; and in true/false items such as “every n-state NFA has an equivalent DFA with at most 2n states” (true), “swapping the accepting states of an NFA accepts the complement” (false, §4.1), “if L is regular, so is {ww∣w∈L}” (false: L=0∗1), and “if L is regular, so is {w∣ww∈L}” (true, Lemma 4.5).
