Worked problem — State elimination by hand

Problem · the regular-expression half of a Midterm-1-style DFA problem, done mechanically · uses §4.8 · concepts: state-elimination, regular-expressions, dfa

Problem

Let L={w∈{0,1}∗∣#(0,w)−#(1,w) is divisible by 3}. For example, 0011, 000 and 1100 are in L; 0 and 011 are not.

(a) Give a DFA for L with mnemonic state names (no proof required).

(b) Turn your DFA into a regular expression for L by state elimination. Show the expression automaton after every elimination.

(c) Sanity-check the expression.

(d) Eliminate the states in a different order. What changes?

(a) A DFA that tracks the difference mod 3

Idea. Reading left to right, an algorithm only needs the difference #(0)−#(1) of the prefix read so far, and only modulo 3: a 0 adds 1 and a 1 subtracts 1. A variable with three values is a DFA with three states.

Answer (a)

States q0​,q1​,q2​, where qi​ means “the prefix read so far has #(0)−#(1)≡i(mod3)”. Start state q0​; accepting states {q0​}; δ(qi​,0)=q(i+1)mod3​ and δ(qi​,1)=q(i−1)mod3​:

statemeaning: difference so far01
→ q0​ *≡0q1​q2​
q1​≡1q2​q0​
q2​≡2, that is, ≡−1q0​q1​

Check. 0011 visits q0​,q1​,q2​,q1​,q0​ and is accepted; 011 ends in q2​ and is rejected; the empty string stays in q0​ and is accepted (0−0=0).

(b) State elimination

The tool is state elimination (§4.8): give the automaton a start state s with no incoming edges and a target t with no outgoing edges, then remove the other states one at a time. Removing q replaces, for every remaining pair p,r — including p=r —

R(p→r)byR(p→r)+R(p→q)R(q→q)∗R(q→r),

where a missing edge is ∅. When only s and t are left, R(s→t) is the answer. We eliminate q1​, then q2​, then q0​: the state adjacent to s and t goes last (part (d) shows why).

Step 0 — new start and target. q0​ cannot serve as either: it has incoming edges, and it is accepting with outgoing edges. Add sε​q0​ and q0​ε​t.

Skipping step 0

If you eliminate q1​ and q2​ in the DFA itself, you are left with q0​ and a loop label R, and nothing tells you whether the answer is R, R∗ or R+. With s and t in place, the last elimination produces the right star by itself. Add them whenever the start state has incoming edges or the accepting state is not a single state without outgoing edges — that is, almost always.

Step 1 — eliminate q1​. There is no loop at q1​, so R(q1​→q1​)∗=∅∗=ε. The predecessors of q1​ are q0​ (label 0) and q2​ (label 1); its successors are q2​ (label 0) and q0​ (label 1). That gives four pairs:

edge p→rold labeldetour p→q1​→rnew label
q0​→q0​∅0⋅101
q0​→q2​10⋅01+00
q2​→q0​01⋅10+11
q2​→q2​∅1⋅010

Step 2 — eliminate q2​. Its only predecessor and only successor is q0​, and it now has the loop 10, which gets starred:

R(q0​→q0​)=01+(1+00)(10)∗(0+11).

Step 3 — eliminate q0​. Its predecessor is s and its successor is t, both by ε, and its loop is the label just computed:

R(s→t)=ε(01+(1+00)(10)∗(0+11))∗ε.

Answer (b)

L=L((01+(1+00)(10)∗(0+11))∗)

Where elimination steps go wrong

  • Forgetting p=r. Two of the four new labels in step 1 are loops: the round trips q0​→q1​→q0​ and q2​→q1​→q2​. Drop them and the same steps produce ((1+00)(0+11))∗, which misses 01, 0101, 010101, …
  • Dropping the old label. R(q0​→q2​) becomes 1+00, not 00: the direct edge stays.
  • Starring the wrong loop. In step 2 the loop of the state being removed (q2​) is starred; the loop at q0​ gets its star only when q0​ itself goes, in step 3.
  • “Simplifying” without a rule. Rewrite only with identities you can name (Lemmas 2.1–2.2). A longer correct expression earns full credit; a shorter wrong one does not.

(c) Sanity check

Three quick tests, each of which catches a different kind of slip.

  1. The empty string. The expression is a star, so it matches ε; and ε∈L. ✓
  2. Everything it matches is in L. The block 01 has difference 0. In the block (1+00)(10)∗(0+11), the first piece contributes −1 or +2, both ≡−1; each 10 contributes 0; the last piece contributes +1 or −2, both ≡+1. So every block has difference ≡0, and so does every concatenation of blocks. ✓
  3. Short strings of L are matched. Length 2: 01 (one block 01) and 10 =1⋅(10)0⋅0. Length 3: only 000 =00⋅0 and 111 =1⋅11 are in L. Length 4: the strings of L are the six with two 0s and two 1s, and all six match: 0011 =00⋅11, 0101 =01⋅01, 0110 =01⋅10, 1001 =10⋅01, 1010 =10⋅10, 1100 =1⋅10⋅0. ✓

Test 3 is what catches the forgotten loops of the trap above: ((1+00)(0+11))∗ passes tests 1 and 2, but not 01.

Why the answer looks like this

Each block is a walk that leaves q0​ and returns to it for the first time: either through q1​ (reading 01), or into q2​ (by 1, or by 00 via q1​), any number of round trips q2​→q1​→q2​ (each reading 10), and back to q0​ (by 0, or by 11 via q1​). A string is in L exactly when its walk ends in q0​, that is, when it splits into first returns — hence the outer star.

(d) A different order

Now eliminate q0​ first, then q1​, then q2​. q0​ is the only state joined to s and t, so removing it hands edges from s and to t to both remaining states, and every later step must carry them along.

Step 1 — eliminate q0​ (predecessors s, q1​, q2​; successors q1​, q2​, t; no loop):

to q1​to q2​to t
from s01ε
from q1​100+111
from q2​1+00010

Step 2 — eliminate q1​ (loop 10): R(s→q2​)=1+0(10)∗(0+11),  R(s→t)=ε+0(10)∗1,  R(q2​→q2​)=01+(1+00)(10)∗(0+11),  R(q2​→t)=0+(1+00)(10)∗1.

Step 3 — eliminate q2​:

R(s→t)=​ε+0(10)∗1+(1+0(10)∗(0+11))(01+(1+00)(10)∗(0+11))∗(0+(1+00)(10)∗1).​

This expression is exactly equivalent to the answer of (b) — every order is correct — but it has 28 symbol occurrences instead of 10. It spells out separately the walks that end in q0​ without ever visiting q2​ (ε+0(10)∗1), the walk up to the first visit to q2​, the round trips from q2​, and the walk after the last visit to q2​. Over all six orders, the expression has 10 symbols when q0​ goes last, 22 when it goes second, and 28 when it goes first; the order q2​,q1​,q0​ gives the mirror image (10+(0+11)(01)∗(1+00))∗ (swap the roles of 0 and 1).

Choosing an elimination order

Eliminate first the states with the fewest edges, and keep the states joined to s and t for last. No order is wrong, but sizes differ, and in the worst case they grow by about a factor of 4 per elimination (Θ(4n) in all).

How this would be graded

Midterm-1-style exams ask for a DFA and a regular expression for the same language (no proof needed); state elimination is one reliable way to get the expression from your DFA when it does not come by inspection. The expression is graded 2 for syntax and 8 for correctness, with exam deductions doubled: 2 for one mistake (often a missing or extra ε), 4 for a few wrong strings, and all 8 if infinitely many strings are wrong — which is what a forgotten loop or a dropped term usually costs. Hence the sanity checks. Homework answers also need a one-sentence explanation of each piece, like the intuition box above.
