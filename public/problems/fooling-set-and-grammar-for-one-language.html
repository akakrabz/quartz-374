Worked problem — A fooling set and a grammar for one language

Problem · style of the Midterm 1 non-regularity-and-grammar problem · uses §3.8, §5.3 · concepts: fooling-sets, context-free-grammars

Problem

Let L={0i1j0k∣i,j,k≥0 and j=i+k}: a run of 0s, a run of 1s and a run of 0s (each possibly empty), with exactly as many 1s as 0s in total. For example, ε, 01, 10, 0110 and 001110 are in L; 0, 1, 0101 and 1001 are not.

(a) Prove that L is not regular.

(b) Give a context-free grammar for L. Describe the language of each nonterminal, and argue briefly that the grammar generates exactly L.

What any algorithm for L must remember. Reading 0000…, a machine for L has to remember how many 0s it has seen: after 0m the continuation 1m must be accepted, and 1n for n=m must not. An unbounded count is exactly what a fooling set exploits. A grammar, on the other hand, can match symbols from the outside in, and every string of L splits into two such nested pieces:

0i1j0k=0i1i+k0k=(0i1i)(1k0k).

(a) Not regular: a fooling set

Idea. Take F=0∗: different numbers of leading 0s need different numbers of 1s. For x=0m, the suffix z=1m completes x to a string of L (with k=0). To show that yz is not in L, do not fight with the decomposition of yz into runs; use a property that every string of L has: equally many 0s and 1s, since #(0,w)=i+k=j=#(1,w).

Proof of (a) — model answer

Let F=0∗={0n∣n≥0}. Let x and y be arbitrary distinct strings in F. Then x=0m and y=0n for some integers m,n≥0 with m=n. Let z=1m.

  • xz=0m1m∈L: take i=m, j=m and k=0; then j=i+k.
  • yz=0n1m∈/L: every string 0i1j0k of L contains i+k 0s and j=i+k 1s, equally many; but yz contains n 0s and m=n 1s.

So z distinguishes x and y, and F is a fooling set for L. Because F is infinite, L is not regular. ■

Where (a) loses points

  • Ruling out one decomposition instead of all of them. ”yz=0n1m00 and m=n+0” checks just one way to write yz as 0i1j0k. When m=0, yz=0n splits as 0i100k in n+1 ways, and the proof must show that none of them has j=i+k (each has j=0<n=i+k). The counting argument handles every decomposition at once.
  • Reusing the statement’s letters. Writing x=0i and y=0j collides with the i and j in the definition of L, and "j=i+k" then means two different things. Pick fresh names.
  • One example pair. “0 and 00 are distinguished by 1” proves nothing about the other pairs; the argument must work for arbitrary m=n.
  • A finite set. {ε,0,00} is a fooling set, but it only proves that every DFA for L has at least 3 states — and earns no credit as a non-regularity proof.

An alternative: closure. If L were regular, then L∩0∗1∗ would be regular too (Corollary 3.4). A string of L with no 0 after a 1 has k=0 (or it has no 1 at all, and then i=k=0), so L∩0∗1∗={0n1n∣n≥0}, which is not regular by Lemma 3.6. That proof is correct too — but when the exam asks for a fooling set, give the fooling set.

(b) A grammar: two nested halves side by side

Idea. Split the run of 1s: the first i 1s match the leading 0s, and the last k match the trailing 0s. Each half is a nested language like the book’s {0n1n}, and one start rule puts the halves next to each other.

Answer (b)

S→ABA→0A1∣εB→1B0∣ε
  • A generates {0i1i∣i≥0}: some 0s followed by equally many 1s.
  • B generates {1k0k∣k≥0}: some 1s followed by equally many 0s.
  • S generates L: a string generated by A followed by a string generated by B.

Why the grammar is right.

  • The nonterminals. A is the book’s grammar C→ε∣0C1 under another name, so L(A)={0i1i∣i≥0} by Lemmas 5.1 and 5.2. B is the same grammar with 0 and 1 exchanged, so the same two lemmas (with the symbols exchanged) give L(B)={1k0k∣k≥0}.
  • L(S)⊆L. Every derivation from S begins S⇝AB, and from then on A and B derive their parts independently; so L(S)=L(A)∙L(B). Each such string is 0i1i∙1k0k=0i1i+k0k, which is in L with j=i+k.
  • L⊆L(S). If w=0i1j0k∈L, then j=i+k, so w=0i1i∙1k0k, and S⇝AB⇝∗0i1iB⇝∗0i1i1k0k=w.

Check. ε: both halves empty. 10: A⇝ε and B⇝1B0⇝10. 0110 = 01·10. And 0101 cannot be generated: every generated string has the shape 0∗1∗0∗.

Where (b) loses points

  • Nesting instead of concatenating. S→0S1∣T, T→1T0∣ε puts the 1k0k block inside the 0i⋯1i block, so it generates 0i1k0k1i: it produces 0101 ∈/L and misses 0110 ∈L. Wrong on infinitely many strings, so no correctness credit.
  • Losing the empty halves. With A→0A1∣01 and B→1B0∣10 neither half can be empty, so the grammar misses ε, 01, 10 and every 0n1n — again infinitely many strings.
  • A grammar for a bigger language. S→0S1∣1S0∣SS∣ε generates every string with equally many 0s and 1s, including 0101 and 1001. Equal counts are necessary for L, not sufficient: the shape 0∗1∗0∗ matters too.
  • Descriptions that are not self-contained. ”B does the second part” says nothing. ”B generates exactly the strings 1k0k with k≥0” does.

How the problem is graded

Midterm-1-style exams pair a non-regularity proof with a grammar for the same language. The fooling-set proof (out of 10): 4 for an explicit infinite set that really is a fooling set — a finite set earns nothing — and 6 for the argument with arbitrary distinct x and y: 2 for an explicit suffix z, 2 for showing that one of xz, yz is in L, and 2 for showing that the other is not. The grammar (out of 10): 2 for syntax and 8 for correctness, with the same deductions as for regular expressions (one mistake, a few wrong strings, or all 8 points for infinitely many wrong strings). Homework also requires a self-contained description of every nonterminal’s language; ambiguity is not penalized. See how exams are graded.
