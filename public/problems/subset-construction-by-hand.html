Worked problem — The subset construction by hand

Worked problem — The subset construction by hand

Problem · an NFA-to-DFA conversion by hand, the computation behind many Midterm 1 answers · uses §4.3, §4.5 · concepts: subset-construction, nfa, dfa-minimization

Problem

The NFA N has alphabet {0,1}, states s,p,q,t, start state s, accepting states {t}, and the transitions below (empty cells are ∅).

δ01ε
→ s{s}{p}
p{q}{t}
q{p}
t *{t}

(a) Describe L(N).

(b) Convert N to a DFA with the incremental subset construction. Show the full table: for each DFA state S, its ε-reach, whether it is accepting, and its transitions.

(c) Is the resulting DFA minimal? If not, find the number of states of a minimal DFA, and prove your answer.

(a) The language: three phases

Idea. The ε-transitions only go forward, s→p→t, so every run of N has three phases and never returns to an earlier one: in s it reads 0s; around the cycle p0​q1​p it reads blocks 01; in t it reads 1s.

Answer (a)

L(N)=0∗(01)∗1∗={0i(01)j1k∣i,j,k≥0}. For example 0011 =0⋅01⋅1, ε, 0 and 1 are in L(N); 010 and 10 are not.

(b) The incremental subset construction

The recipe, as in the book. A DFA state is a set S of NFA states, and everything is computed from its ε-reach, the set of states reachable from S by ε-transitions alone:

  • the start state is {s} itself (its ε-reach goes in its own column);
  • S is accepting iff ε-reach(S) contains an accepting state of N;
  • δ′(S,a)=⋃r∈ε-reach(S)​δ(r,a): slide along ε-moves first, then read a.

Start a table with the row {s}. Whenever a set appears in a transition column that has no row yet, give it the next row. Stop when every set in the transition columns has a row. Here the ε-reaches of single states are ε-reach(s)={s,p,t}, ε-reach(p)={p,t}, ε-reach(q)={q} and ε-reach(t)={t}.

Row 1, in full. ε-reach({s})={s,p,t}, which contains t, so {s} is accepting. Then

δ′({s},0)δ′({s},1)​=δ(s,0)∪δ(p,0)∪δ(t,0)={s}∪{q}∪∅={s,q},=δ(s,1)∪δ(p,1)∪δ(t,1)=∅∪∅∪{t}={t}.​

Both sets are new, so they become rows 2 and 3, in that order. The other rows are computed the same way:

The DFA has these 7 states (of the 24=16 subsets of {s,p,q,t}, only these are reachable), start state {s}, the five accepting states marked “yes”, and the transitions in the last two columns. ∅ is a genuine state — the dump state, reached when no thread of N survives.

Check. On 0011: {s}0​{s,q}0​{s,q}1​{p,t}1​{t}, accept. On 010: {s}→{s,q}→{p,t}→{q}, reject — halfway through a block. On 10: {s}→{t}→∅, reject — after a trailing 1, a 0 kills every thread.

Where subset constructions go wrong

  • Accepting S only when S itself contains an accepting state. Acceptance looks at ε-reach(S). Without it, rows 1, 2 and 7 become non-accepting, and the DFA rejects ε, 0, 00 and 0101 — all in L(N).
  • Reading before sliding. δ′({s},1) is not δ(s,1)=∅: the NFA can slide s→p→t by ε-moves and then read the 1. Forgetting the ε-reach in the transitions sends 1 and 01 to ∅.
  • Dropping the ∅ row. The empty set is reachable (on 10), and a DFA needs a transition from every state on every symbol. Keep the row, or say explicitly that missing transitions go to a dump state.
  • Tabulating all 16 subsets. Only reachable sets get rows; the incremental construction never creates the other nine. (A table of all 16 still describes a correct DFA, with nine unreachable states, but it is not what was asked and it wastes exam time.)

A second convention. Some textbooks name each DFA state by its ε-reach instead: the start state is ε-reach({s})={s,p,t} and δ′(S,a)=ε-reach(⋃r∈S​δ(r,a)). That also gives a correct DFA — here a 6-state one, because rows 4 and 7 have the same ε-reach and become a single state. On this site, as in the book, the table keeps S and its ε-reach in separate columns.

(c) Not minimal: two twin rows

Idea. Look for rows that agree in everything. Rows 4 and 7, {p,t} and {p}, are both accepting, both go to {q} on 0, and both go to {t} on 1. States with identical rows are equivalent: both accept or both reject the empty suffix, and after any first symbol the two are in the same state. They agree because they have the same ε-reach {p,t}, and the construction computes everything from the ε-reach. In terms of the language: 01 reaches {p,t} and 0101 reaches {p}, and both mean “a block 01 has just been completed; more blocks or the trailing 1s may follow”.

Merging the twins leaves 6 states. To show that no DFA for L(N) has fewer, take one string reaching each of them:

F={ε, 0, 1, 01, 10, 010},which reach {s}, {s,q}, {t}, {p,t}, ∅, {q}.

For each pair, the table gives a distinguishing suffix z — exactly one of xz and yz is in L(N) (row x, column y):

For instance, 101 separates ε from 0: 0101 ∈L(N) but 101 ∈/L(N). And 1 separates the dump state from {q}: 0101 ∈L(N) but 101 ∈/L(N). Every ε entry pairs a string of L(N) with one outside it.

Answer (c)

Not minimal: {p} and {p,t} are equivalent. Merging them gives a 6-state DFA, and the 6-element fooling set F shows that 6 is the minimum.

How this is graded

Midterm-1-style exams have no separate subset-construction problem; the construction is a tool — for turning an NFA you designed into the DFA a problem asks for (an NFA where a DFA was asked earns half credit), and for true/false items about state counts. A DFA built this way is graded like any DFA: a complete description (start state, accepting states, every transition, including those into ∅), correctness, and mnemonic names. A set like {s,q} is a meaningful name only if you have said what each NFA state means — “still among the leading 0s, or halfway through a block”. See how exams are graded.
