Worked problem — Undecidability by reduction and by Rice's theorem

Worked problem — Undecidability by reduction and by Rice's theorem

Problem

Let AtLeastTwo:={⟨M⟩∣M accepts at least two different strings}, that is, the encodings of Turing machines M with ∣Accept(M)∣≥2.

(a) Prove that AtLeastTwo is undecidable by a reduction from Accept={⟨M,w⟩∣M accepts w}.

(b) Prove it again with Rice’s theorem.

(c) Show that Quick374:={⟨M⟩∣M halts on input ε within 374 steps} is decidable, and explain why Rice’s theorem does not apply to it.

(d) Is AtLeastTwo acceptable? Is its complement?

Machines have input alphabet Σ={0,1}, and “halts” means “reaches accept or reject”.

(a) A reduction from Accept

Idea. Given ⟨M,w⟩, build a machine M′ whose language is huge — all of Σ∗, so certainly two strings — if M accepts w, and empty otherwise. M′ ignores its own input: the only thing that decides what it does is whether M accepts w. This is the standard shape of a reduction (§7.9).

Proof of (a) — model answer

Suppose for the sake of argument that some Turing machine DecideAtLeastTwo decides AtLeastTwo.

Consider the following machine DecideAccept. Given ⟨M,w⟩, it writes the encoding ⟨M′⟩ of the machine

M′(x): erase x; write w; run M on w; if M accepts, accept; if M rejects, reject,

then runs DecideAtLeastTwo on ⟨M′⟩ and returns its answer.

⇒ Suppose M accepts w. Whatever the input x is, M′ erases it and then does exactly what M does on w, so M′ accepts every input: Accept(M′)=Σ∗, which contains the two different strings 0 and 1. So ⟨M′⟩∈AtLeastTwo, DecideAtLeastTwo accepts ⟨M′⟩, and DecideAccept accepts ⟨M,w⟩.

⇐ Suppose M does not accept w: it rejects w or diverges on w. In the first case M′ rejects every input; in the second, M′ diverges on every input. Either way Accept(M′)=∅, which has fewer than two strings. So ⟨M′⟩∈/AtLeastTwo, DecideAtLeastTwo rejects ⟨M′⟩, and DecideAccept rejects ⟨M,w⟩.

In both cases DecideAccept answers correctly, and it always halts: writing ⟨M′⟩ is a finite edit of ⟨M⟩ and w, and DecideAtLeastTwo always halts. So DecideAccept decides Accept, which is impossible, because Accept is undecidable. Therefore DecideAtLeastTwo does not exist: AtLeastTwo is undecidable. ■

Four machines, four names: the hypothetical decider DecideAtLeastTwo; the decider we build from it, DecideAccept; its input machine M; and M′, whose encoding DecideAccept writes down but never runs.

Where reductions go wrong

  • An M′ that does not land in the property. ”M′(x): run M on x” gives Accept(M′)=Accept(M), which has nothing to do with w. ”M′(x): if x=ε, run M on w; otherwise reject” gives Accept(M′)⊆{ε} — never two strings — so the ⇒ direction fails. In the yes-case the language must have the property; Σ∗ has two strings to spare.
  • Running M′ (or M). DecideAccept only writes ⟨M′⟩. If it ran M on w itself, it could run forever, and a decider must halt.
  • Forgetting divergence. “Does not accept” includes running forever. Then M′ runs forever on every input, so Accept(M′)=∅ — do not write ”M′ rejects”.
  • The wrong direction. Deciding AtLeastTwo with the help of a decider for Accept proves nothing.

(b) The same result by Rice’s theorem

Proof of (b) — model answer

Let L:={L⊆Σ∗∣∣L∣≥2}, the set of languages with at least two strings. Then AtLeastTwo=AcceptIn(L)={⟨M⟩∣Accept(M)∈L}: whether ⟨M⟩ belongs depends only on the language Accept(M).

  • Y:=MAccept​, with δ(start,a)=(accept,a,+1) for every a∈Γ. It accepts every input, so Accept(Y)=Σ∗∈L.
  • N:=MReject​, with δ(start,a)=(reject,a,+1) for every a∈Γ. It accepts nothing, so Accept(N)=∅∈/L.

By Rice’s theorem, AcceptIn(L)=AtLeastTwo is undecidable. ■

The property speaks about the strings M accepts, so the AcceptIn form of the theorem is the right one. For ”M rejects at least two strings” you would use the rejection version, RejectIn(L), and describe the witnesses by their Reject languages: then MReject​ (Reject=Σ∗) is the Y and MAccept​ (Reject=∅) the N. Part (a) is the proof of Rice’s theorem specialized to this property, with Y=MAccept​ — except that it reduces from Accept, where the book’s proof uses Halt.

Rice traps

  • Vague witnesses. “A machine that accepts two strings” is not a witness; give the machine (its transitions, or an unmistakable description) and its language.
  • Swapped witnesses. Y’s language must have the property (≥2 strings) and N‘s must not. Both are judged by Accept(⋅) alone — not by how fast or whether the machines halt.
  • Applying Rice to behavior — the next part.

(c) A look-alike that is decidable

Proof of (c)

A decider. Given ⟨M⟩, simulate M on the empty input for at most 374 steps, using the universal machine with a step counter. If M accepts or rejects within those steps, accept; if it is still running after 374 steps, reject. Only 374 steps of M are ever simulated, so this machine halts on every input, and it accepts exactly the encodings in Quick374. (A crash within the 374 steps is detected the same way; count it as halting or not, as your definition of “halts” says.)

Why Rice’s theorem does not apply. Quick374 is not AcceptIn(L) for any set of languages L, because membership does not depend on the language alone. MAccept​ halts on ε after one step, so ⟨MAccept​⟩∈Quick374. The machine Mslow​ that walks right for 400 steps and then accepts has the same language, Σ∗, but halts on ε only after 400 steps, so ⟨Mslow​⟩∈/Quick374. Two machines with the same language, one in and one out: this is a property of machines, not of languages.

Rice’s theorem is silent about such behavioral properties: some are decidable, like this one and the book’s ThisIsSparta, and some are not (§7.13). What makes this one decidable is the step bound: the question is about a finite piece of one computation.

An even closer look-alike. ”M accepts at least two different strings, each within 374 steps” is decidable too. In 374 steps the head reads only cells 0,…,373, so whether M accepts x within 374 steps depends only on the first 374 symbols of x. Simulate M for 374 steps on every string of length at most 374. If some string of length exactly 374 is accepted within those steps, so are all of its infinitely many extensions: answer yes. Otherwise no longer string is accepted within 374 steps either, and you just count. That is 2375−1 simulations — absurd, but finite, and decidability asks for nothing more. The step bound, not the “two strings”, is what changes the answer.

(d) Acceptable, but its complement is not

Answer (d)

AtLeastTwo is acceptable: dovetail — for t=1,2,3,…, run M for t steps on each of the first t strings in shortlex order, and accept as soon as two different strings have been accepted. Its complement is not acceptable: AtLeastTwo is acceptable but undecidable, so by Lemma 5 its complement cannot be acceptable as well.

Why dovetail? Running M on ε, 0, 1, 00, … one after the other fails when M runs forever on one of them: a machine that diverges on ε but accepts every other string is in AtLeastTwo, yet the one-at-a-time search never gets past ε. Dovetailing gives every string an ever-growing time budget, so if M accepts x=y, some round runs both long enough. (The same idea simulates nondeterminism in §9.4.) If M accepts at most one string, the acceptor runs forever — allowed for an acceptor.

The same answer from §7.12. “At least two strings” is monotone (a superset still has two strings), compact (any two of the strings form a finite subset with the property) and finitely acceptable (count the strings in a finite list), as the Rice–McNaughton–Myhill–Shapiro theorem requires of an acceptable AcceptIn(L). The complementary property “at most one string” is not monotone — ∅ has it, Σ∗⊇∅ does not — so Lemma 17 gives unacceptability again. (The complement also contains every string that encodes no machine; those form a decidable set and change nothing.)

How these proofs are graded

Chapter 7 is tested on the final exam only. A reduction is graded out of 10: 4 for the reduction itself — a correct description of the new decider and of M′, in the right direction — 3 for the yes-direction and 3 for the no-direction, which must cover both rejecting and diverging. A proof by Rice’s theorem: 4 for a machine whose language has the property, 4 for one whose language does not, and 2 for the details, including stating the property as a set of languages and using the right variant of the theorem.
