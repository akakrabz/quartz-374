Worked problem — Proving what a grammar generates

Worked problem — Proving what a grammar generates

Problem · a grammar-correctness proof: two inductions, graded with the induction rubric · uses §5.3 · concepts: context-free-grammars, induction-on-strings, parse-trees-and-ambiguity

Problem

Let G be the grammar with one nonterminal S and the rules

S→0S11∣0S∣ε,

and let L={0m12n∣m≥n≥0}: a block of 0s followed by an even number of 1s, with at least one 0 for every two 1s.

(a) Prove that L⊆L(G).

(b) Prove that L(G)⊆L.

(c) Is G ambiguous? Does that matter for (a) and (b)?

Test the claim before proving it. The strings of length at most 6 that G generates are ε, 0, 00, 011, 000, 0000, 0011, 00000, 00011, 000000, 000011, 001111 — exactly the strings 0m12n with m≥n of that length. 0111 (an odd number of 1s) and 01111 (too few 0s) are correctly missing. Reading the rules explains why: S→0S11 adds one 0 and two 1s, and S→0S adds an extra 0, always on the outside.

(a) Everything in L is generated

Idea. Build a derivation from the outside in. If the string has 1s, peel off a 0 in front and 11 at the back (rule S→0S11); if it has none, peel off one 0 (rule S→0S). Induct on m, the number of 0s.

Proof of (a) — model answer

Claim. S⇝∗0m12n for all integers m≥n≥0.

Let m and n be arbitrary integers with m≥n≥0, and assume that S⇝∗0m′12n′ for all integers m′≥n′≥0 with m′<m. There are three cases.

Case m=0. Then n=0, because 0≤n≤m. So 0m12n=ε, and S⇝ε by the rule S→ε.

Case m≥1 and n=0. The pair (m−1,0) satisfies m−1≥0 and m−1<m, so the induction hypothesis gives S⇝∗0m−1. Hence

S⇝0S⇝∗0∙0m−1=0m12n,

by the rule S→0S and then the hypothesis, applied inside the context 0  ​.

Case m≥1 and n≥1. The pair (m−1,n−1) satisfies m−1≥n−1≥0 and m−1<m, so the hypothesis gives S⇝∗0m−112n−2. Hence

S⇝0S11⇝∗0∙0m−112n−2∙11=0m12n,

by the rule S→0S11 and then the hypothesis inside the context 0  ​11.

The three cases cover every pair with m≥n≥0, and in each case S⇝∗0m12n. ■

For m=3, n=1 the proof builds S⇝0S11⇝00S11⇝000S11⇝00011: one 0…11 layer, then the two extra 0s, then S→ε.

Where (a) loses points

  • Missing the case n=0. The rule S→0S11 cannot produce a string without 1s, so 0m needs its own case and its own rule. Inducting on n alone has the same hole: its base case n=0 is the whole family 0m, which needs a second induction.
  • Using the hypothesis without checking that it applies. Say why (m−1,n−1) is a legal pair: m−1≥n−1 because m≥n, n−1≥0 because n≥1, and m−1<m.
  • Only describing the derivation. “Use S→0S11 n times, then S→0S m−n times, then S→ε” is the right idea; the induction is what turns it into a proof.

(b) Everything generated is in L

Idea. Take an arbitrary derivation apart at its first step — one case per rule. The string derived from the inner S is shorter than w, so the hypothesis applies to it.

Proof of (b) — model answer

Claim. Every string w∈L(G) equals 0m12n for some integers m≥n≥0.

Let w be an arbitrary string in L(G), and fix a derivation S⇝∗w. Assume that every string x∈L(G) with ∣x∣<∣w∣ is in L. The derivation starts with one of the three rules for S.

Case S→ε. Then the derivation is S⇝ε, so w=ε=0010, with m=n=0.

Case S→0S11. Then the derivation is S⇝0S11⇝∗w. The 0 and the 11 are terminals, so every later step rewrites the middle S or a symbol derived from it; hence w=0x11 for some string x with S⇝∗x. So x∈L(G) and ∣x∣=∣w∣−3<∣w∣, and the induction hypothesis gives x=0m12n for some m≥n≥0. Then w=0m+112(n+1) with m+1≥n+1≥0, so w∈L.

Case S→0S. In the same way w=0x with S⇝∗x and ∣x∣=∣w∣−1<∣w∣, so x=0m12n with m≥n≥0 by the hypothesis. Then w=0m+112n with m+1>m≥n, so w∈L.

In all three cases, w∈L. ■

Where the ε-rule needs care. Two details make this induction work, and both concern ε.

  • The inner string may be empty. 011 has the derivation S⇝0S11⇝011, with x=ε. The hypothesis covers x=ε because it is about every shorter string, ε included; the base case is not a separate assumption but the case S→ε of the same argument.
  • The inner string is strictly shorter — because every rule except S→ε puts at least one terminal next to S. This is exactly what fails for a rule whose right side has only nonterminals: with S→SS, one of the two halves can derive ε, the other is then all of w, and the hypothesis says nothing about it. For such grammars, fix a shortest derivation (a half that derives ε could then be cut out) or induct on the length of the derivation — see Careful with those epsilons and Lemma 5.3. (Here, adding S→SS would also break the claim itself: S⇝SS⇝∗011∙0=0110∈/L.)

Where (b) loses points

  • Reading the rule off the string. ”w ends in 11, so its derivation starts with S→0S11” is false: 0011 also has the derivation S⇝0S⇝00S11⇝0011. Split into cases on the derivation you fixed, not on what w looks like.
  • Weak induction. A hypothesis only for strings of length ∣w∣−1 does not cover the case S→0S11, where x is three symbols shorter. Assume the claim for every shorter string.
  • Not justifying ∣x∣<∣w∣ — true here, but it is the reason the hypothesis applies, so say it; fatal in grammars with rules like S→SS.
  • Checking only half of the definition of L. Membership of w=0m+112(n+1) needs both the shape (0s, then an even number of 1s) and the inequality m+1≥n+1.

(c) Ambiguity

G is ambiguous: 0011 has two parse trees. In one, the root uses S→0S11 and the inner S uses S→0S and then S→ε; in the other, the root uses S→0S and the inner S uses S→0S11 and then S→ε. In general 0m12n has exactly (nm​) parse trees: a parse tree is a chain of m rules that each add one 0, followed by S→ε, and any n of those m rules can be the ones that also add 11.

It does not matter. L(G) is a set of strings; (a) needs some derivation of each string of L, and (b) works for any derivation of each generated string. The grading rubrics do not penalize ambiguity either. If you want an unambiguous grammar anyway, produce the extra 0s first:

S→0S∣TT→0T11∣ε.

Here T generates {0n12n∣n≥0} and S puts the m−n extra 0s in front; every string of L has exactly one parse tree.

How a proof like this is graded

Midterm-1-style exams ask for a grammar without a proof (homework also asks for a description of each nonterminal). A correctness proof like this one consists of two inductions, each graded with the standard induction rubric, out of 10: 1 for starting from an arbitrary object (an arbitrary pair m≥n≥0; an arbitrary string with a fixed derivation), 2 for an explicitly stated strong induction hypothesis, 2 for cases that cover everything (three in each direction here), 1 for the base case, 2 for using the hypothesis correctly — only on legal, smaller objects, which is what the checks m−1≥n−1 and ∣x∣<∣w∣ are for — and 2 for the remaining details. “Clearly” draws scrutiny.
