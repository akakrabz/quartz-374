Problem

For every binary string w, define

sort(w):=⎩⎨⎧​ε0⋅sort(x)sort(x)∙1​if w=εif w=0xif w=1x​

for every string x. For example, sort(0110)=sort(1010)=0011. You may use Lemmas 1.1–1.3 without proof.

(a) Prove that ∣sort(w)∣=∣w∣ for every binary string w.

(b) Prove that sort(sort(w))=sort(w) for every binary string w.

Unfold the definition before proving anything. On a short string:

sort(101)=sort(01)∙1=(0⋅sort(1))∙1=(0⋅(sort(ε)∙1))∙1=(0⋅1)∙1=011.

A 0 at the front stays in front (second case); a 1 at the front is taken off and re-attached at the very end, after the rest has been sorted (third case). So sort(w) is w with every 0 moved before every 1, sort(w)=0#(0,w)1#(1,w), and both claims are believable. The job is to prove them from the definition. Notice the two different dots: the second case puts one symbol in front (⋅, a pair), the third glues two strings (∙, concatenation) — that difference is what each proof has to handle.

(a) Sorting keeps the length

Idea. The definition has three cases, so the proof has three cases. The cases w=ε and w=0x unfold with the definitions alone. The case w=1x ends in a concatenation, and the definition of length peels the first symbol of a string, not the last — so it needs Lemma 1.2, ∣y∙z∣=∣y∣+∣z∣.

Proof of (a) — model answer

Let w be an arbitrary binary string. Assume that ∣sort(x)∣=∣x∣ for every binary string x with ∣x∣<∣w∣. There are three cases.

Case w=ε. sort(ε)=ε by definition, so ∣sort(w)∣=∣ε∣=∣w∣.

Case w=0x for some string x. Then ∣x∣=∣w∣−1<∣w∣, so the induction hypothesis applies to x, and

∣sort(0x)∣​=∣0⋅sort(x)∣=1+∣sort(x)∣=1+∣x∣=∣0x∣​​by definition of sortby definition of ∣⋅∣by the induction hypothesisby definition of ∣⋅∣.​

Case w=1x for some string x. Again ∣x∣<∣w∣, and

∣sort(1x)∣​=∣sort(x)∙1∣=∣sort(x)∣+∣1∣=∣x∣+1=∣1x∣​​by definition of sortby Lemma 1.2by the induction hypothesis, and ∣1∣=1+∣ε∣=1by definition of ∣⋅∣.​

The three cases cover every binary string, and in each case ∣sort(w)∣=∣w∣. ■

Where (a) loses points

  • Two cases where the definition has three. Writing “case w=ax” is fine only if you then split on a=0 and a=1: sort does different things in the two cases, and an argument that treats them together proves nothing about either.
  • Treating ∙ like ⋅. ”∣sort(x)∙1∣=1+∣sort(x)∣ by definition of length” cites the wrong reason: the definition peels the first symbol, and this 1 is the last. Cite Lemma 1.2.
  • A vague hypothesis. “Assume it works for smaller strings” does not say what works. Write the claim out for every string shorter than w; that sentence is worth two rubric points by itself.

(b) Sorting twice changes nothing

Idea — and where the obvious attempt gets stuck. Try the same three cases. The first two go through (they are written out in the proof below). The third does not:

sort(sort(1x))=sort(sort(x)∙1)= ?

The definition of sort looks at the first symbol of its argument, and the first symbol of sort(x)∙1 is not the 1 just attached (unless x=ε). The induction hypothesis does not help either: it is about sort(sort(y)), not about sort(y∙1), and the string sort(x)∙1 has length ∣x∣+1=∣w∣ (by part (a) and Lemma 1.2), so it is not even shorter than w. What is missing is a fact about sorting a string that ends in 1 — a final 1 is already where sort would put it. State that fact as a lemma, prove it first, and the stuck case becomes one line.

Lemma

sort(y∙1)=sort(y)∙1 for every binary string y.

Proof of the lemma

Let y be an arbitrary binary string. Assume that sort(z∙1)=sort(z)∙1 for every binary string z with ∣z∣<∣y∣. There are three cases.

Case y=ε. By the definition of ∙, ε∙1=1=1⋅ε, so the third case of the definition of sort (with x=ε) gives sort(ε∙1)=sort(ε)∙1.

Case y=0z for some string z. Then ∣z∣<∣y∣, and

sort(0z∙1)​=sort(0⋅(z∙1))=0⋅sort(z∙1)=0⋅(sort(z)∙1)=(0⋅sort(z))∙1=sort(0z)∙1​​by definition of ∙by definition of sortby the induction hypothesisby definition of ∙by definition of sort.​

Case y=1z for some string z. Then ∣z∣<∣y∣, and

sort(1z∙1)​=sort(1⋅(z∙1))=sort(z∙1)∙1=(sort(z)∙1)∙1=sort(1z)∙1​​by definition of ∙by definition of sortby the induction hypothesisby definition of sort.​

In all three cases, sort(y∙1)=sort(y)∙1. ■

Proof of (b) — model answer

Let w be an arbitrary binary string. Assume that sort(sort(x))=sort(x) for every binary string x with ∣x∣<∣w∣. There are three cases.

Case w=ε. sort(sort(ε))=sort(ε), because sort(ε)=ε.

Case w=0x for some string x. Then ∣x∣<∣w∣, and

sort(sort(0x))​=sort(0⋅sort(x))=0⋅sort(sort(x))=0⋅sort(x)=sort(0x)​​by definition of sortby definition of sortby the induction hypothesisby definition of sort.​

Case w=1x for some string x. Then ∣x∣<∣w∣, and

sort(sort(1x))​=sort(sort(x)∙1)=sort(sort(x))∙1=sort(x)∙1=sort(1x)​​by definition of sortby the lemma, with y=sort(x)by the induction hypothesisby definition of sort.​

In all three cases, sort(sort(w))=sort(w). ■

Look at how the two tools split the work. The induction hypothesis is applied only to x, which is shorter than w. The lemma is applied with y=sort(x), to the string sort(x)∙1, which is exactly as long as w — but the lemma holds for every string y, so no length condition is needed.

Where (b) loses points

  • Applying the hypothesis to sort(x)∙1. That string is as long as w, so the hypothesis does not cover it — and even for a shorter string the hypothesis would only give sort(sort(y))=sort(y), which is not the step needed. This is the rubric’s “correct use of the hypothesis” item.
  • Asserting the lemma. “A 1 at the end is already in place” is the right intuition and not a proof. The lemma is not a result from lecture, so it needs its own induction; on an exam, prove it right before you use it.
  • Proving a false lemma. Test a lemma on a two-symbol example first. The look-alike sort(y∙0)=sort(y)∙0 fails at y=1: sort(10)=01, but sort(1)∙0=10. The same example refutes sort(x∙y)=sort(x)∙sort(y).

Another route, and why it is not shorter. You could first prove the closed form sort(w)=0#(0,w)1#(1,w) and then sort(0m1n)=0m1n. That is two inductions as well, plus facts about powers such as 1n∙1=1n+1. When a direct induction gets stuck, ask: what fact about the stuck expression would let me continue? The answer is usually a lemma as small as the one above — and it is usually proved by the same kind of induction.

How this problem is graded

Midterm-1-style exams devote a whole problem to a newly defined string function like sort. A proof is graded with the induction rubric, out of 10: 1 for starting from an arbitrary string; 2 for an explicitly stated strong hypothesis (weak induction is discouraged); 2 for cases that cover every string — three here, mirroring the definition; 1 for the base case; 2 for applying the hypothesis correctly — to x, never to sort(x)∙1; 2 for the remaining details, with every line justified by a definition, a lemma or the hypothesis. A lemma you need is part of your proof and is graded with it; results from lecture, the course notes, labs or homework solutions (Lemmas 1.1–1.3, for instance) may be cited without proof. “Clearly” draws scrutiny.
