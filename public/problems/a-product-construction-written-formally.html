Worked problem — A product construction, written formally

Problem · a DFA built by the product construction, as in a Midterm 1 DFA problem, plus a minimality question · uses §3.6, §3.10 · concepts: product-construction, fooling-sets, dfa-minimization

Problem

Let L be the set of binary strings w such that #(1,w), the number of 1s in w, is divisible by 3, and w does not contain the substring 00. For example, ε, 0, 111, 0111 and 10101 are in L; 1, 11, 00 and 1001 are not.

(a) Give DFAs M1​ and M2​, with mnemonic state names, for the two conditions separately.

(b) Describe a DFA for L formally by the product construction: its states, start state, transition function and accepting states.

(c) How many states does your product DFA have? Is it minimal? Find the number of states of a minimal DFA for L, and prove that no DFA with fewer states accepts L.

(a) The two factors

Idea. One condition is a counter, the other a pattern. M1​ remembers the number of 1s mod 3. M2​ remembers just enough about the end of the input to notice 00: whether the last symbol was a 0 — and, once 00 has appeared, that it has.

Answer (a)

M1​: Q1​={0,1,2}, s1​=0, A1​={0}, δ1​(r,0)=r and δ1​(r,1)=(r+1)mod3. State r means: the number of 1s read so far is ≡r(mod3).

M2​: Q2​={safe,zero,dead}, s2​=safe, A2​={safe,zero}, and

statemeaning: the input read so far …on 0on 1
→ safe *contains no 00, and is empty or ends in 1zerosafe
zero *contains no 00, and ends in 0deadsafe
deadcontains 00deaddead

Both factors are minimal on their own: three remainders need three states, and safe and zero differ on the suffix 0.

(b) The product, formally

Idea. Run both machines in parallel on the same input. A state of the product is a pair — one state of each machine — and by Lemma 3.1 the product is in state (δ1∗​(s1​,w),δ2∗​(s2​,w)) after reading w. For ∩, accept when both components accept.

Answer (b)

M=(Σ,Q,s,A,δ) with

Q=Q1​×Q2​={0,1,2}×{safe,zero,dead},s=(s1​,s2​)=(0,safe), δ((r,p),a)=(δ1​(r,a), δ2​(p,a)),A=A1​×A2​={(0,safe), (0,zero)}.

State (r,p) means: the number of 1s read so far is ≡r(mod3), and the input so far is in situation p of M2​. Written out:

stateon 0on 1
→ (0,safe) *(0,zero)(1,safe)
(1,safe)(1,zero)(2,safe)
(2,safe)(2,zero)(0,safe)
(0,zero) *(0,dead)(1,safe)
(1,zero)(1,dead)(2,safe)
(2,zero)(2,dead)(0,safe)
(0,dead)(0,dead)(1,dead)
(1,dead)(1,dead)(2,dead)
(2,dead)(2,dead)(0,dead)

Check. On 0111: (0,safe)0​(0,zero)1​(1,safe)1​(2,safe)1​(0,safe): accept. On 1001: (0,safe)→(1,safe)→(1,zero)→(1,dead)→(2,dead): reject — and once the second component is dead, no continuation can make the product accept.

Where product answers lose points

  • “Run M1​ and M2​ in parallel” and nothing else. The rubric wants each factor completely and then the product’s states, start state, transitions and accepting set. The accepting set is the only part that knows whether you mean ∩, ∪ or ∖.
  • The wrong accepting set. {(r,p)∣r=0 or p=dead} is the union: it accepts 1, which has no 00 but one 1.
  • Pairs without meanings. (2,zero) is a mnemonic name because each component is; names like q7​ are not.

(c) Nine states, but seven are enough

The count. The product has 3×3=9 states, and all 9 are reachable: 1r reaches (r,safe), 1r0 reaches (r,zero), and 1r00 reaches (r,dead). Reachable does not mean necessary, though. The three states (0,dead), (1,dead), (2,dead) are non-accepting and lead only to each other, so from none of them does any suffix lead to acceptance. No suffix distinguishes them: they are equivalent, and merging them into one dump state gives a 7-state DFA for L. Moore’s algorithm agrees — it marks every pair of states except the pairs of dead states.

The lower bound. Seven states are also necessary. Take one string for each state of the merged DFA,

F={ε, 1, 11, 0, 10, 110, 00},

which reach (0,safe), (1,safe), (2,safe), (0,zero), (1,zero), (2,zero) and the dump state. For a string x without 00, let tx​∈{0,1,2} be the number of 1s that x lacks to a multiple of 3: tx​=(3−#(1,x))mod3.

Proof that F is a fooling set

Let x and y be arbitrary distinct strings in F. Whether a suffix distinguishes x and y does not depend on which of the two is called x, so it suffices to consider three cases.

  • One of them is 00; call it y. Let z=1tx​. Then xz contains no 00 (x contains none, and appending 1s creates none), and its number of 1s is #(1,x)+tx​≡0(mod3), so xz∈L. But yz contains 00, so yz∈/L.
  • Neither is 00, and they contain different numbers of 1s. In F these numbers are among 0, 1, 2, so they differ mod 3. Let z=1tx​. As before, xz∈L. And yz contains no 00, but #(1,yz)=#(1,y)+tx​≡#(1,x)+tx​≡0(mod3), so yz∈/L.
  • Neither is 00, and they contain equally many 1s. These are the pairs ε/0, 1/10 and 11/110; call x the one that is empty or ends in 1, and y the one that ends in 0. Let z=01tx​. Then x0 contains no 00, because x does not end in 0, and neither does xz; its number of 1s, #(1,x)+tx​, is divisible by 3; so xz∈L. But in yz the last 0 of y is followed by the first 0 of z, so yz∈/L.

Every two distinct strings of F have a distinguishing suffix, so F is a fooling set of size 7, and every DFA for L has at least 7 states. ■

Answer (c)

The product DFA has 9 states, all reachable, but it is not minimal: (0,dead), (1,dead) and (2,dead) are equivalent. Merging them gives a 7-state DFA, and the 7-element fooling set F shows that 7 is the minimum.

Which operations let the dead states merge. After a 00, the fate of a string under ∩ no longer depends on its number of 1s: it is out of L whatever follows. That is why the three dead states merge. The same happens for every combination whose answer, once 00 has appeared, ignores the count — L2​∖L1​, or the complement of L1​∩L2​, also need only 7 states. For L1​∪L2​, L1​∖L2​ or L1​⊕L2​ the count still matters after a 00, and the 9-state product is already minimal. So the product of two minimal DFAs need not be minimal, and whether it is depends on the boolean operation: mn states always suffice, and sometimes fewer do.

How a product construction is graded

On a DFA problem, a product construction is graded with the DFA rubric (out of 10): 2 for an unambiguous, complete description — which for a product means each factor completely, then the product’s states, start state, transitions and accepting states; 6 for correctness; 2 for mnemonic state names (pairs named by their components, like (2,zero), qualify). Minimality is not required: the 9-state product earns full credit. Statements like “the product of two minimal DFAs is minimal” (false, as (c) shows) are natural true/false items.
