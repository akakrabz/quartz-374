Definition — expression automaton and the elimination rule

An expression automaton has a start state s with no incoming edges, a target state t=s with no outgoing edges, and a regular expression R(p→q) on each edge (a missing edge means ∅). It accepts w if w=x1​x2​⋯xℓ​ for some walk s=q0​→q1​→⋯→qℓ​=t with each xi​∈L(R(qi−1​→qi​)). To eliminate a state q∈/{s,t}, delete it and, for every pair of remaining states p, r (including p=r), set

R′(p→r):=R(p→r)+R(p→q)R(q→q)∗R(q→r).

When only s and t are left, R(s→t) is a regular expression for the language.

Why it works. A walk through q arrives from some p, loops at q zero or more times, and leaves to some r; the new term R(p→q)R(q→q)∗R(q→r) matches exactly those detours. So the language does not change and the automaton loses a state (Lemma 4.3, by induction on the number of states). Any NFA becomes an expression automaton by adding a new start and a new target with ε-edges, so every NFA language is regular — the last arrow of Kleene’s theorem. The book presents the method as McNaughton and Yamada’s (1960), a modern form of Kleene’s 1951 argument.

Recipe — automaton to regular expression by hand

  1. Add a new start s with an ε-edge to the old start, and a new target t with an ε-edge from every accepting state.
  2. Merge parallel edges with +; a missing edge is ∅.
  3. Eliminate the old states one at a time, in any order (states with few edges first keep things small): for every predecessor p and successor r of q, add R(p→q)R(q→q)∗R(q→r) to R(p→r).
  4. Simplify as you go: ∅ terms vanish, εR=R, and ∅∗=ε.
  5. The answer is R(s→t). Test ε and a few short strings.

Classic mistakes

  • Forgetting p=r: eliminating q also changes the self-loop of every state with edges both to and from q.
  • Dropping the old direct term R(p→r).
  • Skipping the new s and t when the old start state has incoming edges or there are several accepting states.
  • Writing R(q→q) instead of R(q→q)∗; with no loop at q the factor is ∅∗=ε.
  • Different orders give different (equivalent) answers, and the expressions grow fast: by roughly a factor of 4 per elimination in the worst case, to length Θ(4n) for n states.

Example. The 2-state DFA for “an even number of 1s” has states E (start, accepting) and O, a loop on 0 at each, and 1-edges between them. Add sε​E and Eε​t. Eliminating O (its only predecessor and successor is E) changes just the loop at E: R′(E→E)=0+10∗1. Eliminating E then leaves R(s→t)=ε(0+10∗1)∗ε=(0+10∗1)∗. The other order gives the longer, equivalent 0∗+0∗1(0+10∗1)∗10∗.

Where it appears. §4.8 (expression automata, Lemma 4.3, the multiples-of-3 example), §4.4 (Kleene’s theorem). Arden’s rule does the same job algebraically (§2.2), and the book derives its expression for the binary multiples of 3 (§2.3) by eliminating the states of the remainder-mod-3 DFA.
