NFA (nondeterministic finite automaton)

NFA (nondeterministic finite automaton)

Oct 13, 20263 min read

  • concept
  • regular
  • midterm-1

Definition — NFA (with ε-transitions)

An NFA M=(Σ,Q,s,A,δ) is like a DFA, except that δ:Q×(Σ∪{ε})→2Q returns a set of states, possibly empty. The ε-reach of q is the set of states reachable from q by zero or more ε-transitions. M accepts w iff some walk from s to an accepting state spells w; formally, iff δ∗(s,w)∩A=∅, where

δ∗(q,ε):=ε-reach(q),δ∗(q,ax):=r∈ε-reach(q)⋃​ p∈δ(r,a)⋃​δ∗(p,x).

Intuition. Three equivalent pictures: the machine guesses, always making a choice that leads to acceptance if one exists; it runs every choice as a parallel thread, a thread dying when it has no move, and accepts if any thread ends in A; or a prover supplies the choices and the machine only verifies them. Running an NFA by hand means tracking the set of current states — which is exactly the subset construction, so NFAs accept only regular languages. Their value is convenience: “guess where the pattern starts” and “glue two machines together with ε-edges” each take one line.

Removing ε-transitions needs no new states: keep Q and s, make q accepting iff ε-reach(q) meets A, and set δ′(q,a):=⋃r∈ε-reach(q)​δ(r,a).

Recipe — designing with nondeterminism

  1. Decide what to guess: where a pattern starts, which of several cases holds, a symbol you never get to read.
  2. Let wrong guesses die — only one thread has to accept.
  3. Use ε-transitions to make a guess without reading anything, or to glue machines together.
  4. Give δ(q,a) and δ(q,ε) as sets for every state, and say which transitions are ε-transitions.
  5. Check both directions: every string in the language has an accepting walk, and no other string does.

Classic mistakes

  • Swapping accepting states does not complement an NFA (example below). Determinize first.
  • An NFA accepts if some walk accepts, not all; a string on which every thread dies is rejected.
  • ε-moves count before the first symbol and after the last one: always take the ε-reach.
  • Where a DFA is asked for, an NFA earns half credit.

Example — strings that end in 01. States s, a, b: s loops on 0 and 1, s0​a, a1​b, and A={b}. The machine guesses which 0 is the second-to-last symbol. On 1001 the set of current states is {s},{s},{s,a},{s,a},{s,b}; the last set meets A, so it accepts. Making s and a accepting instead does not give the complement: that machine accepts 01, through the thread that stays in s.
