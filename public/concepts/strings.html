Definition — alphabet, string, Σ∗

An alphabet Σ is a finite set of symbols. A string over Σ is either the empty string ε, or a pair a⋅x (written ax) of a symbol a∈Σ and a string x. Σ∗ is the set of all strings over Σ: an infinite set (if Σ=∅), but every string in it is finite. Length and concatenation follow the same two cases:

∣w∣:={01+∣x∣​if w=εif w=ax​w∙z:={za⋅(x∙z)​if w=εif w=ax.​

Where it comes from. A string is built like a linked list: a first symbol and the rest. So every function on strings has a case for ε and a case for ax that recurses on the shorter string x, and every proof about strings is an induction on strings with the same two cases. Concatenation takes apart only its left argument, which is why proofs about w∙z induct on w. Lemmas 1.1–1.3 say w∙ε=w, ∣w∙x∣=∣w∣+∣x∣, and (w∙x)∙y=w∙(x∙y): concatenation is associative (so dots and parentheses are dropped) but not commutative.

A proper prefix, suffix, substring or subsequence is one other than w itself. Every substring is a subsequence, but not conversely.

Recipe — a newly defined string function (an exam problem type)

  1. Unfold it on two or three tiny inputs, case by case, exactly as the definition says (as in the example below).
  2. Test the claim you are asked to prove on those inputs; a false “identity” usually fails on a two-symbol string.
  3. Find the argument the definition takes apart — for ∙, the left one. The induction goes on that argument.
  4. Write the string-induction template, with a definition, the hypothesis, or one of Lemmas 1.1–1.3 cited on every line.

Classic mistakes

  • ε is a string; {ε} is a language with one string; ∅ is the empty language (languages).
  • Σ∗ contains no infinite strings: "000⋯" is not an element of {0}∗.
  • Reversal flips the order: (wx)R=xRwR, not wRxR (try w=0, x=1).
  • Substring is not subsequence: 0110 contains 00 as a subsequence but not as a substring. “Contains 00” means substring unless the problem says otherwise.
  • Formally the symbol a and the one-symbol string a⋅ε differ; a∙z=a⋅z uses both cases of the definition of ∙.

Example. Unfolding the definition, ba∙na=b⋅(a∙na)=b⋅(a⋅(ε∙na))=bana. The string w=banana has length 6, so it has 7 prefixes and 7 suffixes (counting ε and w). It has only 15 distinct non-empty substrings, not 6⋅7/2=21, because some repeat — ana starts at positions 2 and 4 — and only 40 distinct subsequences, not 26=64. bnn is a subsequence of banana but not a substring.

Where it appears. §1.1 (definition), §1.2 (length and concatenation), §1.5 (indices and pieces), more recursive functions (#(a,w), reversal, powers, complement). Later definitions recurse the same way, for example a DFA’s δ∗ (§3.2).

Practice. Induction on strings and recursive functions (9 problems) — for example 1.1 Unfold an accumulator (easy), 1.4 Reversal with an accumulator (medium), 1.7 Complementing every other symbol (hard).
